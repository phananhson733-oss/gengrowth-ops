## 二、流量来源结构

### brdecogroup.com（集团站）
- **自然搜索**：近12个月约37%，关键词100%非品牌词
- **直接流量**：约54%（说明品牌知名度靠业务积累，不靠SEO冷启动）
- **付费搜索**：<1%，有少量Google Ads投放
- **外链引荐**：约8%
- **社媒**：接近0（SimilarWeb无记录）
- 出站流量最大目的地：`api.whatsapp.com`（WhatsApp是主要询盘转化入口）

### brdecomy.com（马来西亚）
- 自然搜索为主，非品牌词100%
- 美国流量占比最高（68.88%），马来西亚本地仅15.68%——说明SEO内容面向英语全球买家，不只服务本地
- 社媒流量：可忽略不计
- Backlinks质量：Ref. Domains 305个（最多），但大多数backlinks是nofollow(14.71%)和主要的followed(85.29%)

### brdeco.jp（日本站）
- 自然搜索：60.08%（绝对主力）
- **外链引荐：35.03%**（异常高，来自metusce.com和grss.com，疑似PBN/垃圾外链）
- 直链：6.95%
- 有机词以日语sandwich panel相关词为主，全为非品牌词
- 竞品：daido.co.jp、yokoyama-techno.net（本地工业建材商）

### en.brdecosa.com（南非/中东站）
- 体量极小，SimilarWeb无法追踪（月访问<5000）
- Ahrefs有机流量仅34/月，Ref. Domains只有4个
- 主要收录美国(48.5%)、马来西亚(27.3%)流量，说明这个站本地化并不成功

## 三、SEO策略分析

### 内容策略
所有站点共同特征：
- **纯产品页SEO**：没有博客、没有内容营销，流量完全来自产品/品类页
- **关键词类型**：B2B制造业词（sandwich panel、EPS insulation board、cold room system、rock wool panel）
- **购买意图词为主**：Commercial + Transactional意图关键词合计占比最高（以brdecomy.com为例，Commercial 202词，Transactional 89词，Informational 250词）

### 核心有机词（跨站共性词）
- sandwich panel / sandwich wall panel
- aluminum composite panel
- EPS/PU/PIR insulation board
- cold room system / cold room panel
- rock wool insulation
- metal roofing / metal caving wall panel

### 付费搜索（仅brdecogroup.com有）
| 关键词 | 流量占比 |
|---|---|
| puff panel with easy for ce | 57.89% |
| sandwich panel（中文品牌词） | 10.51% |
| roof sandwich panel install... | 9.26% |
| sandwich panel | 5.26% |
| how to install sandwich pa... | 5.26% |

→ 付费词集中在安装指南和通用品类词，说明在测试转化路径

### 顶级流量页（以brdecogroup.com为例）
1. 首页（综合品牌+品类词）
2. aluminum composite panel产品页
3. aluminum cladding composite panel页
4. EPS roofing/sandwich panel页
5. channel bar/composite panel页

→ 每个产品子类都有独立URL，做长尾词覆盖

### 技术SEO观察
- 所有站点Ahrefs UR都极低（0或个位数），说明内链权重分配不足
- brdeco.jp的外链来源可疑（metusce.com、grss.com），可能是购买的低质量链接
- brdecogroup.com的有机流量在2026年Q1-Q2出现**明显下滑**（从月6000+跌至2600），需关注是否因Google算法更新被降权

## 五、关键洞察

### 1. 这是一家靠SEO产品页 + WhatsApp询盘的外贸B2B企业
整个获客漏斗：
```
Google搜索产品词 → 落地产品页 → WhatsApp咨询 → 业务员跟进报价
```
没有内容营销、没有社媒运营、没有邮件营销，纯流量漏斗。

### 2. brdecomy.com是SEO最成熟的子站
- Ref. Domains最多（305）
- 产品页数量最多（68页）
- 关键词覆盖最全（252个）
- 但流量主要来自美国，说明内容是面向英语B2B买家，不是本地马来西亚市场

### 3. brdecogroup.com流量正在下滑，值得关注
- 2026年Q1-Q2从月均6000+跌至2600
- Ahrefs数据显示有机流量年内有+1变化（几乎停滞）
- 可能原因：Google核心更新影响、内容停止更新、竞争加剧

### 4. 日本站用了可疑外链策略
- brdeco.jp的Ref. Domains 279个，但主要引荐来源是两个可疑域名
- 流量的35%来自这些引荐，不可持续

### 5. 所有站点都没有内容营销
- 零博客文章
- 零关键词教育内容
- 如果竞品开始做内容营销，BRDECO极易被超越
