# 趋势词桥接逻辑规范

---

## 一、问题背景

Module 1.5 的 Path ① 判断问题是："这个词有明确的占星/星座角度？"

当前执行时，操作者将"明确的占星角度"理解为**词本身带占星属性**，导致：

- "Bing Hastert"、"Harry Kane"、"World Cup 2026" 等高热度词全部被判为无占星角度
- 系统运行 5 天零产出
- 而这类词实际上已通过 `[人名] birth chart`、`[赛事] astrology` 的形式为 astrologywiki 带来高曝光（GSC 验证）

**根本原因：** 趋势词不需要本身与占星相关，只需要**可以通过固定公式桥接到占星内容**，即可走 Path ①。

---

## 二、Path ① 的扩展判断标准

Path ① 通过条件（满足任一）：

```
Level 1：直接相关
  → 趋势词本身属于占星/星座话题（天象事件、星座概念、占星工具词等）

Level 2：可桥接
  → 趋势词属于以下可桥接类型（见第三节）
  → 且原始词在 Google Trends 估算搜索量 ≥ 50,000（Module 1 已过滤，直接复用）
```

两级都未通过 → Path ① 不适用，继续判断 Path ②（有工具化空间？）。

---

## 三、可桥接类型定义

| 类型 | 识别方式 | 桥接公式 | 内容产出示例 |
|---|---|---|---|
| **热门人物**（运动员/演员/政治人物/网红）| 趋势词为人名 | `[人名] birth chart` / `[人名] zodiac sign` | `Harry Kane birth chart` |
| **体育赛事** | 趋势词包含赛事关键词（见附录 A）| `[赛事] astrology` / `zodiac signs as [队伍]` | `England World Cup 2026 astrology` |
| **影视作品/角色** | 趋势词为电影/剧集/角色名 | `[角色名] zodiac sign` / `[作品] characters zodiac signs` | `Troy Story 5 zodiac signs` |
| **文化事件/颁奖** | 趋势词包含文化事件关键词（见附录 B）| `[事件] astrology` / `[事件] zodiac predictions` | `Oscars 2026 astrology` |

---

## 四、出生日期验证（热门人物专用）

热门人物桥接需要已知出生日期才能写 birth chart 内容。判断流程：

1. 查询 Wikidata API，检查 `date of birth`（P569）字段
2. **有完整出生日期** → Path ① 通过，桥接公式用 `[人名] birth chart`
3. **仅知出生年份或星座** → 降级桥接，公式改为 `[人名] zodiac sign`，Path ① 仍通过
4. **完全无生日信息** → Path ① 不通过，继续判断 Path ②

---

## 五、Path ① 通过后的输出

Module 1.5 判定为 Path ① 后，推送给内容负责人的通知需包含：

| 字段 | 内容 |
|---|---|
| 原始趋势词 | 如 `Harry Kane` |
| 桥接类型 | 如 `热门人物` |
| 推荐内容关键词 | 如 `Harry Kane birth chart` |
| 出生日期（人物类）| 如 `1993-07-28`（Wikidata 自动获取）|
| Google Trends 估算搜索量 | 如 `500K+` |
| Trending Now 发现时间 | 如 `2026-07-06 14:00` |

内容负责人收到通知后按现有内容 SOP 产出文章，目标 48 小时内发布。
