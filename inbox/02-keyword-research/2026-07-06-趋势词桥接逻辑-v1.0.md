# 趋势词桥接逻辑规范

---

## 一、问题背景

当前 G1 闸门通过脚本匹配 `TOPIC_KEYWORDS` 数组判断趋势词是否与产品相关。  
这要求**趋势词本身**带有占星属性，导致：

- "Bing Hastert"、"Harry Kane"、"World Cup 2026" 等热词全部被过滤
- 系统运行 5 天零产出
- 实际上这类词已通过 `[人名] birth chart`、`[赛事] astrology` 的形式为网站带来高曝光（GSC 验证）

**根本原因：** 趋势词不需要本身与占星相关，只需要**可以通过固定公式桥接到占星内容**。

---

## 二、新 G1 判断逻辑

将 G1 从单一匹配改为**两级判断**：

```
G1 通过条件（满足任一）：

Level 1：直接相关
  → 趋势词本身命中 TOPIC_KEYWORDS 数组（原有逻辑，保留）

Level 2：可桥接
  → 趋势词属于以下任一可桥接类型（见第三节）
  → 且对应桥接词的预估搜索量 ≥ 阈值（见第四节）
```

两级都未通过 → 标记 `⚠️待确认`，走人工判断，不进趋势桶。

---

## 三、可桥接类型定义

| 类型 | 判断方式 | 桥接公式 | 输出关键词示例 |
|---|---|---|---|
| **热门人物**（运动员/演员/政治人物/网红）| 趋势词为人名，且 Wikipedia/Wikidata 有出生日期记录 | `[人名] birth chart` / `[人名] zodiac sign` / `[人名] rising sign` | `Harry Kane birth chart` |
| **体育赛事** | 趋势词包含赛事关键词（见附录 A）| `[赛事] astrology` / `zodiac signs as [队伍/参与者]` / `[赛事] astrology predictions` | `England World Cup 2026 astrology` |
| **影视作品/角色** | 趋势词为电影/剧集/角色名，且角色有已知或官方设定生日 | `[角色名] zodiac sign` / `[作品名] characters zodiac signs` | `Troy Story 5 zodiac signs` |
| **年度事件/节日** | 趋势词包含节日或周年事件关键词（见附录 B）| `[事件] astrology meaning` / `[事件] zodiac` | `Super Bowl astrology` |

---

## 四、搜索量预估过滤

桥接词在进入趋势桶前，需通过 DataForSEO 或 Ahrefs 验证桥接词的月搜索量：

| 桥接类型 | 最低月搜索量阈值 | 说明 |
|---|---|---|
| 热门人物 | 原始人名搜索量 ≥ 5,000 | 人名热度代理桥接词热度；月搜量过低说明该人物已退出热点 |
| 体育赛事 | 赛事关键词搜索量 ≥ 10,000 | 赛事规模决定流量天花板 |
| 影视作品/角色 | 作品名搜索量 ≥ 5,000 | 同人名逻辑 |
| 年度事件/节日 | 事件关键词搜索量 ≥ 20,000 | 节日类竞争较强，设更高门槛 |

> 若 DataForSEO 返回搜索量为 0 或无数据，默认不通过，标记 `⚠️待确认`。

---

## 五、出生日期验证（热门人物专用）

热门人物桥接需要**已知出生日期**，否则无法生成 birth chart 内容。验证步骤：

1. 用人名查询 Wikidata API（`https://www.wikidata.org/w/api.php`）
2. 检查是否存在 `date of birth`（P569）字段
3. 有出生日期 → G1 通过
4. 无出生日期 → 降级为 `zodiac sign` 桥接（仅需出生年份或星座信息，降低门槛）
5. 完全无生日信息 → 不通过，标记 `⚠️待确认`

## 七、附录 B：年度事件/节日关键词列表（初始版）

```
new year, valentine, halloween, christmas, thanksgiving,
mercury retrograde, eclipse, solstice, equinox,
oscars, grammy, met gala, golden globes
```

> mercury retrograde / eclipse / solstice 属于直接相关词，通过 Level 1 即可；此处主要为文化事件兜底。

---

## 八、G1 输出状态对照

| G1 输出 | 含义 | 后续动作 |
|---|---|---|
| `✅直接相关` | Level 1 命中 TOPIC_KEYWORDS | 直接进趋势桶，走 G2 |
| `✅可桥接` | Level 2 命中桥接类型且搜索量达标 | 直接进趋势桶，走 G2；同时记录桥接公式和输出关键词 |
| `⚠️待确认` | 两级都未通过 | 人工判断；默认不进趋势桶 |
| `❌无出生日期` | 人物类，Wikidata 无生日数据 | 尝试降级为 zodiac sign 桥接；否则丢弃 |

---

## 九、桥接词写入规范

G1 通过后，系统需在选题登记表中额外记录：

| 字段 | 内容 |
|---|---|
| 原始趋势词 | 如 `Harry Kane` |
| 桥接类型 | 如 `热门人物` |
| 输出关键词 | 如 `Harry Kane birth chart` |
| 出生日期（人物类）| 如 `1993-07-28` |
| 桥接公式 | 如 `[人名] birth chart` |

这些字段供内容生产流程直接使用，无需人工再次查找。
