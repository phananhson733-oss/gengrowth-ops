# GenGrowth 社媒运营工作台（Gao Xuan）

这里是 Gao Xuan 的个人加工区，用于支撑 **AstrologyWiki** 的社媒账号维护、KOL/KOC 建联与合作、内容排期、数据复盘及日常工作资料。现阶段以 TikTok 内容矩阵为主要协作场景，同时保留对其他平台的记录能力。

正式需要跨团队确认、发布或迁移的事项，应按团队协作流程另行提交；本目录优先保证工作过程清晰、可追溯。

## 默认工作节奏

1. 新线索先登记在 `03-kol-koc-operations/koc-kol-resource-pool.csv`，再开始建联，避免信息只留在私聊里。
2. 每次有效沟通补充至 `03-kol-koc-operations/outreach-log/`，并更新资源池的“当前状态”和“最近跟进日期”。
3. 已确定合作时新建 Brief；若达人承担内容生产或发布，应先和内容负责人确认账号定位、内容 Hook、CTA、素材版权和审核节点。
4. 上线后记录真实发布链接；在 `campaign-retrospectives/` 用统一的 24 小时 / 72 小时观察窗口完成效果与下一步结论。没有真实链接或数据来源时，明确标为“待补”。
5. 每周在 `05-data-and-reports/weekly-reports/` 记录进展、风险、下周计划和需要协助的事项。
6. `00-inbox` 不作为正式状态来源；每周至少归类一次。

## 与内容矩阵的协作边界

AstrologyWiki 当前有官方号、AI 占星师、热点占星测试和普通爱好者等不同内容定位。高璇的 KOL/KOC 工作应服务于这些既定定位，而不是为了合作而复制相同素材或混淆账号人设：

- **官方号**：可信的天象解释、心理/关系落点和工具承接；合作内容须符合品牌表达与事实边界。
- **AI 占星师**：占星 × 心理机制的可解释内容；不得将解读包装为绝对预测或医疗/心理诊断。
- **热点占星测试**：以时效性带来自然流量；热点、人物和版权素材须先确认可用范围。
- **爱好者测试号**：用于验证 Hook、评论问题和内容形式；合作结论必须沉淀，才能反哺其他账号。

达人合作不是替代内容团队的日常排产。跨团队合作前，先在 Brief 写清目标账号、内容形式、目标用户、CTA、审核责任人以及发布后要回传的指标。

## KOL/KOC 状态口径

`待筛选 → 已建联 → 待回复 → 洽谈中 → 已合作 → 复盘中 → 已归档`

“暂不合作”可作为任意阶段的结束标记，并填写原因与未来可重新联系的日期（如有）。未实际发布或交付时，不应标记为“已合作”。

## 命名与记录规则

- 日期型记录使用 `YYYY-MM-DD-主题-用途.md`，例如 `2026-07-27-达人A-首次沟通.md`。
- 每位达人在资源池中保留一个稳定名称，避免同一对象出现多种拼写。
- 任何报价、合作承诺、排期变更都应留下日期和信息来源；敏感合同或凭据不放入本目录。
- 记录合作数据时区分公开互动与后台数据：公开播放/点赞只能反映可见信号，不能替代 reach、留存、主页访问、链接点击或站内转化。
- 草稿、个人笔记和临时文档可自由新增；完成或废弃的材料移到 `99-archive`。
