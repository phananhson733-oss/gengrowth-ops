# KOL/KOC 合作复盘

一项已发布或已交付的合作建立一份复盘，例如 `2026-08-01-达人A-TikTok合作复盘.md`。

## 最低记录项

- 合作目标、目标账号定位、实际交付物与真实发布链接；
- 观察窗口：发布后 24 小时和 72 小时；
- 数据来源与抓取时间；
- 公开指标：播放、点赞、评论、分享、收藏等；
- 后台指标（可取得时）：reach、平均观看、完播/滑完率、主页访问、链接点击、新关注；
- 站内承接（可取得时）：可追踪链接点击、qualified UV、工具使用、注册或购买；
- 结论：保留 / 调整 / 停止，以及下一次只验证的一个变量。

公开播放和互动不能替代后台转化数据；未取得的字段统一标为“待补数据”，不得自行推断。
