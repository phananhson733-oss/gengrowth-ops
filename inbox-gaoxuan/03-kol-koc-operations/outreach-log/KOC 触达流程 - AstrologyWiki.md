| 账号 | 状态 | 当前用途 |

# 1. 先设置 Gmail 的对外身份

个人 Gmail 的地址无法变成 `@astrologywiki.com`，但可以修改收件人看到的**发件人名称、头像和签名**。

## 推荐发件人名称

优先推荐：

```text
AstrologyWiki – Kylie
```

也可以使用：

```text
Kylie from AstrologyWiki
AstrologyWiki | Kylie
```

不建议只写：

```text
AstrologyWiki
Partnership Team
Marketing Department
```

原因：KOC 建联是一对一沟通，显示真实联系人名字通常比只显示公司名更自然、更容易回复。

## 两个账号是否使用相同昵称

两个账号可以都显示：

```text
AstrologyWiki – Kylie
```

但需要注意：

- 同一个 KOC 只能由其中一个账号联系；
- 两个账号使用相同头像、签名和品牌描述；
- 对外身份保持一致，不要一个叫 Kylie、另一个伪装成其他员工；
- 在内部表格中记录实际使用的发件账号。

## Gmail 修改发件人名称

电脑端 Gmail：

1. 点击右上角齿轮；
2. 选择 **查看所有设置**；
3. 打开 **账号和导入**；
4. 找到 **用这个地址发送邮件 / Send mail as**；
5. 点击对应地址旁的 **修改信息**；
6. 将名称改为 `AstrologyWiki – Kylie`；
7. 保存更改；
8. 给自己的另一个邮箱发测试邮件，检查收件人实际看到的名称。

## 推荐签名

```text
Kylie
KOC Partnerships | AstrologyWiki
https://astrologywiki.com
```

如果网站尚未完善，可以暂时不放链接，避免把 KOC 引导到无法建立信任的页面。

## 发件前的账号检查

- [ ] 两个账号都开启两步验证；
- [ ] 设置恢复邮箱或手机号；
- [ ] 发件人名称统一；
- [ ] 头像清晰且一致；
- [ ] 签名简短、真实；
- [ ] 官网链接可正常打开；
- [ ] 两个账号分别给自己发一封测试邮件；
- [ ] 手机端和电脑端显示正常。

# 2. 两个账号的冷启动策略

这里的“冷启动”不是制造虚假邮件往来，也不是购买所谓的自动养号服务。正确方式是：保持真实使用、逐步增加相关的一对一商务邮件，并观察退信与回复。

以下数量是保守的操作建议，不是 Gmail 官方承诺的安全额度。

## A. 半年账号：`kimkylie01399@gmail.com`

如果该账号过去一直有真实收发记录，而且近期没有安全警告或发送限制：

### 第 1–3 天

- 每天发送约 10–15 封 KOC 建联邮件；
- 一封只发一个人；
- 分散在一天的工作时间内；
- 每封做真实的个性化；
- 当天及时处理回复。

### 第 4–7 天

只有在以下情况正常时，才提高到每天约 15–20 封：

- 没有连续退信；
- 没有 Gmail 警告；
- 名单来源清楚；
- 开始收到真实回复；
- 没有发现重复联系人。

### 后续

如果一周以上表现稳定，可以再考虑逐步接近每天 20–30 封，但不应把 Gmail 的技术发送上限当成目标。

## B. 新账号：`pafofanam656@gmail.com`

新账号不建议第一天就发送 30 封陌生开发信。

### 准备阶段：第 1–3 天

- 完成头像、名称、签名、安全设置；
- 正常登录并使用 Gmail；
- 与自己的其他邮箱进行少量真实测试邮件；
- 如有真实业务沟通，可以正常收发；
- 不使用自动养号、虚假回复或批量群发服务。

### 初始建联：第 4–7 天

- 每天约 3–5 封高匹配度建联邮件；
- 优先联系最相关、最可能回复的 KOC；
- 每封单独发送；
- 不加附件；
- 第一封最多放一个必要链接。

### 第二周

如果账号正常：

- 逐步提高至每天约 5–10 封；
- 继续观察退信、回复和账号警告；
- 不与半年账号联系同一批人。

### 第三周以后

表现稳定后，再逐步增加至每天约 10–15 封。不要因为急于完成名单而突然加量。

## 现阶段两个账号的建议分配

| 账号 | 建议联系人 | 目的 |
|---|---|---|
| 半年账号 | 高优先级和中优先级 KOC | 承担主要发送量 |
| 新账号 | 少量高匹配度 KOC | 建立真实发送与回复记录 |

如果今天有 60 位 KOC，不代表今天必须全部发完。可以先筛选优先级，将名单分成 3–7 天完成。

# 3. 发送方式：应该做与不应该做

## 应该做

- 一封邮件只发送给一个 KOC；
- 使用对方真实姓名；
- 提到对方一条真实内容或明确的内容方向；
- 说明为什么 AstrologyWiki 与其受众相关；
- 保持邮件简短；
- 只提出一个明确的下一步；
- 分散发送时间；
- 及时回复对方；
- 对拒绝者立即停止联系；
- 记录每一封邮件的状态。

## 不应该做

- 不用 CC 或 BCC 一次密送三位陌生 KOC；
- 不把一模一样的邮件连续发给多人；
- 不按照机械的固定间隔持续批量发送；
- 不伪造“Re:”或“Fwd:”让人误以为以前沟通过；
- 不使用误导性标题；
- 不在第一封邮件塞多个链接、图片或大型附件；
- 不使用短网址；
- 不把来源不明的私人邮箱直接加入名单；
- 不用两个账号重复联系同一个人；
- 不在对方拒绝后换邮箱继续联系；
- 不把邮件追踪结果当成绝对准确的数据。

## 发送间隔

不需要追求一个“保证不进垃圾箱”的神奇间隔，也不存在这样的间隔。

操作上可以：

- 将邮件分散在一天的工作时段；
- 使用 Gmail 自带的定时发送；
- 避免几秒钟内连续发出大量相同邮件；
- 不必每封都严格固定为 5 分钟或 10 分钟；
- 发送量突然异常比某个具体分钟数更值得关注。

# 4. KOC 邮件名单的合规和质量检查

如果邮箱和主页来自公开页面，应优先使用明确标注为以下用途的邮箱：

- Business inquiries；
- Collaborations；
- Partnerships；
- PR / Media；
- Management contact。

谨慎使用：

- 来源无法确认的私人邮箱；
- 数据经纪商出售的名单；
- 很久没有更新的账号；
- 与 AstrologyWiki 完全无关的 KOC；
- 已明确表示不接受商业合作的人。

> [!important]
> “能找到邮箱”不等于“适合联系”。名单质量、相关性和尊重停止联系请求，比单纯扩大数量更重要。发送商业邮件时还需要遵守收件人所在地适用的隐私和反垃圾邮件规则。

## 名单最低字段

| 字段 | 是否必需 | 示例 |
|---|---:|---|
| KOC Name | 是 | Anna Lee |
| Email | 是 | anna@example.com |
| Platform | 是 | TikTok |
| Profile URL | 是 | 主页链接 |
| Bio / Niche | 建议 | Astrology education |
| Recent Content URL | 建议 | 最近相关内容链接 |
| Email Source URL | 建议 | 邮箱公开出现的位置 |
| Country / Language | 建议 | US / English |
| Notes | 可选 | 接受品牌合作 |

# 5. 从名单到发送的完整流程

## Step 1：你收集原始资料

你可以提供：

- CSV；
- Excel；
- Google Sheets 导出的文件；
- Markdown 表格；
- 直接粘贴的一批邮箱和主页链接；
- KOC 主页链接列表；
- 截图，但表格或文本效率更高。

## Step 2：AI 清理名单

AI 可以批量完成：

- 统一姓名和邮箱格式；
- 检查明显错误的邮箱格式；
- 删除完全相同的重复项；
- 根据主页链接识别跨平台重复 KOC；
- 标记缺少邮箱、主页或姓名的记录；
- 标记疑似私人邮箱或来源不清的记录；
- 建立 `Do Not Contact` 字段；
- 检查两个 Gmail 是否曾联系过同一人；
- 输出干净的 CSV 或 Excel。

AI不能仅凭邮箱格式保证该邮箱真实有效，也不能保证对方愿意接收邮件。

## Step 3：AI 分析 KOC 匹配度

如果提供主页资料或允许查看公开页面，AI可以：

- 总结内容领域；
- 判断是否与 AstrologyWiki 相关；
- 找到适合的个性化切入点；
- 将 KOC 分为高、中、低优先级；
- 标记不建议联系的人；
- 说明评分理由；
- 推荐优先发送顺序。

建议评分：

| 优先级 | 定义 | 操作 |
|---|---|---|
| A | 内容高度相关，有明确合作邮箱 | 优先发送 |
| B | 受众相关，但切入点一般 | 第二批发送 |
| C | 相关性较低或资料不足 | 补充研究后决定 |
| Skip | 明显不相关、拒绝合作或来源有问题 | 不发送 |

## Step 4：AI 生成个性化邮件草稿

针对每位 KOC，AI可以生成：

- 真实的个性化切入点；
- 2 个标题备选；
- 第一封建联邮件；
- 第一次跟进邮件；
- 第二次、也是最后一次跟进邮件；
- 推荐发送账号；
- 发送前风险提示；
- 需要你人工确认的信息。

AI必须遵守：

- 不编造看过对方不存在的视频；
- 不编造粉丝数据；
- 不假装已经使用或购买对方产品；
- 不写虚假的共同经历；
- 资料不足时明确标注，而不是强行个性化。

## Step 5：AI 做交叉检查

生成后，AI可以批量检查：

- 姓名是否与邮箱对应；
- 邮件中是否出现其他 KOC 的姓名；
- 是否错误提到其他产品；
- 标题和正文是否过度重复；
- 是否出现多个链接；
- 是否有夸张营销词；
- 是否有明显语法问题；
- 是否重复联系；
- 是否应当停止联系。

## Step 6：你人工抽查和批准

你需要：

- 确认产品描述真实；
- 确认合作条件；
- 确认个性化内容确实来自对方主页；
- 决定是否发送；
- 对高价值 KOC 逐封检查；
- 对批量草稿至少进行抽样检查；
- 批准最终版本。

## Step 7：创建草稿或发送

在没有连接 Gmail 并获得明确授权时，AI不能直接进入你的 Gmail 账号发送邮件。

当前最稳妥方式：

1. AI 输出最终发送表；
2. 你在 Gmail 创建或粘贴邮件；
3. 你选择正确收件人和账号；
4. 你使用 Gmail 定时发送；
5. 你更新状态。

如果以后使用经过授权的 Gmail 连接或可靠工具，可以研究批量创建**草稿**，但仍建议由你审核后发送。不要使用模拟点击、绕过限制或要求提供 Gmail 主密码的工具。

## Step 8：回复与跟进

你把回复内容提供给 AI 后，AI可以：

- 判断回复类型；
- 提取对方的问题和合作条件；
- 起草回复；
- 推荐下一步；
- 生成跟进时间；
- 更新合作状态；
- 汇总常见异议。

最终发送、报价承诺和合作条件由你确认。

# 6. AI 与人工工作的边界

## AI 可以高度自动化

| 工作 | 自动化程度 | 说明 |
|---|---:|---|
| 清洗 CSV / Excel | 高 | 格式统一、去重、缺失项检查 |
| KOC 分类与优先级 | 高 | 基于你提供的资料或可访问的公开资料 |
| 个性化切入点提取 | 高 | 需要可靠的主页内容 |
| 标题与正文生成 | 高 | 可一次生成多封独立草稿 |
| 跟进邮件生成 | 高 | 根据首次邮件与状态生成 |
| 文案质量检查 | 高 | 检查错名、错品牌、重复、链接等 |
| 数据表和发送队列 | 高 | 可输出 CSV、Excel 或 Obsidian Markdown |
| 回复分类与摘要 | 高 | 需要你提供回复或授权访问 |
| 周报与转化分析 | 高 | 需要完整发送和回复数据 |

## 需要你参与

| 工作 | 原因 |
|---|---|
| 确认产品事实 | AI不能替你承诺不存在的功能 |
| 确认合作预算和条件 | 涉及商业决策 |
| 确认名单来源适合使用 | 涉及合规与个人信息使用 |
| 审核高价值 KOC 邮件 | 需要品牌判断 |
| 决定是否发送 | 发送属于外部行动 |
| 处理账号安全验证 | 只能由账号所有者完成 |
| 接受报价或签署合作 | 涉及实际义务 |
| 尊重拒绝和退订 | 需要维护停止联系名单 |

## 目前必须手动完成

- 登录 Gmail；
- 修改 Gmail 名称、头像和签名；
- 处理验证码和安全提醒；
- 在没有 Gmail 授权连接的情况下创建或粘贴草稿；
- 最终点击发送或设置定时发送；
- 决定价格、合同和付款；
- 确认对方是否真实回复。

# 7. 为了让 AI 最大程度提效，我需要提供什么

## A. AstrologyWiki 品牌资料

- 官网；
- 一句话产品介绍；
- 主要功能；
- 目标用户；
- 产品当前阶段；
- KOC 为什么可能感兴趣；
- 可以提供什么合作条件；
- 是否付费；
- 是否提供免费账号；
- 是否有 affiliate commission；
- 不能承诺或不能提及的内容；
- 希望的邮件语气；
- 你的对外称呼是否确定为 Kylie。

## B. KOC 原始名单

最好包含：

```text
Name
Email
Platform
Profile URL
Bio / Niche
Recent Content URL
Email Source URL
Country / Language
Notes
```

只有“邮箱 + 主页链接”也可以开始，但主页无法访问或内容不足时，个性化质量会降低。

## C. 发送规则

需要告诉 AI：

- 本批次计划发送多少人；
- 使用英语还是其他语言；
- 合作类型；
- 是否可以直接提预算；
- 第一封是否放官网链接；
- 邮件长度偏好；
- 是否需要 1 次或 2 次跟进；
- 两个账号当前每天计划发送多少封；
- 以前已经联系过的名单；
- `Do Not Contact` 名单。

## D. 历史结果

如果希望不断提高效果，需要保存：

- 实际发送版本；
- 使用的标题；
- 发送账号；
- 发送日期；
- 是否退信；
- 是否回复；
- 回复是正向、拒绝还是询价；
- 是否进入合作；
- 合作结果。

AI可以根据这些数据分析哪类 KOC、哪个标题和哪种价值主张效果更好，但不应只依赖不准确的“打开率”。
