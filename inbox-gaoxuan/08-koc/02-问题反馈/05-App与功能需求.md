# App与功能需求

## 当前情况

目前有两位不同的KOC主动询问AstrologyWiki是否会推出App，说明移动端App可能存在重复出现的用户需求信号。

此外，Richelle希望在当前行星信息上方看到“当前时刻的即时星盘”。这可以作为独立功能需求记录。

## 需求一：移动端App

### Richelle

- TikTok：[@thegoodwitchofsylvanlake](https://www.tiktok.com/@thegoodwitchofsylvanlake)

> “My biggest question, is there an app for this site yet? Because it’d do well I feel.”

她询问网站目前是否已有App，并认为AstrologyWiki如果推出App可能会有不错的表现。

### Alyssa

- TikTok：[@crypticsirena](https://www.tiktok.com/@crypticsirena)

> “I can definitely see myself using this website though, is it also going to be an app?”

她表示自己可以想象以后继续使用AstrologyWiki，同时询问产品是否会推出App。

### 需求判断

- 两位KOC都在没有被主动询问的情况下提出App问题。
- 两人都表达了继续使用产品的意愿。
- 这说明App需求与持续使用、移动端便利性可能有关。
- 当前反馈只能视为初步需求信号，尚不足以单独证明开发App的优先级。

## 需求二：当前时刻的即时星盘

### Richelle的原始反馈

> “The only thing I’m wishing the website had is a current chart for the moment above the current planets, but maybe it’s there and I didn’t see.”

她希望在当前行星信息上方增加代表此刻天空状态的即时星盘图（Current Chart for the Moment）。同时，她也说明可能是网站已经存在该功能，但自己没有找到。

### 需求判断

Richelle经常发布当前行运和行星相位内容。即时星盘图既可能满足普通用户查看当前天空的需求，也可能成为占星内容创作者进行讲解时的可视化工具。

## 风险与机会

- 如果已有类似功能但用户没有找到，说明入口或命名需要优化。
- 如果尚未提供，即时星盘图可能丰富Today或Current Planets体验。
- App可能增强日常使用、通知、Journal和Today类功能的使用频率。
- 两项需求都可能为KOC制作持续性的占星内容提供素材。

## 当前建议

1. 记录两位KOC对App的重复需求，但暂不承诺开发计划。
2. 确认网站目前是否已有当前时刻的即时星盘。
3. 如果已有，检查入口和展示是否明显。
4. 如果没有，评估其与Today、Current Planets和Transit功能的结合方式。
