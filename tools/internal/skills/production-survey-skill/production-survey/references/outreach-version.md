# 对外版输出规范（Outreach / External-facing Variant）

默认本 skill 产出的是**对内版**（BD/决策导向，可含商业策略）。当调研结论要**给被调研方本人或任何外部方看**时（典型：把一家品牌的调研发给其创始人，用来展示能力、开启沟通），必须从对内版派生一份**对外版**。**永远不要把对内版原样外发。**

## 一、对外版的目标

一份**基于公开信息与第三方工具的独立业务观察**，要同时做到：
1. 用覆盖度与严谨度**自证调研能力**（多站点/多渠道/竞品/SEO/GEO/置信标注）；
2. **既讲优势也坦率指出不足**（平衡=可信；纯亮点=像宣传，反而减分）；
3. 对无法从外部确认的事项**明确保留判断**；
4. **不冒犯对方，不暴露我方底牌，不暗示合作、不推销**。

它不是提案。文档里没有 CTA、没有报价、没有"该不该合作"。

## 二、派生方法：从对内版做减法（保留分析深度）

**保留**全部数据表、竞品对比、SWOT/Porter、TAM/GMV 情景/SAM、深度分析各模块、置信标注与口径说明——这些是能力的体现。只删/改三类：

### A 类 · 底牌（整段删除）
分析方的商业策略，**不是冒犯问题，是战略上不能给对手看**：
- 报价、分成比例、base/封顶、计费结构
- 合作与否判断、pilot 选站、落地方案/SOW、"卖能力不卖人手"
- 防白嫖话术（"别给完整 playbook"）
- 把对方当"待管理目标"的风险矩阵、与成交挂钩的情景规划
- 一切 "我方/GenGrowth 该怎么做" 的措辞

### B 类 · 冒犯性框架（中性化）
- 标签化贬义（白牌/护城河薄/落后者）→ 数据化措辞（R9）
- 渲染对方的召回/质量投诉/差评 → 召回等只作一句中性"公开合规记录"，不强调、不替其淡化（不写"属行业常见"）
- 质疑对方自身声称（"打脸 No.1"）→ "此口径不支持…，其统计口径待确认"
- 让对方"被扒底"的母公司/归属深挖 → 删或弱化
- 内部组织判断（"各自为战"）→ 删或限定为"从公开信息看协同有限"

### C 类 · 内部痕迹（删除，R7）
"已按证据强度收紧""纠正上一版误读""原数字已撤""此前…应理解为""待归档以便复核""正式提案前应…"——成品不解释自己的草稿史，直接给最终结论。

## 三、比对内版更严的约束

| 维度 | 对内版 | 对外版（更严） |
|---|---|---|
| R1–R10 | 应遵守 | **零容忍**，每处越界都要限定范围 |
| 事实 vs 情景 | 分开 | 分开且反复自检（GMV 必须标"模型，非实际经营规模"）|
| 单指标因果 | 避免 | 一律限定（"从公开指标看…"）|
| 内部事实（净毛利/渠道占比/组织协同/共用供应链）| 可标推断 | **不得断言**，限定或省略 |
| 语气 | 中性 | 不卑不亢、低推销、文档内无 CTA |
| 自夸速度/skill | — | **禁止写进文档**（放到随附的人际消息里）|
| 评分 | 星级可带口径 | 优先定性（较强/中等/待提升）+ 口径说明 |
| 高权重结论溯源 | 硬事实需源 | 执行摘要/最终判断里复现的结论（畅销多国、供应链自研、母公司归属）都要直接来源或标"行业媒体口径/据公开信息推断" |

## 四、结构要求
1. 开头加**执行摘要**：业务结构 / 独立站增长特征 / 主要优势 / 主要风险与待验证。
2. 散落的 `[Low]`/待验证**集中到一节**「关键假设与数据局限」，正文不逐段反复解释（降低阅读阻力）。
3. 综合判断章**去重**：不重复正文数字，只保留最终判断与痛点。
4. 保留竞品差距、弱项、风险——不做成宣传册。

## 五、输出与交付
- **导出自包含 HTML**：`tools/scripts/export-html.sh <文件>.md` → 目录侧栏 + 置信色标 + 打印友好 + 离线单文件。
- 交付前**剥 frontmatter/内部元数据**：正文与文件名都不得留 `audience: 外发版` 之类标记。
- **随附一段人际消息**（微信/邮件）承载暖场与软邀约（"想请你指正""有空当面聊"），不进文档。文档保持不卑不亢的成品感。

## 六、外发前检查清单
- [ ] 无报价/分成/pilot/合作判断/防白嫖/风险矩阵（A 类清零）
- [ ] 无标签化贬义、无召回渲染、无质疑对方声称（B 类中性化）
- [ ] 无"已收紧/纠正上一版/待归档/正式提案前"等过程叙述（C 类清零，R7）
- [ ] 同一结论全文置信度一致（R6）；无 SWOT/摘要里把已 hedge 的结论又说成事实
- [ ] 售价区间未当 AOV（R8）；每个指标标清口径
- [ ] 内部事实（毛利/渠道占比/组织/供应链）已限定或删除（R10）
- [ ] 星级已改定性或补口径；高权重结论已溯源
- [ ] 已导出 HTML、已删 frontmatter、文件名无"外发版"
- [ ] 随附人际消息已单独给出，文档内无 CTA
