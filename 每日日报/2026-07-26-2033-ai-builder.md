## 1. 本周最大趋势

**① Agent 从“能生成”进入“可控自治”**  
证据：Anthropic 的 Claude Code auto mode 以隔离环境减少点确认；Karpathy 强调低成本验证与逐步放权。  
重要性：权限、预览、回滚、验收成为交付门槛。  
启发：GenGrowth 应卖“可审计闭环”，不是“全自动 Agent”。

**② 开放权重成为经营与合规变量**  
证据：NVIDIA 联合约 25 家机构为开放权重背书，模型来源、蒸馏争议和跨辖区可用性同步进入政策层。  
重要性：不能只按单一模型评估成本与稳定性。  
启发：方案应有多模型备选、降级路由与风险说明。

**③ Agent 的基础设施是可验证的工作环境**  
证据：Karpathy 将验证定义为瓶颈；Anthropic 的路线覆盖托管运行、记忆、主动触发与技能迭代。  
重要性：客户付费的是可追踪结果。  
启发：将 cron、任务板、知识库、审批门组合为运营样板。
