# 深圳市环球易达供应链管理有限公司调研报告

> 报告日期：2026-07-16 | 调研目的：通用商业尽调，重点核验副总裁林旭负责的业务、产品线、店铺及独立站

## 一、执行摘要

深圳市环球易达供应链管理有限公司（下称“环球易达”）是2014年成立的深圳跨境电商集团，主要通过多平台销售、自有品牌和创业合伙人孵化模式开展业务。公开资料能高置信确认其孵化体系中的深圳市第一构想科技有限公司（FIDEAL），以及FIDEAL旗下智能家居安防品牌ieGeek。FIDEAL官网自报2023年销售额突破7.5亿元，但未有审计财务文件交叉验证。最重要的调研结论是：**截至报告日，未找到可信公开来源证明“林旭”任环球易达副总裁，也未找到证据证明FIDEAL、ieGeek或任何具体店铺/独立站归林旭管辖**；因此，本报告不将集团资产直接归入林旭旗下。

### 关键发现

1. **可验证的核心资产是 FIDEAL → ieGeek**：FIDEAL官网明确其隶属环球易达，并明确ieGeek为其打造的安防品牌。
2. **ieGeek已经是“平台店+品牌独立站”模式**：官方站点列出美国、英国、德国、法国、欧洲和日本区域站，产品涵盖室外/室内摄像头、4G摄像头、PoE系统、婴儿监视器和可视门铃。
3. **林旭的身份和管辖边界是本次尽调的主要缺口**：搜索结果中存在优必选副总裁林旭及速卖通同名从业者，均不能与环球易达混同。
4. **合规风险已有官方记录**：国家外汇管理局深圳市分局于2025年4月15日因违反外汇登记管理规定对公司予以警告并罚款4万元。

### 2.3 核心管理团队与林旭身份核验

公司官网未公开完整管理层名单。可验证的公开线索包括：

- 政府处罚页面将公司负责人标记为“钟**”。
- 2022年易仓科技活动稿显示“环球易达供应链总经理邓小洋”参会；该信息只能证明当时职务。
- **未找到环球易达官网、政府公示、子公司官网、可靠媒体或招聘页面确认林旭的副总裁身份。**
- 公开网络中的“副总裁林旭”高频指向优必选科技，另有“速卖通商家拓展运营专家林旭”；没有证据显示两者与环球易达的林旭为同一人。

**结论：林旭职务和旗下业务均属待证事项，不应根据口述身份直接归属集团品牌。**

### 2.4 企业文化与愿景

公司官网公布的使命愿景为“善易有道，通达天下”，核心价值观为“正直、进取、利他、协作、创造”。组织机制强调内部创业、独立核算和供应链共享。

#### 3.1.1 木材、家具与家居品类补充核验

**结论：可以确认环球易达体系曾经营“家居”品类，但现有公开证据仍不足以确认其存在独立的“木材”或“家具”产品线，也未找到对应品牌、店铺或独立站。**

| 证据 | 能够支持的结论 | 不能支持的结论 | 置信度 |
|---|---|---|---|
| 义乌睿腾网络科技有限公司的公开招聘介绍列出“3C电子、汽摩配件、玩具、服装、家居、小家电”，并使用环球易达的使命表述 | 集团孵化/合资体系中至少有一个主体曾将“家居”作为出口品类 | “家居”具体是家具、家饰、收纳、厨房用品还是其他子类 | 中 |
| 环球易达现时公开工商经营范围包含“智能家居” | 公司具备销售智能家居的工商范围 | 公司实际销售木制家具；工商范围不等于实际营收 | 中 |

| 对公司名、集团主要人员、已知孵化主体与“木材/木制品/家具”进行组合检索 | 未发现可交叉验证的品牌、Amazon店铺或独立站 | 证明该业务一定不存在；店铺可由其他境内外主体持有 | 中 |

### 3.4 商业模式解构

- **前台：** Amazon等平台电商 + Shopify/品牌独立站 + 部分零售渠道。
- **中台：** 数据化选品、网络营销、品牌运营、客服与售后。
- **后台：** 供应商整合、产品开发、采购、仓储和跨境履约。
- **组织模式：** 集团提供共享能力，孵化子公司/事业部独立核算，以合伙人机制激励品类负责人。
- **收入来源：** 核心应为自有/合作品牌产品零售差价；品牌出海服务是否独立收费未公开。

### 3.5 技术、供应链与运营

公开资料显示公司以数据决策、网络营销和供应链整合为主要能力。奥尼电子IPO审核材料显示，2020年环球易达曾为其音视频产品客户；富视康公开转让说明书亦披露环球易达采购云摄像机，说明其智能摄像头业务采用外部制造/供应链合作。研发投入、自建工厂、海外仓面积和主要供应商集中度未公开。

## 四、市场与行业分析

### 4.1 市场规模（TAM/SAM/SOM）

- **TAM（中国跨境电商口径）：** 国家统计局披露，2025年中国跨境电商进出口额为2.75万亿元，较2020年增长69.7%，2021–2025年均增长11.2%。
- **SAM：** 应限定为欧美日等目标市场的智能家庭安防、婴儿监护和相关配件零售市场；现有资料不足以给出可复核数值。
- **SOM：** 不宜用FIDEAL 2023年的公司级销售额代替ieGeek的实际可获得市场份额；缺少品牌收入、各渠道GMV和区域占比。

### 4.2 行业趋势与驱动力

1. 跨境电商总盘仍在增长，但从粗放铺货向品牌、产品和合规能力迁移。
2. 深圳形成产业集群优势：2025年上半年中国跨境电商品牌影响力百强中，深圳品牌占51个；截至2025年末，深圳企业建设运营的海外仓面积超420万平方米。
3. 智能家居安防的产品竞争从硬件参数延伸到App、AI识别、云服务、隐私和售后体系。
4. 平台依赖风险促使头部卖家建设独立站，ieGeek的区域化官网已体现这一趋势。

### 4.3 Porter五力分析

| 力量 | 评估 | 原因 |
|---|---|---|
| 供应商议价能力 | 中 | 深圳硬件供应链可选供应商多，但摄像头芯片、传感器和合规认证存在门槛 |
| 买方议价能力 | 高 | 消费者转换成本低，Amazon等平台价格透明 |
| 新进入者威胁 | 中高 | OEM起步容易，但品牌、App、认证、营销与售后要求持续投入 |
| 替代品威胁 | 高 | Ring、Blink、Tapo、eufy、Reolink以及大量白牌产品可替代 |
| 行业竞争强度 | 高 | 产品同质化、渠道集中、广告与促销竞争激烈 |

### 4.4 监管环境

重点合规领域包括进出口申报、外汇登记与收付汇、境外VAT/销售税、产品安全与CE/FCC等认证、消费者保护、数据隐私、无线设备网络安全和知识产权。2025年外汇处罚说明集团需要加强跨境主体的登记与资金合规内控。

ieGeek在家庭安防领域直接面对Reolink、eufy Security、TP-Link Tapo、Ring/Blink等品牌；低价平台上还面临大量无品牌或弱品牌摄像头。

### 5.3 护城河分析

- **供应链与规模经济：中。** 集团协同采购和孵化经验有助于降低成本，但缺少可量化数据。
- **品牌：中。** ieGeek已有多地区官网与成熟产品矩阵，但与Ring、eufy等相比品牌心智仍弱。
- **转换成本：低至中。** App、云存储和多摄像头系统可以提升粘性，但消费者仍可按设备逐步替换。
- **技术/数据壁垒：中低。** 未查到能显著阻止竞争者的独占专利、芯片或算法数据。

## 六、客户分析

### 6.1 客户细分与画像

ieGeek核心客户是注重性价比的欧美日家庭用户，细分场景包括房屋外围、室内看护、无Wi-Fi场所、婴儿监护和门前安全。公司也可能通过分销商/零售商覆盖B2B2C客户，但渠道收入占比未公开。

### 6.2 获客与增长策略

主要获客方式应包括Amazon站内搜索/广告、独立站SEO与促销、红人/社媒、联盟营销、邮件营销以及第三方零售渠道。区域化站点可支持本地语言、货币、税务和售后政策。

### 6.3 留存与扩展

多摄像头组网、App账户、云服务、配件和同一家庭内的门铃/婴儿监视器交叉销售可提高客户价值。留存率、复购率、云服务渗透率和NRR均未公开。

## 七、财务分析

环球易达为私营公司，未公开合并财务报表、融资历史、估值、毛利率和现金流。现有的主要规模线索是FIDEAL官网自披露：2018年销售额过亿，2019年同比增长101.50%，2023年突破7.5亿元。该数据没有财报或税务文件支撑，不应直接作为集团营收，也不应归属为ieGeek单品牌收入。

## 八、战略与增长

1. **从多平台卖家向品牌化迁移：** ieGeek的区域独立站、App和客服体系已经形成品牌直达消费者的基础。
2. **从单摄像头向家庭安防组合扩张：** 可视门铃、婴儿监视器、4G摄像头和PoE系统扩展了客群与客单价。
3. **孵化机制扩展新品类：** 集团曾通过内部裂变和外部加盟扩张，但现时子公司清单、控股比例与业绩需重新核验。
4. **林旭线索的尽调优先级：** 如果本次调研用于合作、求职或人员评估，应先取得内部组织架构和林旭的职责说明，再展开业务分析。

| 人员/业务归属误判 | 高 | 林旭身份和管辖资产无公开证据，同名人混淆风险高 |

| 产品同质化/价格竞争 | 高 | 安防硬件替代品多，价格透明 |
| 合规风险 | 中高 | 已发生外汇登记类处罚；同时面临VAT、隐私、产品与网络安全规则 |
| 供应链/质量 | 中高 | 依赖外部制造，摄像头安全性和售后故障会直接损害品牌 |
| 数据隐私与网络安全 | 高 | 家庭摄像头涉及敏感视频、账户和云端数据 |
| 财务透明度 | 中高 | 无合并财报，子公司自披露业绩无法交叉验证 |
| 仿冒站/渠道混淆 | 中 | 多个仿冒ieGeek站点可造成消费者损失和品牌责任混淆 |

## 十、SWOT综合分析

|  | 有利因素 | 不利因素 |
|---|---|---|
| **内部** | **优势：** 深圳供应链、多平台运营经验、孵化机制、ieGeek区域化DTC站点与广产品线 | **劣势：** 集团结构与财务透明度低、品牌声量弱于头部竞品、人员职责无公开披露 |
| **外部** | **机会：** 跨境电商总盘增长、家庭安防智能化、4G/太阳能无线场景、独立站沉淀用户 | **威胁：** 平台政策、价格战、隐私/网络安全监管、贸易壁垒、仿冒站与品牌信任损耗 |

## 十一、结论与展望

环球易达的商业价值不在于“供应链服务商”标签本身，而在于通过共享供应链和合伙人机制批量孵化跨境电商业务。FIDEAL和ieGeek是目前公开证据中最清晰、最具业务实质的链条，ieGeek已经从平台品牌走向多区域独立站和家庭安防产品矩阵。但对林旭的分析目前只能停留在“待证”：不建议将FIDEAL、ieGeek或其官方站点称为林旭旗下业务，除非后续取得公司内部组织架构、林旭名片/企业邮箱、人事任命文件或可验证的官方介绍。

### 建议的下一步核验清单

1. 向公司索取最新组织架构图，确认林旭的法定姓名、职位、汇报线和分管事业部。
2. 获取林旭负责主体的营业执照名称、店铺ID、商标权利人和网站页脚主体。
3. 将店铺后台账户、收款主体、商标持有人、域名注册/隐私政策主体和供应商采购主体做五方交叉验证。
4. 单独获取近2024–2026年各事业部GMV、营收、毛利、广告费、退货率和库存周转数据，以验证真实经营质量。
