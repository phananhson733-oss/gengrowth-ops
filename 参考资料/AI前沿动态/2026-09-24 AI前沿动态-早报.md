# 🧬 深度研究 · 949 个 agent 会话跑出一个新酶家族，重跑十次一次都没再找到

**一句话定性**：这是前沿实验室第一次用**完全无人值守的多 agent 研究 harness** 在原始生物数据里"看出"人类漏掉的异常，并做了湿实验初步验证。但预印本里藏着一个更重要的结论：**同样配置重跑 10 次，没有一次再找到这个阵列**；而且**给模型的工具越多，它越看不到答案**。对做多 agent 系统的人来说，这篇论文最有价值的不是那个酶，而是这两条。

- **来源**：Anthropic 官方博文 + 40 页预印本《Autonomous AI agents discover reverse transcriptases with tandem repeat arrays》（Yoon, Athukoralage, Ameisen, Kauderer-Abrams, Perry†, Durrant†；Anthropic）
- 🔗 **原始链接**：https://www.anthropic.com/news/claude-discovers-novel-enzyme-system
- 📄 预印本：https://www-cdn.anthropic.com/22573675ada52a8ca8a97a1a4b4326b2f208a071.pdf

## 一、为什么值得深读

1. **"AI 做科研"第一次从"帮人跑分析"变成"自己提出值得追的异常"**。以往的自动化科研里，判断"什么算反常"、"什么值得追"都由人类专家提供。论文 Discussion 原话：*"Here, the agents supplied both the expectation, drawn from their own knowledge rather than their task, and the judgment that the atypical observations merited further pursuit."*
2. **这是一份罕见的、带完整运行数据的大规模多 agent 生产案例**：任务数、会话数、角色分布、token 构成、失败率、复现率都有。实验室很少公开这些。
3. **时间点**：同一周 Anthropic 刚发布 Opus 5.5 并降价，9/23 还推出了 Claude Marketplace，Amodei 当天也在联合国安理会发言。这篇论文实际上是在给"agent 能做长程自主工作"提供证据，属于战略叙事的一部分。
4. 媒体普遍在炒"类 CRISPR"。**但真正该读的是预印本第 4 节（benchmark）和复现实验**，大多数报道都没提。

## 二、核心事实（以预印本为准；媒体数字有误差）

### 2.1 规模与成本
| 指标 | 数值（预印本） |
|---|---|
| 搜索空间 | **1.94B** 条宏基因组蛋白簇 |
| RT 簇（过滤后） | **198,290** 个，分为 **9** 类 |
| 邻域普查 | **10,983** 个 RT 位点、**3,564** 个候选伙伴蛋白家族 |
| 深挖 | 16 个家族晋级，另有 1 个由 agent 自发追加，共 **17** 个 |
| 任务 / 会话 | **119** 个任务；**949** 个 agent 会话（launch 1 + worker 414 + supervisor 375 + curator 107 + editor 52） |
| 时长 | **21.5 h** 墙钟时间，**76.9 agent-hours**（其中 worker 占 63.7） |
| Token | **215.6M** = 未缓存输入 11.3M + 输出 14.9M + **缓存写入 189.5M**（缓存读取不计入） |
| 人工介入 | 运行期间**零介入** |
| 主力模型 | **Claude Mythos 5** |

> ⚠️ 媒体普遍写"3,500 个候选系统、筛到 20 个"，这是把两个数混在了一起：3,564 是伙伴家族普查数；**3,500 其实是 benchmark 的尝试次数**（7 个模型 × 5 个难度级别 × 100 次）。最终产出是 **19 份报告**。

### 2.2 命中率：大部分候选被 agent 自己否掉
- 17 个候选伙伴家族中，**只有 3 个被确认为未报道过的 RT 关联**；另外 14 个被 agent 判为注释伪影、已知系统的一部分，或只是"邻居"而非专属伙伴。
- worker 还额外标记出 **3 个新 RT 谱系**，ART 就是其中之一。
- 19 份报告用**锦标赛式两两比较**排序（one pair per task），人类只审排在前面的报告。

### 2.3 ART 是什么
- 仅存在于**巨型噬菌体（jumbo phage）**中的一个新 RT 家族，由三部分组成：RT 酶、专属伙伴基因、RT 上游约 1 kb 的非编码 DNA 阵列（每个单元约 200 nt，重复序列 15–49 nt，含约 15 nt 回文核心；间隔序列 120–220 nt）。
- **与 CRISPR 的关键区别**：相关噬菌体之间间隔序列**保序且保守**，分化速度与 RT 基因相当，附近**也没有 cas 基因**。作者推测它是"一个酶配一整套模板或诱饵 RNA"，而不是免疫记忆。
- **湿实验**：在葡萄球菌噬菌体 SA1 感染后 15 分钟，阵列 RNA 占到**噬菌体 RNA 的最高 8%**，属于最丰富的转录本之一。转录本会被切成边界可复现的短 RNA，在大肠杆菌里质粒表达也能复现。
- **尚未证明的部分**（论文原话）：*"we have not shown that the RT is active or that the unit RNAs are its substrates. Whether the RT and its partner interact, and what the system does for the phage, are currently unknown."*
- **新颖性边界**：RT 本身此前已有人报道，MarsHill 的原始基因组报告识别出了 RT，也提出了 5′ ncRNA，但**没有描述重复阵列，也没有描述伙伴基因**。另外，最近有研究用专门的基因组语言模型在不相关的 UG27 RT 旁边也发现了 ncRNA 阵列，说明这种架构在自然界可能独立演化过不止一次。

## 三、机制拆解：这个 harness 怎么搭

```
研究 brief ──► 拆成若干分析阶段（stage）
                 │
                 ▼
        每个任务 = Worker（Claude Code 实例：出计划+执行）
                 + Supervisor（审计划、审结果；可「开新任务」）
                 │
    所有计划/结果/评审 ──► 共享记录（Curator 维护知识库）
                 │
        Editor 合并/修订 ──► 19 份报告 ──► 锦标赛排序 ──► 人类审阅 ──► 湿实验
```

关键设计有四点：
1. **二人制（worker + supervisor）是最小单元**，不是一个大 orchestrator 指挥一群 agent。375 个 supervisor 会话对 414 个 worker 会话，**几乎每一步都有人审**。
2. **任务队列会自己长**：119 个任务里 **98 个是运行中自发开出的 follow-up**，只有少数来自 brief。ART 恰恰来自一个**偏离 brief 的 follow-up**：brief 要找的是"新的伙伴蛋白编码基因"，而 ART 的定义性特征却是非编码 DNA。
3. **共享记忆**：所有 agent 读写同一份记录，论文称之为 "a multi-agent system with a common memory"。
4. **token 构成**：缓存写入占 **88%**（189.5M / 215.6M），输出只占 7%。**这类系统的成本主要花在"反复给新会话装载上下文"上，不在生成上**。

### 发现的那一刻（worker 推理原文节选，task t0062）
> *"Look: 'TACATGTGTATCGCATGTTAAGTAAAGTATT...' repeated... ~17-bp repeat, spacers ~110-170 bp. This looks like a DGR-like VR array? No — more like a CRISPR mini-array or a retron-like repeat region... Same architecture, different repeat sequence!"*

紧接着它开始**自我质疑新颖性**：*"Actually wait — reconsider... The honest path: characterize quantitatively, then run the novelty kill-test literature search with precise descriptors."*

这就是论文说的"agent 自己提供预期和判断"：在任务没有要求的情况下，它读了**原始 DNA 字符串**，看出了重复，然后自己设计了一个证伪步骤。

## 四、最重要的两段（媒体几乎没报）

### 4.1 复现失败
> *"We next asked whether the discovery of ART was reproducible within our harness, so we ran the same campaign ten more times... in two campaigns, workers investigated the lineage as follow-up. However, none read the DNA upstream of the RTs, and the array was missed in every rerun."*

作者归因为 RT 搜索空间太大，加上 harness 本身不确定。**换句话说，这次发现有相当大的运气成分**：同一套系统跑 11 次，只有 1 次找到。

### 4.2 工具越多，越看不见
为了排除运气因素，作者做了固定输入的 benchmark（7 个模型 × 5 个难度级别 × 100 次）：
- 把 ART 位点**直接放进上下文**：最强的几个模型**≥90%** 的尝试都能正确描述阵列。
- 改成**以文件形式提供并配上工具**：最低降到 **32%**（Opus 5，level 4）。
- 原因：**有文件时，39% 的尝试从头到尾都没读过一段 ≥200 nt 的连续序列**，最多只看到一个重复单元。模型在用工具（grep、HMM、结构预测）"处理"数据，却没有"看"数据。
- 读入的 DNA 越多，识别率越高：四个强模型合计从 29% 升到 76%，**Mythos 5 最高 96%**。
- 模型分层明显：Opus 5.5、Mythos 5.1、Mythos 5、Opus 5 是一档，Opus 4.6、Opus 4.8、Sonnet 5 明显落后。

### 4.3 可解释性佐证
作者拿原始发现会话的转录，把 Mythos 5 的内部激活分解成可解释信号，找到了**对重复 DNA 有响应的内部特征**，并与 Evo 2、gLM2 等专门的基因组语言模型做了对照。论文把这种能力称为 "genomic vision"。

## 六、正反观点

**支持方**
- **真实的"异常感知"**：发现来自 agent 读原始序列时的直觉，而不是预设的 pipeline 特征，这正是规模化基因组挖掘中人工策展这个瓶颈所在。MarsHill 的原始论文确实漏掉了这个阵列。
- **有湿实验数据**：阵列高表达（最高占噬菌体 RNA 的 8%），且加工边界可复现，说明它不是凭空编造。
- **诚实度高**：论文主动披露了复现失败、工具反效果和 14/17 的否决率，比典型的厂商 PR 扎实得多。
- **成本很低**：人类专家要花数周到数月的初筛工作，21.5 小时完成。

**质疑方 / 风险**
- **"不知道它做什么"**：研究者 Ravid Shwartz-Ziv 的说法是，"我们找到了一个有趣的系统，但还不知道它做什么"在博士答辩里是过不了关的（Decrypt）。连 Amodei 也承认其功能、生物技术价值和重要性"not yet clear"。
- **"类 CRISPR"是营销框架**：附近没有 cas 基因，间隔序列保守而不是获得性的，机制上更可能接近 retron 家族。Decrypt 还提到，公告当天基因编辑类股票反而下跌。
- **可复现性差**：1/11 的命中率意味着，这套 harness 目前还**不是一个可靠的发现引擎**，而是一个高方差的彩票机，只是每张彩票很便宜。
- **不算完全首创**：RT 早已被报道；UG27 旁的阵列已经被专用基因组语言模型发现过。Claude 的贡献是"看出了这个家族的定义性特征"。
- **自我评测的循环**：benchmark 的评分标准由作者选定（10 条二元特征），裁判模型也是 Mythos 5。
- **双用途隐忧**：Amodei 本人多次表达过对生物恐怖主义的担忧，而"让 Claude 自主操作实验设备"已经被写进愿景。

## 七、深度解读

### 对行业
1. **"科学发现"正在成为前沿实验室的新战场和新叙事**。Anthropic 有了自己的湿实验室和生命科学团队，数学方面已有"LLM 解开长期未解问题"的案例，论文也明确对标了这一点。下一轮模型发布的卖点，可能从 benchmark 分数变成"它发现了什么"。
2. **模型代际差异在长程自主任务中被放大**。Opus 4.x/Sonnet 5 和 Opus 5+/Mythos 的差距在这里是断层式的。"用便宜模型跑大量 agent"在需要感知异常的任务上可能根本不成立。
3. **harness 是核心资产**。论文原话：*"agentic harness configurations and model capabilities can dramatically affect research outcomes."* 同一个模型，换一种给数据的方式，识别率可以从 32% 变成 90%+。

### 对「做多 agent 系统的我们」（可执行判断）
1. **把"worker + supervisor 二人制 + 自增任务队列 + 共享记录"当成默认参考架构**。它比"一个 orchestrator 带 N 个子 agent"更适合开放式探索：supervisor 既审查又能开新任务，任务树自然生长（98/119 来自运行中）。我们现有的流水线如果任务列表是写死的，就拿不到这种"偏离 brief 的发现"。
2. **给关键判断节点强制设定"直接看原始数据"的步骤**。39% 的尝试从未读过足够长的原始序列，这个失败模式在我们的场景里也普遍存在：agent 用 grep/摘要/工具输出替代阅读原文。做法：
   - 对关键证据，要求 agent **把原文片段读进上下文并引用**（例如至少 N 行连续原文），不能只看工具统计；
   - supervisor 的审查清单加一条："结论是否基于直接读到的原始内容？"
3. **"加工具"不一定增益，要做消融**。对每个 agent 角色，至少对比"原文直接放进上下文 vs 文件+工具"两种设置。很多时候工具越多，agent 越倾向于"处理"而不是"阅读"。
4. **对探索型任务，用多次独立运行 + 并集，而不是追求单次跑对**。1/11 的命中率说明单次运行的方差极大。对"找机会/找异常/找选题"这类任务，更合适的是 **k 次便宜的独立运行 → 合并候选 → 锦标赛排序 → 人审前几名**。每次运行的配置（温度、分解方式、起始阶段）刻意打散，多样性比单次深度更值钱。
5. **成本核算按"上下文装载"算，不按输出算**。88% 的 token 是缓存写入。优化方向是：共享记录的结构化摘要要短、新会话只加载需要的部分、尽量复用缓存前缀。输出 token 的优化几乎不影响账单。
6. **锦标赛式两两评审适合做报告排序**。19 份报告两两比较，比让一个 judge 给绝对分更稳。我们的深度研究选题、SEO 选题评估都可以直接借用。
7. **把"否决率"当作健康指标**。17 个候选否掉 14 个，说明 supervisor 在起作用。如果我们的系统几乎不否决候选，多半是审查环节形同虚设。

## 八、接下来盯什么
- **ART 的功能验证**：RT 是否有活性、阵列 RNA 是否是它的底物、伙伴蛋白是否与它互作。**这决定了它是真发现还是一个有趣的注释**。
- **是否提交同行评审期刊**，以及领域专家（retron/DGR 研究组）的正式回应。
- **Anthropic 是否开源或产品化这个 harness**（博文提到 Claude Science 和 Claude Code），以及是否开放外部合作提案。
- **复现率的改进**：下一版是否通过"强制读原始数据"把 1/11 提高上去。这是对所有 agent 研究 harness 都有价值的信号。
- **OpenAI/Google 的回应**：谁会拿出类似的"自主发现"案例来对打？
- **监管层面**：自主 agent 加湿实验室的组合，会不会被纳入各家的 RSP/Preparedness 生物风险框架讨论。
