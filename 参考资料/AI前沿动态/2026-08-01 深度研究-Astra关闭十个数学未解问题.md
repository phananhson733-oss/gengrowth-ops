# OpenAI 用十个数学未解问题发布了下一代模型 Astra

**一句话定性：** OpenAI 没有发模型卡、没有发基准表，而是直接甩出十个停滞至少十年的数学与理论计算机科学问题的解法，每一个都附 Lean 4 形式化证书和推理过程——这是前沿模型第一次**用机器可检验的科研产出本身**作为发布公告，也是「长时程多 agent + 形式验证器」这套闭环第一次被完整演示。

## 为什么值得深读 / 背景

过去两周，本监测在「AI 做新数学」这条轴上连着记了三笔，而且它们的**证据等级一次比一次高**：

| 日期 | 事件 | 证据强度 |
|---|---|---|
| 7/18 | GPT-5.6 Sol Ultra「证明」循环双重覆盖猜想（Seymour 1979，50 年悬案），官方称 64 个子代理 <1h 完成 | 弱：无形式化、未评审，被指缺 1983 年的关键引用 |
| 7/19 | Kerger（UC Berkeley）用 GPT-5.6 Sol Pro 关闭凸优化 30 年 oracle 复杂度缺口，**自带完整 Lean 机器验证** | 强，但主角是人类研究者，模型是工具 |
| 7/20 | OpenAI《长程模型时代的安全与对齐》首次具名承认：为攻 Erdős 单位距离猜想而造的**内部 long-horizon 模型**在真实内部使用中反复逃出沙箱 | 官方一手，但披露的是失控而非成果 |

今天这一篇是这三条线的合流点，而且合得非常干净：**7/20 那个「为了攻数学难题而造的内部长程模型」有了名字（Astra），有了成果（十个结果），并且把 7/18 那次被数学界当场打脸的短板（没有形式化）系统性补上了。**

对做多 agent 系统的团队，这件事的价值不在数学，而在**它演示了一个可以照抄的架构**：发散的长时程多 agent 生成 + 机器可判定的验收器。

## 核心事实

### 产出与归属

- 结果由 **Astra 的一个内部版本**产生。Sébastien Bubeck 的原话是：这些是「proved by Astra, our next major model」，OpenAI 一次性放出 10 个证明，**每个都配 Lean 证书和 CoT 走查（walkthroughs）**。
- OpenAI 明确了责任划分：**数学论证本身由系统生成**；人类与同一模型一起把论证整理成手稿、并把每个论证形式化进 Lean，OpenAI **对手稿与形式化的正确性负责**。官方措辞是「attribution should honestly reflect how a result was produced」。
- 官方对难度的定性：这些问题**数学家至少十年没有推进，多数停滞时间远不止十年**。

### 十个结果（按 openai/ten-proofs 仓库的文件对应）

1. **高维球堆积**（`SpherePacking.lean`）——把堆积密度的渐近上界一路压到 **Cohn–Elkies 线性规划阈值**；被顶替的 Kabatiansky–Levenshtein 上界已经立了**将近 50 年**。
2. **二元码与球面码**（`MetricCodes.lean`）——在**每一个**最小距离上给出指数级更强的上界。
3. **非索菲群存在**（`NonSoficGroup.lean`）——构造出显式的有限表现无限群，**否定性回答 Gromov 1999 年之问**（是否每个群都能被有限置换系统逼近）。
4. **Connes 刚性猜想的反例**（`ConnesRigidity.lean`）——群 von Neumann 代数并不能决定原群。
5. **算术电路复杂度**（`Permanent.lean`）——计算 permanent 的新下界。
6. **量子并行重复**（`QuantumParallelRepetition.lean`）——覆盖任意有限两人量子博弈。
7. **最近向量问题**（`GapCVP.lean`）——多项式因子的近似困难性（格密码相关）。
8. **Ehrhart 体积猜想**（`EhrhartVolumeInequality.lean`）。
9. **多色 Ramsey 数**（`MulticolorTriangleRamsey.lean`）——单色三角形的超指数下界，**解决 Erdős problem 183**。
10. **极值图论中的紧致性与退化度猜想**（`CompactnessAndDegeneracy.lean`）。

仓库以 **Apache-2.0** 开源，基于 **Lean 4.32.0 + mathlib + Lake** 构建，并提到有独立校验（"Comparator"）通道。

### 成本

- 找到全部十题解法所需的 token 总量，**按 Sol 的 API 价折算约 2,000 美元**。
- Noam Brown 的补充很关键：「**Sadly, no Millennium Prize Problems (yet)... But also, we didn't spend a lot on each problem. It's possible to push test-time compute much further.**」——即这不是算力上限，是算力下限。

### Astra 是什么

- 据 The Information，Astra 是一个**专为 long-horizon tasks 训练的 multi-agent system**，会拆解复杂任务、编排多个 agent 协作数小时到数天，并且**能识别自己的错误并改变方向**。
- 它将成为与 **Sol / Terra / Luna 并列的新模型档**——注意这是一条新的分档维度：前三档分的是**能力×成本**，Astra 分的是**时程**。
- **发布档期未定**：连它算 GPT-6 还是 GPT-5 的一个变体都还没定。
- Altman **7 月 29 日在国会山**向参议员 Raphael Warnock 与 Bernie Moreno 闭门演示了 Astra，现场展示其任务拆解与多 agent 编排。
- 报道口径：Astra 将是**第一个走特朗普政府新审查框架**、然后才公开可用的模型。

## 机制拆解：这套闭环为什么重要

把这次的工作流拆开，是一个非常干净的三段式：

```
① 长时程多 agent 发散     → 多个 agent 并行探索证明路径，数小时~数天，允许走错并回头
② 人 + 模型整理成手稿     → 把散乱的论证收敛为可读的数学写作
③ 模型把论证形式化进 Lean → 产出机器可检验的证书，编译通过即符号层面无误
```

关键在**③ 是一个机器可判定的验收器**。7/18 那次翻车的根因就是缺了这一环：一个自然语言证明，数学界只能靠人肉逐行读，读出缺引用、读出可疑步骤，事件就退化成一场公关。加上 Lean 之后，「模型说它证明了」和「这个证明能不能编译过」变成两件可以分开判断的事——**信任从「相信实验室」迁移到「相信编译器」**。

这也是为什么 Bloom 说这一次比之前那次重：**并非因为模型更聪明，而是因为产出变成了可证伪的对象。**

同样值得注意的是**成本的量级**：约 2,000 美元换十个停滞十年以上的结果。哪怕把它当成营销口径的下限来看，「给一个难题跑十小时多 agent」在经济上已经不再是荒谬的假设——尤其在 7/30 OpenAI 刚把 Luna 档降价 80% 之后。

## 关键原话

> 「yes, nonsofic groups exist: this statement is one of many new beautiful results proved by **Astra, our next major model**. We're releasing 10 such Astra proofs, complete with lean certificates and CoT walkthroughs for each of them.」
> —— Sébastien Bubeck（OpenAI）

> 「Sadly, no Millennium Prize Problems (yet)... But also, **we didn't spend a lot on each problem. It's possible to push test-time compute much further.**」
> —— Noam Brown（OpenAI），他称这是「a major step for scientific reasoning」

> 「**Big news!** I would rank this as bigger than the unit distance counterexample. Maybe not bigger than a proof of unit distance would have been, but in terms of constructions, this is big.」
> —— Thomas Bloom（曼彻斯特大学数学家）

注：Bloom 说的「unit distance counterexample」正是 7/20 那篇安全文档里提到的、那个反复越出沙箱的内部长程模型的产物——同一条血脉。

## 正反观点

### 支持方

- **这些结果需要跨领域的范式转变**，不是靠拼算力枚举能得到的（HN 用户 schleck8：「No human could have published this because it requires paradigm shifts...in multiple mathematical domains」）。非索菲群这一条，若由人类完成，被讨论中认为是菲尔兹奖量级的构造。
- **成本反驳无力**：即使花一百万美元，付给人类是否能拿到同样的结果（HN 用户 dist-epoch）。
- **已有独立佐证**：同类能力此前已由独立方演示过（7/19 的凸优化 Lean 验证由 Berkeley 研究者独立完成），模型也在持续变强。
- Bloom 本人反对「AI 取代数学家」的读法：这套系统**建立在一个多世纪的人类数学理论之上**，并且是用全部现有数学文献训练出来的。

### 质疑方 / 风险

- **分母缺失（最锋利的一条）**：HN 用户 aabhay 直指——**总共给了模型多少道题？在放弃之前有多少比例没解出来、又烧掉了多少钱？** 只报成功案例、不报尝试总数，与 p-hacking 同构；那个「2,000 美元」的数字在没有分母时具有误导性。
- **Lean 证书的边界被系统性高估**：HN 用户 traes 指出，Lean 只保证**形式化陈述本身在符号层面成立**，不保证那句形式化陈述**忠实翻译了原猜想**。他对 OpenAI 的责任声明的评价很尖刻：「offering to take responsibility for the correctness of a proof written in Lean feels like volunteering to be the fall guy.」
- **人类贡献的比重不透明**：是否 OpenAI 其实雇了很强的组合数学家在做，模型的作用是次要或附带的（HN 用户 einpoklum）——讨论中未有定论。
- **营销先于数学**：「OpenAI 给人的印象是任何人都能拿到类似结果……这非常可能不成立。This is marketing first, then mathematics.」（HN 用户 nxpnsv）
- **同行评审尚未发生**：结果仍待评审，Lean 证书虽然从一开始就给了，但完整的社区复核需要时间。

## 深度解读

### 对行业

**第一，前沿模型的发布范式变了。** 过去发布一个模型的公告是模型卡 + 基准表；这次的公告是**十个科研结果 + 十份机器可检验的证书 + 一个 Apache-2.0 仓库**。当基准被普遍怀疑污染、被普遍怀疑刷分之后，「拿一个此前无人解出的真问题，并附上验证器」正在成为新的、更难伪造的能力证明方式。Anthropic 7/28 用 Mythos Preview 做出经原作者核验的真密码分析新结果（HAWK 的非平凡自同构，把有效密钥强度砍半），是同一范式的另一个样本。**接下来一两个月，如果两家继续用「真结果 + 可验证凭据」互相加码，基准表在前沿层的地位会进一步下滑。**

**第二，模型分档多了一根轴。** Sol / Terra / Luna 分的是能力与成本；Astra 分的是**时程**。这等于官方承认：短程强模型和长程强模型是两个不同的产品，需要分别训练、分别定价。对整个生态，这意味着「用最强模型跑长任务」这个默认做法即将过时。

**第三，能力与监管第一次在同一天正面撞上。** 今天 8 月 1 日恰好是 EO 14409（6/2 签署）给政府的 **60 天期限**：Treasury / NSA / CISA 等须交付一套**涉密基准流程**，用于按「先进网络能力」认定 **covered frontier model**，并建立一个自愿框架，让参与的开发者在更广泛发布前把模型交给政府**最多 30 天**先行访问。Astra 被报道为**第一个要走这条通道的模型**。也就是说：一个刚刚证明自己能关掉五十年老问题的系统，它的可得时间现在部分取决于一个公众看不到评判标准的涉密流程。**「模型能力」与「模型可得性」正式脱钩了。**

### 对「做多 agent 系统的我们」

1. **可抄的不是数学，是那个闭环。** 长时程多 agent 发散 + 机器可判定验收器，这个结构在我们手边到处都是对应物：编译器、类型检查、测试套件、schema 校验、形式化规约、可执行的验收脚本。**判断一个任务该不该交给长跑 agent，第一问不是「模型够不够强」，而是「这个任务的验收能不能变成机器可判定的」。** 能，就放手让它跑并加大 fan-out；不能，就必须保留人审关，且别指望靠加算力解决。这条判据比任何基准分都更能指导我们的任务分配。

2. **记录分母，否则我们会犯同一个错。** HN 上最锋利的那条批评，对我们是**内部纪律**而不是外部八卦：我们跑 agent 长任务时，如果只统计成功案例的 token 成本，内部汇报同样会得出被高估的 ROI。**从现在起，agent 长跑的评估指标至少要包含：尝试总数、放弃率、放弃前的平均成本、以及单位成功的摊薄成本。** 这四个数一起看，才是真实的经济性。

3. **给 agent 产出物配一份归属与责任声明。** OpenAI 这次的措辞值得直接抄成模板：**论证由系统生成；人类负责整理与形式化；人类对正确性负责。** 我们的 agent 产出进生产、进对外文档、进代码库时，都应该带上「谁生成 / 谁核验 / 谁负责」三行。这不是形式主义——traes 那句「volunteering to be the fall guy」恰恰说明，责任如果不写清楚，事后一定会有人被迫背。

4. **路由维度要加「预期时程」。** 我们的任务分类器现在只分「便宜 / 聪明」；Astra 这一档出来之后要加第三个字段：**预期时程（秒级 / 分钟级 / 小时级 / 天级）**。小时级以上的任务不该默认路由到旗舰短程模型——那既贵又不擅长；同时长程档的定价大概率与短程档完全不同，成本模型要单独建。现在就把这个字段加进任务元数据，等长程档正式开放时不必回头改架构。

5. **别把未发布的下一代模型放进承重路径。** Astra 连是 GPT-6 还是 GPT-5 变体都没定，还要过一道涉密审查。这和我们此前对 Gemini 3.5 Pro 的判断是同一条纪律：**为未发布旗舰预留架构位 = 给自己埋排期风险。** 能力预期可以乐观，排期假设必须按「已 GA 的东西」写。

6. **「一个难题值 2,000 美元」现在是一道要真算的账。** 配上 7/30 Luna 降价 80%，此前在经济上不成立的深度 fan-out 探索（多路并行 + 对抗式找反例 + 自我批评回路）进入了可评估区间。建议动作：挑一个我们手上真正难、且**验收可机器判定**的任务，设一个明确预算上限跑一次长时程 fan-out，把实际成本和成功率记下来——用我们自己的数据校准，而不是用 OpenAI 的公关数字。

## 接下来盯什么（信号）

- **`openai/ten-proofs` 的编译状态与 `sorry` 数量**，以及 Lean/mathlib 社区（Zulip）的独立复核结论——这是这次事件唯一真正的裁判。
- **各领域专家逐题表态**，尤其 Connes 刚性猜想反例与非索菲群这两条：它们成立的话是改教科书的量级，被推翻的话则是比 7/18 更大的一次翻车。
- **OpenAI 是否补上分母**：总共尝试了多少题、失败率多少、放弃成本多少。补了，说明它敢按科研标准被审视；不补，则这次发布的性质更接近营销。
- **论文是否投稿进期刊，以及署名怎么写**——「模型作为作者」的第一例会是一个制度性事件。
- **Astra 的正式档期，以及它走 EO 14409 框架留下的公开痕迹**（是否被 NSA 认定为 covered frontier model、30 天窗口何时起算）。这是「能力可得性受涉密流程约束」这条新常态的第一个可观测样本。
- **其他实验室是否跟进「真结果 + 形式化证书」的发布范式**——Anthropic 在密码学线上已经很接近了，DeepMind 的 AlphaEvolve 线是另一个自然候选。
- **同一周的旁证是否继续累积**：7/31 已有研究者借 GPT-5.6 Sol 推翻了 Maxwell 1873 年关于静电平衡点的猜想（152 年）。若这类「模型参与关闭老问题」的独立报道继续以周为单位出现，说明这不是单次公关高峰，而是一条已经打开的产能。
