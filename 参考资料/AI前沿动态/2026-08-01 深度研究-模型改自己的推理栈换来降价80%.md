# 模型改自己的推理栈，换来降价 80%

**一句话定性：** 这是第一次，一家前沿实验室把「模型自己优化了自家推理栈」当作降价的公开归因写进价目表——递归自我改进从论文和安全叙事，落到了一张所有人都要重算的账单上。

**来源：** OpenAI 官方（价格公告 + 工程说明两篇）
🔗 原始链接：<https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6/>
🔗 工程细节：<https://openai.com/index/gpt-5-6-frontier-intelligence-efficiency/>
**日期：** 2026-07-30 生效（工程说明 7/29-30 发布），7/31 全网跟进

## 为什么值得深读

过去六周我们连续深挖过三件事：6/09 Anthropic 讲**递归自我改进**（概念与风险）、7/22 Gemini 效率层出货把战场从旗舰峰值搬到**单位智能成本**、7/25 Claude Opus 5 首次把旗舰发布的卖点从「最聪明」改成「逼近前沿的一半价格」。

这一次是三条线的交汇点，而且是最硬的那种交汇：**不是论文里的能力宣称，也不是营销口径的性价比，而是一张改了的价目表，以及一份说明「这笔钱是模型自己省出来的」的工程文档。**

对我们这种做多 agent 系统的团队，这件事有双重含义。近的一层：便宜档降价 80%，此前在经济上不成立的 fan-out / 多路投票 / 自我批评回路，现在可能成立了。远的一层：如果推理成本的改进有相当一部分开始由模型自己贡献，那么成本曲线的斜率不再只由硬件和人类工程师决定——这会改变追赶者的处境，也会改变我们对「明年的单价」做的任何假设。

## 核心事实

### 一、价目表（每百万 token，2026-07-30 生效）

| 档位 | 输入（原→新） | 输出（原→新） | 幅度 |
|---|---|---|---|
| GPT-5.6 **Luna** | $1 → **$0.20** | $6 → **$1.20** | **−80%** |
| GPT-5.6 **Terra** | $2.50 → **$2** | $15 → **$12** | −20% |
| GPT-5.6 **Sol**（旗舰） | $5（不变） | $30（不变） | 0% |

同期 API 上线 **Fast mode**（替代原 Priority Processing）：官方口径 Sol 档最高约 2.5 倍标准速度、2 倍价格——Sol $10/$60、Terra $4/$24、Luna $0.40/$2.40。

**注意这张表的形状**：降价全部发生在低价档，旗舰纹丝不动。这不是普降，是**在被挤压的那一段做防守性定价**。

### 二、OpenAI 给出的归因：模型自己改了四处

官方工程说明把「GPT-5.6 Sol + Codex 自主优化生产服务」拆成四个方向：

1. **负载均衡** —— 分析线上真实流量，识别 GPU 分配不均，自主测试新的路由策略；
2. **GPU kernel 重写** —— 用 **Triton 与 Gluon**（OpenAI 维护的两种开源 GPU 编程语言）重写生产 kernel，找出可预计算段落与可并行执行的机会 → 与其他 kernel 改进合计，**端到端服务成本降低 20%**；
3. **投机解码（speculative decoding）** —— 自主跑**数百次**架构实验重新设计自己的 draft model → **token 生成效率提升 15% 以上**；
4. **部署参数** —— 针对不同负载类型自动调优 batching、sharding 与 KV cache 参数。

两项主要增益（−20% 服务成本、+15% 生成效率）在同一套服务栈里复利，构成了这次降价的毛利空间。

该工程说明的署名作者中包含 **Philippe Tillet（Triton 的作者）**。

### 三、被大多数报道漏掉的两条

**（1）验证工具是配套的，不是可选的。** OpenAI 明确说投入了验证工具链来校验 Sol 写出的 kernel 是否正确，其中包括开源的 **FpSan（Floating-Point Sanitizer，浮点消毒器）**。

**（2）它顺手承认了自家评测分数有一大截来自 harness 配置。** 同批材料里，ARC-AGI-3 分数从 **13.3% 跳到 38.3%**——**不是模型变了**，而是打开了两个 API 设置：保留 reasoning message，以及对 token 做压缩而非截断。OpenAI 的措辞大意是：评测衡量的从来不只是孤立的模型。

同时公布的 Rust 版 **Agent Harness** 有两个可直接抄的设计：**Lazy Discovery**（不把工具一股脑塞进上下文，且工具输出硬上限 10,000 token）与 **Append Only**（只追加不改写，保住 prompt cache 有效性）。

### 四、内部数据（自报，且官方自己打了折扣）

OpenAI 称内部 token 用量增长 **22 倍**、研究员产出翻倍，但同一份材料里也承认，这**不能直接证明**研究速度按比例提升。

## 机制拆解：这算不算「递归自我改进」

先把定义摊开，因为这是所有争论的根。

- **「AI 加速 AI」** —— 模型作为工具，提升人类研发效率或系统效率。**这件事正在发生。**
- **「AI 造 AI」** —— 模型改写自己的架构、训练流程或权重，产生能力上的自我复利。**这仍是预测。**

这次的四项优化，**全部落在第一类**，而且全部是经典系统工程：kernel、投机解码、批处理、KV cache、路由。**没有一项触及模型架构或训练过程本身。** 所以严格说，这是「模型把自己跑得更便宜」，不是「模型把自己变得更聪明」。

但恰恰是这个「不够激进」的边界，让它成立。**为什么 OpenAI 敢让模型自主改生产 kernel，却不敢让它自主改训练流程？答案是裁决函数的成本。**

kernel 有一个近乎完美的性质：**生成很难，验证很便宜**。一个 kernel 写得对不对，可以用 FpSan 这类工具程序化地判；跑得快不快，可以直接测。数百次投机解码架构实验之所以能「自主」跑，也是因为每次实验的成败有一个不需要人判断的标量输出。

这条判据我们在过去一周已经连着记了三次：
- 7/28 Anthropic 密码学篇：真正的瓶颈是验证（生成 1 周 : 验证 1 个月）；
- 7/29 AlphaFold 解散篇：编排层范式成立的前提不是「通用模型够强」，而是「该领域有便宜的裁决函数」；
- 7/30 Gemini Robotics 2 篇：动作空间的维度必须由任务回报证明。

**这次是同一条定律的第四个实证，而且是正面的那种**——它告诉你，当裁决函数便宜到接近零成本时（编译器 + sanitizer + 基准测试），自主优化立刻就能规模化到生产环境。

## 正反观点

### 支持方：这是推理经济学的拐点

- **归因是具体的、可检验的**，不是「我们变高效了」这种空话：Triton/Gluon、投机解码 draft model、FpSan 验证工具、Triton 作者署名——每一项都能被同行拿去质问或复现。
- **客户侧有对照数据**：Notion 称 Terra 达到上代质量但成本减半、耗时少 60%；Dust 称 Luna 快 40% 且便宜 40%。
- **分析师认为降价是趋势不是促销**：InfoWorld 引述的判断是，未来 24 个月推理成本下降会在各家之间持续。
- **对开发者是真实解锁**：Luna 一档 100 万输入 + 100 万输出的成本，从 $7 掉到 $1.4。这不是省钱，这是**改变哪些架构值得做**。

### 质疑方：别把工程加速比读成能力起飞

- **定义之争**：这是「AI 加速 AI」，不是「AI 造 AI」。把两者混为一谈是目前最常见的误读。
- **边际递减**：自我改进未必复利。最容易摘的 kernel 果子摘完之后，第二个 20% 会比第一个 20% 难得多——它可能收敛，而不是发散。
- **商业动机可疑**：IPO 窗口（报道口径 9-11 月）在前，而在开源持续商品化的世界里，**说服市场相信递归自我改进临近，是维持定价权最有效的叙事**。这不代表事实是假的，但它意味着口径会被选择性呈现。
- **自家档案里的反证**：GPT-5.5 的 system card 曾自承模型在 OpenAI 自己的 RSI 内部基准上表现不佳。
- **Gary Marcus** 直接说 2027 的 RSI 时间线完全不可信，2030 也存疑。
- **真正的推手可能是竞争，不是技术**：据 36氪口径，7 月下旬中国模型占 OpenRouter token 量的 **66.5%**；DeepSeek V4 在 OpenAI 公告**同一天**发新版本，且此前已引入高峰/非高峰分时定价（V4-Pro 非高峰输入约 $0.435）——降价后 **Luna 的 $0.20 输入价已低于 DeepSeek**。降价是防守，技术归因是包装，两者可以同时成立。
- **财务侧的反问**：降价压缩的是自己的毛利。yellow.com 引述的分析警告，这会在 IPO 前拉紧财务；同一篇提到 **Uber 四个月就用光了 2026 年的 AI 预算**——需求侧的价格敏感是真实的，但供给侧能扛多久是另一回事。
- **无第三方复现**：22 倍 token 用量、研究员产出翻倍，全是自报，官方自己都不敢说等于研究速度翻倍。

## 深度解读

### 对行业

**第一，降价的形状比降价本身更有信息量。** 旗舰不动、低价档腰斩到脚踝，说明高端仍有定价权，被打穿的是**高吞吐量那一段**——那正是中国开源模型和 Gemini Flash 的主场。这是「效率层战争」在 7/22 Gemini 一次发三款独缺旗舰之后的第二次确认：**2026 下半年的竞争焦点不是谁最聪明，是谁在「够用」这个区间的单位成本最低。**

**第二，成本曲线的驱动因子结构变了。** 过去推理成本下降靠三样：更好的硬件、更好的人类系统工程、更大的规模摊薄。现在多了第四样，而且这第四样的产能可以用买 GPU 的方式扩张。这对追赶者不是好消息：**领先者不仅模型更强，连「把模型跑便宜」这件事也开始由更强的模型来做。** 这是一个温和但真实的正反馈。

**第三，它把「递归自我改进」这个词的政治含义拉进了商业现实。** 7/28 那份 1,273 人联署要求给「自动化 AI 研发」装刹车的声明，指的正是这一类循环。现在这个循环有了公开的、被 OpenAI 自己承认的商业实例——即便它今天只作用于推理效率。监管讨论会立刻拿它当锚点，而 OpenAI 的辩护会是「这只是编译器优化」。**两边都对，这正是接下来一年最难吵清楚的一块。**

### 对「做多 agent 系统的我们」

1. **立刻重算 fan-out 的账，但只在便宜档。** Luna 降 80% 意味着「并行开 5 个子代理各自尝试 + 一个裁决者」这类此前算不过来的结构，现在进入可行区。**具体动作**：把现有 pipeline 里被成本砍掉的分支（多路采样、自我批评轮、refactor-only 轮）拉出来重新估价，凡是单价敏感型的重新试跑一遍。

2. **但账要按 cost-per-completed-task 算，不是按单价。** 这是 7/25 Opus 5 篇和 7/28 SlopCodeBench 篇的合并结论：**单价降 80%，如果失败率上升导致重试翻两倍，你什么都没省。** 每个候选档位必须有自己实测的「端到端一次通过率」，而且要在没有针对性调优的任务集上测。

3. **把 harness 配置提升为评测报告的必填项。** ARC-AGI-3 那 25 个百分点是这次最便宜的一课：**同一个模型，改两个 API 设置，分数几乎三倍。** 如果我们的内部评测没有记录 reasoning message 是否保留、超长上下文是截断还是压缩、工具输出上限是多少，那我们的模型对比结论有相当概率在测 harness 而不是在测模型。**动作**：评测集加一份 harness 指纹，换模型时先冻结 harness 再比。

4. **抄那两条 harness 设计，今天就能抄。** 工具输出硬上限 10,000 token（防止一次工具返回冲垮上下文预算）+ append-only 上下文（保 prompt cache 命中）。后者与 7/29 MCP 新规范里 `tools/list` 确定性排序、`ttlMs` 缓存是同一个杠杆——**这是零成本的成本优化，不需要换模型。**

5. **把「有没有便宜的 sanitizer」写进自动化决策清单。** OpenAI 敢让模型自主改 kernel，是因为有 FpSan + 基准测试构成的近零成本裁决层。**反过来问我们自己**：准备交给 agent 自主迭代的每一类改动（SQL、配置、schema、prompt、基础设施），有没有一个等价的、判一次远便宜于生成一次的验证器？没有的话，那块就不该无人值守，无论模型多强。这条判据现在已经连着四篇成立，可以当作稳定原则用了。

6. **把单价当变量而非常量写进系统。** 三周内一个档位价格砍掉 80%，说明任何写死在代码、成本模型或对外报价里的 token 单价都会过期。**动作**：单价进配置；每月重跑一次「成本-质量前沿」并允许路由默认值随之改变；给客户的成本承诺留下重新定价的口子。

7. **供应商的成本结构改善 ≠ 你的成本改善。** Sol 没降价这件事要读进去：**降价发生在竞争最激烈的地方，不发生在你最依赖的地方。** 如果关键链路吃的是旗舰档，这次降价对你是零。冗余与多模型路由的逻辑不因这次降价而放松。

8. **别据此调整对能力时间线的判断。** 这次的一切都发生在「生成难、验证便宜」的窄区间里。它证明的是这类问题可以规模化自动化，**不证明**模型能自主推进能力边界。我们的产品路线图不应该因为这条新闻而假设明年会有能力跃迁——应该假设的是**成本会继续掉，而竞争节奏会继续加快**。

## 接下来盯什么

- **跟进降价**：Google（Gemini Flash / Flash-Lite）与 Anthropic（Haiku 档）30 天内是否跟。跟了，说明效率层价格战全面开打；不跟，说明各家毛利结构差异比想象大。
- **Sol 档是否降**：降价传导到旗舰，才说明推理成本地板真的结构性下移，而不只是低端促销。
- **可复现性**：OpenAI 是否给出可复现的 kernel 性能基准，或把 FpSan 之外的验证方法开源。这决定「模型自己优化」是可审计的工程事实，还是只能信其自报。
- **拆分归因**：那 20% 的服务成本下降里，模型贡献了多少、人类工程师贡献了多少。官方至今用的是合并口径。
- **22 倍 token / 产出翻倍**是否有任何第三方或离职者口径的交叉验证。
- **中国侧回应**：DeepSeek / Moonshot / Qwen 是否跟进降价，以及 OpenRouter 上 66.5% 的 token 份额是否因这次降价而反转——这是判断「降价到底是技术红利还是竞争被迫」最直接的读数。
- **下一步边界**：OpenAI 是否宣布让模型参与**训练栈**（而不只是推理栈）的优化。那才是「AI 加速 AI」跨到「AI 造 AI」的门槛，也是 7/28 联署真正想踩刹车的地方。
- **监管引用**：这次的自优化循环是否被写进白宫前沿 AI 框架或 AI Kill Switch Act 的听证材料。
