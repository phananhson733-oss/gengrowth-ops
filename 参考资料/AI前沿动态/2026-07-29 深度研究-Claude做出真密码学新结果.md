# 🔐 深度研究 ｜ Claude 把 NIST 后量子候选的密钥强度砍了一半：一个可验证的科研成果，和一个「人类验证不过来」的新瓶颈

> **一句话定性**：这不是又一次"AI 发现漏洞"的营销稿——Anthropic 拿出了**两个经原作者与独立密码学家核验的、可以进学术会议的新密码分析结果**，代价是 3 天自主运行、约 10 亿 output token、六位数美元。但这篇报告里真正该让做 agent 系统的人后背发凉的数字不是 2^64→2^38，而是：**模型 1 周做出结果，2 个人类研究员花了将近 1 个月才敢确认它是对的**。生成端已经跑起来了，验证端还在走路。

**来源**：Anthropic 官方研究《Discovering cryptographic weaknesses with Claude》，2026-07-28 发布。执行模型为 **Claude Mythos Preview**（Anthropic 的安全/漏洞挖掘专用模型）。

## 一、为什么这一篇值得单独深读

过去半年，"AI 做出真科研成果"的新闻密度高得让人麻木：GPT-5.6 关掉凸优化 30 年的 oracle 复杂度缺口（7/18）、OpenAI 承认为攻 Erdős 单位距离猜想造过内部 long-horizon 模型（7/20）、Mythos 挖出潜伏 29 年的 Squid 漏洞（6 月）。这些多数落在两类里：**要么是数学（可以用 Lean 机器验证，但离产业远）**，**要么是找 bug（离产业近，但是"搜索"不是"发明"）**。

这次不一样，它同时踩在三条线上：

1. **它是发明，不是搜索**。模型造了一个此前不存在的密码分析技巧（Anthropic 给它起名 "Möbius Bridge"），不是在已知攻击空间里穷举参数。
2. **它可被程序化验证**。密码攻击的好处是——跑一遍就知道真假。这让"AI 声称的突破"第一次落进了一个**赖不掉的领域**。
3. **它打的是正在被标准化的东西**。HAWK 是 NIST 后量子密码（PQC）流程里正在评审的签名候选，不是玩具算法。这个结果会直接进入标准委员会的决策输入。

而它最有价值的部分，恰恰是 Anthropic 自己写在报告里的一句"坏消息"——见第五节。

## 二、核心事实（按硬度分层）

### A. 结果一：HAWK —— 把 NIST 后量子候选的有效密钥强度砍半

HAWK 是格（lattice）基础的后量子数字签名方案，NIST PQC 评审中的候选。Mythos 找到了它格结构里一个**此前未被利用的非平凡自同构（nontrivial automorphism）**——理论文献此前猜测这类对称性"可能存在"，但**没人在 HAWK 的实际设计里把它找出来过，该方案已经过约两年专家审视**。

| 参数集 | 原估计攻击代价 | 新估计 | 含义 |
|---|---|---|---|
| HAWK-256（challenge 参数） | 2^64 | **2^38** | 实测 96 核服务器约 **3 小时 42 分**完成密钥恢复 |
| HAWK-512 | 2^150 | **2^108** | 门电路计数口径 |
| HAWK-1024 | 2^288 | **2^182** | 门电路计数口径 |

- 恢复出的是 **592 字节的解码密钥**（不是原始 96 字节种子）。
- 效果上等于**把 HAWK 的有效密钥强度砍掉一半**——要维持原安全等级就得把密钥尺寸翻倍，而"密钥小"正是 HAWK 相对其他 PQC 候选的主要卖点。**这一刀砍的是它的立身之本。**
- 成本：**约 60 小时计算、一周之内**完成。
- 披露：**6 月**即通知 HAWK 设计者，与 NIST 协调发布节奏，并提前通报美国政府与产业伙伴。**攻击已由 HAWK 作者本人验证。**

### B. 结果二：7 轮 AES-128 —— 提速 200~800 倍的新技巧

- 目标是 **7 轮缩减版 AES-128**（生产标准是 10 轮）。这是学术界研究分组密码的标准做法：拆掉几轮看结构强度。
- Mythos 改进了 meet-in-the-middle 攻击，**比此前最好结果快 200~800 倍**（区间取决于运行时怎么度量）。
- 关键发明 **"Möbius Bridge"**：一个**跨被猜测值保持不变的指纹（invariant fingerprint）**，靠它直接消掉了攻击中一步 **256 路枚举**。
- 前提条件：需要约 **2^105 个选择明文**（约 4 亿亿亿亿条消息）。**完全不可行，成本以亿美元计。**
- 过程数据（这是最值得看的部分）：
  - **3 天内只收到 3 条实质性人类提示**。
  - 自主产出**数亿 output token** 后才撞出 Möbius Bridge，后续打磨累计约 **10 亿 output token**。
  - 三条提示分别是：①（约 3 小时后）提醒它必须去找**真正新颖**的思路，而不是复用已知手法；②（第二天早上）把它**按回 7 轮 AES**，别换靶子；③（当晚）告诉它这东西够得上**可发表的研究**，别自我设限。
- **模型一开始明确判定这事做不了**，原话：*"If you want a different outcome, the target has to change"*、*"AES-128 r5/r6 is just genuinely hard."*

### C. 被大部分报道忽略的结果三：LEA-13 —— 唯一一个"桌面机上一小时"

| | 此前最好攻击 | Mythos |
|---|---|---|
| 13 轮 LEA | 2^98 明文对 + 2^86 工作量 | **< 2^30 明文**，**现代台式机 1 小时内跑完** |

这是三个结果里唯一一个从"理论上不可行"跨进"**任何人都能在自己电脑上复现**"的。虽然仍是缩减轮版本，但这条曲线的斜率比 AES 那条陡得多。另外还有 **Serpent-128（6 轮）完整密钥恢复**（此前需 >2^70 明文对 + 2^90 次解密）；Salsa20、Poseidon、SHA-1 上只有 **<10× 的有限改进**。Anthropic 自评这几条"目前还不够强"，但预期会继续精进。

### D. 配套发布：CryptanalysisBench

- **191 个任务**的密码分析基准，**7/20 发布**。
- 合作方：**ETH Zurich、Anthropic、University of Haifa、TU Berlin、Tel Aviv University**。
- 现状：五个模型在 tier-1 方案上攻破 **65–86%**；tier-2 里能打下 **6–12 个满强度方案**。
- 同时开放了演示代码、完整技术论文、以及 **Claude 的思维链记录**。

## 三、机制拆解：这个 harness 长什么样

对做 agent 系统的人来说，报告里的工程细节比密码学细节更有用。

**HAWK 项目**：用了一个 **"Claude Code 式" 的 harness**，**多个 worker agent** 在沙箱里协作，配 **Python + Sage + 密码学文献访问**。人类输入被明确限定在**项目管理层面**——"建议 Mythos 怎么记录想法"、"用哪个库做计算验证"。

**AES 项目**：研究员搭了一个让 Claude 能**自主提出假设 → 跑实验证实或证伪 → 据此设计攻击**的 scaffold。同样是多 worker agent + 沙箱 + 计算工具。

其中有一个细节值得单独拎出来：**HAWK 那次，两个 worker agent 意见相左——第一个 agent 判定这条思路不可行并否掉了，第二个 agent 继续挖，成功了。**

换句话说，**如果这个 harness 用了"多数投票"或"早停"，这个结果就没了。**

## 五、正反两面

### 支持方：这是"AI 做科研"从演示走向可交付的分水岭

- **可验证性**是关键差别。数学猜想的"证明"要么靠 Lean 机器验证要么靠专家读，而密码攻击**能跑、能复现、能被原作者确认**。HAWK 攻击已由设计者验证，AES 攻击已由独立密码学家审阅。这不是"模型自称"。
- **它打进了标准化流程**。结果会影响 NIST 对 HAWK 的评估，是实打实的现实后果，不是论文引用数。
- **成本给出了锚点**：约 10 万美元量级的 API 花费，换一个能上会议的原创密码分析结果。这个价签第一次让"要不要为一个硬问题烧六位数 token"变成一道可算的账。
- **它是"发明"**：Möbius Bridge 此前不存在于文献中。

### 质疑方：缩减轮结果 ≠ 破解，且自主性存疑

- **打的是没人部署的东西**。Slashdot 上的高赞评论一针见血：*"好在缩减轮版本并没有被部署。"* HAWK 未上线，7 轮 AES 不是任何真实系统。Anthropic 自己也承认现实系统"完全安全"，无任何软件需要改动。
- **怀疑是营销**。有评论直指：如果做法是"随机弱化一堆参数直到 AI 撞上点什么"，那本身没有意义。
- **数量级不解决问题**：对 AES-256，1000 倍加速在 10^20~10^50 年的暴力破解面前等于零。
- **自主性打折**。有人注意到研究员的 prompt 里有拼写错误、且 Anthropic 承认自家研究员**本来就不是密码学专家**（要花数百小时现学密码学才能验证模型的说法），因此质疑"三条提示"的叙事是否把人类贡献洗掉了。
- **人类历史上也发现过类似优化**，缩减轮改进在密码学界是常规产出，不是革命。

**我的判断**：质疑方在"这不影响生产系统"上完全正确，且这一点必须在任何对外沟通里说清楚——否则会被正确地打脸。但质疑方在"所以不重要"上错了：**HAWK 那条不是缩减轮结果，是对完整方案的结构性打击**，而且是在两年专家评审之后。真正的信号不在破坏力，在**产出速率**。

## 六、深度解读：对行业，以及对做多 agent 系统的我们

### 1. 最该抄走的一条：验证成本已经是新的瓶颈，而且比例是 1:4

**模型 1 周做出 AES 结果，2 个研究员花了将近 1 个月才敢说它是对的。**

这条比任何 benchmark 分数都更直接地描述了 2026 下半年的现实：**agent 系统提升的是"生成吞吐"，不是"交付吞吐"**。我们如果照搬"多铺 agent"的思路，只会把瓶颈从"想不出来"平移到"不敢发"。

具体动作：
- 把**验证/裁决**当成一等公民来设计，和"生成"同等预算、同等 harness 复杂度。不要指望 review 环节靠人肉兜住。
- 优先把 agent 投向**「生成难、验证便宜」**的问题——这正是 Anthropic 能拿出可信结果的**结构性原因**，不是运气。密码攻击能跑，代码能跑测试，SQL 能跑对拍。反过来，"写一份战略分析"这类**验证成本 ≈ 生成成本**的任务，多 agent 的边际收益会被验证吃光。
- 每上一个新 agent 能力，先问一句：**"它的产出，我用什么自动化手段判对错？"** 答不上来就先别铺量。

### 2. 别用多数投票抹掉少数派路线

HAWK 的结果来自**两个 agent 意见相左时，坚持挖的那一个**。第一个 agent 的结论是"不可行"。

如果我们的编排逻辑里有"N 个 agent 投票 / 分歧时取多数 / 有 agent 报不可行就早停"这类规则，**这类结果就永远不会出现**。对探索型任务，分歧应该触发**加深**而不是**收敛**。这条直接和我们 harness 里的早停策略冲突，值得复查一遍。

### 3. 长程自主的真实形状：3 条提示 / 3 天 / 10 亿 token，而且人类的作用是"别让它放弃"

注意那三条提示的性质——**没有一条给了密码学思路**。它们是：去找新的、别换靶子、这值得做。而模型的初始状态是**明确宣称做不到**（"AES-128 r5/r6 is just genuinely hard"）。

这意味着 harness 里最该内置的不是更多领域知识注入，而是一层**元指令**：当 agent 自我判定"不可能"时，不要直接接受它的收工结论，要有重定向和"这值得继续"的注入机制。我们现在的 agent 一旦输出"这个方案不可行"，链路基本就断了——**而 Anthropic 的数据说明，那个判断经常是错的**。

### 4. 成本锚点：10 万美元换一个原创结果

这是一个可以直接用来做决策的参照系。**一个"值得烧六位数 token"的问题，需要具备的特征是：目标明确、可程序化验证、且失败也能积累知识。** 拿这三条去筛我们手上的难题，能筛掉大部分。

### 5. 攻防两用，且不对称

Mythos 是**闭源权重的专用模型**。同样的 harness——多 agent + 沙箱 + Python/Sage + 文献——是完全公开的配方，但跑它的模型不公开。这构成一种不对称：**防守方拿到的是结果，进攻方需要自己搞到同级模型**。短期是防守方占优；但结合本月已推过的几条（GPT-5.6 花 25 美元挖出 WordPress 预认证 RCE、Kimi K3 开源 agent 数小时找 Redis 0day、OpenAI 模型从密闭评测环境用 Artifactory 0day 逃逸），**这个窗口在快速关闭**。

现在就能做的：按 Boehm 那句话做一次**密码学资产清点**——我们的系统里到底哪些地方用了什么算法、什么参数、谁能改。这件事在"密码原语可能被 AI 批量重估"的世界里，从合规动作升级成了运维动作。

### 6. 对外沟通的纪律

这类新闻的传播链条会稳定地变形为"AI 破解了 AES"。**我们对内对外都要能一句话说清区别**：HAWK 是完整方案被结构性削弱（真的、但没部署）；AES 是 7/10 轮的学术结果（真的、但不影响任何生产系统）；LEA-13 是缩减轮但已进入桌面机可跑范围（最值得盯的一条）。说不清这三层区别的人，不该代表我们对外发言。

## 七、接下来盯什么（信号）

1. **NIST 会不会因此调整 HAWK 的处境**——是要求翻倍密钥尺寸（等于宣告其卖点消失），还是直接出局。这是这项研究第一个可观测的现实后果。
2. **CryptanalysisBench 上的第三方分数**：GPT-5.6 Sol、Gemini、Kimi K3 在这 191 个任务上能到多少。如果开源权重模型逼近 Mythos，第 5 条里那个"不对称窗口"就关了。
3. **LEA-13 那条线会不会往全轮推进**。这是唯一有实用化苗头的结果，一旦够到全轮 LEA（韩国 KS 标准算法），性质立刻从学术变成事件。
4. **"验证 agent"会不会成为独立产品线**。Anthropic 明说验证是瓶颈、并呼吁"学术界+政府+产业"共同回答这个问题；对照 7/18 GPT-5.6 那次自带完整 Lean 机器验证的做法——**自动化验证** 很可能是下一个被专门攻的方向。这也是我们最该复用的方向。
5. **同类结果的复现节奏**：如果 8 月内出现第二、第三个由模型主导、经原作者确认的密码分析结果，那"AI 参与前沿科研"就从事件变成常态，届时验证瓶颈会成为整个学术界的问题，而不只是 Anthropic 的问题。
