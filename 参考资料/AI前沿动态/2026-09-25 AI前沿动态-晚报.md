# 深度研究 · Anthropic 花 116 亿美元买的不是 GPU，是 CPU——agent 时代的算力账单换了主角

> **一句话定性**：Akamai 与 Anthropic 签下公司史上最大合同：7 年、116 亿美元，**全部是 CPU 算力**，另有 90 亿美元扩容选项，并附带最多约 5% 的 Akamai 股权。这是头部实验室第一次公开地、成规模地为「非 GPU」算力下长约。背后的原因是 agent 负载的瓶颈正在从 GPU 转向 CPU：工具调用、沙箱、代码编译测试、RL 环境都跑在 CPU 上。**对做多 agent 系统的团队来说，这意味着「每个任务的成本」里，沙箱和工具执行这一项会从零头变成主项。**

**来源**：Akamai 官方新闻稿 + 9/24 17:30 ET 投资者电话会（Tom Leighton / Ed McGowan），另参考 The Next Web、Runtime Wire、TrendForce、Pragmatic Engineer 等
🔗 原始链接：https://www.akamai.com/newsroom/press-release/akamai-announces-11-6-billion-multi-year-agreement-with-anthropic-to-support-growing-demand
📅 发布：2026-09-24 16:01 ET（北京时间 9/25 凌晨）

## 为什么值得深读

过去两年，AI 算力新闻几乎都在讲 GPU：谁拿到了多少 H/B 系列卡、多少 GW 的数据中心。这笔交易有三点不同：

1. **买的是 CPU，不是 GPU。** 新闻稿原文是「support Anthropic's accelerating CPU workload demands」。Runtime Wire 也专门指出，这笔交易是「general computing capacity, not a commitment to GPU training capacity」。
2. **卖方是 Akamai，一家 CDN / 边缘网络公司，不是超大云厂商。** 新闻稿强调它的是「a continuum of compute from core to edge」。
3. **供应商拿股权换需求锁定。** 以往的算力换股权交易，多数是实验室拿股权去换芯片。这次反过来，由供应商把自己的股权给了客户。

三点放在一起看，说明 **agent 负载正在改变 AI 基础设施的结构**。上游这一变化最终会落到每一个跑 agent 的团队的账单上。

## 核心事实

### 合同本身
| 项 | 数字 | 出处 |
|---|---|---|
| 基础承诺 | **116 亿美元 / 7 年** | 新闻稿 |
| 扩容选项 | 最多再加 **90 亿美元**，同一期限内；合计约 **200 亿美元** | 新闻稿 |
| 负载类型 | **全部 CPU**（Akamai 其他新签大单是 CPU + GPU 混合） | 新闻稿；电话会 |
| 在 Akamai 的地位 | **公司史上最大合同** | 多家报道 |
| Anthropic 高管引语 | **新闻稿里没有** | 新闻稿 |

### 认股权证（这是结构上最特别的部分）
- 最多约 **770 万股**（按转换后计算），约占 Akamai 已发行普通股的 **5%**。行权价 **111.33 美元**，形式为无投票权、可转换的 Series B 优先股（据 TNW）。
- 约 **2%** 与 116 亿美元的基础承诺挂钩；其余约 **3%** 随扩容逐步归属，**每多采购 30 亿美元，约归属 1%**。
- Leighton 在电话会上估算，这份认股权证按行权价计算「a little over **$150 million**」，而整笔交易价值 116 亿美元。
- 这是 Akamai **第一次在云客户交易里发行认股权证**。Leighton 的说法是：「It's a serious step, but I think in this case it made sense.」

### Akamai 的投入和收入节奏（电话会 CFO Ed McGowan）
- **Capex 约 55 亿美元**，分三年投：**2026 Q4 约 17 亿**（主要是供应链和**提前采购内存**）、**2027 年约 31 亿**、**2028 年约 7 亿**。TNW 的说法是，这相当于 Akamai 2025 年全年 capex 的约 6 倍。
- 收入节奏：**2026 年零收入**，**2027 年 1.5–3 亿美元**，**2028 年底完全爬坡**，之后年化约 **17 亿美元**。
- 利润测算：每 MW 约 **300–400 万美元**（McGowan 的口径），经营利润率「about 30% or so」。McGowan 对 CPU 经济性的原话是：「CPUs have a different dynamic… you can get a lot more CPU, therefore generally more revenue per dollar of megawatt of power」。
- 部署地点：「The majority of all of this… is in the U.S.」
- 排他性：「No limitations at all」，Akamai 仍会与所有主要 AI 厂商和超大云厂商合作。
- 市场反应：盘后股价最高涨约 **17%**，到 **129.60 美元**（TNW）。

### 放在 Anthropic 的算力版图里看
- 据 The Information 9/6 的报道（经 TFTC 转引），Anthropic 在这笔交易之前已签下约 **5170 亿美元、14.8 GW** 的算力承诺，包括 AWS 约 1000 亿、Broadcom 约 630 亿、Fluidstack 500 亿、Nscale 450 亿、SpaceX 450 亿、Lambda/Nvidia 350 亿等。
- 换句话说，116 亿美元在总盘子里只占约 2%，**金额本身不是重点，重点在于买的是什么（CPU）、跟谁买（边缘网络公司）、怎么付（股权绑定）。**

## 机制拆解：为什么 agent 会把 CPU 吃光

**1. 一次 agent 任务里，GPU 只负责「想」，其余的「做」大多在 CPU 上。**
一个 coding / research agent 的一轮循环是：模型出 token（GPU）→ 解析工具调用 → **在沙箱里执行命令、编译、跑测试、抓网页、查数据库（CPU）** → 把结果塞回上下文（GPU）。TrendForce 引用的研究显示，在 agent 系统里，**CPU 侧的工具处理最多可占总延迟的 90.6%**。会话越长、循环次数越多，CPU 消耗就越高，而且这部分和模型本身的推理效率关系不大。

**2. RL 训练同样依赖 CPU。**
用 RL 训练 agent 时，每一步动作都要在真实环境里执行并评估：起容器、跑测试、打分。前沿实验室已经在和云厂商抢普通的 x86 服务器（TrendForce、Pragmatic Engineer 都提到了这一点）。Anthropic 最近的 Opus 5.5、Mythos 5.1 都主打长时程 agent 能力，这类能力的训练就是 CPU 密集型的。

**3. 行业比例正在被改写。**
- TrendForce 的数据：传统 AI 数据中心的 CPU:GPU 比例约为 **1:4 到 1:8**，agentic 时代可能走向 **1:1 到 1:2**。
- Arm 的估算：每 GW 需要的 CPU 核数从约 **3000 万**增加到约 **1.2 亿**，是原来的 4 倍。
- Pragmatic Engineer《The Pulse》：CPU 现货实例原来能打到约 90% 的折扣，**现在这种折扣基本没了**；新的预留要**提前 12 个月以上**规划；服务器交付周期从 1–2 周拉长到约 6 个月；价格上涨 10–20%。turbopuffer CEO Simon Eskildsen 的原话是「Getting CPUs is not easy anymore」。

**4. 为什么选 Akamai？（推断，未经官方确认）**
- 超大云厂商自己的 CPU 也在限量分配，Anthropic 需要一个**愿意为它专门扩产的第二供应商**。Akamai 为此提前采购内存、投 55 亿美元 capex，本质上就是「专门为一个客户建厂」。
- Akamai 的强项是分布式网络：「thousands of locations for function as a service… dozens of core regions」。**把工具执行、网页抓取、沙箱放在离用户和目标站点更近的地方**，可以降低 agent 每轮循环的网络延迟。不过电话会上列举的用例（语音客服 agent、翻译、字幕、图像生成）是 Akamai 平台层面的通用例子，**没有明确说是 Anthropic 的具体负载**。Anthropic 实际拿这些 CPU 跑什么，目前没有公开。

## 正反观点

**支持方 / 看多**
- eMarketer 分析师 Jacob Bourne 认为，这份潜在股权是对「AI 驱动的云需求具有持久性」的信任票，基础设施投资正在为越来越算力密集的 agentic 负载扩张。
- 对 Akamai 来说，CPU 负载每 MW 的收入更高、经营利润率约 30%，并且不用去跟超大云厂商比拼 GPU 采购能力。这是一个**差异化的切入口**。
- 对 Anthropic 来说，CPU 供应分散到多家，降低了对 AWS / GCP 在 CPU 分配上的依赖；股权又让它分享供应商增长的收益，一定程度上对冲了算力价格上涨。

**质疑方 / 风险**
- **循环交易**：华尔街已经在担心所谓「circular AI deals」，即买卖双方互相持股，使得「真实的 AI 需求更难衡量」（Reuters / TNW）。Akamai 用股权换订单，正好落在这个担忧上。
- **单一客户集中度**：Crypt0's News 的评论是「building factories for a single customer and handing that customer a slice of the factory」。55 亿美元 capex 押在一个 2026 年零收入、2028 年才完全爬坡的客户身上。
- **信息缺口**（Runtime Wire）：服务起始日期、具体 CPU 容量、负载分配、部署地点都**没有披露**。
- **资金来源**：TFTC 指出，Anthropic 5000 亿美元级别的算力承诺属于「credit-expansion-funded buildout」，靠外部资本和未来收入预期支撑，而不是当前现金流；并称 2026、2027 年各亏约 110 亿美元（该数字为 TFTC 转述，未经一手核实）。如果 agent 收入增速放缓，这些长约就会变成负担。
- **反向论证**：如果 CPU 真的这么紧，更合理的做法是提高 CPU 利用效率（沙箱快照 / 回滚、轻量 VM、WASM），而不是只靠多买。长约很可能在 2028 年前后被技术进步部分抵消。

## 深度解读：对行业 + 对「做多 agent 系统的我们」

### 对行业
1. **「算力 = GPU」这个说法开始过时。** agent 负载把 CPU、内存、网络重新变成了约束条件。之后值得跟踪的指标，除了 GPU 数量，还有**每 GW 配多少 CPU 核**、**沙箱容量**、**工具执行延迟**。
2. **第二梯队云厂商有了切入点。** Akamai、Cloudflare、Fastly 这类有分布式网络的公司，可以在「agent 执行层」和超大云厂商竞争，不需要去抢 GPU。
3. **供应商开始用股权换需求。** 以后更多供应商可能用认股权证去争取头部实验室的长约，财报里的「AI 需求」会越来越难分辨真假。

### 对我们（具体、可执行）
1. **每个任务的成本要把 CPU 算进去。** 现在大多数团队只按 token 算 agent 成本。建议从下个迭代开始，**给每条 trajectory 记录沙箱秒数、容器启动次数、工具调用的 CPU 耗时**，和 token 成本一起记账。如果 CPU 侧超过总成本的 20–30%，优化重点就应该从 prompt 转到执行层。
2. **别把便宜的现货实例当成默认条件。** 自托管沙箱、CI 评测机、RL / eval 环境如果依赖 spot 实例，要准备最多 6 个月交付周期和 10–20% 涨价的预案。**评测和回归跑批的算力预留应该提前一个季度锁定。**
3. **减少每次任务消耗的 CPU。** 具体做法：
   - 预热容器池和复用沙箱，不要每轮都冷启动；
   - 用快照 / 回滚（参考 DeltaBox 这类毫秒级 checkpoint 方案）代替重建环境；
   - 测试只跑受影响的部分，不要每步都跑全量测试；
   - 多个子 agent 共享只读依赖层。
   这些做法在 CPU 紧张的环境里，效果会比换一个更便宜的模型更明显。
4. **托管沙箱的价格和限流会跟着 CPU 走。** Claude Code 云会话、Codex 云任务这类托管执行产品，**价格和限流很可能跟随上游 CPU 成本调整**。在关键链路上保留「本地 / 自有沙箱」这条退路，不要把 agent 执行层绑定在单一托管方上。
5. **多 agent 编排的主要成本在循环里。** 并行 fan-out 的子 agent 越多，CPU 峰值越尖。编排层要有**并发配额和排队**，按 CPU 预算限流，不能只按 token 限流。

## 接下来盯什么
- **Anthropic 是否披露这批 CPU 的用途**（托管 agent 执行 / Claude Code 云会话 / RL 环境）。如果是云会话，托管产品的定价和配额很可能会调整。
- **是否扩容 90 亿美元**：每 30 亿美元归属 1%，可以通过 Akamai 季报和 8-K 跟踪。这是衡量 agent CPU 需求是否真实的一个硬指标。
- **OpenAI / Google 是否跟进签类似的纯 CPU 长约**，以及 Cloudflare、Fastly 等是否拿到同类订单。
- **CPU 价格和交付周期**：AMD Venice、Intel 18A Clearwater 的量产节奏，以及超大云厂商 CPU 实例的价格变化。
- **Akamai 2027 年收入是否落在 1.5–3 亿美元区间**：这可以直接检验「循环交易」的质疑是否成立。
