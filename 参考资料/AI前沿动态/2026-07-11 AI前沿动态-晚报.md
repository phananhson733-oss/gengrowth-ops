# Meta Muse Spark 1.1：全球最大『开源旗手』首次对模型直接收费

**一句话定性**：Meta 把最强能力彻底转入**闭源 + 付费 API**，第一次以「收费的前沿模型供应商」身份与 OpenAI/Anthropic 同台竞价——曾经用免费开源换生态的最大金主亲手为「免费时代」画上句号，前沿开源的重心进一步东移。

## 为什么值得深读 / 背景

过去两周这个监测的主线是「前沿能力边境武装化」（出口管制/Trusted Access/门控）与「效率拐点」（DeepSeek 降 90%/自研硅）。Muse Spark 1.1 看似只是「又一个模型发布」，但它触动的是一个我们**反复当作架构底线**的假设：**开源权重 = 抗单边下线/抗厂商断供的业务连续性保险**。

这份保险最大的历史提供方是 Meta——是 Llama 用「免费开放」把开源社区养成气候。而 7/9 这一天，Meta 首次**对模型直接收费**，把最强能力关进闭源付费 API。这不是「又一个模型」，是一家公司商业模式与开源理想主义的**范式反转**，也是资本压力传导到「最后一个免费玩家」的标志性节点。对做多 agent 系统的团队，它同时改写了「多模型热切换名册」和「开源 fallback 供给侧」两张牌。

需要先厘清一个易混淆点（避免夸大）：
- **Meta 首次闭源** ≠ 本次新闻。那发生在 **2026-04-08**：Meta 同日双轨发布 Llama 5（开源权重）+ 初代 Muse Spark（闭源，即内部代号 Avocado），首次拆分开/闭源策略。
- **本次（7/9）真正的新转折** = Muse Spark 从「闭源但仅经自家 App 自用」升级为 **Muse Spark 1.1 + Meta Model API 付费公测**——Meta 第一次**把模型当商品卖**，正式成为付费模型供应商。这是从「闭源」到「闭源且商业化」的质变。

## 核心事实（硬数据分层）

**产品 / 定位**
- Muse Spark 1.1：出自 Meta Superintelligence Labs 的**多模态推理模型，为 agentic 任务打造**。
- **Meta Model API 公测**——Meta **首个付费/商业模型**；美国 only，**无 EU**；Preview 状态（定价/限额/可用性可变）。
- 闭源 / closed weights，只经 Meta apps（Meta AI app「Thinking」模式、meta.ai）或付费 API 访问。
- 早期伙伴：**Replit、Cline、Box**（企业/开发工具侧）。
- 扎克伯格**时隔三年重返 X** 亲自发布=高层重视信号。

**定价（极具攻击性）**
- **$1.25 / 百万输入 token｜$4.25 / 百万输出 token** + **$20 免费额度**。
- Meta 自述「**比竞品便宜 10 倍、快 2 倍**（10x cheaper and twice as fast）」。
- 横向对照（均有据）：GPT-5.6 Terra $2.5/$15、Luna $1/$6；Claude Sonnet 5 基线 $3/$15；GPT-5.5 ≈ $5/$30。Muse Spark 1.1 卡在**中低价带**，输出价尤其便宜。

**能力（全部为 Meta 自报，对照数字亦由 Meta 提供）**
- 领先项（tool-use / 编排是强项）：
  - **JobBench**（专业工具使用）**54.7** vs Opus 4.8 48.4 / GPT-5.5 38.3
  - **MCP Atlas**（规模化工具使用）**88.1** vs Opus 4.8 82.2
  - **Humanity's Last Exam**（带工具推理）**62.1**
- 落后项（编码不是强项）：
  - **SWE-Bench Pro** 61.5 vs Opus 4.8 **69.2**（但 > GPT-5.5 58.6）
  - **DeepSWE 1.1**（长程编码）53.3 vs GPT-5.5 **67.0**
  - **BabyVision**（多模态）76.3 vs GPT-5.5 **83.6**

**Agent 原生特性**
- **1M 上下文 + active compaction**（模型主动压缩/管理上下文）。
- 多模态：**图像 / 视频 / 文档单次调用**入。
- **native tool integration + structured output + parallel tool calling**。
- 编排能力：能「gather context, make a plan, and delegate execution across **parallel subagents**」。

**战略背景**
- 掌舵人 **Alexandr Wang**（2025-06 从 Scale AI 挖来任 Chief AI Officer，随同 $14.3B 收购 Scale 49% 无投票权股），mandate = **把 Meta AI 研究变成营收业务**，直接动因是 Llama 4 系列表现不佳。
- **2026 Capex $115–135B**（近乎 2025 两倍）——纯开源无法回收的量级。
- 扎克伯格 2025-07-31 essay 已埋下伏笔：定位「**Personal Superintelligence**」（代表个人自主规划行动的 agent）。

## 机制 / 战略拆解：双轨制不是妥协，是「开源养生态、闭源收前沿」的分工

Meta 现在是明确的**双轨制**：
- **Llama 5（开源权重）** → 维系开发者生态、平台可信度与社区好感；
- **Muse Spark（闭源 + 付费）** → 追前沿能力、支撑 Meta AI 助手竞争力、并**首次直接变现**。

这套分工的潜台词是一句冷酷的资本算术：**$115–135B 的 capex，靠免费开源收不回来**。当前沿训练/推理成本进入百亿美元量级，「用免费换生态」的战略在前沿层已不可持续——所以 Meta 把**最强的那一档能力**从开源侧抽走、闭源、收费。这不是背叛某个理念那么简单，是「免费换生态」这套打法在前沿层的经济性终结。

关键机制含义：**开源侧从此拿不到 Meta 的最强能力**。开发者仍能免费拿 Llama 5，但那不再是 Meta 的天花板。前沿能力的开源供给，由此进一步向**中国系（LongCat / DeepSeek / GLM / Qwen / 腾讯 Hy3）+ 社区系（gpt-oss / OLMo / Nemotron）** 集中——这正是我们此前多篇（LongCat 2.0、DeepSeek、Watermelon）追踪的「开源冗余东移」的又一次确认，且这次是「西方最大开源金主主动撤出前沿」。

## 正反观点

**支持方（看多）**
- **真正的低价 agentic 搅局者**：tool-use / 编排类基准（JobBench、MCP Atlas）自报**领先 Opus 4.8 与 GPT-5.5**，且 $1.25/$4.25 + 「10x cheaper」定价极具攻击性。
- **为 agent 而生的 API 契约**：1M 上下文 + active compaction、parallel subagents、parallel tool calling、structured output、多模态单次调用——不是聊天模型套壳，是冲着 agent 工作负载设计。
- **企业侧背书**：Replit / Cline / Box 首批接入，落在真实开发/办公场景。

**质疑方（看空 / 风险）**
- **基准全部 Meta 自报、无第三方核验**——JobBench/MCP Atlas 领先与对照数字都出自 Meta，需自测证伪。
- **编码明显落后**：SWE-Bench Pro 61.5 vs Opus 69.2、DeepSWE 1.1 53.3 vs GPT-5.5 67.0——「not a coding leader」，高价值/低容错编码不能指望它。
- **效率败仗的延续**：承接 7/6 深研的 Watermelon（Meta 用 ~10× 算力才追平落后两代的旧靶 GPT-5.5）——「钞能力/算力 ≠ 能力/效率」，Muse Spark 1.1 是 4 月 Avocado 的 1.1 迭代 + 商业化，**非全新前沿跃迁**。
- **背弃开源承诺的信誉成本**：最大开源旗手转身收费，社区反弹（remio「breaks every promise Zuckerberg made about open AI」）。
- **US-only / 无 EU**：又一个「按辖区可用性切割」的模型（同 Grok 4.5 缺 EU），疑与 EU AI Act 合规规避有关；Preview 状态定价随时可变。

## 深度解读：对行业 + 对「做多 agent 系统的我们」的具体含义

### 对行业
1. **「免费换生态」时代在前沿层落幕**。Meta 是开源最大金主，它把最强能力闭源收费，等于替全行业宣布：前沿模型的经济学不再容得下「免费」。付费模型供应商阵营从「OpenAI/Anthropic 双寡头 + Google + xAI」扩到「**+Meta 五强**」，且 Meta 以**最低价切入**——价格战再加一把火。
2. **前沿开源重心确定性东移**。西方最大开源供给方主动退出前沿开源，「近前沿开源」的现实答案越来越只剩**中国系 + 社区系**。这不是叙事，是供给侧事实——直接改写「开源 = 抗断供保险」这张牌的**发牌人名单**。

### 对做多 agent 系统的我们（落地可执行）
1. **「开源 = 抗断供/抗下线保险」必须重新校准发牌人**。别再把 Llama 系当前沿 fallback——Meta 的前沿已不在开源侧。真正可当近前沿 fallback 的开源只剩 **LongCat / DeepSeek / GLM** 等中国系 + 社区系，且它们**都带地缘/ToS/监管敞口**（可能成下一个出口/进口侧管控目标）。把这条更新进**供应商登记册**：抗断供保险仍要买，但保单的承保方变了、且更贵（合规成本更高）。
2. **Muse Spark 1.1 进热切换名册，但按「agentic 编排 / tool-use 档」定位，不是「编码档」**。它 tool-use/orchestration 强、编码弱——高价值/低容错编码留 **Opus / GPT-5.6**，工具编排、多模态胶水活、glue 任务可路由试 Muse Spark 的低价档（$1.25/$4.25）。**上生产前置 = 独立第三方基准 + 我们自己的 $/task 实测**，别拿自报数字下注（延续 Grok 4.5、Sonnet 5 的一贯纪律）。
3. **cost-per-task 地板继续下移**，把它做成**一等 KPI + 智能分档路由**。Muse Spark $1.25/$4.25 + 「10x cheaper」承接 Lindy→DeepSeek 降 90%、GPT-5.6 Luna $1/$6、Sonnet 5 促销主线——名义单价还会更便宜，但要区分「软件可省」（缓存/蒸馏/路由/上下文压缩现在就拿）与「换供应商才省」。
4. **agentic 原语值得抄作业**：**active context compaction**（对长会话 token 经济学是真杠杆）+ parallel subagents + parallel tool calling + structured output——把这些当成「为 agent 而生」的 API 契约对齐，尤其上下文主动压缩这一档，直接压长程 agent 的 token 账单。
5. **地缘可用性风险 +1**：US-only / 无 EU 又一例。多模型 × 多地缘 × 多阵营热切换从加分项变生存底线——别把任一辖区受限的模型放进不可替换的关键路径。
6. **别把「又一个模型发布」误读为能力跃迁**。真正可下注的时点 = 第三方基准落地 + 我们自己的**无人工跑完率 / $per-task 实测**，而非 demo 与自报榜单。
