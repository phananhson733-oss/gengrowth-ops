# 💰 深度研究 ｜ 收入王座第一次易主：Anthropic Q2 反超 OpenAI，以及这个数字背后的两种赌注

> **一句话定性**：这是生成式 AI 商业化三年来**第一次**，通用大模型的收入第一名换人——而且换得非常难看：**Anthropic 用 $116 亿收入 + 小幅正利润，压过了 OpenAI 的 $67 亿收入 + $123 亿亏损**。但真正的看点不是谁领先，而是**这个"利润"能不能扛过下一个季度的算力账单**，以及两家 IPO 之前，第一次有人被迫用"单位经济"而不是"叙事"说话。

**来源**：《华尔街日报》独家《OpenAI's Second-Quarter Sales Show Tepid Growth Compared With Anthropic》，2026-08-18/19；Investing.com、Quartz、PYMNTS、Yahoo Finance、Cryptonomist、Stocktwits 同日跟进转述。
🔗 原始链接：https://www.wsj.com/tech/ai/openais-second-quarter-sales-show-tepid-growth-compared-with-anthropic-5cb42998

## 一、为什么这一条值得单独深读

过去三年，"OpenAI 收入第一"是整个行业的默认底座。Nvidia 的订单簿、Oracle 的 4.5GW Stargate、微软的 Azure 追加承诺、CoreWeave 的资本开支——全都建立在"OpenAI 的曲线会一直陡下去"这个假设上。

WSJ 这篇报道第一次把两家的**同一季度、同一口径**数字并排放在一起，结果是：底座裂了。

更关键的是时点。两家都已保密递交 S-1（Anthropic 6/1，OpenAI 6/8），Anthropic 传闻最快 10 月上市。**这是最后一个"没人需要出审计报表"的季度**——从下一季开始，"调整后经营利润"这种说法要接受 GAAP 检验。所以这一条不是财经花边，它是**整个 AI 供给侧信用结构的一次压力测试**。

---

## 二、核心事实（分层）

### A. 收入（Q2 2026，即截至 6 月的三个月）

| | OpenAI | Anthropic |
|---|---|---|
| Q2 2026 收入 | **$67 亿** | **$116 亿**（初步口径 >$115 亿） |
| Q1 2026 收入 | $57 亿 | $47.3 亿 |
| 环比 | **+18%** | **+145%**（翻倍以上） |
| Q2 2025 同期 | — | $7.87 亿 |
| 同比 | — | **约 14.7 倍** |

- Anthropic 的季度收入现在比 OpenAI **高约 73%**。
- WSJ 措辞：OpenAI 的 18% 增长"**让一些原本期待更快进展的投资人失望**"。
- 环比增速对照：OpenAI 的 18% **落后于 Palantir、CoreWeave、Micron** 这些已上市的 AI 概念股（Stocktwits 口径）。

### B. 利润（这才是真正的分水岭）

- **OpenAI 经营亏损（含股权激励）：Q1 $93 亿 → Q2 $123 亿**。
- 算一下单位经济：**Q1 每收 1 美元亏 1.63 美元，Q2 每收 1 美元亏 1.84 美元**。
  → **亏损扩张速度快过收入扩张速度，单位经济在恶化，不是在改善。**
- **Anthropic：小幅为正的"调整后经营利润"**——公司历史上第一次。

> 注：网上流传的 "$5.59 亿首次经营利润" 这个具体数字，在可交叉核实的报道里对不上（同一处的收入口径写的是 $109 亿，那是 5 月泄露的投影数而非实际数），**故不采用**。目前可靠的只有定性表述："small adjusted operating profit"。

### C. Run rate（口径陷阱，单独拎出来）

- Anthropic：7 月底年化 **$650 亿**（5 月 Series H 时为 $470 亿）。
- OpenAI：**$400 亿**（联合创始人 Greg Brockman 上周内部消息口径，8/13 Bloomberg）。
- **但 Anthropic Q2 实际收入 $116 亿，年化只有 $464 亿**——和 $650 亿差了 **40%**。

> Run rate 是"月末快照 × 12"，季度实收是"三个月真金白银"。在一条陡峭的曲线上，前者天然比后者虚高一大截。**看到 run rate 想到季度实收，看到季度实收才敢比。**

### D. 结构差异（为什么会拉开）

**Anthropic 这边：**
- 约 **80%** 收入来自 Claude API 与企业（第三方拆解口径）。
- 增长引擎是 **Claude Code**：从 2025/9 的 $5 亿 run rate → 2025/11 的 $25 亿 → 2026/5 约 $80 亿 ARR；占 AI 编码市场约 54%（第三方口径，非官方确认，仅作量级参考）。
- 客户是 Netflix、Spotify、KPMG、L'Oréal、Salesforce 这类企业；企业用途占 Claude Code 收入一半以上。

**OpenAI 这边：**
- **数亿不付费的 ChatGPT 用户，算力成本全部自己扛**——WSJ 明确点名这是亏损结构的一部分。
- **两个近期发布的模型被迫降价**，原因是企业客户"对 AI 支出转趋谨慎，并把部分负载转向更便宜的中国模型"。
- 消费者订阅增长在减速，企业侧被 Claude Code 抢滩，公司被推到**被动应战**的位置。

### E. 组织与资本面的连带

- **人事**：Greg Brockman 亲自下场同时管产品与业务；CRO Denise Dresser 上任不满 12 个月被撤；此前 COO Brad Lightcap、Fidji Simo 已离开（Cryptonomist/Stocktwits 口径）。
- **供应商敞口**（同口径，量级参考）：微软 Azure 追加承诺 $2500 亿；Oracle $3000 亿+ / 4.5GW Stargate；AWS $380 亿 / 7 年；CoreWeave 约 $224 亿。**这些合同是照着"OpenAI 会一直陡下去"签的。**
- **IPO**：Anthropic 6/1 保密递交，仍瞄准秋季（传闻 10 月纳斯达克）；OpenAI 6/8 保密递交，但已倾向推到 **2027**，目标万亿估值。私募估值口径分歧较大（Anthropic 最近一轮融资约 $9650 亿，二级报价已被引述到 $1.12 万亿；OpenAI 约 $8826 亿）——**这类口径不统一，别当硬数据用**。

## 三、机制拆解：不是"谁的模型更好"，是三个结构性差异

**1. 谁在替谁的算力买单。**
OpenAI 的成本结构里有一大块是**给不付钱的人做推理**。这在"用户增长即价值"的时代是投资，在"该证明单位经济"的时代是纯失血。Anthropic 从来没有一个十亿级免费消费者盘子——它的痛苦是获客难，但它的每一次推理基本都有人付账。**这一季，第二种痛苦更便宜。**

**2. Agent 把"用量"从人的注意力上限里解放出来了。**
消费者订阅的天花板是人一天能用多少次；而一个跑在 CI 里的编码 agent，一次任务可以烧掉人类一整天的 token 量。Claude Code 之所以是这轮胜负手，不是因为它"体验好"，而是因为**它把收入从"人的使用时长"重新锚定到"机器的工作量"上**——这是一条完全不同的、几乎没有生理上限的增长曲线。OpenAI 手里 Codex 也有同类资产，但收入结构还没转过来。

**3. 降价的方向是反的。**
OpenAI 因为企业转投中国模型而**被迫降价**；Anthropic 则在 9/1 让 Sonnet 5 的促销价 $2/$10 **回到标准价 $3/$15**。同一个市场，一家在往下打，一家在往上收——**这是对各自定价权的最诚实的自我评估**。

## 五、正反两面

### 支持方：这是商业模式第一次被验证

- **正利润在前沿实验室是零的突破。** 过去三年所有人都在赌"规模先行、利润以后再说"。Anthropic 第一次给出了另一种可能：**在前沿模型这一行，是可以不亏钱的**。
- **算力效率是真实的护城河。** WSJ 明确提到 Anthropic "更高效地使用算力"。同样烧钱训模型，一家在赚一家在亏 1.84 倍，差的不只是收入端。
- **企业侧的黏性比消费者订阅硬。** 接进 CI 的编码 agent 迁移成本远高于换一个聊天 app。$116 亿里的大头是**已经嵌进别人生产流程**的收入。
- **增速不是靠一次性合同堆的**：$7.87 亿 → $47.3 亿 → $116 亿，连续两个季度翻倍以上。

### 质疑方：这个"利润"可能是日历做出来的

- **Ed Zitron《Anthropic's "Profitability" Swindle》**（2026-05-21，早在实际数字公布前三个月就发难，基于当时泄露的 Q2 投影）：Anthropic 拿下 SpaceX 下一代超算集群 Colossus-2 的大份额，稳态成本约 **每月 $12.5 亿**，但**合同头几个月是打折的 ramp-up 价——恰好覆盖 Q2**。他的结论：**"这个经营利润是会计的结果，不是商业模式改善的结果。"**
  - ⚠️ 这是 Zitron 基于 SpaceX S-1 的推断与 Anthropic 投影，**非 Anthropic 官方确认**，请按"有力质疑"而非"已证实事实"处理。
- **"调整后（adjusted）"三个字没人知道调掉了什么。** 非上市公司，无审计，无 GAAP 对账表。WSJ 自己都写了"不清楚用了什么会计方法"。
- **口径对不上的旧账**：Zitron 指出 CFO Krishna Rao 在 2026-03-09 宣誓作证时称"迄今收入超过 $50 亿"，与同期流传的 $140–300 亿 ARR 说法难以调和。
- **对 OpenAI 的公平提醒**：$123 亿亏损是**含股权激励**的口径。SBC 是非现金支出，对一家 IPO 前的公司来说数额天然巨大。用它和 Anthropic 的"调整后"利润直接对比，其实**是拿最严的尺子量一家、最松的尺子量另一家**。真实差距大概率没有账面这么夸张——但方向是对的。
- **OpenAI 的反驳点**：WSJ 也提到，7 月新模型发布后 **Q3 增速已经回升**。Q2 可能是低点而非拐点。

## 六、深度解读：对行业，以及对"做多 agent 系统的我们"

### 对行业

**1. AI 供给侧的信用锚换了。**
过去两年，Nvidia/Oracle/CoreWeave 的估值逻辑里嵌着一个隐含假设："OpenAI 的收入曲线兜得住这些合同。" 这一季之后，这个假设第一次需要被单独论证。**风险不在于 OpenAI 会垮——它不会——而在于市场此前从没给"OpenAI 增速可能是线性而非指数"这件事定过价。**

**2. 竞争维度从"谁的模型强"迁移到"谁的每 token 能赚钱"。**
基准分数已经挤在一起（GLM-5.3 用 743B 参数打到 Artificial Analysis 60 分，逼近闭源前沿）。当能力趋同，**毛利结构就是护城河**。接下来一年，实验室之间真正的差距会体现在推理成本、算力合同条款、和收入结构上，而不是 benchmark 排名。

**3. 中国模型的价格压力已经具备了财务证据。**
WSJ 报道里"企业把部分负载转向更便宜的中国系统，迫使 OpenAI 降价"这句，是第一次有主流财经媒体把这条替代链**写进一家美国前沿实验室的降价归因**里。这不再是论坛观点。

### 对我们（做多 agent 系统 / AI 产品的团队）

**① 不要把"Anthropic 赢了"读成"锁定 Anthropic"——供应商风险的方向和直觉是反的。**
赚钱的一方有涨价底气（Sonnet 5 已宣布 9/1 从 $2/$10 回到 $3/$15），亏钱的一方反而更可能继续降价补贴抢份额。**从纯采购角度，这一季的赢家对你不是好消息。** 做多供应商抽象层（模型可替换）现在有了硬财务理由，不再是架构洁癖。

**② 预算立刻按 $3/$15 重算，别按促销价做年度规划。**
如果 Zitron 的 ramp-up 折扣推断成立，Anthropic 的算力成本会在 Q3/Q4 折扣退坡时抬升，**涨价压力会顺着 API 价格传导下来**。Sonnet 5 的定价恢复很可能只是第一步。今天用 $2/$10 算出来的单位经济模型，请当作乐观情形而不是基准情形。

**③ 分层路由从"省钱技巧"升级为"结构性策略"。**
现在有了明确的市场证据：企业级客户正在真金白银地把低价值负载迁到便宜模型上，并且这个迁移大到能逼前沿实验室降价。落到执行：**把 agent 流水线按"这一步错了代价多大"分层**——批量预处理、格式化、分类、初筛走开源/低价模型；需要长程规划、工具编排、不可逆动作的关键步骤才用前沿模型。这不是抠成本，这是让你的毛利结构在下一轮涨价里活下来。

**④ Claude Code 的数字说明了 agent 产品唯一被验证的规模化收入形态。**
$5 亿 → $25 亿 → $80 亿 ARR，一年多的时间。共同特征是：**面向开发者/企业、用量可计量、单次任务消耗远超人类交互、直接嵌进生产流程**。反过来，消费者订阅在同期减速。如果你在设计 agent 产品的商业模式，**这一季给出的信号是：按机器工作量计价、进生产流程，比按人头订阅更有前途。**

**⑤ 学会读 run rate 的水分——包括你自己的。**
$650 亿 run rate vs $464 亿季度年化，40% 的差。以后看任何一家（包括竞品、包括你自己的融资材料）的 run rate 数字，默认打个七折再比较。**这个口径差在陡增期是系统性的，不是偶然。**

**⑥ 未来 3–6 个月有一个罕见的可证伪点，别错过。**
如果 Anthropic 真在 10 月上市，**S-1 公开版会强制暴露 GAAP 经营利润、算力承诺表、以及和 SpaceX/Google/AWS 的合约结构**。这将是三年来第一次，我们能用审计过的数字验证一家前沿实验室到底赚不赚钱。**在那之前，把所有"AI 已经能赚钱了"的论断都当作待验证假设。**

## 七、接下来盯什么（信号）

1. **Anthropic S-1 公开版**（若 10 月上市，约 9 月前后翻公开）——看三样：GAAP 口径经营利润、算力承诺明细表、SpaceX/Colossus-2 合约条款是否印证 ramp-up 折扣说法。**这是本篇所有质疑的唯一裁决点。**
2. **Anthropic Q3 是否还能维持正利润**——折扣退坡后仍为正，Zitron 的批评就基本被证伪；转负则被证实。
3. **Sonnet 5 定价 9/1 是否真的回到 $3/$15**，以及 Opus 系列是否跟涨。
4. **OpenAI Q3 增速**——WSJ 提到 7 月模型发布后增长已加速，能否重回 30%+ 环比，决定 Q2 是低点还是拐点。
5. **Brockman 接管后的商业化动作**——ChatGPT 广告已扩到英国/墨西哥/巴西/日本/韩国五个新市场，下一步是提价、还是更激进的广告化。
6. **OpenAI IPO 时点是否进一步后移**——从"2026 秋"到"倾向 2027"已经是一次退让，再退就是信号。
7. **中国模型在西方企业的实际渗透率**——GLM-5.3、DeepSeek V4-Pro 这一批，是否从"降价筹码"变成"真实份额"。
