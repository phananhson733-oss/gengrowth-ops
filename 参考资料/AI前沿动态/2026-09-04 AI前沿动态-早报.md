# 深度研究 · 「欢迎来到 AGI 时代」——GPT-6 Astra 正式发布，代际更迭与一场提前引爆的叙事战

**一句话定性：** OpenAI 于 9/3 正式发布 GPT-6 Astra 并由 Brockman 亲口宣布「欢迎来到 AGI 时代」——这是旗舰代际更迭（GPT-5.6 Sol → GPT-6）、「AGI」首次被头部实验室用作正式发布叙事、以及「同一模型两种牌照」门控发放范式的三合一事件；能力跃迁最硬的证据不在聊天，而在 computer use 与自主网络攻击。

**来源：** OpenAI《GPT-6 Astra: A new generation of intelligence》
🔗 原始链接：https://openai.com/index/gpt-6-astra/ （官方，抓取 403；正文以 VentureBeat / Fortune / CNBC / Forbes / 9to5Mac / 9to5Google / Reuters 多源交叉核实）
**日期：** 2026-09-03（美东时间周四下午上线，官方页一度上了又撤、约 15:31 ET 才「Live now」）

## 为什么值得深读 / 背景

这是本频道近一个月主线的正式收口，也是一次超预期的提前引爆：

- **8/19 深研《停下的是最大那一次训练》**：OpenAI 在训练中按下暂停键的那个模型，就是 Astra。
- **9/3 早报深研《第一个被自己厂商判为 Critical 的模型》**：OpenAI 发布《Path to Astra》，宣布 Astra 网络能力越过 Preparedness Framework 最高档「Critical」红线——当时**发布日期未定**，预测市场一度只给「11 月发布」约 55% 概率。
- **48 小时后（9/3）**：Astra 以 **GPT-6** 的正式代号全量登场。预测市场、分析师和大部分媒体都没料到这么快。

发布过程本身也是新闻：CNBC、Reuters、VentureBeat 等拿到发布材料先行刊发，而 openai.com 的官方页**先上线、被撤下、约一个半小时后才恢复**（Forbes 称之为「a curious false start」）。这种混乱与其说是事故，不如说折射出这次发布在内部也是踩着刹车推出去的。

更大的背景张力：**同一天（9/3），Sanders 与 Casar 宣布将提出《Ban Artificial Superintelligence Act》**——永久禁止在美国开发超级智能、暂停前沿 AI 训练直至联邦监管就位、违者最高 20 年监禁。OpenAI 宣布「AGI 时代开始」与国会山第一份 ASI 禁令法案出现在同一个新闻周期里，这个对撞本身就是 2026 年 AI 政治的缩影。

## 核心事实（硬数据分层）

**基准读数（对比 GPT-5.6 Sol / 竞品）：**
- **ARC-AGI-3：98.6%**（GPT-5.6 Sol 仅 7.8%，Claude Opus 5 约 30%）——这是宣称「AGI 时代」的核心证据
- **FrontierMath Tier 4 v2：97.6%**（官方称已协助解决多个长期未解数学问题）
- **GPQA Diamond：96%；BenchCAD：95.9%；DeepSWE v1.1：74.1%**
- **ExploitBench：100%**（Sol 为 78.5%；与 9/3 早报的 Critical 判定一致）
- **OSWorld 2.0（离线子集）：72.6%，单任务均耗时 40 分钟**（Sol 为 65.7% / 75 分钟）→ 官方称任务完成**快 47%**
- **授权边界测试：越权率 0%**（Sol 高达 48.2%）——对齐侧最硬的一个数字

**训练与工程：**
- OpenAI 称这是**迄今最大训练 run**：首个预训练规模**超过 100,000 GPU** 的模型，在德州 Stargate 设施完成
- Codex 同步升级：**跨 context window 保留笔记、旧窗口可检索**，不再靠反复摘要压缩——先以实验特性上线，数周内成为默认

**定价（API）：**
- 标准模式 **$10 / $50 per Mtok**（输入/输出）；Fast 模式 **$20 / $100**
- Brockman 主动淡化 token 价：「Pricing tokens doesn't make any sense… what you actually want is the price per task」

**发放（双轨门控）：**
- 9/3（周四）起先向 **Daybreak 计划**内获批企业开放；「coming days」推至 ChatGPT Plus/Pro/Business/Enterprise、OpenAI API、AWS Bedrock 与 Azure；Pro 用户获「GPT-6 Astra Pro」；企业版**默认关闭**，需管理员启用
- **公开版将拒绝「高级网络安全任务」**；完整网络能力只经 Daybreak Red/Blue 门控发放
- 已提交美国政府自愿审查

**配套：$1B「Daybreak for Frontline Defenders」**
- 面向水务、社区银行、医疗系统、地方政府等关键基础设施，提供补贴访问、培训、技术支持与合作伙伴网络；另设「Daybreak for America」覆盖地方政府与公用事业
- Brockman 在 300 位 Fortune 1000 CISO 参加的峰会上宣布

## 机制拆解：这次发布真正的三个「第一次」

**1）「AGI」第一次成为发布叙事而非愿景。** Brockman 的原话有分寸——他没说 Astra 通过了某个公认技术门槛，而是「it's not unreasonable to feel that we are now in the AGI era」，并承认 AGI 是「a much more gray, fuzzy thing」。但把这句话放进官方发布会收尾，就是把 AGI 从章程里的远期承诺改写成现在进行时的营销资产。值得记住的背景：微软与 OpenAI 2025 年 10 月的重组协议里，AGI 宣告须经**独立专家小组验证**才有合同效力——「感觉上进入 AGI 时代」恰好是既收割叙事、又不触发合同机关的措辞。

**2）第一次「同一模型、两种牌照」的代际发布。** 完整能力版（含 Critical 级网络能力）走 Daybreak 申请制门控；公开版是**主动阉割的**——拒绝高级网络任务，且带 chain-of-thought 实时监控、可中止执行。旗舰发布从「一个产品」变成「一个能力池 + 按信任等级切片」，这是 9/3 早报预判的「军民两用管制范式」落地成产品形态。

**3）第一次把「每任务成本」正式立为定价叙事。** $10/$50 的 token 价并不便宜（Fast 模式翻倍），但 OpenAI 用「47% 更快完成任务、OSWorld 单任务 40 分钟 vs 75 分钟」重新定义比价单位。当模型以小时为单位自主干活，token 单价确实会失焦——但这也让横向比价变难，主动权交给了厂商。

## 正反观点

**支持方主张：**
- 基准接近全面饱和（ARC-AGI-3 98.6%、FrontierMath 97.6%、ExploitBench 100%），且**对齐指标随能力同步跃升**：越权率从 Sol 的 48.2% 降到 0%，拒答率 91.5%（vs Sol 59%）——「能力越强越危险」的默认曲线第一次被官方数据反驳
- Computer use 是真实的质变而非 demo：OSWorld 72.6% + 任务耗时近乎减半，Fortune 描述其操作电子表格、网页「often at superhuman speed」
- 发布姿态相对克制：先公布红线（9/1）、再门控发放、提交政府审查、配 $1B 防御侧补贴——比「闷声发布」负责任

**质疑方 / 风险：**
- **Gary Marcus（当日长文 + X）**：Astra 是「incremental, not a revolution」——发布几小时内已有人用 Fable 和 Sol 复现其部分演示；OpenAI **没有设对照组**，也没给出「不含形式化验证的开放式真实任务」上的证据；robustness 是「THE key question」而至今未知；且系统「less monitorable than prior systems」，从安全视角是退步
- **基准可比性存疑**：ARC-AGI-3 成绩用 Responses API harness 跑出，与他模型不可直接横比；NVIDIA 此前用 Claude Opus 5 + agent 架构也拿过 ARC-AGI-3 满分；OpenAI 自家的 **GDPval（真实职业任务基准）缺席**发布材料
- **叙事与合同的利益冲突**：「AGI 时代」宣言出自一家正需要融资叙事、且 AGI 认定与微软合同直接挂钩的公司之口；各媒体口径的基准数字也不一致（9to5Google 称 ARC-AGI-3「99.9% 饱和」，与简报材料的 98.6% 有出入）
- **开发者未被说服**：HN 讨论区的代表性抱怨是模型「aiming for AGI and beating crazy benchmarks, which is not very aligned with KISS」——刷榜与「别把我 1000 行脚本重构成 180 个文件」之间的落差仍在
- **监控税**：官方承认安全监控「偶尔会误伤合法任务」；合法工作可能被减速或中断

## 深度解读：对行业 + 对我们的具体含义

**对行业：**
1. **代际竞争的时间差被压缩到 48 小时量级。** Anthropic 9/1 发 Fable/Mythos 5.1（本频道 9/2 已深研），OpenAI 9/3 就把 GPT-6 拍上桌——且媒体（trendingtopics 等）直接把这次发布解读为「here to beat Anthropic and be AGI」。前沿实验室的发布节奏已从「季度错峰」进入「贴身互搏」，评估窗口被压得极短。
2. **「AGI」从技术判断变成监管触发器。** 同日出现的 Sanders/Casar ASI 禁令法案（企业「死刑」+ 个人 20 年刑期 + 新建内阁级监管机构）大概率不会通过，但它把「厂商自称 AGI」变成了立法者可引用的证词。以后每一次「AGI era」措辞，都是在给监管弹药库上膛。
3. **门控发放正在成为行业默认。** OpenAI Daybreak、Google Fairwind（Gemini 3.8 Flash Cyber，9/2）、Anthropic Claude Security（8/21）——三家在两周内全部落地「危险能力走申请制」。前沿能力的分发正式从「买 API key」变成「过审查」。
4. **比价单位之战开打。** 「price per task」若被行业接受，模型比价将从可验证的 token 表转向厂商自说自话的任务口径——利好领先者，坑苦采购方。

**对我们（做多 agent 系统的团队）：**
1. **Computer use 到了必须重估的水位。** OSWorld 72.6% / 40 分钟意味着「让模型直接操作 GUI」从玩具变成可依赖路径。凡是我们用脆弱 API 胶水或 DOM 选择器硬撑的自动化环节，应该立一个「computer use 替换试验」的评估项——但注意公开版能力面与 Daybreak 版**不是同一个模型行为**，评测要以我们实际能拿到的 SKU 为准。
2. **Codex 的跨窗口记忆是对 agent 工程的直接抄底。** 「旧 context window 可检索、笔记跨窗口保留」正是我们（和所有 agent 框架）在应用层手搓的 memory/compaction 层。厂商把它下沉进模型服务后，自建 context 管理的差异化价值缩水，应把我们的记忆层重心移向**厂商做不了的部分**：跨模型可移植、业务语义索引、可审计。
3. **成本模型改口径。** $10/$50（Fast $20/$100）叠加长自主运行，单任务成本可能到几美元～几十美元量级。跟进 8/10 Theseus 深研的判断：内部成本看板应改为「每完成任务端到端成本」，并给 Fast 模式设显式预算闸门。
4. **越权率 0% vs 48.2% 是选型硬指标。** 如果第三方复现，这个数字对多 agent 系统的意义大于所有智力基准——它直接决定我们敢给 agent 多大的默认权限半径。应把「authorization boundary」类测试纳入我们自己的模型准入评测。
5. **供应商集中度风险再+1。** 结合 8/28 Cursor 断供深研：OpenAI 既造最强模型、又掌握门控审查权、还在拿「AGI 已至」重塑定价话语权。多模型路由与可替换性不是架构洁癖，是生存策略。
