# 💰 深度研究 ｜ 用 2028 年的收入，买 2026 年的公司：拆解 Anthropic 2 万亿 IPO 的估值算术

> **一句话定性**：路透独家拿到的这个数字，第一次把「AI 到底值多少钱」的争论**变成了一道可以自己算的算术题**——而算完之后你会发现，真正激进的不是那个 $1900–2000 亿，恰恰是华尔街被迫把估值锚点**整体挪到两年之后**这件事本身。

**来源**：Reuters 独家，记者 Echo Wang，2026-08-14（本文引用的是 Yahoo Finance 全文转载版，Reuters 原稿同日经 TradingView / MarketScreener / Investing.com 多平台同步）

## 一、为什么这一篇值得单独深读

过去一年，"AI 公司估值离谱吗"这个问题一直没法好好讨论，因为**没人拿得到分母**。所有争论停留在"$47B 年化收入撑不撑得起万亿市值"这种口号层面。

路透这篇独家的价值不在于爆了一个大数字，而在于它**同时给出了分子的构造方式**：投行和投资人不是在用当前收入定价，而是把 EV/Revenue 倍数**架在 2028 年的预测收入上**。一旦你知道了这一点，$2 万亿这个听起来疯狂的数字，就从"信仰"退化成了"一组可以逐条质疑的假设"。

而且这件事的外溢性远超 Anthropic 自己：**如果 Anthropic 用两年前瞻定价成功上市，它就为整个 AI 板块（下一个是 OpenAI）确立了估值范式**。这才是本条今天压过其他所有新闻的原因。

---

## 二、核心事实（按可信度分层）

**A. 路透独家（8/14，两位知情人士）**
- Anthropic 内部对 **2028 年收入的预测为约 $1900 亿–2000 亿**（此前从未被报道）。
- 对照组：公司 5 月公开的年化收入 run rate 为 **$470 亿**；**2025 年底** run rate 约 **$90 亿**。
- 过去三年（至 2026 年初），年化 run rate **每年增长超过 10 倍**。
- 定价方法：投行与投资人使用**基于 2028 年预测的 EV/Revenue 倍数**。路透明确指出"看两年之后"在 IPO 定价里**不常见**（less typical）。
- 可比公司倍数：**Palantir 约 53x** 当年预期收入；**SpaceX 与 Cloudflare 均为 41.6x** 2026 年预期收入。
- 先例：**Cerebras** 上市前即援引 2028 年收入预期；**SpaceX** 在 6 月以创纪录估值上市前，预测已铺到 2029 年。

**B. Bloomberg 同日（投资人文件）**
- **Q2 2026 初步收入 > $115 亿**，对比 **Q2 2025 的 $7.87 亿**——**同比约 14 倍**。
- Q1 2026 为 **$47.3 亿**，即环比翻倍以上。
- Q2 **调整后经营利润转正**，为公司**首个盈利季度**。
- **保密版 IPO 文件已提交**；主承销商 **Morgan Stanley / Goldman Sachs / JPMorgan Chase**；目标 **2026 年秋**，意图**抢在 OpenAI 之前**。
- 文件标注为 preliminary，可能修订；Anthropic 拒绝置评。

**C. 更早的一手/二手锚点（用于校验）**
- 5 月 WSJ / CNBC 口径：Q2 预计收入 **$109 亿**、首个经营利润 **$5.59 亿**——**实际结果（>$115 亿）跑赢了自己 5 月的预测**。
- 投资人预期 **10 月上市、估值 $2 万亿以上**，将成史上最大 IPO；对照 **SpaceX 6 月以 $1.77 万亿上市**（QZ 8/13）。
- 半数以上投资方预期 **2026 年底年化收入落在 $1000 亿–1200 亿**。
- WSJ（经 the-decoder 8/11）：路演阶段公司估值口径为 **$9650 亿**，计划 9 月–10 月初上市。

## 三、机制拆解：华尔街怎么把 $1900 亿变成 $2 万亿

这一段是全文的核心。把上面的数字代进去，**"两年前瞻"这个动作到底赚了多少**：

| 分母（口径） | $2 万亿对应的 EV/Revenue | 参照 |
|---|---|---|
| $470 亿（2026-05 年化 run rate） | **≈ 42.6x** | 恰好压在 SpaceX / Cloudflare 的 41.6x 上 |
| $1100 亿（2026 年底年化，中值） | **≈ 18.2x** | 高成长 SaaS 上沿 |
| $1950 亿（2028 全年预测，中值） | **≈ 10.3x** | 看起来**便宜得像一家成熟软件公司** |

**这就是全部的魔术**：同一个 $2 万亿，用当期 run rate 算是 42.6x（需要投资人相信"AI 是特殊物种"），用 2028 年预测算只有 10.3x（连质疑者都很难说这个倍数贵）。**把锚点向后挪两年，等于把"这家公司值不值"的问题，替换成"这份预测靠不靠谱"的问题**——而后者的举证责任在质疑方，不在承销商。

第二层机制更微妙：**这份 2028 预测在增速上其实是"减速预测"**。

- 2023–2026 年初：年化 run rate **每年 >10 倍**。
- 2026 全年收入：H1 已知约 **$162 亿**（Q1 $47.3 亿 + Q2 $115 亿），若下半年做到年底 $1000–1200 亿的**退出年化**，全年收入大致落在 $450–550 亿量级。
- 2026 全年 → 2028 全年（$1900–2000 亿）：约 **3.5–4.4 倍 / 两年**，年均约 **90%–110%**。

也就是说，**这份预测把增速从 10 倍/年砍到约 2 倍/年**。这是刻意的：太激进机构不敢背书，太保守撑不起 $2 万亿。这个"看起来保守"恰恰是它最好卖的地方——**也是它最脆弱的地方，因为它没有给"减速比预期更快"留任何缓冲**。

第三层是**利润率的隐含承诺**。Fortune 的反方算法给出了另一个约束：按大盘股常规倍数，$2 万亿需要**每年 $590 亿–790 亿的净利润**。放在 $1950 亿收入上，那是 **30%–40% 的净利率**——微软级别。而 Anthropic 同期要背的是（The Information 5 月口径）**五年 $2000 亿的 Google Cloud 算力承诺**，年均约 $400 亿，单这一家就吃掉 2028 年收入的约 **20%**，还没算 Amazon、Nvidia 与今年 8 月密集签下的一批新算力合约。

**结论：这个模型要同时成立三件事——收入两年翻 4 倍、算力单位成本大幅下降、且不再打价格战。三缺一，估值就要重算。**

## 四、关键原话

> "Could they get a $2 trillion valuation, yeah they could and I just wonder if it would stay there over time."
> —— **David Merkel**，Aleph Investments principal（Reuters）

这句话的分量在于它没有否认 $2 万亿的**可达性**，只否认了它的**持续性**——而 SpaceX 正是现成的反面教材：6 月以 $1.77 万亿上市，冲上 $2 万亿之后**回吐了大部分涨幅**。

> "Anthropic would need to post annual profits in the neighborhood of $59 billion to $79 billion to keep pace."
> —— Fortune，8/14（Jim Edwards 撰稿，援引 Amanda Gerut 报道）

对照组：**亚马逊市值 $2.86 万亿，Q2 收入 $2006 亿、净利润 $626 亿**。Fortune 的原话是 Anthropic 在亚马逊旁边"像一条小鱼"。

## 五、正反观点

**支持方（为什么两年前瞻是合理的）**
1. **它不是新发明**。Cerebras 上市前就援引 2028 预期，SpaceX 铺到 2029——对重资产、超高速扩张的公司，用当期收入定价本身就是失真的。
2. **Anthropic 跑赢了自己的短期预测**。5 月说 Q2 $109 亿，实际 >$115 亿；说会有首个经营利润，做到了。一个连续上修的预测者，比一个只画长期饼的公司可信度高一档。
3. **收入结构在往"更值钱"的方向走**。同期 CNBC 口径称 OpenAI 的企业业务收入已超过消费者业务——两家都在从"聊天订阅"转向"企业 agent 部署"，后者的续约率、客单价与可预测性都远好于前者，正是支撑长期预测的东西。
4. **10.3x 2028E 真的不贵**。如果预测兑现，这笔买卖在事后看会是便宜的。

**质疑方（为什么这套算术可能是纸糊的）**
1. **"调整后经营利润"不是 GAAP 利润**。Fortune 明确指出公司在**净利润口径上仍未盈利**；Ed Zitron 在 5 月（`wheresyoured.at`）更直接：这是 EBITDA 口径的"盈利"，并指控 Q2 的成本结构受益于一份阶段性算力折扣、全价将从 7 月起生效——**若属实，Q3 就是第一个"全价季度"，也是这套叙事的第一次真实压力测试**。（此为独立博主推论，未获公司确认，需按 Q3 数据验证。）
2. **护城河正在被明码标价地侵蚀**。WSJ 报道，路演中投资人直接把 **Kimi K3、Qwen3.8** 列为风险项，认为 Anthropic 自称的"6–8 个月领先"已明显收窄。这不是舆论——这是**已经写进估值模型的折价因子**。（本频道 8/14 亦记录了 GLM-5.3 / Qwen3.8-27B / DeepSeek Harness 同日发布。）
3. **政治与选址风险被点名**。同一批投资人列出的另外两条：与特朗普政府的紧张关系、美国本土数据中心建设的反对声浪（本频道已推过德州暂停并网审批、多州撤销数据中心税收优惠）。
4. **预测本身没有留余量**。前文算过，$1900–2000 亿已经隐含"增速从 10x 掉到 2x"。**如果实际减速到 1.5x，2028 年就是 $1200 亿，$2 万亿对应 16.7x——立刻回到"贵"的区间。**

## 六、深度解读：对行业，和对「做多 agent 系统的我们」

**对行业格局**

1. **估值范式的定型时刻**。Anthropic 若在 10 月以两年前瞻定价成功上市，OpenAI 的 S-1 会立刻照抄这套框架。**AI 板块从此按"2028 年"定价**——这会把整个行业的资本供给节奏，绑定在一份没人能证伪的两年预测上。这是系统性风险，也是系统性机会。
2. **"AI 不赚钱"这个论点今天正式作废，但换来了一个更难的论点**。Anthropic 用一个调整后经营利润转正的季度，把辩论从"能不能赚钱"推进到"赚的是什么质量的钱"。接下来所有关于 AI 经济性的讨论，都要在 GAAP / 算力承诺 / 折旧这三个字段上打。
3. **上市会改变一家实验室的行为**。这是最容易被忽略、但对使用者最直接的一条：**季度财报压力会传导到定价、rate limit、模型弃用节奏和企业条款上**。今天的 Anthropic 还能为长期目标牺牲短期收入；一家公开市场公司很难。

**对我们（做多 agent 系统 / AI 产品的团队）——落到可执行判断**

1. **修正你的成本曲线假设。** 一个必须在 2028 年做到 30–40% 净利率的供应商，**不会在旗舰档上继续打价格战**。把"模型成本每年腰斩"这条规划假设**降级为分档假设**：主力/小模型档继续腰斩（Google 三周一代半价、DeepSeek 分时定价都在这条线上），**旗舰档（Opus 级）应按持平或缓降来做预算**。用旗舰跑全链路的多 agent 架构，成本风险被低估了。
2. **把 provider 抽象层从"架构洁癖"升级为"财务对冲"。** 投资人自己把 Kimi K3 / Qwen3.8 写进了 Anthropic 的风险项——这意味着开源档位的进步**是一个被资本市场定价的变量**，不是技术圈的自娱自乐。实操建议：让 Claude / Gemini / 一条开源线（GLM / Qwen / DeepSeek Harness）**同时能跑通主链路**，开源那条不当备胎、当**成本基线**。有基线才有议价权。
3. **抓上市前的企业化红利窗口。** Anthropic 近两周的动作——Auto mode 默认开（8/7）、自托管环境公测 + Claude for Government beta（8/13）、Compliance API 覆盖 Claude Code——全部指向"把 $1900 亿里的政企那部分先圈起来"。**这是我们成本最低的一段顺风**：合规、私有化部署、审计这些以前要自己造的能力，现在供应商有强动机免费或低价补齐。要谈企业条款、要锁多年价格，**窗口就是 IPO 之前**。
4. **对内部叙事的用法。** 如果需要向老板/投资人论证"押注 agent 而非聊天界面"，本条是目前最硬的外部证据：**两家头部实验室的企业收入都已超过消费者收入**，且 $1900 亿的预测建立在企业 agent 部署上，不是建立在订阅数上。
