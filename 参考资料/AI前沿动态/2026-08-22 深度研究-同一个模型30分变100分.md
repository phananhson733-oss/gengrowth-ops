## 一、为什么这一篇值得单独深读

我们这行过去一年反复吵一个问题：**做 agent 系统，到底是等模型变强，还是自己把 harness 做厚？** 这个问题一直缺乏干净的对照实验——因为模型和脚手架总是一起变，谁也说不清增量从哪来。

ARC-AGI-3 恰好提供了这个对照实验，而且是被动提供的。它的设计初衷正是**堵死脚手架**：不给规则、不给目标、不给说明，只给一个动作集，让 agent 自己进环境探索、自己形成假设、自己发现目标、自己规划执行。François Chollet 的立场很直白——真正的 AGI 不该需要针对任务的人类指导，尤其当普通人不需要任何说明就能通关时。

结果是：**这个专门为「测模型自己会不会」而造的基准，其公开集被三套外部 harness 分别打到了满分或接近满分。** 模型没换（都是 Claude Opus 5），换的全是模型外面那一层。

这不是一条 benchmark 新闻，这是一条**关于「能力到底存在于哪里」的证据**。而且它给出的答案，对任何一个正在决定「下季度是升级模型还是重写编排层」的团队，都是可执行的。

## 二、核心事实（按层次列出）

### A. 基准本身：它有多难，以及它怎么记分

- **ARC-AGI-3 发布于 2026 年 3 月**，ARC Prize 2026 在 Kaggle 上挂了 **200 万美元**奖池。
- 数据集三分：**25 个公开 demo 环境**（本次战场，共 183 关）、**55 个 semi-private 环境**（用于测 API 背后的前沿模型）、**55 个 fully private 环境**（竞赛专用，严格封存）。
- **人类基线**：135 个交互式游戏环境，均由**无任何先验知识、无任何说明**的人类通关。
- **发布时的模型成绩（2026-03）**：Gemini 3.1 Pro Preview **0.37%**、GPT-5.4 **0.26%**、Opus 4.6 **0.25%**、Grok-4.20 **0.00%**。全体前沿模型 **<1%**。
- **记分指标 RHAE**（Relative Human Action Efficiency，相对人类动作效率）：不是「解没解出来」，而是「解出来花了几步」。逐关计分＝**(人类动作数 ÷ agent 动作数)²**，封顶 1.15；只有真正改变环境状态的动作才计数，内部推理、工具调用、重试**不计入**。平方项＋幂律惩罚意味着**暴力搜索会被毁灭性扣分**——人类 10 步、AI 100 步，拿到的不是 10% 而是 **1%**。后段关卡加权更高，逼你形成世界模型而不是穷举。

### B. 五个月的曲线：模型换了一代，其余全是 harness

| 时间 | 系统 | 基座模型 | 公开集成绩 | 动作数 |
|---|---|---|---|---|
| 2026-03 | 裸模型 | Gemini 3.1 Pro / GPT-5.4 / Opus 4.6 / Grok-4.20 | **<1%**（最高 0.37%） | — |
| 2026-07 | 裸模型 | **Claude Opus 5** | **30.2%**（公开榜第一；GPT-5.6 Sol 7.8%，Opus 4.8 1.5%） | — |
| 2026-08-05 | **VISTA**（MIT） | Claude Opus 5.0 | **100.00 RHAE**，25/25 环境 | **7,542**（人类 17,135，少 56%） |
| 2026-08-05 | VISTA | GPT-5.6 Sol | 98.27 RHAE，25/25 | 10,063 |
| 2026-08-21 | **NVIDIA AVO** | Claude Opus 5 | **100.00 RHAE**，183/183 关 / 25 环境 | **6,624**（比 VISTA 少约 12%） |
| 日期未标注 | Schema harness | "Frontier Models" | 自称 **~99% public** | — |

**读这张表的正确方式**：从 0.37% 到 100，中间只发生了一次模型代际更替（Opus 4.6 → Opus 5，贡献约 30 分），**剩下约 70 分全部来自模型外面那层架构**。而且三套 harness 路线迥异——VISTA 走视觉输入 + 无损帧记忆、不做程序合成；AVO 走纯文本网格 + 演化式搜索；Schema 又是另一套。**殊途同归到满分，说明这不是某一套聪明设计的偶然，而是这一层本身还远没到收益递减点。**

### C. AVO 是什么，以及它的机制

- **AVO = Agentic Variation Operators**（智能体变异算子）。**它原本不是为推理基准造的**——它是 NVIDIA 用来做**自主 CUDA GPU kernel 优化**的编码 agent。在本职工作上的公开数据：**连续运行 7 天**，探索 **500+ 个优化方向**，产出 **40 个提交版本的 kernel**。
- **架构三件套**：
  1. **四步主循环**：inspect（检查上下文）→ plan（规划）→ implement（实现）→ evaluate（评估），对每个候选解重复。
  2. **持久记忆**：跨迭代保留历史实现、评估结果、编译器与 profiler 输出、累积推理。关键在于**不重启分析**——好的部件被保留下来继续用。
  3. **supervisor（监督者）**：独立监测轨迹是否陷入停滞，发现在死胡同里打转就**强制改道**。
- AlphaSignal 的定性很准：这套东西**「更接近演化搜索，而不是聊天循环」**（closer to an evolutionary search than a chat loop）。
- **输入条件比 VISTA 更苛刻**：AVO 只吃**纯文本 64×64 网格**，不给图像、不用 image token（VISTA 吃的是 512×512 PNG）；且**不提供任何规则说明**，只告诉它有哪些可用动作。
- **基座**：主体实验跑 Claude Opus 5（完整公开集），另有少量 GPT-5.6 Sol 的子集实验。

### D. 分析化学那一侧的旁证（同期、同一逻辑）

顺带记一笔：Anthropic 8/18 发布的蛋白设计报告里，Claude 在 **23 分钟**内处理原始 NMR 数据、**19 分钟**处理 LC-MS，纯度测出 96.4% vs 实验室 96.33%——同样是**通用模型 + 编排层**打赢专用流程。两件事指向同一个结论，只是一个在基准上，一个在湿实验里。（该条 8/18 首发，超出本轮 2 天窗口，已转入 backlog 留待单独深挖。）

## 三、机制拆解：为什么 harness 能补上 70 分

ARC-AGI-3 惩罚的是三件事，而这三件恰好都是**上下文层面的缺陷，不是智力层面的缺陷**：

1. **探索无记忆** → 裸模型每一步都在有限上下文里重新理解世界，试过的死路会反复再试。RHAE 的平方惩罚对这种重复行为是毁灭性的。**AVO 的持久记忆直接消掉这一项**——试过什么、编译器怎么报错、profiler 怎么说，全都留着。
2. **陷入局部循环无人叫停** → 长视野任务里模型会在一个错误假设上打转几十步。**supervisor 就是那个「拍肩膀说你换个思路」的角色**，它不需要比主模型聪明，只需要能识别「没进展」这一个信号。
3. **没有候选解的横向比较** → 单线程 chat loop 只能顺着一条路走。**演化式的 variation operators 让多个候选并存、被评估、被择优**，把「一次想对」降级成「多次试对再选」——而 RHAE 只数改变环境的动作，**模型内部的思考和重试不计分**。这一条极其关键：**基准的记分规则本身，就给了「在模型外面做大量廉价推理」一个巨大的套利空间。**

换句话说：ARC-AGI-3 想测的是「你会不会自己形成世界模型」，但它的动作计数口径，允许你**把世界模型建在 harness 里**，只要最后落到环境上的动作足够少。这不是作弊——这是基准设计与 agent 工程现实之间的一道缝，而三套 harness 都从这道缝里走过去了。

## 五、正反两面

### 支持方：这是真进展，而且是可迁移的进展

- **跨域迁移是硬证据**。AVO 是为 CUDA kernel 优化造的，**没有为 ARC-AGI-3 做任何任务定制**，直接拿过来就打满了公开集。一个在编译器优化上有效的架构，在完全无关的交互推理环境上同样有效——这说明捕捉到的是**长视野自主任务的共性结构**（记忆、择优、防停滞），不是某个 benchmark 的窍门。
- **条件更苛刻还赢了**。AVO 用纯文本 64×64 网格、无图像 token，比 VISTA 的 512×512 PNG 信息量少得多，动作数反而少 12%。
- **动作效率是真指标**。6,624 动作 vs 人类 17,135——这不是「跑得慢但跑到了」，是**比人类更省步**。RHAE 的平方惩罚让暴力搜索根本拿不到高分，满分意味着它确实形成了可用的环境模型。
- **HN 的历史类比**：Pokemon 那一轮也是先由 harness 打开能力，随后能力逐步被吸收进模型本身。**harness 是能力的先行指示器**，不是替代品。

### 质疑方：这个 100 分不是它看起来的那个 100 分

- **只跑了公开集，没跑 semi-private 和 private**。NVIDIA 自己在博客里明确写了这一点。ARC-AGI-3 分三套数据集的**唯一目的就是防止在已知任务上过拟合**，绕过分割去报满分，等于跳过了考试本身。
- **ARC Prize 的规则直接对上了这一点**：自报的公开集分数**只进 Community Leaderboard，默认不做核验**；要上 Verified 榜，必须满足公开集与 semi-private 成绩「良好一致」（ARC-AGI-3 的容差是 **±15 个百分点**），且需 Kaggle notebook 一键复现、12 小时内跑完、单次评测成本 ≤ **1 万美元**。官方政策原文要求自报者**明确声明「结果未经 ARC Prize 核验」**。
  - ⚠️ HN 讨论中有评论称「verified 榜上 AVO 是 40%」。**此说未能在 ARC Prize 官方页面直接核实，本文不作为事实陈述**，仅记为待核追踪位。若属实，公开集 100 与核验集 40 的落差将远超 ±15pp 容差——那会是本条最重要的后续。
- **不是受控消融**。NVIDIA 自己声明：与 VISTA 的对比**不能当作 controlled ablation**——两者的 agent 后端、观测格式（文本网格 vs PNG）、记忆架构、推理设置全都不同；**持久记忆单独的贡献没有被隔离出来**。所以「12% 提升来自记忆」这个说法，官方没说，我们也不该说。
- **「30% → 100%」这个对比本身就混淆了多个变量**。它好听、好传播，但它比较的是「一个裸模型」和「一整套跑了未公开时长与算力的系统」——AVO 没有披露耗时与成本。
- **AVO 用的不是 NVIDIA 自己的模型**。这是一篇 NVIDIA 的博客，宣布的却是「Claude Opus 5 在我们的架构里表现很好」。HN 上不少人第一反应就是这个。

**我的判断**：反方在「这不等于 ARC-AGI-3 被解决」上完全正确，NVIDIA 也没这么宣称；但反方**不足以否定核心事实**——同一个模型 30 → 100，三套独立 harness 殊途同归，这一点即使全部限定在公开集内，也已经是关于「能力位置」的强证据。**这条新闻的价值不在分数，在分差。**

## 六、深度解读：对行业，以及对做多 agent 系统的我们

### 对行业

1. **「模型层 vs 系统层」的价值分配正在被重新定价。** 五个月里 70 分的增量来自权重之外，这对「买最强模型就赢了」的采购逻辑是直接冲击。同时它解释了一件事：为什么 NVIDIA 会花力气发这篇——**卖硅的公司在证明「系统层归我」**，而这一层恰好是消耗算力最凶的一层（演化搜索 = 大量并行廉价推理）。这与我们 8/20 记的 Poolside 交易、8/22 的 Anthropic 挖走 Google TPU 之父 Amir Salek（Bloomberg 8/21）是同一盘棋的不同落子。
2. **交互式基准的公开集正在快速失去信号价值。** 三套 harness 十七天内打穿一个三月才发布、当时全体模型 <1% 的基准。**任何只报公开集的分数，从今天起都应当默认打折读**。真正的信号在 semi-private / private，以及「一致性容差」这类程序性规则上。
3. **它反过来验证了 Ornith-1.5 那条路线的紧迫性**（见 8/19 深研《脚手架开始被学出来》）。如果 harness 能补 70 分，那么**把 harness 训进权重**的商业价值就极高——这解释了为什么会有实验室专门去做「模型给自己出题、自己生成 scaffold」的配方。**两条路线在抢同一块地：AVO 把能力放在权重外，Ornith 把它塞回权重内。** 谁赢，决定了未来三年 agent 团队的护城河是代码还是模型账单。

### 对我们（做多 agent 系统）——落到可执行判断

1. **停止把「效果不好」默认归因于模型不够强。** 这是最直接的一条。在换更贵的模型之前，先问：我们的循环有没有持久记忆？有没有 supervisor 检测停滞？有没有候选解的择优机制？**这三件事在 ARC-AGI-3 上值 70 分。** 我们系统里但凡缺一件，升级模型带来的边际收益大概率不如补齐这一件。
2. **supervisor 是最低成本、最高回报的那一件。** 它不需要比主模型强，只需要判断「有没有进展」这一个二元信号。我们的 agent 长链路里最贵的失败模式就是**在错误假设上烧掉几十步**——一个独立的停滞检测器就能截断它。**这是本周就能加进去的东西，优先级应该排在任何模型调整之前。**
3. **持久记忆要存的是「过程」不是「结论」。** AVO 存的是历史实现、评估结果、编译器与 profiler 输出——**是失败的细节，不是成功的摘要**。我们做记忆层时的本能是存总结（省 token），但这正好丢掉了防止重复试错的那部分信息。**重新审视我们的记忆写入策略：错误输出、工具报错、被否决的方案，这些是不是被摘要掉了？**
4. **把「模型内的重试」和「环境上的动作」分开计价。** RHAE 的记分口径揭示了一个真实的工程原则：**在模型内部多想几轮是廉价的，对外部世界多动一次手是昂贵的**（真实世界里的「昂贵」＝副作用不可逆、API 有配额、用户在看）。我们的 agent 设计应当显式地向这个方向倾斜——**在提交任何有副作用的动作前，强制在 harness 内做完候选生成与择优。**
5. **架构的跨域可迁移性，比针对性调优更值钱。** AVO 的说服力来自它没有为这个任务定制。这给了我们一条评估自家 harness 的标准：**把它拿到一个完全无关的任务上，还剩多少效果？** 如果我们的编排层里塞满了任务特定的 if-else，那它是工具不是架构。
6. **对外读分数的纪律。** 从今天起，看到任何 agent 系统的 benchmark 数字，先问三句：**跑的是公开集还是私有集？是自报还是核验？有没有做受控消融？** 这三问在本条新闻里分别对应：公开集、自报、明确声明「不是受控消融」。

## 七、接下来盯什么（信号）

1. **AVO 会不会去跑 semi-private / private 集**，以及成绩是否落在 ±15pp 容差内。这是唯一能把这个 100 分坐实的动作。**同时核实 HN 所称「verified 榜 40%」是否属实**——这是本条最大的未决事实。
2. **ARC Prize 官方的回应**。当公开集在 17 天内被三套 harness 打穿，基准方通常会做两件事之一：发新一批环境，或者修改「什么算 agent、什么算脚手架」的规则边界。**后者对整个行业的 harness 定义都有约束力。**
3. **AVO 会不会开源或产品化。** 一个为 CUDA 优化造、能跨域打满推理基准的通用架构，如果 NVIDIA 把它做成开发者可用的东西（哪怕只在自家生态内），那是对现有 agent 框架的正面冲击。
