# Claude Opus 5:近 Fable 5 的智能,只要一半的价——前沿竞争轴从『峰值』转向『每单位智能成本』

**一句话定性:** Anthropic 在 7/24 发布 Claude Opus 5,不主打「最聪明」(那仍是 Fable 5),而是把「逼近前沿的智能」压到 Fable 5 一半的价格($5/$25 per Mtok),并成为 Claude Max 默认、Claude Code 新默认 Opus——这是顶级实验室第一次把旗舰级发布的核心卖点,从「能力峰值」明确切换成「每单位智能成本(cost-per-unit-intelligence)」。

**来源:** Anthropic 官方发布《Introducing Claude Opus 5》
**🔗 原始链接:** https://www.anthropic.com/news/claude-opus-5
**日期:** 2026-07-24(周五)

---

## 为什么值得深读 / 背景

过去两个月,Anthropic 的发布节奏异常密集:Fable 5(6/9,Mythos 类 GA,$10/$50)→ Sonnet 5 → 现在 Opus 5(7/24)。这不是「偶尔放个旗舰」的老节奏,而是明确转向一个**为不同预算/负载分层的模型组合**。

更关键的是叙事的转弯。本监测这两周反复记录一条主线:**当能力峰值开始饱和、且中国开源近前沿(Kimi K3 综合第三、输出 ~$15/Mtok,权重 7/27 释出)从下方施压时,前沿竞争的胜负手正从「谁最聪明」转向「同样的智能,谁更便宜、谁能连续跑更久」。** 上周三(7/22)我们刚深挖过 Google 的镜像动作——一次发三款 Gemini Flash/Flash-Lite 却独缺旗舰 3.5 Pro,把主场搬到 token 效率与单位成本。Opus 5 是同一条趋势线上、来自另一家头部实验室、且带明确一手定价的又一个硬证据。

对「做多 agent 系统」的团队,这条尤其正中靶心:Opus 5 直接成为 **Claude Code 的新默认 Opus 模型**,意味着大量编码/agent 工作流的底座在一夜之间换血。

## 核心事实(硬数据,除注明外均为 Anthropic 自报)

**定位与层级**
- Anthropic 原话定性:**"A thoughtful and proactive model that comes close to the frontier intelligence of Claude Fable 5 at half the price."**(逼近 Fable 5 的前沿智能,价格只要一半。)
- **Anthropic 明确不声称 Opus 5 是自己最聪明的模型**:最强通用仍是 Fable 5,受限的 Mythos 5 在两者之上。层级 = Mythos 5(受限,顶) > Fable 5(最强通用) > Opus 5(逼近前沿、走量)。
- 成为 **Claude Max 新默认模型 + Claude Pro 上最强模型 + Claude Code 新默认 Opus**。

**定价**
- **$5 / 百万输入 token,$25 / 百万输出 token**——与 Opus 4.8 **完全不变**。
- 恰好是 Fable 5($10/$50)的**一半**。
- Fast mode:约 2.5× 速度,价格翻倍。
- 数据保留:通用访问**无 30 天保留要求**(不同于 Fable 5 的 prompt 留存 30 天)。

**可用性(号称 Anthropic 迄今最广的一次首发)**
- Claude API(模型 ID `claude-opus-5`)、Claude.ai、Claude Code、Claude Cowork、平台 App;
- 同时上 **Amazon Bedrock、Google Cloud Vertex AI、Microsoft Foundry**——三大云 day-one。

**基准(Anthropic 自报,尚无独立复现)**
- **Frontier-Bench v0.1:43.3%**(Opus 5)vs Fable 5 33.7% vs GPT-5.6 Sol 34.4%——号称 SOTA,且是 Opus 4.8 的约两倍、单位任务成本更低。
- **CursorBench 3.2**:落后 Fable 5 峰值 **0.5% 以内**,成本只要一半。
- **ARC-AGI-3:30.2%** vs GPT Sol 7.8%——约为次优的 3×。
- **OSWorld 2.0:70.6%** vs Fable 5 66.1%——超过 Fable 5 最好成绩,成本约为其 1/3。
- **Zapier AutomationBench:26.0%** vs 次优 18.1%——同等成本下约 1.5× 通过率。
- **GDPval-AA v2:1,861** vs Fable 5 1,747 vs GPT Sol 1,736——号称 SOTA。
- **BrowseComp:90.8%**;OSS-Fuzz 漏洞识别 **79.4%**,逼近 Mythos 5,但**漏洞利用生成(exploit development)远落后**。
- **它输的地方**:DeepSWE v1.1 GPT-5.6 Sol 72.7% > Opus 5 68.8%;Humanity's Last Exam Fable 5 56.5% ≈ Opus 5 56.3%;法律基准 Fable 5 13.3% > 11.7%;HealthBench Professional Mythos 5 66.0% > 59.8%。

**安全 / 回退机制**
- 分类器介入频率**比 Fable 5 少约 85%**;
- 被拦请求在 Claude.ai / Code / Cowork 上**默认「静默」回退到旧的 Opus 4.8**;
- 网安利用能力仍刻意压在 Mythos 5 之下,企业/研究者可走 Cyber Verification Program(CVP)。

## 情景分析:这一步棋在解什么局

把三条事实叠起来看,Opus 5 的产品逻辑就清楚了:

1. **能力峰值饱和 → 卖点只能下移到成本。** 当 Opus 5 在 CursorBench 上离 Fable 5 峰值只差 0.5%、却便宜一半时,「多花一倍钱买那 0.5%」对绝大多数真实负载不成立。Anthropic 等于自己把 Fable 5 的适用面收窄到「最长、最自主、必须跨小时/天保持连贯」的少数任务。

2. **分层不是切能力,而是切「任务时长/自主度」。** 独立分析普遍指出:**2026 年模型差异化的主轴正从「离散难题的峰值分」转向「有界任务(bounded) vs 长程自主(long-horizon)」。** Opus 5 = 走量的、逼近前沿的「日常主力」;Fable 5 = 留给「多日、密集材料、必须保持连贯」的长跑。这是一条比「参数量/单点跑分」更贴近 agent 真实工程的分界线。

3. **同价翻倍 = 结构性把每任务成本往下压。** Opus 5 价格与 Opus 4.8 一模一样,但 Frontier-Bench 翻倍、多项基准以 1/2~1/3 成本追平或超过 Fable 5。对按 token 烧钱、动辄几十上百步的 agent 队列,这是一次**单位经济学的下移**,不是一次单点提分。

## 正反观点

**支持 / 看多的一方:**
- 这是买方的胜利:近前沿智能价格腰斩,长程 agent 的经济账被结构性改善,cost-per-completed-task 明显下降。
- 三大云 day-one + 成为 Claude Code/Max 默认,分发面极广,迁移成本低。
- 分层清晰(有界 vs 长程),给 agent 选型提供了比「跑分榜单」更可操作的坐标。

**质疑 / 风险的一方:**
- **全部基准都是 Anthropic 自报,目前零独立复现。** tech-ish 直言:"Every figure above is Anthropic's own and no independent testing exists yet."「近 Fable、半价」这句话在 Artificial Analysis / LMArena / 官方 SWE-bench Verified 落地前,只能当厂商口径。
- **「静默回退到 Opus 4.8」是老雷区重演。** 6 月 Fable 5 正因「隐形保护措施 / 静默降级」引爆过 48 小时风波(见 [[Fable 5 invisible-safeguards controversy]] / seen 账本 6/12),最后 Anthropic 道歉并改为「可见回退 + API 暴露原因」。Opus 5 又把「被拦请求默认静默回退」写回默认路径——对生产 agent 是可靠性/可观测性隐患(见下)。
- **它并非全面领先:** DeepSWE 输给 GPT-5.6 Sol、法律/HLE 略逊 Fable 5、HealthBench 逊 Mythos 5。「近前沿」不等于「新前沿」,峰值王座仍是 Fable 5。

## 深度解读:对行业 + 对「做多 agent 系统的我们」

**对行业:**
- **竞争轴正式换挡。** 继 Google 把 Gemini 主场搬到 Flash 效率层之后,Anthropic 用一次旗舰级发布把「每单位智能成本」摆到台面中央。叠加下方 Kimi K3($15 输出、7/27 开源权重)、Qwen 的价格施压,**前沿定价的天花板正在被自上而下(实验室降价)和自下而上(开源逼近)同时压低**。
- **「模型组合 + 按任务时长分层」会成为默认产品形态。** 未来选型不再是「买不买最强」,而是「哪一层的时长/自主度 × 成本最划算」。

**对「做多 agent 系统的我们」——落到可执行判断:**
1. **重排路由表,别再默认 Fable 5。** 把「有界、几步到几十步、可重试」的子任务默认降到 Opus 5(近 Fable 质量、半价),把 Fable 5 收窄到「必须跨小时/天保持连贯、密集材料」的少数长跑。用 **cost-per-completed-task**(而非单价、也非单点跑分)重算这张表——这正是我们一直盯的口径。
2. **给「静默回退」加探针,当成一等可靠性风险处理。** Opus 5 在被拦时默认静默降级到 Opus 4.8 = agent 半途换模型 → 行为/质量漂移、非确定性。落地动作:在关键链路上**检测回退是否发生**(6 月风波后 API 已暴露回退原因,复用它)、对安全/渗透/读码类任务尤其要显式处理降级、把「模型实际身份」纳入运行日志与评测口径,别默认「我发的是 Opus 5 跑的就是 Opus 5」。
3. **先用自己的任务复测,别吃厂商跑分。** 「近 Fable、半价」若在我们真实工作流上成立,就是一次白捡的降本;不成立就继续留在 Fable。等独立基准前,把 Opus 5 挂进影子评测跑一周再切默认。
4. **多云 day-one = 把它纳入跨云/跨模型热切换池。** Bedrock/Vertex/Foundry 都有,配合我们「辖区路由 + 供应商冗余 + 可热切换」的既定约束,Opus 5 是一个低摩擦的新档位。

## 接下来盯什么(信号)

- **独立基准落地**:Artificial Analysis / LMArena / 官方 SWE-bench Verified 是否坐实「近 Fable 5、半价」——这是「自报」变「事实」的临界点。
- **OpenAI 的价格回应**:7/24 Tibo Sottiaux 预告「Tomorrow is feeling codexy」的 Codex 发布是否含降价/新档位;GPT-5.x 会不会跟进成本-性能叙事。
- **开源下压**:Kimi K3 权重 7/27 释出后,近前沿开源 + 前沿降价的夹击是否进一步压低推理成本地板。
- **静默回退会不会再翻车**:是否又有用户发现被静默降级、触发第二次 6 月式风波;API 回退原因是否真的可靠可读。
- **采用信号**:Cursor / Vercel 等是否把 Opus 5 设为默认、给出 cost-per-task 数据;Claude Code 默认换血后的实测口碑。
