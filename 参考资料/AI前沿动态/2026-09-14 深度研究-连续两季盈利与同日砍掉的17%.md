# 💰 深度研究 ｜ 前沿实验室第一次「连续两季盈利」：Anthropic 的账本，和它同一天砍掉的 17% 额度

> **一句话定性**：这不是一条财经花边。**FT 9/13 报道的「第二个盈利季」＋今天（9/14）生效的 Claude Code 周额度 −17%，是同一件事的两面**——前沿实验室的推理业务确实跨过了单位经济学拐点，而拐点的一部分成本，正被转嫁给用量最重的开发者。对任何把前沿模型当基础设施的团队来说，这是一次供应商风险的重新定价，不是一条估值新闻。

## 一、为什么这一篇值得单独深读

过去三年，「AI 实验室永远烧钱」几乎是行业公理，所有估值模型都建立在「先亏十年换规模」之上。这条公理正在被第一个数据点撬动——而且撬动它的不是 OpenAI，是 Anthropic。

但真正值得深读的，不是「盈利」两个字，而是**这个盈利是怎么算出来的、由谁支付**。同一周里发生了三件在时间上高度耦合的事：

1. **9/11–9/12**：Reuters 独家——Anthropic 洽谈引入 Nvidia 为基石投资人（最高 $10B），寻求最高 $100B 融资、估值约 $2T，窗口在 11 月美国中期选举前（此条已于 9/13 晚报深研中记录）。
2. **9/13**：FT 独家——Anthropic 告诉小范围股东，本季度 adjusted operating income 将连续第二个季度为正。
3. **9/14（今天）**：8/29 公告的 Claude Code 周额度调整正式生效——**相对当前用量减少 17%**。

一家公司在冲刺史上最大 IPO 的同时宣布连续盈利，并在同一天收紧最重度开发者的配给。这三件事放在一起，才是完整的信号。

---

## 二、核心事实（按可信度分层）

### A. FT 9/13 的新增事实（本条的核心）

- Anthropic 告诉一小批股东：**adjusted operating income 将连续第二个季度为正**（"will be positive for a second straight quarter"）。
- **毛利率超过 80%**——但口径关键：这是**在扣除给 Amazon 等分销伙伴的分成之前、也在扣除模型训练成本之前**（"before accounting for revenue shared with distribution partners like Amazon and model training costs"）。
- Reuters 明确标注：**"could not immediately verify the report"**；Anthropic **未立即回应置评请求**。
- 报道背景：公司正在准备上市，这些数字是**初步的（preliminary）**。

### B. 已落地的 Q2 数字（2026-08-15 起由 FT / CNBC 报道）

| 指标 | 数值 |
|---|---|
| Q2 2026 收入 | **> $11.5B**（初步，可能修订） |
| Q1 2026 收入 | $4.73B（环比**翻倍以上**） |
| Q2 2025 收入 | $787M（同比 **>14 倍**） |
| 2026 上半年合计 | ≈ $16.2B |
| 年化运行率 | ≈ $46B（5 月披露口径 $47B；7 月底口径已超 $65B） |
| Q2 adjusted operating income | **为正**（官方未公开具体金额） |

⚠️ **一个必须澄清的数字混淆**：坊间流传的「Q2 盈利 $559M」来自 **WSJ 2026-05-20 的内部预测**，当时对应的收入预测是 **$10.9B**。实际收入落在 $11.5B 以上，但 **$559M 这个利润数字从未被 Anthropic 或 FT 确认**。引用时不要把预测当结果。

### C. 毛利改善的机制（可量化）

- **每 1 美元收入的算力成本：Q1 的 71 美分 → Q2 的 56 美分**，一个季度降 15 美分。这是本次盈利最直接的会计驱动。
- 算力来源：与 SpaceX 的合约 **$1.25B/月、220,000 张 GPU、Colossus 1 机房、期限至 2029 年 5 月**。
- 收入结构：**约 80% 来自 API 与企业**，其余为订阅。**Claude Code 单产品年化收入 >$2.5B**（2 月口径），且**占 Anthropic 企业客户支出的一半以上**。

### D. 今天生效的额度变更（同日、同一家公司）

- Anthropic 8/29 公告原文：**"Starting September 14, we're permanently raising standard weekly limits in Claude Code by 25% for Pro, Max, Team, and seat-based Enterprise plans. Until then, the current 50% increase will be in place."**
- 原帖被**删除**后重发澄清，澄清原文：**"Compared to today, this works out to a 17% reduction in weekly limits on Claude Code."**
- 算式：基线 100 → 5/13 起临时 +50% 至 150 → 今日起永久 +25% 至 125，**相对当前 −17%**。
- 影响范围：Pro / Max / Team / 按席位 Enterprise。**免费版与按量计费 Enterprise 不受影响**；**5 小时会话上限不变**，只动周额度。

## 三、机制拆解：「盈利」到底盈的是哪一层

前沿实验室的财务本质是**两家公司被钉在一起**——一家已经盈利的推理公司，和一家还在巨亏的研究实验室。第三方分析（AI After Hours，2026-04）把这个结构说得最直白：

- **剔除训练成本**：OpenAI 与 Anthropic 都接近盈亏平衡或小幅盈利。
- **计入训练成本**：OpenAI 累计亏损预计 **$85B**、2028 年见顶、2030 年才平衡；Anthropic 平衡点在 **2028–2029**。

FT 那句「毛利 >80%，在分成与训练成本之前」正好坐实了这个结构。作为对照，同一份第三方分析给 Anthropic 的**完整口径毛利率只有约 40%**（OpenAI 约 33%）——**两个数字差一倍，差的就是口径**。所以这里的关键问题从来不是「Anthropic 是否盈利」，而是：

> **adjusted operating income 到底扣除了什么？**

公开报道**至今没有说明**。而 adjusted 口径在科技公司通常会剔除股权激励（SBC）——这在以股权重度支付的 AI 公司里是极大一笔；是否还剔除训练算力摊销与基建 capex，**无人能从现有披露中判断**。

效率侧的对照确实对 Anthropic 有利：同一份测算给出 **Anthropic 每 GW 算力产生 $21.4B 收入，OpenAI 为 $12.6B**——约高 70%。这是「Anthropic 的盈利有真实经营杠杆」这一侧最硬的证据。

## 四、关键原话

**Anthropic 的澄清帖（被删原帖后重发）：**
> "Compared to today, this works out to a 17% reduction in weekly limits on Claude Code."

**Reuters 对 FT 报道的保留：**
> "could not immediately verify the report."

**Ed Zitron（《Anthropic's "Profitability" Swindle》，2026-05-21）对盈利成色的质疑：**
> "If Anthropic paid full-rate for its compute in those two months, its economics would shift back to what they've always been… a business that has costs that linearly increase with its revenue growth."

**Anthropic 自己对投资人的风险提示（5 月口径）：**
> 计划中的数据中心支出可能把后续几个季度**推回亏损**，profitability **可能无法维持全年**。

**对照组 · Sam Altman（Fortune，2026-09-12）：**
> "given everything happening with safety, right now would be an ill-advised moment to go public."（明确排除 2026 年 IPO）

## 五、正反观点

### ✅ 支持方：这是真实的经营拐点，不是会计花招

1. **收入曲线不是靠口径做出来的**：同比 >14 倍、环比翻倍，$787M → $11.5B，这些是收入端，与「adjusted」无关。
2. **成本曲线在真实下行**：每美元收入的算力成本一个季度从 71 美分降到 56 美分，是运营效率而非记账方式。
3. **有单品级证据**：Claude Code 年化 >$2.5B，且占企业支出一半以上——这是一个**高毛利、高粘性、按席位收费**的软件形态，不是纯 token 转售。
4. **算力效率领先**：每 GW 收入比 OpenAI 高约 70%，说明「烧一样的电，赚更多的钱」是结构性的。
5. **「分层看待」本身是合理的**：把持续性推理业务与一次性训练投入分开看，与半导体公司区分 fab 建设与晶圆毛利并无本质差别。

### ❌ 质疑方：时点、口径、可持续性三重可疑

1. **时点（最致命）**：Zitron 指出，SpaceX 合约存在 **ramp-up 期的折扣费率**，而这段折扣窗口**恰好落在被宣布盈利的那两个月**。若按全价付算力，经济模型会退回原样。
2. **口径不透明**："adjusted" 剔除项未披露；「毛利 >80%」是**扣分成和训练之前**的数字，与第三方完整口径的 ~40% 相差一倍。在 IPO 前用有利口径是常规操作，但投资人无法校验。
3. **公司自己不背书可持续性**：Anthropic 已经告诉投资人数据中心支出可能让后续季度重回亏损——**这句话与「连续两季盈利」的叙事是矛盾的**，只是前者说给风险披露，后者说给市场。
4. **信息渠道本身是选择性的**：消息经由「a small group of shareholders」→ FT，**未经审计、未经公司确认、Reuters 无法验证**。
5. **同日的额度收紧提供了反向证据**：如果单位经济学真的宽裕，为什么要在同一天把最重度开发者的周额度砍掉 17%？更难看的是**发布话术**——先用「永久提升 25%」做标题，原帖被删后才承认「相对今天减少 17%」。

## 六、深度解读：对行业，以及对「做多 agent 系统的我们」

### 对行业格局

**其一，「AI 实验室永远烧钱」的公理正式出现裂缝，但裂缝只在推理层。** 行业从此会分成两个叙事：卖推理的（可以讲盈利故事）和买训练的（继续讲愿景故事）。Anthropic 靠 80% 的 API+企业收入占比，站在了叙事有利的一侧。

**其二，OpenAI 与 Anthropic 的路径第一次明确分岔。** 9/12 Altman 排除 2026 IPO 并把理由归给「安全」，9/13 Anthropic 宣布连续盈利并冲刺中期选举前上市。一家在延后暴露账本，一家在抢先暴露账本——**这本身就是对各自账本成色的表态**。

**其三，IPO 前的季度是「粉饰期」，而粉饰的代价会向下游传导。** 本次 −17% 就是第一个可观测的传导样本。

### 对我们（做多 agent 系统的团队）——可执行判断

1. **把「订阅额度」从容量规划里剔除，只用可计量的 API 口径做承诺。**
   今天这件事已经证明：**周额度是供应商的可调阀门，不是合同承诺**。任何依赖 Claude Code / Codex 订阅额度跑生产任务的流水线，都是建在别人可以随时下调 17% 的地基上。本周内应完成：盘点所有跑在订阅额度上的自动化任务，把生产路径迁到按量计费，订阅只保留给人工交互。

2. **给 harness 加「配额余量」探针与降级路径。**
   现在多数 agent 系统只在**调用失败时**才知道撞额度。应该加两件事：①周额度余量的主动探测与告警阈值（如剩余 <30% 触发）；②触顶后的**自动降级路由**（切到备用供应商 / 更小模型 / 排队而非硬失败）。这与我们已有的子 agent 并发上限、预算上限并列，属同一类「资源边界」控制。

3. **建立我们自己的「每美元收入的 token 成本」指标，与供应商的 71¢→56¢ 同口径对照。**
   供应商的成本改善**不等于**传导到我们。没有这个指标，我们永远只能被动接受调价与调额，无法判断「这次涨价是成本传导还是利润转移」。这是一个可以在两周内建起来的看板。

4. **把「供应商已盈利」当作稳定性信号是错的，Zitron 的质疑就是理由。**
   盈利来自一份 2029 年才到期、但 ramp 折扣有限期的算力合约。折扣结束时成本会回升，而回升的部分要么由供应商的利润吸收，要么由我们的价格/额度吸收。**多模型路由 + 合同锁价仍然必要**，不能因为「供应商赚钱了」就放松。

5. **我们正是被优化的那一类客户——这既是优先级，也是风险。**
   Claude Code 占 Anthropic 企业支出的一半以上，80% 收入来自 API 与企业。好消息：我们这类用户的诉求会被认真对待，产品迭代会向我们倾斜。坏消息：**当需要改善毛利时，我们也是最优先被动手的那一档**——今天动的正是 Pro/Max/Team/席位版 Enterprise，而**按量计费的 Enterprise 完全没被动**。这个豁免名单本身就说明了优化逻辑：**按量付费的客户不碰，包月吃到饱的客户先砍**。结论很直接——想要稳定性，就付按量的钱。

6. **把「公告话术风险」写进供应商评估表。**
   「永久提升 25%」在字面上完全真实，但掩盖了对现状的 −17%。原帖删除+澄清重发意味着这不是笔误而是策略失败。**未来读所有供应商的额度/定价公告，都要先问一句：这个百分比的分母是哪一天？** 建议在依赖清单里为每个供应商增加一个字段，记录「上次公告与实际影响是否一致」。

7. **不因本条改模型选型。** 这是一条**商业与供应链新闻，不是能力新闻**。模型选型仍应由能力与成本基准决定；本条只改变**合同与容量策略**。

## 七、接下来盯什么（信号清单）

1. **S-1 正式公开后的 "adjusted" 定义**——到底剔除了 SBC / 训练算力摊销 / capex 中的哪几项。这是判断本次盈利成色的**唯一决定性证据**，其余都是推测。
2. **Q3 实际数字是否兑现「第二个盈利季」**——FT 报的是「将会」，不是「已经」。
3. **每美元收入的算力成本是否继续下行**——若从 56 美分回升，说明 SpaceX ramp 折扣期结束，盈利叙事承压。
4. **Anthropic 自己警告的数据中心支出何时落账**——它自己说了可能把后续季度推回亏损，兑现与否是诚信度测试。
5. **9/14 之后 Claude Code 的投诉量与迁移信号**——是否出现向 Codex 的可见流失；Anthropic 是否在 30 天内二次调整额度。
6. **是否出现第二次「提额公告实为减额」**——一次是话术失误，两次就是模式，应直接下调该供应商的公告可信度权重。
7. **OpenAI 是否跟进披露同口径财务数字**——Altman 已排除 2026 IPO，披露压力不同；若被迫跟进，说明资本市场已把「盈利披露」变成竞争必答题。
8. **Nvidia 基石投资 + $100B 融资是否落定**（Reuters 9/11 口径，窗口在 11 月中期选举前）——若落定，Anthropic 的算力成本结构会再变一次。
