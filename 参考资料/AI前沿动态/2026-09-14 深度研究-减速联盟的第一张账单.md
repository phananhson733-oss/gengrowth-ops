# 📉 深度研究 ｜ 减速联盟的第一张账单：9/14 同一天，市场、同行与北京各递上一张

> **一句话定性**：过去 72 小时里，四家前沿实验室的掌门人第一次就「减速」对齐了口径；而 9 月 14 日周一，这个联盟同时收到三张账单——**亚洲 AI 股一日蒸发数百亿美元市值、第二梯队实验室公开指控其为「卡特尔」、北京把它定性为「冷战剧本」**。这是「AI 安全」第一次不再只是叙事成本，而是被资本市场当作**现金流风险直接定价**。对任何把前沿模型当基础设施的团队来说，今天真正改变的不是安全共识，而是「模型每年更强更便宜」这条规划假设第一次带上了政策风险折价。

## 一、为什么这一篇值得单独深读

9/12 晚报与 9/13 早报，这个频道已经推过两篇「减速」主题：一篇讲 Altman 内部松口后 OpenAI 去问国会协同减速是否触犯《谢尔曼法》，一篇拆解 Amodei《We Must Pace the Frontier》里「嵌入式评估员」的条款设计。**那两篇写的都是提案。今天这篇写的是后果。**

这个区别很重要。行业里关于「该不该减速」的表态已经太多，多到边际信息量趋近于零。真正稀缺的是**外部世界对这些表态的反应函数**——而 9 月 14 日一天之内，三个互相独立、动机完全不同的外部主体同时给出了反应：

- **资本市场**用抛售给「减速」标了价；
- **同行竞争者**（Cohere）用一篇署名檄文把它定性为反垄断问题；
- **主权国家**（中国）用外交部例行记者会把它定性为地缘遏制。

三者指向同一个结论：**这个由四家美国公司在 48 小时内自发形成的联盟，其外部性远超它自己设定的议题边界。** 它以为自己在讨论对齐，但被定价的是资本开支、被指控的是限产合谋、被反击的是技术封锁。

### C. 周一的账单之二：同行（Cohere，一手）

Cohere 联合创始人兼 CEO **Aidan Gomez** 发表《Who Gets to Define the Rules for AI?》（cohere.com 标注 **2026-09-13**，09-14 广泛扩散；HN item 49692118，45 分 / 32 评论）。核心论点：

- 该计划向政府索要的是 "**a narrow antitrust waiver to make that coordination lawful**"——即，**竞争者协同限制产出本属违法**，所以需要一张豁免票；
- 结果是「**一国之内少数最强实验室商定共同标准**」，而其他人**必须遵守却无从参与**；
- 历史类比：**1975 年债券评级机构**、**1985 年汽车法规**——安全理由掩盖了反竞争结果；
- 对「嵌入式评估员」的直接攻击：**由被审计方亲手挑选（"handpicked by them"）、且存在财务或意识形态利益冲突的审计员**，是 "**a path to regulatory and ideological capture, not safety or trust**"；
- 程序质疑：整个过程没有 **public comment period**、没有 **consultation**；真正的规则制定需要「**会判公司败诉、包括判 Cohere 自己败诉的人**」，以及**小实验室与开源开发者**在场。

## 三、机制拆解：市场到底给什么定了价？

这次抛售最值得看的不是跌幅，而是**跌幅的分布**。它不是「AI 概念股普跌」，而是一次高度结构化的定价。

**跌得最狠的三类**：

1. **纯粹的前沿实验室股权敞口**——SoftBank（−13%）。它不卖芯片、不卖云，它的资产就是 OpenAI 的股份。OpenAI 推迟 IPO ＋ 承诺减速，直接砍掉了这份资产的兑现路径与增长斜率。
2. **卖给训练集群的铲子**——存储（SK Hynix、Kioxia、Micron、CXMT）、光模块（Zhongji Innolight、Largan）、加速器（Nvidia、AMD）。这些公司的订单簿直接挂钩**前沿训练的资本开支增速**。
3. **前沿模型本身的追赶者**——Z.ai（−10.5%）、MiniMax（−5.4%）。

**跌得轻的**：Tokyo Electron（−0.9%）、SMIC（−1.4%）——设备与成熟制程，客户结构更分散，对「最贵那一档训练」的敞口小得多。

**没跌的**：恒生 +0.3%、上证 +0.2%。

officechai 的总结点破了这条线：**"The stocks that fell hardest share a common thread: direct financial exposure to the pace of frontier AI spending rather than AI adoption broadly."**

**这个分布意味着什么**：市场**没有**把 pacing 读成「AI 需求见顶」。它读成的是「**前沿训练 capex 的增速可能被人为按住**」——而这两件事对应完全不同的资产。AI 应用层、推理需求、企业采纳这些逻辑几乎没被波及；被波及的是「明年再建一个十倍大的集群」这条假设。

**Brockman 的口径收窄正好印证了这个读法，也暴露了它的政治问题**：如果 pacing 只针对「需要数千亿美元超算的 sprint」，那么被限速的恰好只有那三四家能玩这个档位的公司——这既让减速的实际约束力比字面小得多，也让 Cohere 的卡特尔指控更难反驳：**一条只适用于头部、且由头部自己制定的限速，在效果上与准入壁垒难以区分。**

## 五、正反观点

### 支持方：这次是机制，不是表态

- **48 小时内五家对齐，且各自拿出了可检查的东西**，不只是发推：Anthropic 给出嵌入式评估员的条款文本（含「评估员有权公布自己没拿到哪些权限」）；Microsoft 把 MAI 的 Code of Conduct 拿出来**公开征询**；DeepMind 推的是**常设标准机构**而非逐家一次性协议。
- **OpenAI 推迟 IPO 是真金白银的代价**。如果这只是公关，最便宜的做法恰恰是先上市再谈安全。
- **市场反应本身就是证明**：能让 SoftBank 单日蒸发 200 亿美元市值的，不会是一份没有约束力的声明——投资人显然认为它有约束力。
- **Amodei 给了可证伪的时间表**：「6–12 个月内 agent swarm 接管互联网」。这句话把他自己钉在了一个可验证的赌注上，起算点 2026-09-12。

### 质疑方：限速栏依然是空的，而豁免票是实的

- **Cohere 的反垄断指控是这轮最硬的一击**，因为它来自一个有资格说话的竞争者，而不是评论员。它精确命中了 9/12 那篇深研里已经点出的问题：**协同限产需要豁免，而豁免的受益人和规则制定者是同一批人。** 9/12 时《谢尔曼法》还是假设性风险，今天它有了公开原告。
- **「安全」与「遏制」在同一份文件里无法切割**。Amodei 一边呼吁全球减速，一边主张继续卡中国芯片——这让北京的「冷战剧本」指控在文本层面成立，也让任何非美实验室有理由把这套标准读作壁垒。
- **口径在 48 小时内就开始收窄**。Brockman 把范围限定到「sprint」，意味着被限的是最贵的那一档；而**能力提升并不只来自最贵的那一档**——过去一年 harness、工具调用、上下文管理、后训练带来的增量，全都不在这条限速线内。
- **HN 讨论里的怀疑同时指向两边**：既有 ozgung 的护城河论、Moon_Y 的「把公共政策制定外包给利益相关方」，也有人指出 Cohere 自身的商业动机——提交者 throwworhtthrow 的反讽很到位：**没有任何一家 AI 公司会主张自己应为其托管 agent 的违法行为负责。** 双方都在为自己的位置辩护。
- **归因不可全给 pacing**：同日油价 +3%。单日跌幅是情绪与多因素叠加；只有连续重定价才能证明这是结构性的。

## 六、深度解读：对行业与「做多 agent 系统的我们」的具体含义

### 对行业

**「AI 安全」完成了从叙事到财务科目的转换。** 过去安全议题的成本体现在合规团队人头和发布延期上，它从不进入估值模型。9/14 之后进入了：任何一家对前沿训练 capex 有敞口的公司，其现金流预测现在必须包含一个新变量——「头部实验室自愿减速的概率与幅度」。这个变量没有历史数据、没有对冲工具，而且由四个私人主体的口径决定。

**同时，规则制定权的争夺正式开场。** 今天有三方各自提出了合法性来源：头部实验室（技术能力 + 自愿承诺）、第二梯队与开源（程序正当性 + 反垄断法）、主权国家（管辖权 + 发展权）。The Information 披露的那个工作组的**真正分歧点「政府介入程度」，就是这场争夺的核心**——它决定最终出来的是行业自律组织，还是有法定授权的监管机构，二者对第二梯队的含义天差地别。

### 对我们（做多 agent 系统的团队）—— 五条可执行判断

**1. 把「模型每年更强更便宜」从公理降级为带风险的假设。**
过去三年的产品路线图默认 capability 单调↑、price 单调↓。9/14 是市场第一次公开给这条曲线打问号。任何 18 个月以上的规划，现在应该显式回答一个问题：**如果前沿基模能力增速被按住一整年，我们的差异化还剩什么？** 如果答案是「等下一代模型」，那就没有答案。

**2. 减速只针对 sprint，不针对我们这一层——这既是好消息也是坏消息。**
Brockman 把范围明确限定在「数千亿美元超算的前沿模型」。好消息：harness、工具编排、记忆、子 agent 调度这些层面的进步**不在限速范围内**——而 9/13 晚报拆的 Agents API、以及 ARC Prize 对 GPT-6 Astra 的测量（同一模型换 provider adapter harness，ARC-AGI-3 从 62.7% 跳到 99.9%，快 3.66 倍、省 49% token）都指向同一件事：**harness 层的杠杆本来就比大家以为的大。** 坏消息：如果基模增速放缓，所有竞争会挤到这一层，而这一层的护城河比模型薄得多。**结论是加速在 harness/编排层的投入，但不要假设它能长期独占。**

**3. 「能否重放」多了一个理由，从工程要求升级为准入要求。**
9/13 晚报把「能否重放 agent 执行轨迹」列为托管 runtime 的一票否决项，理由是工程可控性。今天它多了第二个理由：如果标准机构真的落地，「你的 agent 用了哪个模型、有没有沙箱逃逸记录、出事能不能复现」很可能从内部工程问题变成**外部准入证据要求**。加州 SB 813 / AB 1405 已经把独立审计机构注册制写进法律（9/10）。**现在补执行轨迹的留存与重放，比被要求时再补便宜一个数量级。**

**4. 供应商集中度从理论风险变成已观测事实。**
如果四家实验室能在 48 小时内就发布节奏对齐口径，那「我们的模型供应商会不会同时收紧」就不再是假设。**今早那篇讲的 Claude Code 周额度 −17% 与今天这篇是同一枚硬币的两面**：配给权在对方手里，而对方之间存在协调机制。最低要求：有一条**被真实切换测试过**的二供路径——不是写在架构文档里，是跑过一次全量回归的那种。

**5. 地缘分叉已经在被定价，它不再只是道德问题。**
Kospi −2.5% 对上证 +0.2%、恒生 +0.4%——市场已经开始把中国 AI 资产当成**不受这套减速约束的另一条曲线**。叠加北京的公开拒斥与 9/13 金砖 AI 合作共同体的提议，「两条独立演进的能力曲线」正在从预测变成可观测事实。如果产品覆盖非美市场，**模型供应的地缘可切换性从合规选项变成了成本变量**。

## 七、接下来盯什么（信号）

1. **今日（9/14）Microsoft 公布的 MAI Code of Conduct 实际文本**——判断标准只有一个：**里面有没有可核查的能力阈值与触发条件**，还是只有价值观表述。这是区分「机制」与「表态」的第一个硬测试。
2. **FTC / DOJ 是否介入**。9/12 那篇讲的《谢尔曼法》风险，今天有了公开原告（Cohere）。看的是**有没有人真的去申请那张豁免票**——申请动作本身会把整件事推进正式程序。
3. **第二梯队与开源阵营的站队**：Mistral、Meta、xAI（Musk 已口头支持，但 xAI 是否签任何有约束力的东西是另一回事）、以及 Hugging Face 的 Open Alignment Initiative。**签署名单的长度决定这是标准还是俱乐部。**
4. **美股是否连续重定价**。单日跌是情绪（尤其叠加油价 +3%），**连跌两三日并伴随分析师下调 capex 预测**才是结构性信号。这是本条最值得跟踪的量化指标。
5. **The Information 那个工作组的「政府介入程度」分歧如何收敛**——收敛到「自律组织」还是「法定监管」，对我们这种下游团队的合规成本差一个量级。
6. **Amodei 那个可证伪的赌注**：「6–12 个月内 agent swarm 接管互联网」，起算 **2026-09-12**，到期窗口 **2027-03 ～ 2027-09**。记下它。到期时无论应验与否，都会重塑下一轮政策辩论的可信度分配。
