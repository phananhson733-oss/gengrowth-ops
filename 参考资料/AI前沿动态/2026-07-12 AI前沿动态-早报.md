## 核心事实（分层）

### 一、资本市场拐点（硬数据）

**宇树 Unitree（科创板）**
- CSRC **7/2 过会**；市场预期市值 **超 1000 亿元（约 147 亿美元）**，远高于早前约 420 亿元（约 62 亿美元）的预期。
- 但**单位经济学在恶化**：Q1 2026 营收 **4.23 亿元（+68.49% 同比）**，增速较 2025 全年 **+332.64%** 急剧放缓；扣非净利 **4025 万元，同比 −52.55%（腰斩）**。
- 均价从 2023 年 **59.34 万元** 降到 2025/9 的 **16.76 万元（−70%）**；毛利率 **87.67% → 62.91%**。
- 出货：2025 年 **5,500+ 台**（超过其余所有人形机器人之和），2026 目标 **20,000 台**。

**Agility Robotics（SPAC，一手条款）**
- 与 **Churchill Capital Corp XI**（Michael Klein 旗下 SPAC）合并，**投前股权估值 25 亿美元**，募资 **超 6.2 亿美元**（含 **Foxconn 领投约 2 亿美元 PIPE**），代码 **AGLT**，**H2 2026** 完成。
- Digit 已在 **Schaeffler / GXO / Toyota Motor Manufacturing Canada / Mercado Libre** 商业落地，**9 个客户现场累计运行 65,000+ 小时**。

**Tesla Optimus（产线转产）**
- Fremont 末代 Model S/X 产线改造为 Optimus Gen3 自动线，**设计年产能 100 万台**，约 **40 条子线**。
- 周产能路线：6 月几十台 → **7 月 100–150 台** → 8 月约 300 台 → **9 月 1,000 台**；单台约 **10,000 个全新零件**；**真正量产要等 2027 年德州厂**。Musk 自认初期「极慢」。

**旁证**：UBTECH（09880.HK）消费机器人订单破 1 万台、股价一度涨超 10%；Laifual Harmonic（港股）7/3 涨近 12%；AgiBot 2026/3 底累计 10,000 台（2025 仅 1,000 台）。

- **VLA（视觉-语言-动作）成主流范式**：ICLR 2026 收到 **164 篇 VLA 投稿，同比 18 倍**。当红模型多在 **2–10B 参数**：
  - Nvidia **GR00T N1.6**（2.2B，32 层扩散 transformer）
  - Physical Intelligence **π-0.5**（3B，7 平台 / 68 任务 / 104 户家庭）、**π-0.7**（4 月，「只见过两次的空气炸锅也能操作」）
  - **OpenVLA**（7B，97 万条轨迹，**比 550 亿参数的 RT-2-X 强 16.5%、却小 7 倍**）

## 机制 / 技术拆解：那道 60% 的墙

- **核心瓶颈 = sim-to-real 可靠性坍塌**：实验室 **95%** 成功率，部署到现实掉到 **60%**。数学很残忍——每步 95%、10 步链路成功率 ≈ 0.95^10 ≈ **60%**；一台 95% 准确率的仓库机器人**每天约失败 50 次**；而工业部署要 **99.9%**。
- **长程一致性**：当前系统自主运行约 **30 分钟** 后任务连贯性开始退化（但「AI 任务时长每 7 个月翻一倍」）。
- **推理速度**：大 VLA 边缘推理 **50–100ms → 只有 10–20Hz 控制频率**，而灵巧操作要 **20–100Hz**，物理上不匹配。
- **电池**：90–120 分钟 vs 工业需 8–20 小时；固态电池规模化预计 **2035**，无近解。
- **灵巧手**：Rodney Brooks——过去 **40 年**广泛部署的机械手「没有实质进步」，可部署灵巧度 2036 年前仍「相比人手很可怜」。
- **评测可信度危机**：「从 100 次失败里挑最好看的 demo」，真实任务 **1% 成功率**常见。
- **一个反直觉结论**：OpenVLA 7B 打赢 RT-2-X 55B（+16.5% 且小 7 倍）——在 VLA 里，**数据与 harness 比堆参数更重要**。

## 正反观点

**支持方（拐点已到）**
- 出货曲线真实（Unitree 5,500 台超所有人之和、AgiBot 10x 增长）；
- 真实营收落地（BMW 30,000 辆 X3、Digit 65,000 小时、9 个客户现场）；
- 公开市场用真金背书（Unitree 过会、Agility SPAC + Foxconn PIPE）；
- scaling law 被证明成立（EgoScale）；
- 均价 −70% 同时毛利仍维持 ~60%——**成熟平台特征，而非纯泡沫**。

**质疑方（还差临门一脚）**
- 单位经济学在恶化（Unitree Q1 利润腰斩、增速从 332% 掉到 68%）；
- Tesla 一再跳票（Gen3 从 1 月推到 7–8 月，Musk 自认「极慢」，仍偏 R&D 阶段）；
- 技术墙硬（95%→60%、30 分钟一致性、电池 / 灵巧手无近解）；
- 评测注水（1% 真实成功率、挑 demo）；
- 还没有任何一家发出「人形机器人年入 5 亿」的财报（Kisdi 的证伪点）；
- **地缘**：中国把持约 **90% 永磁、40% 精密轴承、35% 电机**；Unitree G1 售 **13,500 美元** vs Optimus 预期 2–3 万；不用中国供应链造 Optimus 成本约 **3 倍（~13.1 万美元）**。物理 AI 会**复刻软件 AI 已在打的出口管制 / 供应链博弈**。

## 深度解读：对行业 + 对做 agent 系统的我们

### 对行业

- 又一个「**资本先于能力到位**」的赛道。9 万台/年已足够让公开市场把它当真实产业定价，但 99.9% 可靠性还没到，中间是一段**靠资本 + 真实部署数据填的沟**。谁攒数据谁赢（EgoScale），所以早期「赔本铺机器人换轨迹数据」会像当年铺云、铺出行一样理性。
- 前沿实验室的战线从「屏幕里的 agent」**外溢到「物理世界的 agent」**：Mistral 7/8 下场、Google Gemini Robotics、Nvidia GR00T——机器人大脑正被 LLM 实验室吃下，正如上周办公桌被 Cowork / ChatGPT Work 吃下。这是同一套「基础模型吞并应用层」剧本的物理续集。

### 对做 agent 系统的我们（可执行）

1. **那道 60% 的墙，就是我们的「无人工跑完率」墙，只是被量化到残忍。** `0.95^10 ≈ 60%` 是所有长程 agent 的共同宿命。落地：把 **per-step 可靠性当一等 KPI**（别信 demo 成功率），长程成功率 ≈ 单步^步数——这正是**危险原语 allowlist + 可回滚 + 循环熔断 + 关键节点人审**存在的数学理由。想让 10 步任务到 90%，单步要 ~99%。
2. **长程一致性 ~30 分钟、每 7 个月翻倍**——这就是「后台长跑 agent」（Cowork / ChatGPT Work / Ona）真实的连贯视界。按**当下视界**设计：超过就 checkpoint / 拆子任务 / 插人审，别把「能跑数小时」写进架构依赖。
3. **数据护城河被 scaling law 坐实（EgoScale + OpenVLA 7B 打赢 55B）。** 对我们：自有的**工具调用 / 工作流执行轨迹是可复利资产**（呼应 Cursor×Grok 联训、Bespoke Labs 环境）。现在就把 agent 执行 trace 当一等数据资产采集、清洗、拥有——它比再大的基座更值钱。
4. **「数据/harness > 参数」再次成立。** 对齐我们一贯的**分档路由 + harness 护城河**判断：解一个具体 agent 任务，针对性数据与脚手架经常打赢更大的通用模型（Sonnet 5 / Luna 分档 + 工作流护城河）。
5. **物理 agent = agent 编排/可观测/安全的新市场。** 机器人也要 allowlist、可回滚、审计、人在环——我们在软件侧沉淀的这套治理原语是**可迁移资产**；把它做成跨「数字 + 物理」agent 的中立控制面，是一条可选但真实的第二曲线。
6. **地缘风险 +1 维。** 物理 AI 的供应链地缘集中度（中国 90% 永磁等）比软件更硬。若产品链条会触及具身 / 边缘，把**硬件供应链地缘敞口**写进供应商登记册，和已有的模型出口管制 / 断供冗余并列。
