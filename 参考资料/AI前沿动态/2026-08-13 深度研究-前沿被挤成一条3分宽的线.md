# 前沿被挤成一条 3 分宽的线

**一句话定性：** 2026-08-12，SpaceXAI 与 Cursor 联合发布 Grok 4.6，在 Artificial Analysis 智能指数上以 61 分与 GPT-5.6 Sol 打平、距榜首 Opus 5 仅 2 分，而输出价只有对手的五分之一 —— 前沿不再是一个位置，而是一条 3 分宽的横线，选型的决定权从"谁最强"移交给了"每完成一个任务花多少钱、在哪种任务上会塌"。

**来源：** SpaceXAI 官方发布（x.ai）+ Cursor 官方博客（同日联合发布）+ Artificial Analysis 独立评测文章与模型页 + VentureBeat / the-decoder / Neowin / 9to5Mac / digitalapplied 交叉
🔗 原始链接：https://x.ai/news/grok-4-6 ｜ 独立评测：https://artificialanalysis.ai/articles/grok-4-6-benchmarks-and-analysis
**日期：** 2026-08-12（Techmeme 当日头条）

## 为什么值得深读 / 背景

本频道 7/9 推过 Grok 4.5，当时的结论是明确的**保留意见**：xAI 自报基准只赢一半、无第三方核验、Artificial Analysis 独立指数只给 54 分排第 4、幻觉率约 54%，因此"只当成本/效率档候选，高价值低容错任务留 Opus/GPT"。

一个月后，同一个第三方把分数从 54 抬到了 61。这不是又一次厂商自吹 —— **AA 是我们此前用来否掉 Grok 4.5 的那把尺子，现在这把尺子改口了**。而价格一分没涨。

这件事的重量不在"xAI 变强了"，在于它把前沿的形状改了：

| 模型 | AA 智能指数 | 输入 / 输出（每 Mtok） |
|---|---|---|
| Claude Opus 5 | 63 | $5 / $25 |
| Claude Fable 5 | 62 | — |
| GPT-5.6 Sol | 61 | $5 / $30 |
| **Grok 4.6** | **61** | **$2 / $6** |
| Grok 4.5（上一代） | 56（xAI 表）/ 54（AA 7 月发布口径） | $2 / $6 |

榜首到第四名之间只差 2 分，价格差 4–5 倍。**当能力差进入基准噪声区间，定价和失败模式就成了唯一的选型依据。**

## 核心事实

### 一、发布与分发（一手）
- 2026-08-12 由 SpaceXAI 与 Cursor **联合发布**。Cursor 官方博客原话：*"Today we are releasing Grok 4.6 together with SpaceXAI."* —— 注意措辞是"我们一起发布"，不是"我们接入了"。
- 同日上线：Cursor、Grok Build、xAI API（console.x.ai），以及 OpenRouter / Vercel / Cloudflare。
- 首周在 Cursor 与 Grok Build 内 **2x 包含用量** 促销。
- 上下文窗口 500K，与 4.5 持平（未扩）。

### 二、智能与 agent 基准（xAI 官方对照表，Grok 用 high 档 vs 对手 max 档）

| 基准 | Grok 4.6 High | Grok 4.5 High | GPT-5.6 Sol Max | Fable 5 Max |
|---|---|---|---|---|
| AA 智能指数（9 项复合） | **61** | 56 | 61 | 62 |
| GDPVal-AA v2（Elo） | **1753** | 1526 | 1728 | 1741 |
| CursorBench v3.2 | **69.9%** | 66.7% | 67.2% | 70.5% |
| APEX-Agents | **57.5%** | 47.1% | 56.7% | 59.2% |
| FrontierCode v1.1 | **61.3%** | 56.6% | 60.6% | 63.6% |
| DeepSWE v1.1 | 65.9% | 54% | **73%** | 70% |
| Terminal-Bench v3.0 | **26%** | 15.7% | 34.6% | 34.1% |

读法：七项里 Grok 4.6 对 Sol **四胜三负**，但两处败得难看 —— DeepSWE v1.1 落后 7.1 个点，Terminal-Bench v3.0 落后 8.6 个点（相对差距 33%）。

### 三、Artificial Analysis 独立口径（第三方，最硬的一组）
- 智能指数 **61**，全库 184 个模型中排 #6（同分并列拉低名次）；AA 文章标题直接写"Grok 4.6 让 SpaceXAI 重回智能前沿，并在成本效率上领先"。
- GDPval-AA v2 Elo **1753**，仅次于 Opus 5。
- AA-Briefcase（长时程 agent 型知识工作私有基准）Elo **1577**，落后 Opus 5 —— **长时程仍是它的弱项。**
- τ³-Banking **50.7%**（前二档）。
- Terminal-Bench **v2.1 88.4%**（与领先者持平）—— 注意这是旧版本，与官方表里 v3.0 的 26% 不矛盾：v3.0 是更难的新一代，全场都低。
- 跑完整套智能指数的实测成本 **$1,068.47**，消耗 **72M 输出 token**；混合单价 $1.35/Mtok。
- 输出速度 **67.6 tok/s**；首 token 延迟 **TTFT 42.09 秒**（显著高于同侪中位数）。

### 四、成本效率（AA 口径，本篇最值钱的数字）
- 平均解决一批任务用 **约 53 轮 / 约 5 亿输入 token**；Claude Opus 5 (max) 用 **约 103 轮 / 约 20 亿输入 token**。
  → **四分之一的输入 token，一半的轮数。**
- 每任务成本 **$0.84**，AA 称较 Opus 5（$5/$25）低 **60% 以上**。
- 结论不是"单价便宜 4 倍"，是"单价便宜 4 倍 **且** 达成同一结果所需的 token 少 4 倍"，两者相乘才是真实账单差。

### 五、训练侧（机制关键）
官方与 Cursor 博客口径一致：本代增益来自 **补充训练**，不是新底座 ——
- 用 **Grok 4.5 自己重新生成 SFT 轨迹**（覆盖推理、agentic 任务、STEM 与软件工程）；
- 掺入"精选的模型生成推理数据"与"高质量工程数据"；
- 改进 optimizer 与训练配方；
- 在**大范围 agentic RL 任务**上做强化学习。

## 机制拆解

### ① 这一代的涨分不是"更大"换来的，是"自产数据 + agentic RL"换来的
上下文没扩（仍 500K）、价格没动、底座没换，5–7 分的提升全部来自后训练。这与本频道 8/5 记的另一条线严丝合缝：Google 谈以超 $15 亿 hire-and-license 收编 Mechanize（专做前沿编码 agent 的**环境与评分器**）。两件事指向同一个判断 —— **前沿的瓶颈已经从"预训练规模"转移到"环境 + 评测 + RL 数据"**。Grok 4.6 是这个判断迄今最干净的一次实证：同一个底座，换一套 agentic RL 与自产轨迹，一个月抬 5–7 分。

### ② 200K 定价断崖：不是新政策，是这次终于被人算清楚了
$2/$6 **只在 prompt 低于 200K token 时成立**。一旦达到长上下文阈值，xAI 定价文档的口径是 **整个请求的全部 token** 按 $4/$12 计（缓存 $0.50 → $1.00），不是只对超出部分加价。

断点落在标称 500K 上下文的 **40%** 处。也就是说：一个 200,001 token 的 prompt，会把这一整轮请求（含输出）的单价翻倍。

> 本频道 7/9 的 Grok 4.5 记录里已写有">200K 加价"，所以阈值本身不是新的；**新的是它的计费方式被独立算清楚了** —— 这正好是长跑 agent 的工作负载形状：上下文单调爬升，越接近有价值的后期，越容易踩线。

### ③ 缓存涨价打在 agent 循环的正中央
AA 与 digitalapplied 均称缓存输入价从 4.5 的 $0.30 涨到 $0.50（+67%），而 xAI 发布公告未提。**口径存疑**：本频道 7/9 记录的 4.5 缓存价即为 $0.50（$2 的 75% 折），与"$0.30"打架 —— 以 xAI 定价页现值为准，此处不作断言。但方向明确：**agent 循环每轮重发前缀，缓存单价是它最敏感的一个数**，任何变动都要重算，不能沿用发布公告里的头条价。

### ④ 基准口径不对称
xAI 对照表用 Grok 4.6 的**默认 high 档**对 GPT-5.6 Sol **Max** 与 Fable 5 **Max**。这一次方向对自己不利（拿低档打对手高档还赢了四项），但同一张表不能反过来当"高档更强"的证据 —— 档位混比就是不可比。

## 关键原话

- Cursor 官方博客：*"Today we are releasing Grok 4.6 together with SpaceXAI."*
- xAI/Cursor 对能力的定位：模型"achieves frontier intelligence across several agentic coding and knowledge work benchmarks"，尤其擅长"turning a broad product idea into a working first version"，在长轨迹上表现出更多**自测与验证**行为。
- Artificial Analysis 文章标题：*"Grok 4.6 returns SpaceXAI to the intelligence frontier and leads on cost efficiency."*
- digitalapplied 的批评核心：以头条单价评估前沿模型"is measurably wrong at exactly the prompt sizes agentic workloads use"（在 agent 负载恰好用到的那个 prompt 尺寸上，是可被测量地算错了）。

## 正反观点

### 支持侧
1. **独立第三方背书，且就是此前唱反调的那家。** AA 用自己的钱跑了完整指数（$1,068.47 / 72M 输出 token），给出 61 分与 GDPval Elo 1753。这不是自报。
2. **成本效率是结构性的，不只是标价便宜。** 四分之一输入 token + 一半轮数，意味着即使对手降价，Grok 的 $/task 优势也不会立刻蒸发。
3. **agent 型基准上真赢。** GDPVal-AA v2 超过 Sol Max 与 Fable 5 Max，APEX-Agents、FrontierCode、CursorBench 三项也过 Sol —— 这些正是 agent 工程关心的量表，不是纸面知识题。
4. **分发已经就位。** Cursor / Grok Build / OpenRouter / Vercel / Cloudflare 同日可用，接入成本接近零。

### 质疑侧
1. **第三方证据仍然薄。** 除 AA 之外，公开可查的独立复现极少（BenchLM 口径：382 个基准槽位只有 5 行可展示证据）。7/9 那次也是先有自报后被打折，这次只是打折幅度小了。
2. **长时程仍落后。** AA-Briefcase Elo 1577 落后 Opus 5；Terminal-Bench v3.0 26% vs Sol 34.6% / Fable 34.1%。**"能一口气把 idea 做成第一版"和"能在终端里跑 40 步不塌"是两件事，它强的是前者。**
3. **CursorBench 的分数要打折。** Grok 4.5 时期 Cursor 已承认自家代码库的早期快照误入训练数据。现在 Cursor 既是训练数据来源、又是联合发布方、又是评测基准的命名者 —— **69.9% 这个数字的三个环节都在同一家人手里。**
4. **延迟不适合交互。** TTFT 42 秒、67.6 tok/s，AA 明确标注低于同侪。它是批处理/长跑 agent 的模型，不是补全式交互的模型。
5. **信任与中立性。** xAI 有编辑 system prompt 引导政治议题输出的公开记录；同日另有报道称 SpaceX 主张员工工作产出可用作 AI 训练素材（该报道站点抓取 403，仅得标题口径，**未核实，不作为结论使用**）。对输出中立性敏感的用途，这条风险不因基准分数改变。
6. **头条价与实际账单不是一回事。** 见上文 200K 断崖与缓存涨价。

## 深度解读

### 对行业
**"前沿"这个词今天正式贬值了。** 榜首 63 到第四 61，2 分，落在任何一套复合指数的噪声里。过去两年"选最强的那个"是一条有效启发式，因为差距是 5–10 分级的；现在它失效了。

三条推论：

1. **定价权在崩。** Sol 卖 $30/Mtok 输出，Grok 卖 $6，同分。OpenAI 与 Anthropic 要么解释清楚那 4–5 倍溢价买到了什么（长时程稳定性？终端任务？责任承担？），要么降价。本频道 7/30 已记过 OpenAI 的防守性降价、8/3 记过阿里 Qwen3.8-Max 以 $2/$6 上桌 —— **$2/$6 正在成为前沿档的事实地板，而这次踩到这个地板的是一家美国实验室。**
2. **后训练成了竞争的主战场。** 同底座、一个月、+5～7 分，靠的是自产轨迹与 agentic RL。这意味着**追赶周期从"再训一个底座"（季度级）缩短到"再跑一轮 RL"（月级）**，前沿的领先窗口会持续变窄。
3. **模型方与工具方的界线没了。** Cursor 说的是"我们一起发布"。6/16 SpaceX 以 $600 亿全股票收购 Cursor，Grok 4.5 是这个闭环第一个兑现物，4.6 是第二个 —— 而这次连品牌上的分隔都取消了。

### 对做多 agent 系统的我们（可执行判断）

1. **今天就在网关层加 prompt size guard，硬阈值设 190K。** 这是本篇唯一一条不需要任何前置验证就该做的事。超阈值前触发压缩/切分/摘要，否则整条请求（含输出）按双倍计价。长跑 agent 的上下文是单调增长的，**踩线是必然事件而不是异常**。顺带：这条守卫对所有带长上下文阶梯定价的供应商都成立，不是只为 Grok 做。

2. **把 Grok 4.6 放进路由的"高吞吐生成档"，不放"长时程执行档"。** 依据是它自己的分数形状：GDPVal 1753 / CursorBench 69.9 强（一次性把想法做成第一版），Terminal-Bench v3.0 26% / AA-Briefcase 1577 弱（多步终端执行、长时程）。我们的用法应该是：**方案生成、批量草稿、结构化改写、第一版实现 → Grok；40 步以上的执行链、终端密集、不可回滚的动作 → 留 Opus 5 / Sol。**

3. **在切换任何默认档之前，先跑我们自己的 $/task。** AA 的"53 轮 / 0.5B token / $0.84 每任务"是 AA-Briefcase 的口径，不是我们的工作负载。要测的三个数：每任务平均输出 token、平均轮数、**踩 200K 线的请求占比**。第三个数决定前两个数是否还成立。

4. **成本口径正式从 $/Mtok 改为 $/完成一个任务。** 本频道 8/11 在 Anthropic 机房那篇已经提过这条（固定成本刚性 → 厂商有动机推高 token 消耗），Grok 4.6 给了它第一个可以正着用的例子：**token 效率 4 倍，是可以和单价平级摆在一起谈判的维度。** 我们的模型评估表应该长出这一列。

5. **CursorBench 类分数在我们这里权重降半。** 训练数据污染史 + 联合发布关系 + 基准命名权同源。不是说数字假，是说它不能作为独立证据；要看的是 DeepSWE / Terminal-Bench 这类第三方持有的量表，而 Grok 恰好在这两个上输。

6. **工具中立性的触发器已经响过第二次。** 6/25 与 7/9 两篇写过"用 Cursor 就要保留独立 Claude/OpenAI key + Claude Code 备胎"。今天 Cursor 从"接入方"变成"联合发布方"，这条从推演变成了事实。**具体动作：确认我们在 Cursor 内对 Claude/GPT 的访问与配额没有被动降级；把"Cursor 内非 Grok 模型的可用性或定价变更"写进风险登记册的触发器清单。**

7. **对外内容、评审、裁判模型三类用途不接 Grok。** 理由不是能力，是输出中立性的治理风险（system prompt 编辑史）。裁判模型尤其 —— 一个会被厂商调整立场的模型不能当我们的评分器。

8. **别把它当交互式补全用。** TTFT 42 秒。它的位置在后台批处理和长跑任务，不在人等着看光标的地方。

## 接下来盯什么

1. **非 AA 的第三方复现**，尤其 Terminal-Bench v3.0 与 SWE-Bench Pro —— 若 26% 被复现，"长时程弱"就从观察升级为定论，路由分档可以固化。
2. **200K 整请求计价是否在批评后修改**（改成只对超出部分加价）。若改，Grok 的 agent 经济性再上一台阶；若不改，说明这是有意的价格歧视设计。
3. **缓存价 $0.30 vs $0.50 的口径** —— 以 xAI 定价页为准核一次，并回填我们 7/9 的记录。
4. **OpenAI / Anthropic 是否降价回应。** Sol $5/$30 对 Grok $2/$6 的同分价差撑不了太久。若 Sol 降价，本轮就从"xAI 追平"升级为"前沿档整体重定价"。
5. **Kimi K3 开源权重何时放出**（AA 口径 57 分，各二手源在 57–60 间打架）。一旦开权重且分数坐实，低价档的地板会再降一层，并且是可自托管的地板。
6. **NVIDIA Nemotron 4**（The Information 8/11：至少 1T 参数开源模型，最快晚秋，尚未完成训练）—— 若落地，同价位档会被从开源侧再挤一次。
7. **Cursor 内的模型默认值与定价**是否开始向 Grok 倾斜（工具中立性的第三次触发）。
8. **EU 可用性** —— Grok 4.5 发布时缺 EU，4.6 的欧洲上线状态需要确认后才能进任何有欧盟用户的链路。
