# 🧠 深度研究 ｜ 62.7% 还是 99.9%？GPT-6 Astra 打穿 ARC-AGI-3，而那 37 个百分点属于 harness

**一句话定性**：ARC Prize 官方验证的 GPT-6 Astra 成绩单，把「模型能力」与「harness 工程」第一次并排标价——同一个模型，标准 harness 62.7%，OpenAI 自家 adapter 99.9%，后者还更快更便宜；Chollet 因此把自己的 AGI 预测提前。这是评测史的分水岭，也是给所有做 agent 系统团队的一份「上下文工程价值」官方定价表。

- 来源：ARC Prize 官方博客《OpenAI's GPT-6 Astra on ARC-AGI-3》
- 🔗 原始链接：https://arcprize.org/blog/astra
- 日期：2026-09-03（HN 234 分/153 评论；Techmeme 9/4 头版）

## 一、为什么这一篇值得单独深读

ARC-AGI 系列是行业公认「离 AGI 还有多远」的计时器：Chollet 设计它专测**流体智能**——用极少经验习得新技能，而非复读训练数据。ARC-AGI-3 今年 3 月 25 日才上线，形态从静态谜题改为**交互式游戏**：agent 要在没有说明书的环境里自己摸索机制、规划、执行——这正是 agent 系统的日常。

本频道 8/21 深研过「同一个模型 30 分变 100 分——ARC-AGI-3 公开集被 harness 打穿」（Opus 5 裸跑 30.16%，套上 NVIDIA AVO 到 100%、AWS 系统 99.95%）。当时那是第三方 harness 在公开集上的操作；**这次是 ARC Prize 自己在半私有集上验证、双 harness 并排公布的官方成绩**——harness 归因问题从社区争议升格为官方榜单的一等结构。旗舰发布日（GPT-6 Astra，本频道 9/4 已深研）叠加基准打穿，两条线在同一天交汇。

## 二、核心事实（按可信度分层）

**官方一手（ARC Prize 博客，半私有集）**
- **Standard harness：62.7%，花费 $26,098**（max reasoning effort；low effort 仅 17.5%）。前代 GPT-5.6 Sol 同口径只有 **7.78%**——一代之内 8 倍跃迁，62.7% 本身就是标准赛道纪录。
- **Provider Adapter harness（OpenAI 自家）：99.9%，花费 $18,817**（high effort；甚至**不开推理也有 96.7%**）。
- Adapter 相比 Standard：**快 3.66 倍、少用 49% 的 token、总花费便宜约 28%**。更好的成绩，更低的成本。
- 方法：167 个「游戏×推理档」组合在两套 harness 下对跑；环境只含核心知识先验；难度经约 500 名公众受试者校准，**人类可 100% 解出**（人类成本 ≈ $12.78/局；脑能耗口径 0.067 美分/局）。
- **行动效率跨过人类线**：Astra 在 **96.0% 的关卡里行动数低于人类中位数**，平均每关少 51.7% 的行动。作者原本假设「行动效率（从多少经验里学会）会是人机之间的分界线」——这条线没守住。

**两套 harness 差在哪（机制核心）**
- Standard：请求之间**只传递模型自己写下的可见笔记**——所有厂商在同一条件下可比。
- Provider Adapter：用 OpenAI 原生 context 管理，**在请求之间保留不透明的推理状态（reasoning state），并对长对话做 compaction（压缩续接）**——模型能复用自己之前的全部思考，而不是每次从笔记重建世界模型。
- 那 37 个百分点的差距，不来自权重，**来自记忆管理**。

**交叉与对照（二手）**
- Chollet（X）：Astra 是交互推理上的「**step-function change**」；查看推理链时发现模型在为每个游戏**即时构建符号世界模型，甚至发明了自己的速记 DSL** 来表示局面；adapter 口径成本约 $360/局。
- 评测机构互相打架（the-decoder 汇总）：**Epoch AI 把 Astra 排第一**（169 分，50+ 基准），**Artificial Analysis 只给 61 分**——与前代持平、落后 Claude Fable 5.1（66 分）。「这个模型有多强」正在变成多真相问题。

> 「Once frontier AI understands the mechanics, it generally executes within the range of human efficiency.」——ARC Prize
>
> 「While we believe Astra represents meaningful progress towards generalization, we are not claiming that it is AGI… Saturating the benchmark would not represent proof of achieving AGI.」——ARC Prize

## 四、正反观点

**支持方（这是真跃迁）**
- 标准赛道 7.78%→62.7% 与 harness 无关，是同条件下的纪录；Chollet 本人——史上最著名的 LLM 怀疑派之一——公开说「step-function」并把 AGI 预测提前，这个背书分量罕见。
- 行动效率超过人类中位数，直接命中「流体智能=少量经验习得」的定义，不是刷题记忆能解释的。
- Adapter 成绩不是作弊：ARC Prize 自己跑的、分开列榜；HN 用户 WASDx 的辩护有代表性——标准 harness 故意丢弃上下文才是「人为削弱」，OpenAI 的 harness 并非为 ARC 定制，是通用 context 管理能力。

**质疑方（先看清楚再喊 AGI）**
- metallab 等尖锐指出：99.9% 的头条数字「来自 harness 而非模型」，媒体几乎全用 99.9% 做标题——**评测传播层已经出现归因失真**；并呼吁榜单强制披露 harness 配置。
- Artificial Analysis 口径下 Astra 相对前代**零进步**，还落后 Fable 5.1——跨基准看，「跃迁」并不稳健。
- HN 方法论批评：人类受试被限时、模型只受预算约束，比较条件不对称（zone411）；「99.9% 了，那我们到 AGI 了？接下来该移动球门柱了」（piloto_ciego）——基准迭代（ARC-1/2/3/…）永远追着饱和跑，「AGI 认证」意义存疑。
- ARC Prize 自己承认：ARC-AGI-3 范围窄、机制确定且封闭，复杂度比真实世界低几个数量级。

## 五、深度解读：对行业、对做多 agent 系统的我们

**对行业**
1. **harness 成为榜单的一等公民**。从此看任何评测数字，第一个问题必须是「哪个 harness」。各家会开始提交 adapter 成绩，harness 披露规范将成为评测行业的下一个标准之争——谁先把「透明 harness 文档」做成规矩，谁就掌握评测话语权。
2. **评测机构分裂成方法论阵营**（Epoch 第一 vs AA 持平）。采购方、融资叙事、政策听证都会各挑对自己有利的榜单——第三方评测的公信力问题会在 Anthropic IPO、监管立法这些高 stakes 场景里被反复引爆。
3. **基准生命周期崩缩**：ARC-AGI-3 从上线到 99.9% 只用了 5 个月出头，Chollet 说比预期快一倍。ARC 已在探索下一代方向——「递归自我改进与开放式创新」——基准测什么，本身就是行业对「下一个能力前沿在哪」的投票。

**对我们（可执行判断）**
1. **我们做的 harness 层，官方定价 37 个百分点**。这是第一次有权威榜单给「上下文工程 vs 模型权重」的贡献比标出硬数字。团队资源分配的含义很直接：在换更贵模型之前，先把记忆管理做对——收益可能远大于升级模型。
2. **能抄的机制清单就两条，今天就能动手**：①请求间保留推理状态（OpenAI 侧=Responses API 的 reasoning state 复用；Anthropic 侧=extended thinking + 保留 thinking blocks）；②长任务用原生 compaction 而不是自己粗暴截断。注意反直觉的数字：**这么做同时提分（+37pp）、提速（3.66x）、降本（-28% 花费、-49% token）**——记忆管理不是成本项，是省钱项。
3. **评测纪律立刻改**：内部 benchmark 报告加「harness 版本」字段；跨模型比较只信 standard 条件；生产选型必须用**我们自己的 harness** 复测——榜单上的 adapter 成绩只证明「该厂商自家栈」的上限，不代表你的栈能拿到。
4. **交互式任务的自动化边界外移**。「需要在陌生界面/工具里试错摸索」的任务，过去被判为 AI 低效区；现在 96% 关卡行动数低于人类中位。盘点我们流程里被搁置的「探索型」自动化候选（陌生后台操作、无文档 API 摸索、逆向排查），判断依据已过期。
5. **风险面同轴推进**：adapter 的本质是把「不可见的推理状态」延续得更长——与 Astra 用 recurrent depth 潜空间推理、CoT 可监控性下降（system card 自认）是同一枚硬币。审计与安全设计要假设**推理层不可读**，把监控重心放在行动层与网络出口层（8/4 AISI 事件篇的结论在这里再次成立）。
6. **别把「99.9%」当成模型间可迁移的事实**。如果有人拿这个数字论证「Astra 遥遥领先、全栈迁移」，正确回应是：标准条件下是 62.7%，AA 口径下它没超过 Fable 5.1；多供应商热切换的架构判断不变。

## 六、接下来盯什么（信号）

- ARC 下一代基准官宣（「递归自我改进/开放式创新」方向）——测什么=下一个能力叙事。
- Anthropic / Google 是否提交 Fable 5.1、Gemini 的 provider adapter 成绩；榜单是否开始强制 harness 披露。
- OpenAI 的 reasoning-state 保留与 compaction 在 API 的开放程度与定价——决定第 2 条「抄机制」的落地成本。
- Epoch vs Artificial Analysis 的方法论分歧是否公开交锋（AA v4.2 刚把私有测试权重提到 40%）。
- 开源模型（K2 Horizon、GLM-5.3、Qwen 系）追平 62.7% 标准分的速度——衡量这次跃迁的护城河深度。
