# 💸 深度研究 ｜ 钱包先叛变：OpenRouter 上 OpenAI 两年半来第一次在「花钱」上超过 Anthropic

> **一句话定性**：这不是一次跑分超越——在 Artificial Analysis 的智能指数上两家打成平手、在标价上 Claude 甚至更便宜的前提下，付费开发者的钱还是流走了。**能力平价之后，胜负手换成了交付确定性**；而它偏偏发生在 Anthropic 把 Claude Code 周额度砍掉 17% 的同一周。

**来源**：@openrouter 官方数据，经 Techmeme 2026-09-15 收录
**🔗 原始链接**：https://www.techmeme.com/260915/p48

## 一、为什么这条值得深读

过去两年半，「Anthropic 在开发者里更受欢迎、OpenAI 在消费者里更受欢迎」几乎是行业共识，也是 Anthropic 一切叙事的地基——它的收入约八成来自 API 与企业、Claude Code 单品年化超 $25 亿、毛利故事全建立在「开发者愿意为 Claude 付溢价」之上（见 [[2026-09-14 深度研究-连续两季盈利与同日砍掉的17%]]）。

9/15 这条数据第一次从**付费行为**这一侧凿了一个口子：不是问卷、不是氛围、不是跑分，是真金白银的周度结算。而且它的方向与同一周另外三件事咬合得过于整齐——Anthropic 9/14 砍额度、开发者用代理把 Claude Code 接到 GPT-5.6 Sol 上、Ramp 数据显示 OpenAI 在 Q3 增速反超。单看任何一条都是噪音，四条叠在一起才值得做一次拆解。

---

## 二、核心事实（分层）

### 2.1 这次翻转本身

| 项目 | 数值 |
|---|---|
| 翻转发生周 | **2026-09-07 当周** |
| 上一次 OpenAI 领先 | **2024-02-26 当周**（间隔 2.5 年以上） |
| 本周 OpenAI 在两家合计支出中的占比 | **刚过 50%** |
| Anthropic 2024–2025 的常态区间 | **75–80%** |
| Anthropic 的前一个低点 | 2026-08-10 当周跌至 **50 多的高位**（high 50s） |
| 单一模型贡献 | **GPT-6 Astra 一个模型约占全平台支出的 19%** |

> ⚠️ 口径要点：OpenRouter 这张图量的是 **dollars, not tokens**——是「谁收到了钱」，不是「谁吐了多少 token」。对 Anthropic 这种高单价供应商而言，**丢钱包份额比丢 token 份额严重得多**。

### 2.2 同期的能力与价格对照（Artificial Analysis，2026-09 口径）

| 指标 | GPT-6 Astra (max) | Claude Fable 5.1 |
|---|---|---|
| AA Intelligence Index v4.3 | **53** | **53**（打平） |
| 输入 / 输出（每百万 token） | $10 / $50 | $10 / $50（同价） |
| 混合单价 | $7.70 | **$7.175（更便宜）** |
| 输出速度 | 54 tok/s | **66 tok/s（快约 22%）** |
| SciCode（纯编码） | 56% | **63%** |
| AutomationBench-AA（SaaS 工作流） | **68%** | 59% |

另据第三方定价对照：Astra 的 cache read 为 **$1/M**，Fable 5.1 为 **$0.25/M**；且 Astra 在输入超过 **272K token** 后跳档涨价，Claude 无此附加。

**这组数字是本篇最关键的反直觉点**：翻转既不能用「OpenAI 更聪明」解释（指数打平、纯编码还落后 7 分），也不能用「OpenAI 更便宜」解释（混合单价、缓存价、长上下文三项 Claude 全胜）。**那钱为什么还是走了？**

### 2.3 同一周的三个咬合事件

- **9/14 Anthropic 砍额度**：5/13 起的临时 +50% 于 9/13 到期，9/14 换成相对基线的「永久 +25%」，即**相对当前 −17%**。Anthropic 自己的原文是 "Compared to today, this works out to a 17% reduction in weekly limits on Claude Code."
- **9/15 The Information**：《Developers Find Ways to Use Claude Code Without Anthropic Models》——开发者用本地代理把 Claude Code 的 Anthropic Messages API 请求翻译成别家格式。公开仓库已支持 **GPT-5.6 Sol/Terra/Luna、Gemini 3.1 Pro/Flash、Z.AI GLM、任意 OpenAI/OpenRouter 模型**，README 明写 **"No Anthropic key required."**，并支持会话内 `/model` 热切换。
- **8/20 Ramp 数据（TechCrunch）**：覆盖 7 万余家美国企业的刷卡支出显示，5 月 Anthropic 41% / OpenAI 39%，7 月 Anthropic 约 44% / OpenAI 约 40%——**Anthropic 仍领先且在扩大**，但 OpenAI 在 Q3 至今增速更快。Ramp 经济学家 Ara Kharazian 的原话：*"GPT-5.6 Sol is really good, increasingly the choice for developers"*，而 *"Fable 5, meanwhile, disappointed both in adoption and real-world application."*

## 三、机制拆解：能力平价之后，钱按什么流动？

如果不是跑分也不是标价，剩下的解释只有三条，按证据强度排列：

**① 配给（rationing）本身就是一种涨价。**
标价没变，但你能买到的量变了。Claude Code 用户的典型抱怨是 *"I never really feel like I'm watching my Pro 20x usage on Codex, but with Claude I am checking it like every 30 minutes and rationing my week out."*（ZombieBallz，经 implicator.ai 收录）。对一个跑长任务的 agent 来说，**「随时可能撞墙」的期望成本远高于每百万 token 贵几毛钱**——它导致任务中断、状态丢失、重跑，而重跑的成本是全额的。OpenRouter 是按量付费市场，恰恰是这批「不想被周额度卡住」的负载的第一去处。注意这是**对偶现象**：OpenAI 8/25 也恢复了 ChatGPT Plus 上 Work 与 Codex 的 5 小时上限。两家都在配给，只是 Anthropic 这次的公告话术把「减」说成了「增」，额外付出了信任成本。

**② token 效率可能比单价更决定账单。**
坊间流传 Codex 完成同等任务所用 token 约为 Claude Code 的 1/4（某次 Express.js 重构对比：6.2M vs 1.5M）。**这个数字目前只有单一博客来源、无独立复现，我把它标为未证实**；但它指出的方向是对的：在 agent 场景里，真实账单 = 单价 × harness 的 token 消耗率，而 harness 的消耗率在不同实现间可以差数倍。**只比单价的采购决策在 agent 时代是失效的。**

**③ harness 与模型正在被用户强行解绑。**
Claude Code 的护城河一直被叙述为「产品体验 + 模型」的捆绑。代理层的出现意味着这个捆绑是**可被用户单方面拆开的**：留下 Claude Code 的交互与工作流，把推理换成 Sol 或 GLM。Anthropic 对此的反制是**自 2026 年初起封禁经第三方代理转发的订阅 OAuth token**（该行为违反其 Consumer Terms）——这恰恰证明它把这条路径当成真威胁。

> ⚖️ **规模校准（重要）**：本轮实测，那个最流行的公开代理仓库只有 **20 stars / 6 forks**。所以「开发者正在成规模地把 Claude Code 接到别家模型上」目前**不成立**；成立的是「这条路径已经技术可行、零成本、且被一线媒体点名」。**把它当作趋势的早期指示器，而不是既成事实。**

## 四、正反观点

### 支持「这是真格局转折」的一方
1. **钱比嘴诚实**。周度结算不是问卷，Anthropic 从 75–80% 掉到不足 50%，是一条持续了整个夏天的趋势线，不是单点跳变。
2. **单一模型吃掉 19% 支出**说明存在真实的、集中的迁移目标，而不是散射式的尝鲜。
3. **Ramp 的方向一致**：即便 Anthropic 在企业刷卡口径仍领先，增速已经反转，而增速通常领先存量 2–4 个季度。
4. **供应侧自证**：Anthropic 自己收紧额度，等于承认算力吃紧；吃紧的供应商必然向外挤出边际需求。

### 质疑「别读太多」的一方
1. **样本严重不代表市场**。OpenRouter 是路由市场，天然偏多模型比价、实验性和个人开发者负载；**Anthropic 的大头走直连 API、Bedrock、Vertex，完全不在这张图里**。相对于其 7 月底已超 **$650 亿**的年化收入，OpenRouter 全平台支出只是零头。
2. **一周就是一个点**。8/10 那周已经跌到 high 50s 又弹回去过，噪音幅度和这次翻转的幅度是同一量级。
3. **Astra 是 8 月新模型，19% 里有多少是评测流量而非生产迁移，无从区分**。新模型上线后的支出尖峰是 OpenRouter 的常规现象。
4. **Ramp 的反向读数同样成立**：7 月 Anthropic 44% vs OpenAI 40%，**Anthropic 不但领先而且比 5 月还扩大了**。Ramp 自己的caveat 是排除了走 Amex 的大企业、且有科技行业偏斜。
5. **OpenRouter 的 token 榜早已是另一个世界**：按 token 计，中国开源权重模型一年内从 15% 涨到 52%（1.02T → 39.9T tokens，CodeSOTA 2026-04-14 快照口径）。也就是说这张平台上真正的赢家既不是 OpenAI 也不是 Anthropic。**用 OpenRouter 论证任何一家美国实验室的"胜利"，本身就选错了样本。**

## 五、深度解读：对行业，以及对「做多 agent 系统的我们」

### 对行业

**（1）竞争维度换挡了：从「谁更聪明」到「谁更供得上」。** AA 指数打平、价格打平、编码 Claude 还赢——在这种条件下钱仍然流走，意味着前沿模型的**能力差异已经小到不再是采购的第一变量**。接下来两家拼的是产能、配额稳定性、token 效率和话术信用。这对所有下游都是好消息（可替换性上升），对上游是坏消息（定价权下降）。

**（2）「开发者忠诚」是 Anthropic 估值叙事里最贵的那块资产，现在出现了第一道可量化的裂缝。** 它正在 $2T 估值上冲刺史上最大 IPO（Reuters 9/11），而这条数据会进入每一份尽调。真正的风险不是 OpenRouter 这点钱，而是**「Anthropic = 开发者的默认选择」这句话第一次有了反例可引**。

**（3）配给公告的话术成本正在被定价。** 8/29 用「永久提升 25%」做标题、原帖删除后才承认「相对今天 −17%」，这件事在 9/14 生效、9/15 就撞上一条不利数据。两者未必有因果，但**市场会把它们读成因果**——这就是话术成本。

### 对「做多 agent 系统的我们」——落到可执行

1. **把「供应商可替换性」从架构原则降级为运维演练。** 代理层已经证明 Anthropic Messages API 形状可以被任意别家模型填充。我们的 harness 应当能在**一个配置项**之内切换底座，并且**这一步必须每月真跑一次**（跑一条完整的生产任务链，记录完成率与 p95 时长），而不是写在设计文档里。没跑过的可替换性等于没有。

2. **采购指标从「$/Mtok」改成「$/成功完成的任务」。** 本篇最硬的教训是：Claude 在混合单价、缓存价、长上下文三项全胜，钱还是走了。**单价是错的分母。** 我们应当为每条主力任务链建立 `成本 = 单价 × 该 harness 的实测 token 消耗率 ÷ 一次通过率` 的读数，按季度对各底座重算。那个未证实的「4 倍 token 差」哪怕只有一半为真，也足以吃掉任何单价优势。

3. **给「配额撞墙」建立一等公民级的降级路径。** 承接 9/14 已记录的配额探针建议，这次要补的是**降级目标的预热**：剩余额度 <30% 时不只是告警，而是把备用底座的连接、prompt 适配与缓存**提前打热**。撞墙时才开始适配等于把中断成本翻倍。生产路径全部走按量计费，订阅额度只留人工交互——这一条 9/14 已写，本条数据是它的独立佐证。

4. **别把 OpenRouter 的排名当成我们的选型依据，但要把它当成早期预警器。** 它的样本偏差太大（个人 + 比价 + 实验负载），不适合做选型；但正因为偏差在「最价格敏感、最愿意换」这一端，**它是流动性最高的那批需求的领先指标**。建议把它列为月度观察面板的一格，只看方向不看绝对值。

5. **把「模型侧的中国开源权重份额」正式纳入路由候选池评估。** 同一张平台上 token 份额 15%→52% 这件事，比中美两家谁领先重要得多。我们此前对 GLM / Qwen 档的态度是「观察」，在成本敏感的批处理、回填、评测跑批上，它应该升级为**默认候选并做一次真实 A/B**——代理层的存在意味着接入成本已经接近零。

6. **不因本条改模型选型。** 这是一条**市场与供给格局**的新闻，不是能力新闻。AA 指数打平、Claude 编码仍领先——主力推理路径不动，动的是合同、配额策略和备份路径。

## 六、接下来盯什么（信号）

1. **9/14 之后的第二周、第三周 OpenRouter 钱包份额**——若连续三周 OpenAI >50%，趋势坐实；若回落，本周即噪音。**这是唯一决定性信号。**
2. **Astra 那 19% 在 30 天后是否还在**——新模型尖峰通常在 4–6 周内衰减一半；不衰减则是真迁移。
3. **Ramp 的 Q3 完整读数**（预计 10 月）——若企业刷卡口径也出现 Anthropic 份额绝对值下降，两个独立样本同向即结论成立。
4. **Anthropic 是否在 30 天内二次调整 Claude Code 额度**——记忆里已记下「提额公告实为减额」一次；出现第二次即构成模式，其所有配额公告的可信度权重应当下调。
5. **Anthropic 对第三方代理的封禁是否升级**（从封 OAuth token 扩大到指纹/行为检测），以及是否出现官方「自带模型」选项——后者若出现，等于承认 harness 与模型必须解绑，是行业级转折。
6. **那个「Codex token 消耗仅为 Claude Code 1/4」的说法是否被独立复现**——这是目前最有价值的未证实数字，谁先做出可复现的对比谁就重设了整个采购口径。
7. **OpenRouter 上中国开源权重档的钱包份额（不是 token 份额）何时开始上升**——token 已过半，钱包一旦跟上，故事就不再是「OpenAI vs Anthropic」。
