# Claude Cowork 上移动/网页 + 91.3% 非编码使用数据——"办公 agent"成前沿新战线

**一句话定性**：Anthropic 把通用 agent Cowork 从桌面推到手机和网页、做成"后台长跑+跨设备+手机审批"的常驻协作者，同时首次公开一份反常识使用数据——**91.3% 的会话与写代码无关**。战场由此从"谁的模型/chatbot 最强"移向"谁占住工作真正发生的地方"，"编码 agent 战争"正式外溢到整个办公桌。

## 为什么值得深读 / 背景

过去半年这份监测反复深挖的是"编码 agent 战争"：Codex、Claude Code、Ona 长程 agent、Cursor 收购、Sonnet 5 编码商品化。所有叙事都默认**agent = 写代码的工具**。

Cowork 这次发布把这个默认前提直接掀翻。它不是又一个编码产品，而是 Anthropic 把 [[claude-code]] 那套"占领操作层"的打法**横向复制到普通知识工作**——并甩出一份自家使用数据证明：真正的需求早已不在代码里。这条之所以是本轮窗口（7/6–7/8）里最值得深读的一条，因为它同时命中两件事：

1. **格局层**：办公/知识工作 agent 成为前沿实验室的新主战场（区别于已被反复深挖的"编码 agent + 工具中立性"主线）；
2. **可执行层**："ambient（常驻后台）+ 跨设备 + 人在环审批"正在成为通用 agent 的默认形态，而 91.3% 非编码这个数字直接告诉做 agent 产品的团队：**价值重心该往哪挪**。

窗口内的其他候选（白宫框架仍未定稿、GPT-5.6 仍限 20 家、Gemini 3.5 Pro 延到 7/17、JADEPUFFER 自主 AI 勒索属已多次深挖的安全武器化主线）在"新 + 重 + 对我们直接可执行"三项上都不如它。

## 核心事实（硬数据分层）

**产品动作（2026-07-07）**
- Claude Cowork 2026 年 1 月首次以"预览"形态出现，仅限**桌面 App**；本次进入 **beta，登陆移动端（iPhone / iPad / Android，经 Claude App 侧栏）与网页（claude.ai）**。
- 先对 **Max 计划**开放，未来数周逐步扩展到更多付费计划。
- **会话在远端/后台运行**：关掉笔记本、手机关机也继续跑；**定时任务可无人值守执行**；会话与文件存进 Claude 账户、**跨设备跟随**（桌上起任务→手机上查看→浏览器里取成品）。
- **人在环（human-in-the-loop）**：当只有人能拍板时，agent **经手机弹问**；**"任何东西在用户审阅并批准前都不会被发送/定稿"**。
- **网页版是"阉割版"**：缺少文件访问、本地连接器、插件、浏览器控制、Computer Use——这些仍需桌面/直接操作屏幕。真正的重活还在桌面。
- **Chat 与 Cowork 合并**成一个 home tab（一个侧栏、一个搜索、一处放 Projects & Artifacts）；为配合发布，**翻倍的 Cowork 用量上限延长至 8 月 5 日**。
- **背后模型未公开**（可参照 [[claude-tag]] 跑在 Opus 4.8 上，Cowork 大概率同样吃旗舰，但官方未证实）。

**使用数据（这才是真正的新闻）**
样本：**120 万条匿名聚合 Cowork 会话，来自 60 万+ 组织，2026 年 5 月 11–31 日**：
- 业务流程与运营（Business Process & Operations）：**33.4%**（把散落更新拉成一份报告、做 onboarding 清单、对账电子表格）
- 内容创作与文案（Content Creation & Copywriting）：**16.4%**
- 软件开发：**仅 8.7%**
- 其他/未分类：**41.5%**
- **"91.3% 的抽样会话与软件开发无关"**——Anthropic 自己定性为 staggering（惊人）。
- Anthropic 的目标画像：那些"横跨大量岗位、却极少是某个人核心职责"的任务（*"part of a broad swath of jobs, but are rarely a person's core responsibility"*）。

**旁证：agent 已成软件/工作生产的主力（Vercel，7/6）**
- 半年前编码 agent 触发的部署 **<3%**，如今 **>50%**（Vercel 每天约 600 万次部署，一半由编码 agent 触发）。
- 月 token 量半年 **10×（约 2 万亿 → 20 万亿）**，AI gateway **日均 >1 万亿 token**。
- 两条数据合看：agent 既在吞掉编码（Vercel），又在向编码之外扩张（Cowork）。

## 机制拆解：ambient agent 的形态定型

Cowork 的产品形态把"通用 agent 该长什么样"给具体化了，值得逐条拆：

- **异步 + 后台长跑**：agent 不再是"你盯着它一问一答"，而是"你派活→它离线跑→你有空回来验收"。这解决了"我得一直陪着 agent"的痛点，是把 agent 从"副驾"往"能独立办事的同事"推的关键一步。
- **跨设备状态连续**：会话/文件绑账户而非绑设备。任务的"生命"脱离了单台机器，这是把 agent 当"云端持续进程"而非"一次性对话"来设计。
- **人在环收敛在决策点**：不是每步都问，而是**只在"只有人能决定"的岔口经手机弹问**，且**产出不经人审不外发**。这是 Anthropic 用来换取信任的核心机制——把自主性和可控性缝在一起。
- **能力按平台分层**：网页/手机拿到的是"读写文档、整理、多步办事"这层；文件系统/浏览器控制/Computer Use 这类高权限本地能力留在桌面。等于**按危险度和环境把 agent 能力做了分层暴露**。

一句话：Cowork = "把 Claude Code 的操作层占领打法，脱掉编码外壳，装进每个人的办公桌，并做成跨设备常驻"。

## 正反观点

**支持方（这是格局级动作）**
- **占住"工作发生的界面"> 拥有最强 chatbot**：模型能力在快速趋同/商品化（Sonnet 5 把编码打到 Opus 三分之一价），护城河正从"模型"搬到"工作流入口 + 分发"。谁常驻在用户干活的地方，谁就有留存。
- **91% 非编码 = 巨大的 TAM 证据**：agent 已经在真实世界大规模泛化到编码之外，"通用办公 agent"不是愿景而是现状。这给所有做垂直 agent 的团队指了需求方向。
- **ambient/async + 手机审批解决了"必须陪跑"**：把 agent 变成能后台独立办事、只在关键点找你的同事，是可用性的实质跃迁。

**质疑方 / 风险（TechCrunch 报道几乎零批评，以下为交叉推演）**
- **"工作发生的地方"是巨头的主场，不是 Anthropic 的**：Microsoft 手握 Outlook/Teams/Excel + Copilot Work IQ，Google 有 Workspace + Gemini Enterprise Agent 平台，OpenAI 有 ChatGPT + Codex 通用化。文档、邮箱、表格这些"工作真正发生的容器"归属于在位者；Cowork 是**外挂 agent，不嵌在工作载体里**，分发天然吃亏。
- **91% 非编码是把双刃剑**：它可能是"真泛化"，也可能说明 Cowork 眼下多用于**低风险胶水活**（对账、清单、拼报告），错了成本低——高价值、高容错要求的自主工作仍未被证明。而且编码正在商品化，往办公扩张也带**防御性**色彩。
- **手机人在环 = 吞吐瓶颈**：任务越关键越自主，越会卡在"等人批准"。异步 agent 频繁弹问还会制造**通知疲劳**——把旧瓶颈换成新 chokepoint。所谓"后台自主"有上限。
- **数据治理是准入闸，且官方没讲清**：一个会读文件、整理文件夹、在云端后台跨设备长跑的 agent，是**最重的信任托付**。各家报道均未披露保留策略、跨组织隔离、审计日志、密钥管理——对企业这恰恰是决定买不买的问题，目前空白。
- **"跨设备"是部分的**：网页/手机缺文件访问与 Computer Use，真正的重活仍绑桌面。
- **样本有偏**：数据取自 5 月 11–31 日、桌面独占期、Max/付费早期采用者，不代表大盘。

## 深度解读：对行业 + 对"做多 agent 系统的我们"的具体含义

**对行业**：前沿竞争的坐标轴在换。上一程比"模型强不强"（榜单、参数、算力）；这一程比"谁占住工作界面 + 谁的 agent 能被信任地放进真实工作流"。Cowork + Vercel 两条数据合起来是同一件事的两面——**agent 正从"写代码"扩成"干活的通用底座"**。而 Anthropic 缺 office 原生面，只能靠"跨设备 ambient + 人在环"差异化去抢一块本属巨头的地。承接 [[claude-science]]（护城河搬到 workflow/harness）+ [[claude-sonnet-5]]（编码商品化）主线。

**对我们（可执行判断，落到架构与选题）**
1. **agent 价值重心 ≠ 编码**：91% 非编码把真实需求指向"业务流程运营/内容/数据整理"这类**人人要做、却不是谁主业**的胶水工作。做垂直 agent 选题，优先往这里靠，而不是继续卷编码。
2. **把"ambient + async + 跨设备 + 人在环"做成一等架构**：我们的 agent 要支持后台长跑、断点交人审、跨设备/跨会话续跑；把"人只在关键决策点介入"做成显式原语（呼应此前**危险原语 allowlist / 可回滚 / 高危动作人审**主线）。这正在成为通用 agent 的默认形态，不做就落伍。
3. **但别把"后台自主"当真自主**：给"需人审的动作"建预算、支持批量/异步审批队列，主动压制通知疲劳，别让人在环变成新的吞吐瓶颈。同时**跟踪"无人工介入跑完率"KPI**，用它而非 demo 来判断自主性真实水平。
4. **数据治理是准入项不是加分项**：读文件/组织文件夹/云端后台=最重信任托付。把**保留策略、跨组织隔离、审计日志、密钥管理**做成框架一等公民并对客户讲清楚——Anthropic 都没讲清，这正是差异化机会窗口。
5. **分发劣势的打法**：若我们不拥有 office 原生面，就学 Cowork 走"嵌进用户已有工作面（侧栏/手机/浏览器都在）+ 低摩擦自下而上"；若我们拥有某个界面，就把 agent **嵌进工作真正发生的容器里**，别做外挂。
6. **模型可换、agent 层要中立**：Vercel CEO 同期主张"把模型从 agent 里拆出来"（agent 层应可换模型）——与本监测**多模型热切换 / 工具中立性会过期**主线一致。我们的 agent 别和单一 provider 不可逆绑定，保留跨模型迁移能力。

## 接下来盯什么（信号）

- **下沉与企业化**：Cowork 何时从 Max 下沉到 Pro/免费；是否进 Enterprise（管控/审计/合规细节一旦公布，才知道能不能进严肃场景）。
- **竞品办公 agent 动作**：Microsoft Copilot/Work IQ、Google Gemini Enterprise Agent、OpenAI ChatGPT agent/Codex 通用化、Mistral（已改名 Vibes）——谁把 agent 嵌得更深。
- **Chat + Cowork 合并后的形态**：是否"任何对话都能默认长成一个后台任务"，这会重塑交互范式。
- **可靠性数据**：是否公布 Cowork 背后模型 + 无人工跑完率/失败回滚数据（决定它是玩具还是生产力）。
- **数据治理披露**：保留/隔离/审计/密钥——企业采用的真正闸门。
- **旁证延续**：Vercel/AI gateway 的 agent 部署占比、token 增长是否继续加速。
