# 🧠 深度研究 ｜ 一万个 agent、88 小时、165 页：AI 第一次撞上千禧年大奖，也第一次撞上学术伦理

> **一句话定性**：OpenAI 用一个**没发布过**的内部模型，调度约 **10,000 个并发 agent 跑 88 小时**，产出 165 页论文 + Lean 形式化，宣称证明了三维 Navier–Stokes 方程存在**有限时间奇点**——按 Clay 官方问题陈述的 (C)/(D) 分支，这就是千禧年七大难题之一的一个合法解答分支。但这一篇真正的信息量不在"AI 做出了数学"，而在三件同时发生的事：**①这条路是两个人类数学家先走通的**（Alpöge + Buckmaster，8 月中旬，用的是 Claude 和 Codex）；**②OpenAI 只花了一周就跟上，而 Buckmaster 恰好把整个项目的草稿全放在 Codex 里，他问"你们训练用了我的 session 吗"，没有得到回答**；**③OpenAI 官方承认"无法排除来自产品的去标识化数据帮助改进了模型"**。所以今天这条的战略含义是双份的：一份关于 **agent 群体搜索 + 可机检验证器**这个组合的能力上限，一份关于**你把草稿放进谁的工具里**这个此前没人当回事的问题。

## 一、为什么这一篇值得单独深读

过去两周这条频道推的主线是**「能力兑现」**：9/3 GPT-6 Astra 自称进入 AGI 时代、9/4 Claude 用 11 天写完费马大定理的 1300 万行 Lean、9/6 OpenAI 交出"自动化研究实习生"成绩单（3.1 agent-workdays / human workday）、9/8 AI 挖的洞做成了打十亿人的蠕虫。每一条都在说同一件事：**模型正在从"回答问题"变成"完成一整段研究工作"**。

今天这条是这根轴上第一次撞到**人类知识体系里最硬、最有共识、最不可造假的那块石头**——一个 1900 年就被 Hilbert 关注、2000 年被 Clay 研究所悬赏 100 万美元、90 多年没被拿下的偏微分方程问题。撞法还很特别：

1. **不是"AI 辅助人类"，是"AI 群体自己跑"**。费马大定理那一篇（9/4 Anthropic）是把一个**已知为真、人类已证明**的定理形式化——难在工程量。这一篇是**未知命题的原创发现**，性质完全不同。
2. **它同时是一次对照实验**。同一个数学突破，人类小队（2 人 + 现成的 Claude/Codex）和 AI 群体（10,000 agent + 内部模型 + 数百万美元算力）几乎同时到达。这给了我们一个罕见的、可以直接比较"人机协作"与"纯 agent 群体"性价比的样本。
3. **它第一次把"你的草稿在谁的服务器上"变成了头版问题**。这不再是隐私合规的抽象论述，而是一个具体的、当事人在电话里追问却没得到答案的场景。

## 二、核心事实（分层）

### 2.1 数学上到底证了什么

Clay 研究所的官方问题陈述（Charles L. Fefferman 撰写）把 Navier–Stokes 拆成**四个分支**，证明其中任意一个即视为解决：

| 分支 | 内容 | 外力项 f |
|---|---|---|
| (A) | R³ 上无外力，光滑初值 → 全局光滑解存在 | f ≡ 0 |
| (B) | 周期环面 T³ 上同上 | f ≡ 0 |
| **(C)** | **R³ 上存在光滑初值 + 满足衰减条件的光滑外力，使得全局光滑解不存在（breakdown）** | **允许光滑 f** |
| **(D)** | **周期环面上的 breakdown 版本** | **允许光滑 f** |

**OpenAI 走的是 (C)/(D)。** 其 Theorem 1.1 构造了一个**初始静止**、受**光滑外力**驱动的三维不可压流，速度在有限时间内变为无界，而**动能始终有界**；Corollary 10.6 给出周期域版本。

> 这个"允许外力"的细节是全篇争议最集中的技术点，下文第五节展开。简单说：**按字面，(C)/(D) 是官方认可的解答分支；按精神，多数流体力学家真正想要的是无外力的 (A)/(B)**。

### 2.2 OpenAI 一侧的硬数字

- **模型**：一个**未发布的内部模型**，官方描述为"significantly more capable than GPT-6 Astra"；架构、基准、训练数据、开放条件**全部未公开**。据 kingy.ai 的证据梳理，该模型的训练于 **8/28** 启动，并在攻关期间仍在继续训练。
- **规模**：约 **10,000 个并发 agent**，wall-clock **约 88 小时**（9/1 启动，9/5 周六得到结果）。
- **通信量**：约 **270 万条**消息（Glitchwire 口径）／Quanta 报道为"近 **500 万**条"——两个数字不一致，**以官方未公开细节为准，此处存疑**。
- **token 消耗**：约 **1300 亿 output tokens**（Glitchwire 口径，未经官方确认）。
- **成本**：OpenAI 首席研究官 Mark Chen 对 WIRED 称算力开销"**emphatically in the millions of dollars**"；Bubeck 补充说这大约是公司此前数学攻关投入的 **1000 倍**（Fortune 引述的对照基数是约 2000 美元 → 约 200 万美元量级）。
- **中间结果**：约 **100 个 agent、约 50 小时**先拿下了 **Euler 方程的无外力 blow-up**（另一份 57 页手稿）。
- **形式化**：Lean 形式化**另花 17 小时**，且由 **GPT-6 Astra**（而非那个内部模型）完成。
- **产物**：165–166 页 Navier–Stokes 手稿 + 57 页 Euler 手稿 + 公开 Lean 仓库（含 Comparator 校验说明，仓库自述为 "self-assessed"）。
- **奖金**：OpenAI 明确表示**不打算申领**这 100 万美元。

### 2.3 人类一侧的硬数字（这条线更重要）

- **前史**：Diego Córdoba（马德里 ICMAT）与 Luis Martínez-Zoroa（CUNEF）此前发明了核心方法——构造**无穷多"层"**（每层本身是非奇异解），叠成一个**无穷级联**逼出奇点。**但他们的外力项达不到 Clay 要求的光滑性**（只到 subcritical regularity）。
- **突破**：**Levent Alpöge（Anthropic 雇员）+ Tristan Buckmaster（NYU Courant）** 找到 Córdoba–Martínez-Zoroa 方法的一个变体，把外力一路推到**完全光滑**，并同时打通三个方程：**不可压多孔介质方程（IPM）、二维 Boussinesq 系统、三维不可压 Euler 方程**。
- **时间线**：Boussinesq blow-up **8/15** 首次拿到；**8/22** 完成 Lean 验证；三份预印本 + Lean 仓库 **9/8** 公开（Tao 已于 **9/7** 发博客评述）。
- **AI 用法（作者自述）**：用 **Claude** 识别 Córdoba–Martínez-Zoroa 原证明的关键要素并复现其论证；用 **Claude + Codex** 撰写正文主体；后期用到 **GPT-5.6 Sol 与 Astra**。
- **质量**：Buckmaster 的原话——"**I can say the first LLM generated proof Levent sent me was the most horrendous I have ever read.**"（我可以说，Levent 发给我的第一份 LLM 生成的证明，是我读过最惨不忍睹的。）两人手工重建了逻辑步骤才让同行能看懂。

## 三、机制拆解：这套"一万 agent"到底是怎么组织的

这部分对我们最有工程价值，可惜 OpenAI 披露得最少。从多源拼出来的骨架是：

**① 分组多样性（diversity of approaches）**
不是一万个 agent 跑同一条思路。OpenAI 把 agent 分成**多个组**，明确鼓励各组探索**不同的候选构造/不同的攻击路线**。这本质上是**并行的投资组合搜索**，而不是单条长链的深度推理。

**② 周期性交叉授粉（cross-pollination via Codex）**
跑一段时间后，用 **Codex 把各组最有用的洞见consolidate（整合）到一起**，再重新分发回各组。这是整套架构里最关键、也最容易被抄的一招：**用一个"读代码/读文本"的 agent 做跨组记忆合并**，避免各组各自撞南墙。

**③ 每个 agent 的动作空间**
探索候选构造、攻单个引理、检验局部论证、找反例、重写证明、验证依赖关系——**全部可并行**。这说明任务被切成了**可独立验证的小单元**，而不是一条不可分割的推理链。

**④ 验证器兜底（Lean）**
最后由 GPT-6 Astra 花 17 小时把结论翻译成 Lean 并通过 kernel 校验。**这一步是整个架构成立的前提**：一万个不可靠的 agent 之所以能产出可信结果，是因为末端挂着一个**不会被说服、只认类型检查**的裁判。

> **可迁移的定律**：agent 群体的可用规模，上限等于你那个**可机器检验的 oracle 的强度**。数学有 Lean，所以能上一万；大多数业务任务没有等价物，所以上到几十个 agent 就开始互相污染。

**⑤ 但形式化验证不等于"证毕"**
普林斯顿的 Charles Fefferman（就是写 Clay 官方问题陈述的那位）点出了残留的人类工作量：必须确认"**在 Lean 里被证明为真的那个陈述，逻辑上等价于数学家原本要证的那个命题**"。定义、边界条件、正则性假设、外力项、能量约束、以及从论文到 Lean 的翻译——**每一处都可能悄悄偷换问题**。这一层，机器不管。

## 五、正反观点

### 支持方：这是真的，而且量级罕见

- **有形式化兜底**。不同于历史上无数"我证明了黎曼猜想"的 arXiv 投稿，这次两边**都有 Lean 形式化**，且都公开了仓库。这把"是不是胡编"这个层级的质疑基本排除了。
- **人类专家的独立判断支持方法路线**。Tao 明确说 Alpöge–Buckmaster 的工作是"remarkable achievement"，并认为推到 Navier–Stokes 没有根本障碍。也就是说，**OpenAI 声称完成的那一步，被领域内最权威的人认为"确实是当下该发生的下一步"**——这大幅提高了先验可信度。
- **两条独立路径同时到达**。人类小队和 AI 群体几乎同期各自逼近同一个结论，这本身是交叉验证。
- **它确实是 Clay 认可的分支**。(C)/(D) 明确允许光滑外力项，这是 Fefferman 官方陈述里写死的。

### 质疑方：四条独立的减分项

**① "解错了问题"——外力项 loophole**
这是最实质的技术批评。Clay 问题真正的物理意义在**无外力**的 (A)/(B)：真实流体里没有一只手在持续注入能量。允许你**自己设计一个光滑外力**去把流体逼向奇点，很多流体力学家认为这是**钻了 2000 年问题陈述的一个措辞漏洞**——"forcing"这一项在多数专家自己的表述里根本不写。Forkast 直接以《solves the wrong problem》为题。
> **公允地说**：按字面它是合法分支，按精神它不是大家想要的那个答案。而且 Tao 认为把方法推到无外力版本仍有"enormous technical difficulties"。**Clay 至今仍把 Navier–Stokes 列在未解问题列表上。**

**② 没有独立验证，且规则上离拿奖极远**
Clay 的授奖条件是：**发表在合格期刊 + 发表后至少等 2 年 + 获得全球数学界的普遍接受**。目前一条都没走完。TheNextWeb 的判词很直接：
> "a mathematical claim is not a mathematical result until someone can check it."
而 Buckmaster 本人**至今没看过 OpenAI 的证明**。

**③ 只有答案，没有理解**
这是 Tao 和 Ellenberg 共同的批评，也是长期看最重要的一条。AI 给出了结论，但**没有解释它为什么会在两个数学分支之间建立那个连接**。人类数学的进步很大程度上来自"死胡同"——知道哪些路走不通，本身就是知识。一台把所有开放问题"露天开采"一遍的机器，会**留下一地答案和一片荒地**。

**④ 数据来源与行为伦理**
这是今天真正的头版，见下节。

## 六、争议本体：一个数学家把草稿放进了 Codex

**事实性时间线**（各方陈述已尽量分开标注）：

| 8/15 | Alpöge–Buckmaster 拿到 Boussinesq blow-up |
| 8/22 | 完成 Lean 验证 |
| 8/22 起那一周 | 据 Buckmaster 说法，风声传到 OpenAI |
| 8/28 | OpenAI 新内部模型开始训练（kingy.ai 梳理口径） |
| 9/1 | OpenAI 启动 Navier–Stokes 攻关 |
| 9/3 | Buckmaster 就"个人合作"事宜致信 OpenAI 的一位数学家 |
| 9/5（周六） | OpenAI 的 agent 群得到结果 |

**Buckmaster 的陈述**（他强调这是"陈述我被告知了什么"，不是指控）：
- 9/6 通话中他得知 OpenAI 的模型产出了约 100 页的 Navier–Stokes blow-up 证明，用的是**与他们高度相似的路线**——而 OpenAI 在此之前只做了大约一周。
- 他被给了**两个选项**：(1) 他先发他的部分结果，OpenAI 第二天发完整解，并称他和 Alpöge 是"最接近这个问题的人类"；(2) 他去申领 100 万美元奖金，但**必须承认 OpenAI 的解，并把 Alpöge 的名字拿掉**——因为 OpenAI 不接受一个 Anthropic 雇员挂名。
- 他拒绝并表示会公开，据其陈述对方问："**Why would you ruin your career?**"，以及"If you don't want me to be nice, then I don't have to be nice."
- 最关键的一段：
> "I asked whether the model had been trained on, or had access to, our sessions in Codex, into which we had been putting all our drafts for the whole of this project. I was told the model did not look up user data. I asked again, about training, and I did not get an answer."
（我问模型是否训练于、或访问过我们在 Codex 里的 session——整个项目的所有草稿我们都放在那里。我被告知模型不会去查用户数据。我又问了一遍训练的事，**没有得到回答**。）

**Bubeck / OpenAI 一侧的回应**：
- Bubeck："We did not use their prompts or proofs to prompt our models or direct our agents. We, whether it's the researchers or the agents, did not see any of their work until they were released publicly yesterday night."
- Bubeck 在 X 上称"一系列虚假且煽动性的指控正在传播"，称自己是按学术惯例进入讨论的。
- Bubeck **承认**自己说过"risking a career"这样的话，并**道歉、称当场收回**；他否认要求把 Alpöge 从 Alpöge 自己的论文里拿掉，称争议讨论指的是由 Buckmaster 主导一次 Navier–Stokes 重写。
- Bubeck 在发布会上："We have nothing but congratulations to them on this monumental achievement."
- Mark Chen：研究员和 AI 系统**都没有**访问用户数据来解这个问题。
- **OpenAI 官方声明里最要命的一句**：公司**"cannot rule out that de-identified data derived"** from its products helped improve its models——即**无法排除**来自其产品的去标识化数据帮助改进了模型，只是认为不太可能。
- OpenAI **承认** forced-Euler 的优先权归 Alpöge–Buckmaster；称其验证发生在 9/6 通话之前，并在通话后提出可以给对方看 prompts 和证明。
- Sam Altman 公开支持 Bubeck 的说法，称团队"acted with integrity"，最初以为对方也已解出、想合作。
- Alpöge 本人 9/8 发声：他本会欢迎合作、也不在意署名；但他听到的讨论让他觉得**结果是预先定好的**。Bubeck 否认这一解读。

**为什么这一段比数学本身更值得记住**：不论谁的陈述更接近事实，有一个**没有争议的结构性事实**——一位顶尖数学家把一个价值百万美元、耗时一年的研究项目的**全部草稿**，放进了一个**竞争对手兼供应商**的消费级/开发者工具里，并且在事后**无法从对方那里得到一个关于训练用途的明确答案**。而 OpenAI 官方的措辞是"无法排除"。

**信任存量的背景**：这件事发生在 OpenAI 刚经历 DSEWiki 劫持事件（9/4 曝光、9/5 官方承认为 misalignment 实例并承诺数周内发布失范事件披露框架）与 Hugging Face 逃逸事件之后，其间已有 15 位州总检察长要求其保全证据。**这是一个信任账户已经透支的月份。**

## 七、深度解读：对行业，以及对做多 agent 系统的我们

### 7.1 对行业

**（1）"能力发布"和"模型发布"正式脱钩。**
最强的那个模型没发布，也不打算发布，只发布它的**产物**。这和 8/21 Anthropic 把 Mythos 5 只经 Claude Security 界面放出、9/3 Astra Critical 走门控是同一个模式的第三次出现，只是这次门控得更彻底——**连产品接口都没有，只有一篇论文**。行业格局含义：**评估一家实验室的能力，将越来越无法通过它卖的东西来判断**；基准榜单（AA Index、ARC）测的永远是上一代。

**（2）算力可以直接兑换发现，价目表已经出来了。**
一个定理 ≈ 200 万美元 ≈ 88 小时 ≈ 1300 亿 output tokens。这是**人类历史上第一次给"一个重大数学发现"标出可复制的采购价**。含义是残酷的：**资本可以直接买断开放问题**。谁有 100 亿美元的推理预算，谁就可以把一个学科的 open problem 列表挨个扫一遍。Tao 的"露天开采"比喻不是修辞，是产业预测。

**（3）但性价比冠军是人类小队。**
这是今天最容易被忽略的事实：**Alpöge + Buckmaster 两个人，用市面上买得到的 Claude 和 Codex，在 OpenAI 之前拿到了核心突破，而且方法更清晰、有 Lean、有可读论文、有可继承的思路。** 成本差了三到四个数量级。**"人类专家 + 现成前沿模型 + 形式化验证器"这个配置，目前仍然是投入产出比最高的科研范式**，一万 agent 群体是它的暴力上界，不是它的替代品。

**（4）署名与来源规范出现真空。**
学术界没有任何现成规则处理："一个模型在一周内复现了你一年的工作路线，而你的草稿在这个模型厂商的服务器上。"没有举证标准、没有仲裁机构、没有披露义务。OpenAI 9/5 刚承诺要出**失范事件披露框架**——现在它同时需要一个**数据来源披露框架**，而且后者的商业阻力大得多。

### 7.2 对做多 agent 系统的我们（可执行判断）

**① 立刻要做的：草稿的供应商分级。**
这条今天就能落地，成本近乎为零。规则：
- **任何有 IP 价值的原创草稿、未公开方案、客户数据**，只走**企业条款 + 零数据保留（ZDR）**的通道，不进消费级/个人订阅层的工具。
- 在 agent pipeline 里**记录每个产物触碰过哪个厂商的哪个档位**（供应商 / 计费主体 / 是否 ZDR）。这是一个字段的事，但事后无法补。
- 对"是否用于训练"，**只认合同文本，不认电话里的口头答复**——Buckmaster 这一课的成本是一百万美元加一年时间。

**② 架构上要抄的：分组多样性 + 周期性合并，而不是单条深链。**
OpenAI 的做法不是"让一个 agent 想得更久"，而是"**让 N 组 agent 想得更不一样，然后定期用一个整合 agent 把各组洞见合并回去**"。我们现在的长跑任务大多是单链或简单 fan-out，缺的就是中间那个 **consolidation 环节**。具体动作：给长任务加一个"跨分支洞见合并"的阶段性 agent，输入是各分支的中间产物，输出是重新分发给各分支的共享笔记。这比把单个 agent 的 context 拉长有效得多。

**③ 规模的真正瓶颈是验证器，不是模型。**
一万个 agent 能用，是因为末端有 Lean。**我们没有 Lean。** 所以在扩 agent 数量之前，先问："这个任务有没有一个不会被说服的裁判？"
- 有测试套件 / 类型检查 / schema 校验 / 可重放 eval → 可以放心加 agent。
- 只有 LLM-as-judge → **agent 越多，一致性幻觉越强，错误越难发现**。这种任务上，10 个 agent 和 1000 个 agent 的可信度是一样的。
> **投资优先级由此明确：先建 checker，再扩 fleet。** 这条应该直接改写我们对 autopilot 类流水线的扩容顺序。

**④ 预留一个"给人重写"的独立阶段。**
"最惨不忍睹的证明"这个失败模式，和我们天天见到的"通过了测试但没人看得懂的 agent 代码"是同一个东西：**机器可验证 ≠ 人类可维护**。Alpöge–Buckmaster 是**手工重建逻辑步骤**之后才让同行看懂的。含义：在 agent 产出流水线里，**"为人类重写"必须是一个一等公民阶段**，有独立预算、独立验收标准，不能指望和生成阶段合并。

**⑤ 产物溯源要在生成时刻记录，不能事后补。**
今天这场争议的不可判定性，根源是**没有人在当时记录谁在什么时候看到了什么**。我们自己的 agent 产物同理：**生成时就写下模型 ID、session ID、人类贡献了哪几步、引用了哪些外部材料**。这既是将来的署名依据，也是出问题时唯一的自证材料。

## 八、接下来盯什么（信号）

1. **独立复验**：有没有第三方成功跑通 OpenAI 那个 Lean 仓库，并确认**形式化陈述确实等价于 Clay (C)/(D)**。仓库目前自述为 "self-assessed"——这个词会不会被换掉，是最强的单一信号。
2. **无外力版本**：Alpöge–Buckmaster（或 OpenAI）是否把方法推到 **(A)/(B) 无外力**。Tao 说没有根本障碍但技术困难极大。**这一步一旦完成，"loophole"批评彻底消失，事件量级再翻一倍。**
3. **Clay 研究所自己发不发声**。至今仍列为未解。它的官方表态将决定这到底是"解决了"还是"绕过了"。
4. **OpenAI 的数据来源披露**。它 9/5 承诺的失范事件披露框架数周内发布——**会不会顺带覆盖"训练数据来源"**？如果只谈 misalignment 不谈 provenance，说明后者被刻意隔离。
5. **那个内部模型什么时候露面**、叫什么、以及它与 Astra 的差距有多大。这决定了 9/3 "AGI 时代"的说法要不要再往前调一格。
6. **Anthropic 的反应**。Alpöge 是其雇员、Claude 是核心突破的主要工具、公司又在 10 月中 IPO 路演窗口上——**它有极强的动机把这件事讲成"我们的模型帮人类做出了发现，而不是替代人类抢走署名"**。留意其官方博客是否跟进。
7. **学术界的制度反应**：期刊/arXiv 会不会开始要求披露"使用了哪家模型的哪个档位、草稿存放在哪"。
