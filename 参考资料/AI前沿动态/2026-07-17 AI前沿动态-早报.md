# AI 治理裂成两大阵营：习近平首登 WAIC 推 WAICO，同周美国三大实验室监管抱团

> **一句话定性**：在同一 48 小时里，北京和华盛顿各自为"谁来给世界的 AI 定规矩"插了旗——一边是习近平首次亲登世界人工智能大会、力推以「开源权重 + 全球南方 + 算力普惠」为卖点的 WAICO（世界人工智能合作组织），另一边是 OpenAI/Anthropic/Google DeepMind 三家在监管上罕见趋同、都主张「由美国而非对手国家制度」来主导有国际影响力的机构。**这不是又一条治理新闻，而是全球 AI 明确分叉成两套栈的开幕式**；对做多 agent 系统的团队，它把"多辖区架构 / 多模型热切换 / 开源抗断供"从架构选项升级为一等生存约束。

## 为什么值得深读 / 背景

过去一个多月，本监测反复深挖的都是**美国这一侧的"国家安全门控范式"**：Fable 5 因越狱能力被出口管制强制全球下线（6 月）、特朗普 EO 14409 给联邦"发布前最多 30 天国家安全审查"、GPT-5.6 成为"第一款经门控审批放行才 GA 的旗舰"（7/9）、白宫 Gold Eagle 联邦级 AI 网防清算中心（7/14）、以及 7/13 北京反向对开源权重加出口管制。**一句话：全世界都在给前沿模型的"发布"和"跨境"设闸门。**

7 月 16–17 日发生的事，是这条主线的**质变**——它不再是各国各自设闸，而是**两个阵营开始争夺"由谁来给全世界设闸、按谁的价值观设闸"**：

- **中国侧**：习近平**首次亲自**出席并主旨演讲（该会 2018 年创办以来他从未到场，历年只派贺信或李强出席），把 AI 治理明确升格为最高领导人级的地缘战略议题，并把去年提出的 **WAICO 落地上海**、面向全球南方推销一套"另一条路"。
- **美国侧**：同一周，Axios 复盘指出三家美国前沿实验室 CEO 在过去五周分别发文，**诊断和药方高度趋同**——都要前沿模型"面向公众前先接受外部审查"，都要"美国、而不是碎片化的各州或**对手国家制度**"来主导一个"有国际影响力的机构"。这里的"rival national regimes（对手国家制度）"几乎是点名 WAICO。

两件事撞在一起，等于把"世界会不会分成两套 AI 治理栈"这个悬了两年的问题，**在一个周末给出了肯定回答**。这对任何要在多地区部署、要跨地缘选模型/选算力的团队，都是底层假设级别的变化，值得深读。

## 核心事实（分层）

### 一、中国阵营：WAIC 2026 / 习近平 / WAICO（硬数据）

- **规格与体量**：WAIC 2026 + 全球人工智能治理高级别会议，7/17–20 上海，主题 **"AI Partnership for a Brighter Future"（智能共生 · 全球共赢）**；官方数字 **140+ 场论坛、1,400+ 嘉宾、1,100+ 参展商、300+ 全球首发新品**；**9 位诺贝尔奖 / 图灵奖得主**到场（姚期智、Richard Sutton、Yoshua Bengio、Thomas Sargent 等）。
- **习近平主旨演讲（按官方预告的议程，非已核实逐字稿）**：将"系统阐述中国关于 AI 发展与治理的政策、立场、主张"，并预计发布两项抓手——
  1. **《惠及世界的中国方案》案例集（"China Wisdom for the World"）**：汇编覆盖 **20+ 国**的合作项目，把中国 AI 应用打包成"可供全球采纳的范式"；
  2. **《人工智能发展合作行动计划》（Action Plan on Cooperation in AI Development）**：主推**算力普惠 + 共享开源生态**。
- **WAICO（世界人工智能合作组织）**：2025 年由李强总理在上届 WAIC 提出，**永久总部定于上海**，上海人工智能实验室为事实上的秘书处；定位对标"上海合作组织"，但聚焦技术治理而非安全，明确面向**全球南方**开出"三件套"：**开源权重模型 + 更便宜的推理 + 一个正式的规则制定席位**。
- **算力自主的物质基础（华为 Atlas 950 在会上展出）**：华为 Atlas 950 SuperPoD 由 **8,192 张昇腾 950DT** 组成；华为宣称 **8 FP8 ExaFLOPS / 16 FP4 ExaFLOPS**，总算力约为英伟达下一代 NVL144 的 **6.7 倍**、NPU 数量 56.8 倍、互联带宽 62 倍（16.3 PB/s）、内存 15 倍（1,152 TB）。（注：该系统 2025 年 9 月已首发、2026 年 MWC 展出过，此番是作为"中国算力自主"的旗舰在 WAIC 陈列，**并非当日新发**；且集群级宣称口径难独立复现——见下"质疑"。）
- **另一件事**：英伟达 CEO 黄仁勋以"日程冲突"**缺席**——一年前他还是 WAIC 座上宾，如今在出口管制夹缝里对这个舞台避而远之，本身就是信号。
- **官方叙事定调（新华社 7/16 评论）**：反复强调"**AI 应成为惠及全人类的国际公共产品**""AI for good and for all"；点名反对"**用排他性小圈子或供应链断链**阻碍他国 AI 发展"、反对把 AI 变成"少数富国主导的游戏或维系技术霸权的工具"。中国核心 AI 产业 2025 年规模超 **1.2 万亿元**，人形机器人年产能瞄准 **10 万台+**；并晒出"妈祖（MAZU）极端天气预警系统已被 40+ 国采用"等全球南方样板。

### 二、美国阵营：三大实验室监管趋同 + 门控范式（硬数据）

- **趋同的核心（Axios 7/16）**：OpenAI / Anthropic / Google DeepMind 三家 CEO 在过去五周各自发文，**诊断与药方高度一致**——(1) 前沿模型在面向公众前**应接受外部审查（outside scrutiny before public release）**；(2) 应由**美国**、而非"碎片化的各州或**对手国家制度**"，来主导一个**有国际影响力的机构**。
- **但在"谁来审"上仍有内讧**：
  - **Anthropic** 背书**州级立法**（加州 SB 53、纽约 RAISE Act、伊利诺伊 SB 315、马萨诸塞透明度法案），因其 Responsible Scaling Policy 已满足这些法案的文档 / 风险评估要求，把合规做成 **Q4 2026 IPO 的差异化卖点**；
  - **OpenAI** 走**"反向联邦主义"**、力推单一联邦标准、反对"50 个州各管一套 = 50 倍合规成本"，押注华盛顿关系与**联邦优先（federal pre-emption）**。
- **门控范式做底座**：这套"发布前审查 + 美国主导国际机构"的主张，正落在本监测追踪数月的制度化实体上——EO 14409、白宫前沿模型框架、Gold Eagle、出口管制、可信伙伴（Trusted Access）白名单。**换言之，美方阵营的"栈"是：门控发布 + 出口管制 + 美国定国际规则。**

## 机制拆解：为什么这是"两套栈"，而不只是"两种表态"

把两边的主张翻译成对开发者的**具体约束**，就能看清分叉不是嘴上的，而是**架构级**的：

| 维度 | 美国主导阵营 | 中国主导阵营（WAICO） |
|---|---|---|
| 模型供给 | 前沿闭源为主，**发布前门控审查**，能力可被"下线/限流"（Fable 5 先例） | **开源权重**优先，"可下载可自托管"作为卖点（Inkling/DeepSeek/GLM/Kimi/Bonsai） |
| 算力底座 | 英伟达 + 台积电 + 先进封装（出口管制为杠杆） | **昇腾自研硅 + 国产集群**（Atlas 950），以"抗断供"为纲 |
| 定价逻辑 | 前沿溢价（$/Mtok 高），被 Karp 讥为"财富税" | **推理普惠 / 更便宜**，作为对全球南方的政策卖点 |
| 规则制定 | 美国主导、国际机构、可信伙伴白名单 | **WAICO 多边体、全球南方席位**、"公共产品"叙事 |
| 合规红线 | 国家安全、出口管制、发布前审查 | 内容 / 意识形态 + 防沉迷（对内也硬：见 7/15 拟人化新规下线一整类 agent） |

**关键机制**：一旦"模型来自哪个阵营"开始决定"能不能在某地区合法部署、跑在什么算力上、受哪套审查约束"，那么**模型选择就不再是纯技术/性价比问题，而是地缘合规问题**。这正是本监测此前"多辖区 agent 架构 / 多模型热切换 / 开源=抗断供保险"三条主线**汇流的宏观根因**——今天它们第一次有了一个清晰的"为什么必须现在就做"的答案。

## 正反观点

**支持 / 看多中国阵营（WAICO 有真实吸引力）**
- 全球南方确实被西方框架冷落：既买不起前沿闭源 API，也进不了美国"可信伙伴"白名单。**"开源权重 + 便宜推理 + 一个规则席位"是实打实的价值主张**，对没有前沿实验室的国家很难拒绝。
- 中国的**制造 / 算力自主在材料层面真在推进**（昇腾集群、1.2 万亿产业、10 万台人形机器人产能），"抗断供"不是空话。
- 开源近前沿这一年密集兑现（DeepSeek V4、GLM-5、Kimi K2.5、腾讯 Hy3、Inkling、Bonsai 端侧），给了 WAICO 叙事真实弹药。

**质疑 / 看空（"公共产品"叙事的裂缝）**
- **WAICO 更像势力范围而非中立标准体**：对标"上合组织"本身就说明它是**地缘集团**，不是 ISO 式的技术中立机构；"案例集 + 行动计划"目前是**展示与倡议，非有约束力的标准**，落地存疑。
- **"开放"与自家"硬控"并存**：中国一边喊公共产品，一边 7/15 依《拟人化交互新规》**强制下线一整类已部署 agent**、7/13 对开源权重加**出口管制**——对内对外都在设闸，双标同样存在。
- **Atlas 950 的宣称难独立复现**：集群级 6.7×/62× 是理论峰值，8,192 卡跨 160 机柜 /1,000㎡ 的通信开销、良率、功耗与先进制程/HBM 供给约束都会大幅折损真实性能；且英伟达仍握有软件生态（CUDA）与真实前沿算力。
- **前沿仍在美方手里**：最强模型（GPT-5.6 / Opus 4.8 / 即将的 Gemini 3.5 Pro）、最强算力（英伟达）、最多资本（H1 两家独揽全球 VC 43%）都在美国阵营；WAICO 目前是"追赶者的联盟"。
- **美方阵营自身的矛盾**：一边讲"开放审查 + 多边"，一边搞出口管制、把已部署模型（Fable 5）强制下线——这恰恰是中国指控"排他性小圈子 / 技术霸权"的口实。**两边都在"设闸"，只是叙事包装不同。**

## 深度解读：对行业 + 对「做多 agent 系统的我们」的具体含义

**对行业**：AI 竞争的主战场，正在从"谁的模型强"上移到"**谁来给世界的 AI 定规矩**"。今天之后，模型的"国籍"会越来越多地决定它的可部署性——**技术选型正在被地缘政治重新定价**。这也解释了为什么开源近前沿这一年会如此密集：**开源权重是 WAICO 这套叙事的核心弹药，也是被门控/出口管制/监管下线时唯一不受单边控制的供给**。

**对做多 agent 系统的我们**（落到可执行判断，不是套话）：

1. **把"阵营"变成架构里的一等维度**：不要只按"能力/价格"选模型，要建**跨阵营的可切换供应商矩阵**——至少一家美系闭源前沿（Claude/GPT/Gemini）、一家可自托管的开源近前沿（DeepSeek/GLM/Kimi/Inkling），再加一档端侧兜底（Bonsai 类）。**模型抽象层（provider-agnostic）现在是保险，不是洁癖**。呼接 Fable 5 出口管制下线、Vercel"把模型从 agent 里拆出来"。

2. **多辖区合规做进产品，而非事后补丁**：一套 agent 要能按部署辖区切换"用哪个阵营的模型 / 跑在什么算力 / 受哪套审查"。把**辖区路由**和**多模型热切换**并列为一等约束（与 7/15 拟人化新规笔记里的"多辖区 agent 架构"同源）。

3. **开源权重 = 业务连续性保险，要提前算 TCO**：WAICO 让"可自托管"从政治口号变成真实供给，但**自托管的门槛在内存/算力预算而非"能不能下载"**（Inkling 原生 16-bit 需 >2TB GPU 内存）。现在就把关键 agent 负载的"若前沿 API 被断/被限，我切到哪个开源权重、托管成本多少、能力掉多少"算清，写进业务连续性预案。

4. **算力供应链的单点风险要对冲**：英伟达仍是软硬件事实标准，但出口管制 + 昇腾崛起意味着**算力底座也在分叉**。若产品面向多地区，评估"美系云 + 国产算力"混合部署的可行性，别把"永远买得到英伟达 + 永远有便宜 token"当默认假设（呼接 7/16 台积电 Q2 深研的成本地板判断）。

5. **护城河仍是 eval / 验证 / 可靠性，不是"押对阵营"**：两套栈都会有能用的模型。真正稀缺的是**用更少 token 把任务做对**的工程能力、可回滚/可审计/人审 gate 的安全原语、以及跨模型的一致质量评测。谁能在任一阵营的模型上都稳定交付，谁就不怕分叉。

## 接下来盯什么（信号）

- **习演讲逐字稿**：《人工智能发展合作行动计划》是否含**具体的算力/开源承诺**（如国产算力对外开放额度、开源模型清单），还是仅止于倡议。
- **WAICO 首批成员国名单**：有多少全球南方国家实质加入、是否有约束性条款——决定它是"标准体"还是"势力范围"。
- **美方是否给出对应的国际机构方案**：Axios 说三家都要"美国主导的国际机构"，但具体形态（新条约？CAISI 扩权？G7 框架？）尚未落地；两边会不会各建一套互不承认的"发布前审查"体系。
- **Gemini 3.5 Pro 的 GA**（本应就是今天）：官方仍标 "coming soon"、AI Studio 未上架、定价传闻自相矛盾（$15/$60 vs $1.25/$10 两种口径并存）。一旦真 GA + 出真实 agentic 基准（SWE/Terminal-Bench/OSWorld）+ 定价，单独深挖。
- **昇腾集群的独立实测**：Atlas 950 在真实大模型训练/推理上的可复现性能与良率、功耗，是判断"中国算力自主"成色的关键。
- **企业侧用脚投票**：全球南方 / 一带一路国家的政企采购，是否开始出现"因合规/成本转向中国阵营模型"的实际案例。
