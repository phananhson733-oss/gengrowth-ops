# 深度研究 · 断供成了武器——OpenAI 掐断 Cursor，「API 中立性」时代正式结束

**一句话定性**：SpaceX 完成 $600 亿收购 Cursor 仅两周后，OpenAI 行使 change-of-control 条款宣布 11 月 12 日断供全部模型——模型 API 第一次被前沿实验室公开当作对抗竞争对手的武器，「把核心业务建在别人模型上」的平台风险从理论变成了判例。

- **来源**：OpenAI 官方博客《Our decision on Cursor following its acquisition by SpaceX》（官方页对抓取返回 403，内容经 CNBC / Engadget / the-decoder / TNW / Yahoo Finance 多源交叉核实）
- 🔗 **原始链接**：https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex/
- **日期**：2026-08-28/29（8/14 SpaceX 完成收购交割，两周后 OpenAI 官宣）

## 为什么值得深读 / 背景

本频道 6/16 深挖过 SpaceX $600 亿全股票收购 Cursor（有记录以来最大的 VC-backed 创业公司收购），当时的判断是马斯克拼齐了「自有前沿模型（Grok）× 头部 IDE（Cursor）× 自有超算（Colossus）× 自有分发（X/Grok Build）」的垂直整合闭环。现在闭环的代价单来了：**8/14 交割完成，8/28 OpenAI 就行使合同里的 change-of-control 条款启动断供**，通知期给到合同允许的最长值（约两个半月），11 月 12 日生效。

这件事的战略含义远超 Musk–Altman 私人恩怨：它是第一次有前沿实验室**公开、成文、以官方博客形式**宣布因为「所有权变更 + 不信任新东家」而切断一个头部应用的模型供应。2025 年 6 月 Anthropic 断供 Windsurf（当时 OpenAI 拟收购它）是同一剧本的先例，但那次没有官方檄文。这次 OpenAI 把理由、证据、日期全部写成公开声明——**模型供应从商业合同升格为地缘筹码，且有了可引用的行业判例**。

## 核心事实

**断供决定本身**
- 生效日期：2026-11-12，OpenAI 称这是「合同允许的最长通知期」（8/28 官宣起约 76 天）
- 触发机制：SpaceX 8/14 完成对 Anysphere/Cursor 的 $600 亿全股票收购 → OpenAI 行使 change-of-control（控制权变更）条款
- 断供范围：Cursor 内置的全部 OpenAI 模型 API 通道，**包括未来模型（官方点名 Astra）**
- 保留的口子：用户**自带 OpenAI API key（BYOK）仍可在 Cursor 里用 GPT 系模型**；OpenAI 自家 IDE 扩展不受影响

**OpenAI 的举证（声明中列出的马斯克公司违约史）**
1. Twitter/X：马斯克收购 Twitter 后单方面终止了 OpenAI 的推文数据授权协议（the-decoder 口径：价值约 $200 万/年）
2. xAI 蒸馏：用 OpenAI 模型输出训练 Grok，违反服务条款——马斯克本人已于 2026 年在庭审中宣誓承认 Grok 训练「部分」使用了 OpenAI 输出（The Verge 4 月报道口径）
3. 诉讼背景：马斯克 2024 年起诉阻止 OpenAI 营利化转制，2026 年 5 月联邦陪审团裁定马斯克败诉，其表示将上诉

**各方回应**
- Cursor 联创 Michael Truell：OpenAI 模型只占 Cursor 用户流量约 **5%**；正与 OpenAI 谈判争取转圜；强调 Cursor 是 OpenAI 最早的客户之一（2023 年拿过 OpenAI Startup Fund 种子投资）
- Anthropic 联创 Tom Brown 在官宣后**数小时内**表态补位（原话见下节）
- 马斯克的全部回应："I couldn't care less."（我毫不在乎）

**竞争格局数据（理解此事的坐标系）**
- Anthropic Q2 2026 收入 $115 亿，首次反超 OpenAI 的 $67 亿（WSJ 8/19 独家，本频道已推）；其中 Claude Code 贡献约 $80 亿
- 企业 LLM 支出份额：Anthropic 40% vs OpenAI 27%（Menlo Ventures 数据，forkast 引用)
- Cursor 被收购后已与 Grok 深度绑定：8/12 Grok 4.6 与 Cursor 联合发布（本频道已推）；6 月起在 Colossus 上从零自训 1.5T 参数编码模型

## 机制拆解：为什么 5% 的流量值得一篇官方檄文

表面看这是一次小手术——Truell 自己说只有 5% 流量。但拆开看三层：

1. **对 OpenAI**：Cursor 已经是 Codex 的头号竞品，且新东家 xAI/SpaceX 有蒸馏前科。继续供货等于把自家模型输出源源不断送进对手的训练管线——蒸馏风险下，「卖 API 给竞对」的数学不成立。断供成本（5% 流量的收入）远小于资敌成本。这与 2025 年 Anthropic 方 Jared Kaplan 解释断供 Windsurf 的逻辑一字不差：「把 Claude 卖给 OpenAI 会很奇怪」。
2. **对行业**：change-of-control 条款人人合同里都有，以前没人当真。现在有了公开判例：**你的模型供应商会盯着你的股权结构表**。被收购、被投资、甚至大客户关系变化，都可能触发上游断供。
3. **对监管**：TNW 指出 EU Data Act（2025 年 9 月生效）的云切换条款只保护「主动离开供应商的客户」，不保护「被供应商抛弃的客户」——欧洲的 Cursor 开发者只能拿到合同通知期，没有任何法定保护。模型 API 是否算受监管的云服务，在欧盟法下仍是未决问题。这个缺口大概率会成为下一轮 AI 立法的素材。

## 正反观点

**支持 OpenAI 的一方**：这不是任性，是风控。马斯克公司的违约记录是实打实的——Twitter 数据协议说撕就撕，蒸馏是庭上宣誓承认的。把前沿模型供给一个有蒸馏前科、法律上正在互殴的直接竞对，等于资敌。而且 OpenAI 的执行相对克制：走合同流程、给最长通知期、保留 BYOK 逃生门、只针对 Musk 而非整个编码工具生态。

**质疑的一方**：①「信任」是方便的说辞——Cursor×Grok 恰好是 Codex 最大的对手，信任叙事与竞争利益完美重合，外界无法区分动机权重；②开发者是纯粹的附带伤害：「通过两个第三方之间的合同获得的访问权是借来的，不是你的——一场与你无关的争斗就能把它收回」；③寒蝉效应会反噬 OpenAI 自己：官方成文断供一个最早期客户之后，还有哪家公司敢把核心业务押在 OpenAI API 上？5% 流量换全行业的信任折价，未必划算；④Windsurf 先例证明这不是 Musk 特例而是行业惯例——所谓「中立基础设施」从来就是幻觉，只是现在幻觉破灭得有了文件编号。

## 深度解读：对行业 + 对我们的具体含义

**对行业：模型供应完成了从「商品」到「政治变量」的转变。** forkast 那句总结值得抄下来：「驱动一个工具的底层智能，既是技术选择，也同样是政治选择。」过去 18 个月行业默认的分层——实验室卖智能、应用层买智能、互不越界——已经三面塌陷：实验室下场做应用（Codex、Claude Code）、应用层自训模型（Cursor 的 1.5T）、现在供应关系本身成了武器。与 8/28 GLM-5.3 开放权重发生在同一周绝非巧合地对照出一个事实：**闭源 API 的「断供风险溢价」第一次有了公开定价依据，而开源权重「在自己磁盘上、无法被断供」的主权价值被同步抬高**。

**对我们（做多 agent 系统 / AI 产品的团队），五条可执行判断：**

1. **多模型路由从优化项升级为生存项。** 以前做 model-agnostic 架构是为了省钱和挑能力，现在是为了活命。任何单一模型依赖超过一个可容忍阈值（参考 Cursor：5% 可以谈笑风生，50% 就是生死劫），都应视为未对冲的平台风险。router/harness 层要保证任一供应商 75 天内可整体摘除——75 天就是本案给出的行业通知期基准。
2. **审计你合同里的 change-of-control 条款——双向审计。** 一是你与模型商的协议里这一条何时触发（融资、被收购、股权变更都可能算）；二是反过来，你的客户如果被你的模型商的对手收购，你会不会被连坐。融资和并购尽调清单里应加一项：本次交易会不会触发上游 API 断供。
3. **BYOK 是值得抄的产品设计。** OpenAI 断的是「Cursor 统一采购」的通道，留了用户自带 key 的口子。对产品方，支持 BYOK = 把平台风险部分转嫁并解耦——供应商断的是你，不是你的用户。做 agent 产品时把「模型访问凭证归属」设计成用户可自持，等于给产品上了一层断供保险。
4. **开源权重进入对冲组合的理由变了。** GLM-5.3、Kimi K3 这类前沿级开放权重的意义不再只是「便宜 90%」，而是「不可被断供的兜底运力」。哪怕日常 100% 走闭源 API，也应保有一条随时可切的开源推理路径（自托管或中立云），并定期演练切换。
5. **注意 Anthropic 补位动作的另一面。** Tom Brown 数小时内承诺给 Cursor 加算力，说明模型商会主动用「补位」抢份额——多家实验室的存在本身就是应用层最好的保险。但也别忘了讽刺的一层：Anthropic 自己 5 月刚签了 SpaceX Colossus 的算力租约——今天的补位者与被补位者共享同一个算力房东。供应链的每一层都可能重演今天的剧本，算力层的 change-of-control 风险同样值得审计。

## 接下来盯什么

- 11/12 前谈判是否转圜（Truell 称仍在沟通；若 OpenAI 收回成命，说明这更多是谈判筹码而非既定战略）
- Cursor 在 Colossus 上自训的 1.5T 编码模型何时上线、能否与 Grok 4.6 一起补齐 GPT 空缺——这是「应用层去实验室化」的关键实验
- Anthropic 是否借机显著扩大在 Cursor 内的份额；其与 SpaceX 的 Colossus 算力租约是否因 Musk 关系紧张而波及
- 欧盟是否将模型 API 纳入 Data Act 云切换监管（TNW 指出的「被抛弃客户无保护」缺口）
- 是否出现连锁反应：其他实验室对 Musk 系公司、或对彼此投资组合内的应用公司采取类似断供；Musk/SpaceX 是否就此提起反诉
- 应用层公司是否开始把「多模型对冲 + BYOK + 开源兜底」写进公开架构叙事（融资材料、招股书里出现即为确认信号）
