# 🔧 深度研究 ｜ 前沿实验室的「自研硅军备竞赛」：Anthropic 洽谈三星 2nm，最后一家也下场了

> **一句话定性**：当以「安全优先、最依赖第三方云」著称的 Anthropic 也开始谈自研芯片，前沿实验室「垂直整合进硅、集体去 Nvidia 化」就从趋势变成了定局。这场竞赛真正的战场不在训练，而在**决定每一个 agent 单位成本的推理层**——它是我们过去两周追踪的「推理成本崩盘 / cost-per-task 成一等 KPI」这条需求侧主线的**供给侧答案**。

## 一、为什么这一条值得单独深读

单看「Anthropic 和三星聊了聊做芯片」，这是条中等偏软的传闻——探索性、无金额、连芯片干什么用都没定。但把它放进最近 10 天的时间线里，它的意义立刻变了：

- 6/24：OpenAI 联手 Broadcom 发布首款定制推理 ASIC「Jalapeño」。
- 6/30：Amazon 披露自研硅（Trainium+Graviton+Nitro）年化营收已超 200 亿美元、同比翻倍以上。
- 7/2：Nvidia 反手对 AI 云推出收入分成 + 信贷，帮客户融资继续买卡。
- 7/2：**Anthropic 洽谈三星 2nm** ——四大前沿玩家里最后一个「云原生、最不像会自己造硬件」的公司，也开始下场。

也就是说，**「自研芯片」已经不是某一家的差异化选择，而是所有前沿实验室的默认动作**。Google（TPU）领先多年，OpenAI、Amazon 已落地，如今 Anthropic 补位。对做 agent 系统的团队，这条线不是花边硬件新闻，而是直接重塑你未来 12–24 个月**推理账单的成本地板**——这是我们的第一性单位经济。

## 二、核心事实（按可信度分层）

**A. 本次新消息：Anthropic × Samsung（2026-07-02）**
- 性质：**极早期探索性洽谈**。Anthropic 尚未决定芯片用来做什么、多强、如何塞进服务器机架；项目「尚未进入详细设计、测试或量产」。
- 工艺：讨论用**三星 2nm 逻辑代工** + **先进封装**（把主处理器贴近 HBM 内存，提数据带宽、减「内存墙」瓶颈）。
- 站位：Anthropic 在 5 月 Series H 融资时已把三大存储厂列为战略基础设施伙伴；三星是三家里**唯一兼具先进逻辑代工能力**的，故成首选。若成，Anthropic 将加入三星代工客户名单（特斯拉、Nvidia、Apple 之后）。
- 官方口径（关键）：Anthropic 强调「**由 Google、Amazon、Nvidia 芯片组成的多元硬件栈，仍将是算力战略的核心**」，对三星合作细节不予置评——主动**淡化**这条传闻。
- 背景：2026/4 路透曾报 Anthropic 考虑自产芯片以应对供给约束；据报道前 OpenAI 芯片设计团队成员 Clive Chan 已加入 Anthropic 建内部硬件能力；三星原为 OpenAI 做定制 AI 芯片、6 月初谈崩后转向 Anthropic（此两点为二手报道，权重从低）。

**B. 已成定局的模式：四家自研硅**
- **OpenAI × Broadcom「Jalapeño」（6/24）**：首款定制**推理** ASIC。TSMC 3nm、光罩尺寸（reticle-sized）、脉动阵列（systolic array）架构、1 个计算 chiplet + 6 颗 HBM + IO chiplet。Broadcom CEO/Bloomberg 称**推理成本降约 50%**、能效「明显优于当前 SOTA」；9 个月流片（据称被 OpenAI 自家模型加速）；2026 年底部署。属 2025/10 双方 10GW 合作（FT 估 3500–5000 亿美元）。**仅推理，训练仍用 Nvidia**。
- **Amazon（6/30）**：自研硅年化营收 >200 亿美元、同比 >100%；Jassy 称按市价折算近 500 亿美元。Trainium 已是 Anthropic 训练/推理的主力之一。
- **Google TPU**：自研最久（已迭代到第七代级），既训 Gemini，也把算力卖给 Anthropic、Cursor 等。
- **Nvidia 的反击（7/2）**：对 neocloud/AI 工厂伙伴推收入分成 + 信贷支持，帮它们融资建算力；GTC 2026 上亦加码推理，正面迎战 ASIC。

**C. 经济学硬数据（这才是驱动力）**
- **「Nvidia 税」**：Nvidia FY2027 Q1 数据中心毛利率 74.9%/75.0%（GAAP/non-GAAP），个别产品 79–88%（H100 约 88%、B200 约 84%）。营收 816 亿美元（+85% YoY），数据中心 752 亿（+92%）。**每买一片 Nvidia，约四分之三的钱是 Nvidia 的毛利**——自研硅本质是把这块毛利收回自家。
- **ASIC 增速碾压 GPU**：TrendForce 预计 2026 年定制 ASIC 出货增速 **44.6%**，GPU 仅 **16.1%**。
- **回本账**：在超大规模下，每 token 成本降 50–67%，能把 1000 万–1 亿美元的芯片设计成本变成**首年就回本**的一次性投入。
- **推理是缺口**：Nvidia 在训练近乎垄断，但在**推理**市场份额只有 60–75%——这正是 ASIC 的突破口，也是所有自研芯片都先做推理的原因。

## 三、机制拆解：为什么自研推理 ASIC 能便宜一半

四家的芯片无一例外先攻**推理**，逻辑是一致的：

1. **省掉 Nvidia 的 75% 毛利**。推理是「一次训练、无数次调用」，长期总量远大于训练。把这部分从「按市价买 Nvidia」换成「按成本造自己的」，省的就是那道四分之三的税。
2. **工作负载专用**。通用 GPU 要兼顾训练、图形、各种精度；推理 ASIC 只需把自家模型的 Transformer 推理跑到极致——脉动阵列 + 针对性数据流，砍掉用不上的通用电路，换来更高的每瓦性能（perf/watt），而**电费与机架密度**才是超大规模推理的真实成本大头。
3. **内存墙共封装**。推理瓶颈常在「把权重从 HBM 搬进计算单元」的带宽上。三星讨论的「先进封装、处理器贴近内存」正是冲这个去的——这也是 Jalapeño「1 计算 + 6 HBM」布局的用意。
4. **训练留给 Nvidia**。四家都刻意把训练继续压在 Nvidia/自家训练芯片上——训练对灵活性、生态（CUDA）、可靠性要求太高，短期不值得自研。**赌注全押在推理这块「量大、够专、够贵」的肥肉上**。

## 四、关键原话 / 引述

- Anthropic（官方，淡化）：多元硬件栈「仍将是算力战略的核心」；对三星细节「不予置评」。
- Broadcom 侧（Jalapeño）：推理成本「降约 50%」，能效「明显优于当前 SOTA」（**注意：这是目标 + 早期实验室数据，非量产实测**）。
- 需求侧对照（本监测 6/30 已推）：Lindy CEO Crivello 弃 Claude 全量迁 DeepSeek，推理成本降约 90%，「**成本曲线砸到了地板**」「这是**生存问题**」。供给侧的自研硅，正是要把这条曲线继续往下压。

## 五、正反观点

**看多（这是必然且理性）**
- 毛利套利太诱人：绕开 75% 的 Nvidia 税，超大规模下首年回本。
- 供给安全：2026/4 Anthropic 就是为「买不到卡」才起念自研；自研 = 不被单一供应商卡脖子。
- 需求刚性：推理量随 agent 长任务、子 agent 编排指数增长，成本压力只会更大，自研的账只会越来越划算。
- 趋势已验证：ASIC 出货增速是 GPU 的近 3 倍，Google/OpenAI/Amazon 已用脚投票。

**看空 / 风险（别把 PPT 当量产）**
- **「50% 更便宜」是目标不是结果**：Jalapeño 至今不商用、不对外，2026 年底只是「小规模原型」，2027 才量产爬坡、2028 才铺开。三星-Anthropic 更是连设计都没开始。
- **软件路径可能先到**：OpenAI 曾**纯靠软件**把推理成本砍约一半——意味着未必需要自研硅就能拿到大部分收益，自研的边际回报存疑。
- **造芯极难、易搁浅**：三星刚和 OpenAI 谈崩就是活例；2nm 良率、先进封装、多年周期、上亿投入，任何一环出错都可能打水漂。
- **CUDA 生态锁定**：换硅意味着重写/迁移推理栈，Nvidia 的软件护城河不是靠一颗 ASIC 就能绕开。
- **Anthropic 自己都在降调**：官方主动强调「多元硬件仍是核心」，说明这更像**对冲选项**而非既定战略——现在就当它成了，为时过早。

## 六、深度解读：对行业 + 对「做多 agent 系统的我们」

**对行业**：AI 的价值链正在**从「谁有最强模型」向「谁能把推理做到最便宜」二次分化**。前沿实验室集体垂直整合进硅，本质是在打一场**成本战**——因为模型能力在快速商品化（Sonnet 5、DeepSeek v4、GLM-5.2 已把「够用」的智能打到白菜价），**单位推理成本正取代榜单分数，成为新的护城河变量**。Nvidia 的 75% 毛利是这场战争的靶心，它 7/2 的收入分成反击说明它也嗅到了威胁。

**对我们（可执行判断）**：
1. **把「推理成本地板会持续下移」写进 12–24 个月的成本模型**。今天按 Nvidia 市价推算的 cost-per-task，未来会被自研硅结构性拉低——**别用今天的单价锁死长期定价和毛利假设**。给自己留「成本会降」的乐观档，但也别指望它明天就到（2027 才量产）。
2. **供应商冗余要下沉到「算力/硅」这一层**。我们一直讲多模型热切换；现在要加一维：**同一个模型，跑在谁的硅上、成本差多少**（Claude on Trainium vs Nvidia vs 未来自研）。provider 路由不只看模型，也要看「这条推理链背后的硅经济」。
3. **cost-per-task 继续做一等 KPI，但要区分「软件可省」与「硬件才省」**。OpenAI 纯软件砍半的教训是：**先把该做的软件优化（缓存、蒸馏路由、批处理、上下文压缩）吃干榨净**——这些收益现在就能拿，且不依赖任何厂商的芯片路线图。别为了等自研硅的红利，放着眼前的软件优化不做。
4. **警惕「过度投资于会被硬件抹平的软件工程」**。反过来，如果你在自建极重的推理成本优化基础设施，要评估其中哪些会被 2027 年更便宜的推理硅直接抹平——那部分投入要克制。
5. **谁先把自研硅落到量产、把推理单价打下来，就是下一轮成本领导者**——这是选长期主力 provider 时值得押注的先行信号，比基准分数更能预测两年后谁的 agent 跑得起。

## 七、接下来盯什么（信号）

- **Anthropic 这条会不会从「探索」变「落地」**：是否官宣、是否披露三星 2nm 具体条款/流片时间——一旦坐实，就从传闻升级为战略。
- **Jalapeño 量产实测**：2027 年 OpenAI 自研硅上量后，「降 50%」是真兑现还是缩水；有无独立第三方基准。
- **Nvidia 的推理反击效果**：收入分成 + GTC 推理牌能否守住 60–75% 的推理份额，还是被 ASIC 持续蚕食。
- **成本传导到 API 定价**：自研硅省下的钱，是变成实验室毛利，还是传导为更低的 token 价格（直接影响我们的账单）——盯各家推理定价曲线。
- **三星 2nm 良率**：这是 Anthropic/特斯拉等一众客户能否落地的物理前提，也是三星追赶 TSMC 的胜负手。
