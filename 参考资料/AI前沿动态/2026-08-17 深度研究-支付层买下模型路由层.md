# 💳 深度研究 ｜ 支付层买下了模型路由层：拆解 Stripe 70 亿美元收购 OpenRouter

> **一句话定性**：一家支付公司花掉它史上最大的一笔并购预算（>70 亿美元，是上一次纪录 Bridge 的 6 倍多），买的不是模型、不是芯片、不是数据，而是**「谁的 token 该走哪条线、该按什么价记账」这个开关**——这等于公开宣布：AI 产业下一个收租位不在模型层，而在**计量与结算层**。

**来源**：Bloomberg，2026-08-16，报道 Stripe 已敲定以超过 70 亿美元收购 AI 模型路由市场 OpenRouter。
🔗 原始链接：https://www.bloomberg.com/news/articles/2026-08-16/stripe-nears-deal-to-buy-ai-firm-openrouter-for-over-7-billion
🔗 交叉：TechCrunch 2026-08-16 https://techcrunch.com/2026/08/16/stripe-will-reportedly-acquire-ai-gateway-startup-openrouter-for-7b/

**重要限定**：截至本文写作，**Stripe 与 OpenRouter 双方均未官宣**。Stripe 对 TechCrunch 的回应是「不评论传闻或猜测」（*does not comment on rumors or speculation*）；OpenRouter 官方博客 8/17 当天仍在正常发产品公告，只字未提收购。所以本文的一手事实层是**Bloomberg 的独家报道口径 + 双方拒绝置评**，不是官方公告。下文所有数字都标注了出处与推算标记。

---

## 一、为什么这一篇值得单独深读

过去两年，AI 基建的并购逻辑基本是「往下买」：买算力、买电、买数据中心（本频道 8/14 的 Anthropic-Macquarie、8/14 的英伟达缩减 OpenAI 担保都是这条线）。

这一笔是**反过来的**：一家不碰 GPU、不训模型的支付公司，往**上**买了一个纯软件的中间层，价格是它此前所有收购的总和还多。

它值得单独拆，因为它同时回答了三个此前只在推特上吵的问题：

1. **模型路由层到底有没有价值？** 市场刚给出一个 70 亿美元的报价——而三个月前同一家公司的定价是 13 亿。
2. **agent 经济的收租位在哪？** Stripe 用行动投票：不在生成侧，在**计量、路由、结算**这三件事合流的地方。
3. **「中立的模型市场」能不能被一方拥有？** 这是接下来一年最值得盯的治理问题，也是对我们最有直接操作含义的一条。

---

## 二、核心事实（按可信度分层）

### A. 交易本身（Bloomberg 独家口径，双方未确认）

- 价格：**超过 70 亿美元**，Bloomberg 称交易已「敲定/finalized」。
- 时间线：**WSJ 2026 年 7 月**先报道双方在谈（当时市场流传的口径高至 100 亿美元），Bloomberg 8/16 报道谈成、落在 70 亿以上。
- 上一轮定价：**2026 年 5 月** OpenRouter 完成 **1.13 亿美元 B 轮**，CapitalG（Alphabet）领投，Sequoia、a16z、Menlo Ventures 跟投，投后 **13 亿美元**。
- **三个月，5.4 倍**。
- 这将是 **Stripe 史上最大收购**：此前纪录是稳定币基建公司 **Bridge（11 亿美元，2025 年 2 月完成）**，2025 年 6 月还收了嵌入式钱包 **Privy**。70 亿是 Bridge 的 6 倍多。

### B. OpenRouter 的规模（一手/投资方口径）

- 开发者：**800 万+**（一年前 250 万+）。
- 接入模型：**400+**。
- 吞吐：**每周约 25 万亿 token**，半年前是 5 万亿——**半年 5 倍**。Menlo Ventures 2026 年 5 月的口径是**年化约 1.5 千万亿（quadrillion）token 跑率**，一年前约 100 万亿，**同比 15 倍**（两个口径换算后大致自洽：25–29 万亿/周）。
- Menlo 给的横向参照（估算）：这个跑率约等于 **Google token 跑率的 15–30%、OpenAI 的 20–40%、Azure Foundry 的 50%+**。
- 效率：**人均每年 20 万亿+ token**、**人均净收入约 200 万美元**。
- Andrej Karpathy 的定性引述：OpenRouter 是**「当今 AI 事实上的『转换开关』（the de facto "transfer switch" of AI today）」**。

### C. 钱怎么赚的（Sacra 口径 + 推算）

- 商业模式极简：在用户的推理支出上**抽约 5%**（HN 讨论里被反复确认为「5% markup on all token usage」），资产轻、毛利高。
- 收入曲线：2024 年底年化约 **100 万美元** → 2025 年 5 月约 **500 万** → 2025 年 10 月约 **1000 万** → 2026 年 3 月约 **5000 万** → 2026 年年中约 **1.4 亿美元**（18 个月约 50 倍）。
- **本文推算**：按 5% 抽成反推，年中 1.4 亿美元净收入对应**约 28 亿美元/年的推理支出流过这条管子**；70 亿美元对应**约 50 倍年化净收入**。
  - 注：HN 有热评称 OpenRouter「代表约 1000 亿美元支付流水」，与上述推算差了一个半数量级，**属于社区估算、不采信**，此处仅记录分歧。

### D. 管子里流的是谁的 token（结构，最关键的一层）

这是整笔交易里最反直觉、也最有战略含义的数据：

- **流量侧：中国开源权重模型已经占多数。** 2026 年 2 月末，中国开源模型约占 OpenRouter Top10 模型 token 量的 **61%**；4 月中国厂商合计约占全平台 **51%**；6 月口径回到约 **61%**；**7 月首次包揽全球用量榜前五**（小米 MiMo-V2.5 第一，其后为 DeepSeek、MiniMax、阿里 Qwen 系、月之暗面 Kimi）。对照 2024 年底，中国模型占比还不到 **2%**。
- **同期，美国三家（Google/OpenAI/Anthropic）合计 token 份额从 2025 年 6 月的约 70% 掉到 2026 年 6 月的约 30%。**
- **收入侧：反过来。** Anthropic 只占约 **12%** 的 token 流量，却贡献了平台约 **46%** 的收入。

> ⚠️ 这一组结构数据来自 OpenRouter 公开排行榜的二手转述与分析文章（Dataconomy / MACGPU / BigGo 等聚合口径），**不是厂商审计数**，且「Top10 口径」与「全平台口径」经常被混用。方向可信，具体百分点请当作量级读。

**这组数据合起来说的是一件事**：便宜的中国开源模型在跑量，昂贵的美国闭源旗舰在赚钱——**一条管子里同时跑着两个完全不同的市场**。而 Stripe 买的，就是**同时看得见这两个市场的那台仪表**。

## 三、机制拆解：为什么「模型路由」本质上是个支付问题

把 OpenRouter 的产品拆开，它做的事和支付网关**同构得可疑**：

| 支付网关做的事 | OpenRouter 做的事 |
|---|---|
| 一个 API 接上百家收单行/钱包 | 一个 API 接 400+ 模型/推理商 |
| 按成功率、费率、延迟动态选通道 | 按价格、延迟、可用性动态选模型 |
| 失败自动 failover 到备用通道 | provider 挂了自动 fallback 到备用 provider |
| 统一账单、对账、分润 | 统一充值、统一计费、5% 抽成 |
| 风控、限额、拒付 | 限速、配额、内容分类器 |

而 OpenRouter 最近两周的两个更新，几乎是把这个同构关系挑明了：

- **8/10《Model Routing Powered by Wisdom of the Market》**：Auto Router 不再靠「任务分类器」决定用哪个模型，而是**用数百万开发者的实际选择行为**作为路由信号，官方称其**在广谱任务上跑赢常规的 task-based classifier**。——这是**把路由决策从规则引擎换成了市场价格发现机制**。做支付的人对这套逻辑再熟悉不过。
- **8/17（收购见报次日）《Understand your AI usage: every agent, model, and request》**：上线 Activity 面板与 **Analytics API**，可以「看到团队在每个模型上花了多少、点开任意柱状条直接落到背后的日志、并从终端查同一份数据」，**明确按 agent 维度做归因**。——这是**计量（metering）**。

**路由 + 计量 + 结算，是支付公司的全部内功。** Stripe 已经有第三块，OpenRouter 补齐了前两块。

再叠上 Stripe 自己 2026 年的 agent 商业化栈（Sessions 2026 一口气发了 288 个产品）：

- **Tempo**：面向支付的专用链，支持实时亚分级微支付与结算；
- **Machine Payments Protocol (MPP)**：开放标准，让 AI agent **不经人类点击结账就能自主付款**；
- **Privy**：给 agent 发钱包；**Bridge**：稳定币发行与编排；**Link agent wallet**：给 agent 的支付凭据。

**拼图就完整了**：agent 有钱包（Privy）、有付款协议（MPP）、有结算网络（Tempo/Bridge/Stripe），现在还有了**它最主要的花钱对象——token——的市场与计价台（OpenRouter）**。这不是一次财务投资，是把 agent 经济的收银台一次性焊死。

## 四、关键原话

- **Alex Atallah（OpenRouter CEO，收购前的自我定位）**：OpenRouter 是**「the equivalent of Stripe for AI」**——因为它给客户一个统一接入点，同时**避免供应商锁定**。
  > 这句话现在成了整笔交易最大的反讽注脚：一个以「防锁定」为卖点、自称「AI 界 Stripe」的公司，被 Stripe 买走了。
- **Andrej Karpathy**：OpenRouter 是「当今 AI 事实上的**转换开关**」。
- **Stripe 发言人**：「不评论传闻或猜测。」

## 五、正反观点

### 支持方（为什么 70 亿不疯）

1. **能力迁移是真的**。HN 高赞观点：Stripe 的核心本事就是「在服务特性差异巨大的上百家供应商之间做路由」，而**「LLM 供应商比支付网络简单得多」**——收单行有清算周期、拒付、跨境合规，模型 provider 只有价格、延迟、可用性三个维度。
2. **买的是心智不是代码**。对「这就是个 API 代理，我自己两天写一个」的标准回应是：**「你复制不了它已经建立的普及度和心智」**——800 万开发者、400+ 模型的默认入口，是分发资产不是技术资产。
3. **按增速算不贵**。50 倍年化净收入确实高，但吞吐半年 5 倍、收入 18 个月 50 倍；如果 2027 年流水再翻几倍，70 亿会被追认成便宜。（这条逻辑与本频道 8/15《用 2028 年的收入买 2026 年的公司》是同一个模式，**它的风险也是同一个**。）
4. **战略必要性**：如果 agent 真的开始自己花钱，**token 是 agent 的第一大开销科目**。谁掌握这个科目的计价台，谁就掌握了 agent 经济最早、最大的一条现金流。

### 质疑方（为什么可能是 70 亿买了个寂寞）

1. **护城河存疑**。HN 原话：**「OpenRouter 基本没有护城河，你可以非常轻易地把它换成任何一家别的 AI gateway。」** 替代品是现成的：开源的 LiteLLM，商业的 Portkey / Martian / Not Diamond，云厂的 Bedrock / Vertex / Azure Foundry，以及 Vercel、Cloudflare 的 AI Gateway。
2. **5% 抽成是真金白银，且有涨价预期**。原话：**「如果你是认真按量付费的 AI 客户，5% 是很大一笔钱。」** 被支付公司买下后，市场普遍预期抽成不会降。这直接给了大客户「自建/绕开」的动机。
3. **中立性被结构性破坏**。OpenRouter 的全部价值建立在「我不偏袒任何模型商」上。现在它归属于一个**在 agent 商业化上有明确利益的一方**，排序、默认路由、Auto Router 的权重都变成了**可被商业目标调用的杠杆**。这不是道德指控，是激励结构问题。
4. **隐私与中间人风险**。企业侧的直接顾虑：Stripe 由此成为**所有经过该网关的 LLM 对话的中间人**，对金融、医疗、法务类客户是新的合规科目。
5. **商品化悖论（最深的一条）**。BigGo 的分析指出：路由器把 400+ 模型摆成一张可按价格/延迟排序的表，**它自己就是模型商品化的主要推手**；而模型越商品化，开发者越是无脑选最便宜的那个，**路由器的必要性就越低**。叠加价格塌陷（GPT-4 级能力从 2023 年的 30 美元/百万 token 掉到今天同级开源的不足 0.1 美元）与能力收敛，**平台越成功，越加速自己的不被需要**。原文的说法是「越商品化，开发者越不依赖他」。
6. **地缘政治炸弹**。一家美国支付公司，现在拥有了**六成以上流量流向中国开源模型**的那个关口。Forkast 直接点出：Stripe 由此成为「一个大量企业活动依赖非西方模型供应商的平台的守门人」，需要同时应对美国监管口径与全球模型市场的地缘敏感性。**这是一个此前不存在的监管界面。**

## 六、深度解读：对行业，以及对「做多 agent 系统的我们」

### 对行业

**第一，AI 的价值捕获点正在从「谁生成 token」转向「谁给 token 计价」。** 模型能力在收敛、价格在塌陷，这是所有人都同意的前提；但很少有人推到下一步——**当商品同质化后，利润就迁移到分销与结算**。这就是超市自有品牌、就是 Visa/Mastercard、就是 App Store。Stripe 花 70 亿，是在赌这条历史规律在 AI 上照样成立。

**第二，「中立基础设施」这个物种在 AI 时代可能活不长。** OpenRouter 是最纯粹的中立层样本：不训模型、不站队、只做转接。它的结局是三年内被有利益方买走。这对所有依赖「中立中间层」的架构决策是个警告——**你今天的中立依赖，明天是别人的战略资产**。

**第三，双轨市场被证实了。** 61% 流量给中国开源、46% 收入给 Anthropic——这不是某个团队的偏好，是 800 万开发者用真金白银投出来的行业默认解：**长尾便宜模型跑量，闭源旗舰打硬仗**。任何还在纠结「该不该多模型」的团队，可以把这组数据当作外部结论直接引用。

### 对我们（可执行判断，逐条落地）

1. **立刻检查供应链风险位，别等官宣。**
   如果我们的 autopilot / agent 链路里有任何一环走 OpenRouter，它现在多了一个此前不存在的风险类别：**被收购方的条款、定价、排序、隐私政策变更**。行动项：把「48 小时内能否切走 OpenRouter」当作一次真实演练跑一遍（不是写文档，是真跑）。我们已经有过一次教训——8/16 Claude 大规模宕机时，走 Claude Code 的路径整批停摆而 API 面还活着；这次是同一类课题的另一面：**故障域要分离，供应商归属变更也要当作一种故障**。

2. **把 provider 抽象层留在自己手里。**
   正确的形状是：我们自己拥有 router 接口（LiteLLM 或自研均可），OpenRouter 只是**其中一个可插拔后端**，而不是唯一入口。判断标准很简单：**换掉它需要改几个文件？** 如果超过一个模块，就是耦合过深。

3. **算清 5% 这笔账，设一个直连阈值。**
   5% 抽成买的是「长尾模型的接入便利 + 统一账单」。这笔钱在实验阶段完全值，在规模化阶段是纯损耗。建议的分界线：**主力模型（占我们 token 支出 top 2–3 的那几个）直连官方 API，长尾与实验走 router**。按当前推算的行业口径，路由层每年从约 28 亿美元的推理支出里抽走约 1.4 亿——我们没理由不知道自己贡献了其中多少。

4. **把 per-agent 成本归因提升为一等公民。**
   OpenRouter 8/17 上线「按 agent / 模型 / 请求」的 Analytics API，这不是巧合——**它正是多 agent 系统最缺的那块仪表**。对照今早那篇 Anthropic 多 agent 研究里的读数：一个 30Hz 轮询的守护进程能打出 **240 万次请求却只换来 117 个 job 被接受**。没有 per-agent 的 token 与成本归因，这种事你**事后都查不出来是谁干的**。行动项：不管用不用 OpenRouter，我们的 agent 运行时都要在 run 级别打上 `agent_id / run_id / model / tokens / cost` 五元组，并且能按 agent 聚合。这条和「群级 QPS/token 预算」是同一套护栏的两半。

5. **提前给 agent 预留「预算 + 花钱审计」层。**
   MPP + Link agent wallet + 现在的 token 计价台，意味着「agent 自主付款」会在一年内出现事实标准。我们的 agent 权限模型现在就该有这一层的位置：**每个 agent 有额度、超额需人类批准、所有支出可审计**。等到要接入时再补，就是把财务控制建在已经跑起来的系统上——那时成本高一个数量级。

6. **把「路由排序」当作需要独立验证的外部变量。**
   如果我们的模型选择在任何程度上参考了 OpenRouter 的排行榜或 Auto Router，那么从今天起，**这个信号有了商业倾斜的可能性**。低成本对策：定期抓一份 rankings 快照存档，建立我们自己的基线，日后能 diff 出「排序是否发生了非性能原因的变化」。这和 backlog 里那条「系统提示词逐版本可 diff」是同一个方法论——**对不受我们控制的外部信号，先建基线，再谈信任**。

## 七、接下来盯什么（信号清单）

- **官宣与结构**：Stripe / OpenRouter 是否发布正式公告；最终价格、现金/股票比例、Alex Atallah 与团队的去留。**在官宣前，本条全部事实都应带「Bloomberg 报道口径」的前缀。**
- **5% 抽成是否变化**：是否推出「用 Stripe 结算可减免」的捆绑折扣——这将是中立性受损的第一个可观测证据。
- **Auto Router 的权重是否倾斜**：拿排行榜快照做定期 diff。
- **监管界面**：反垄断问询，以及美国监管方对「美国支付公司为中国开源模型做流量守门人」这一新形态的表态。
- **竞品与定价反应**：LiteLLM / Portkey / Martian 是否被跟进收购；Vercel AI Gateway、Cloudflare AI Gateway、Bedrock/Vertex 的抽成与定价是否应声调整。
- **Stripe 的 IPO 叙事**：70 亿现金/股票的这一笔，会怎么进它的上市故事。
- **反向指标**：如果收购后 OpenRouter 的周 token 量增速掉头，说明「中立性折价」是真实存在的、可被市场定价的。
