# 微软 FY27 销售手册：把 Copilot 引擎悄悄换成自研 MAI，并训练销售正面唱衰 OpenAI/Anthropic

**一句话定性：** 全球最重要的 AI 合作关系正在从"金主+供应商"翻转为"竞争对手"——OpenAI 最大投资人微软，一边把 Word/Excel/Outlook 里 Copilot 的底层模型无声换成自研 MAI 以砍成本，一边训练企业销售团队当面告诉客户"OpenAI/Anthropic 跟不上"。这是本监测反复押注的**"工具中立性会过期 / 你依赖的平台会变成你的竞争者 / 模型是可替换后端"**主线迄今最硬的现实兑现。

**来源：** Bloomberg（首发，7/15）/ TechCrunch / FourWeekMBA / The Decoder / Crypto Briefing

## 为什么值得深读 / 背景

过去三年 AI 产业的地基，是"微软出钱出云、OpenAI 出模型"这段联姻：微软累计投入超百亿美元、Azure 独家承载、把 GPT 塞进 Office 全家桶，换来 OpenAI 的资本与算力。**这条地基本周公开裂开。**

裂缝早有前兆，但本周三件事把它焊成了一个明确信号：
1. **4 月**微软与 OpenAI 修订协议，取消了微软对 OpenAI 模型的**独家使用权**——双方都被"松绑"，OpenAI 可服务微软的竞争对手，微软可自由换用别家/自研模型。
2. **7/7 起**，微软开始把 Excel、Outlook（及 Word）里 Copilot 的一部分请求，路由到自研 **MAI** 模型，用来处理"总结邮件、起草回复、格式化表格"这类家常任务——**用户界面没变，引擎被换了**。
3. **7/14 的 FY27（2027 财年）内部规划会**上，微软高管把上面两步升级成一套**正面竞争销售剧本**：不再遮遮掩掩，直接训练销售团队告诉企业客户，OpenAI 和 Anthropic 的模型不如微软自己的整套系统。

对"做多 agent 系统、把产品建在别人平台/模型之上"的团队，这条不是八卦——它把一个抽象风险变成了可观测的现实：**你以为在'用 Copilot'，其实底层是哪个模型、由谁提供、什么时候被换，平台方说了算，且不会通知你。**

## 核心事实（分层硬数据）

**A. 销售剧本（FY27 内部会，Bloomberg 拿到会议内容）**
- **Jay Parikh（执行副总裁）**定调："别人都在卖零件，我们卖的是完整的端到端系统。"（"Everyone else is selling parts — we're selling the full end-to-end system."）
- **Jacob Andreou（Copilot 执行副总裁）**做了 Copilot vs Claude 的并排对比，称 Claude 在 Office 应用内**"更慢、更不准、且缺乏必要的安全集成"**。
- 三根支柱：**成本（cost governance）/ 安全集成（security integration）/ 平台完整性（platform completeness）**——把"模型能不能被治理、被便宜地热切换"包装成企业刚需，而非功能点。
- 定性：这是 Bloomberg 措辞里"微软自己在销售语境下的内部说法，不是中立第三方评测"。

**B. 引擎替换（MAI 进 Office，7/7 起）**
- 自 7/7，微软把 Copilot 在 Excel/Outlook 的**"相当一部分"日常请求**路由到自研 MAI，量级为**每周数万次 prompt**，覆盖总结/起草/格式化等高频低难任务。
- 动机是纯粹的**推理成本经济学**：在数亿用户规模上，每一条走外部供应商的 prompt 都是一笔费用；把家常活交给"够用就好"的自研模型，等于抬高每个 Copilot 席位的毛利。
- **不是彻底分手**：官方口径是 OpenAI 前沿模型继续承接"更复杂、更吃能力"的任务，Anthropic 模型也仍嵌在特定 Office 场景——**微软走的是"分层路由"**：家常活→便宜 MAI，硬骨头→前沿 OpenAI。
- 背景：微软 6/3 一次性推出了**七个 MAI 模型**正面叫板 OpenAI/Anthropic；本次是把它们真正插进旗舰产品的收口。

**C. 成本与市场数据**
- **Unilever 案例**（Nadella 引用）：把一套自动化理赔系统里"最先进的前沿模型之一"换成更便宜的微软替代后，预计年省**约 3 亿美元**——**但 Unilever 未证实**该数字。
- 微软股价年内约 **-20%**（投资人担忧 AI 原生工具蚕食其软件特许经营权、且资本开支跑在变现前面）；Bloomberg 报道当日微软股价 **+2.9%**（情绪面，非产品优势被验证）。

## 机制拆解：微软凭什么能这么干，以及"good enough 经济学"

**为什么是微软先动手，而不是别家？** 因为它同时握着三张牌，别的模型供应商没有：
1. **界面**：Office / Microsoft 365 是几亿知识工作者"活儿真正发生"的地方。谁掌握界面，谁就能在用户无感知的情况下决定界面背后跑哪个模型。
2. **企业合同 + 数据面 + 身份/合规/采购工具**：这套东西构成切换成本。纯模型供应商（OpenAI、Anthropic）要复刻这层治理，成本极高。
3. **自研模型 + 自有云**：当模型能力"够用即可"时，微软可以把利润最厚的高频请求内部消化。

**"good enough 经济学"的算术**：数亿用户 × 每周数万乃至更多外部 prompt = 天量推理账单。routine 任务（总结、起草、套格式）对模型能力的边际需求已经饱和——Sonnet/Opus 级前沿模型来做这些，是**用大炮打蚊子**。微软的赌注是：这部分请求，MAI"够用"，省下的钱直接变毛利。**这正是分层路由（tiered routing）在超大规模上的必然结果**，也是所有做 agent 的团队迟早要算的账。

**但风险恰好埋在能力边界处**：微软自己 6 月宣称 **MAI-Thinking-1** 在编码上（人评）能匹配 Sonnet 4.6 / Opus 4.6，然而同期放出的基准显示它**大幅落后**于 OpenAI/Anthropic 同级。一个"更便宜但会把邮件写差、把表格上下文读错、把摘要做得不可靠"的模型，会把**后端省下的成本变成前端的产品事故**——而 Office 的用户对"Copilot 变笨了"是有直接体感的。

## 正反观点

**支持方（微软的战略逻辑成立）：**
- **能力收敛论**：当前沿模型能力趋同、商品化，企业采购决策会从"哪个模型最强"迁移到"哪个平台让我以最低成本治理、切换模型"。微软把这个趋势武器化——它卖的是**部署基座**，谁跑在底下不重要。
- **切换成本护城河**：掌握安全、合规、身份、采购工具的平台方，天然拥有纯模型厂商无法复制的锁定力。
- **成本是真的**：超大规模推理账单不是四舍五入的零头，Suleyman 的"消除 Anthropic 成本"是硬约束；Unilever 3 亿美元（若成立）是可复制的参照案例。

**质疑方（可能反噬）：**
- **MAI 质量未经真实 Office 负载验证**：内部销售说辞 ≠ 中立评测；MAI-Thinking-1 的基准落差摆在那里。便宜换来的质量下滑一旦被用户感知，后端省钱变前端流失。
- **数字不可证**：Unilever 未确认 3 亿美元；股价 +2.9% 只是情绪，不是产品优势被证明。
- **投资人已在打问号**：微软股价年内 -20%，市场担心它一边巨额 capex、一边自我蚕食软件特许经营。
- **客户不一定买账锁定**：企业可能反过来要求"模型可见性/可选择权/SLA"，抵制"底层被无声替换"。
- **OpenAI/Anthropic 会反驳**"更慢更不准"的定性，且这套叙事撞上两家 IPO 窗口，火药味只会更浓。

## 深度解读：对行业 + 对"做多 agent 系统的我们"

**对行业：** AI 竞争的主战场，正从"模型能力层"下移到**"部署基座 / 治理层"**。谁掌握界面、合同、数据面、合规与采购，谁就掌握"底层跑哪个模型"的决定权——模型本身在被商品化为可插拔后端。微软是第一个把这套打法公开化、销售化的巨头；谷歌（Gemini Enterprise / 本周把 NotebookLM 收编为 Gemini Notebook）、Salesforce、AWS 大概率跟进"平台方吞并模型层"。**这对纯模型公司（哪怕是 OpenAI/Anthropic）是结构性坏消息：分发被别人攥着，你可能在自己最大客户的产品里被静默降级。**

**对做多 agent 系统的我们，五条可执行判断：**

1. **"底层是哪个模型"永远不是契约——把模型当可插拔后端 + 建行为/质量回归看板。** 微软给全行业演示了"平台方可以无声换引擎"。我们自己搭 agent，也要假设任一供应商会在我们不知情时改版/降级/替换（呼应 7/13 Claude 价值漂移深研）。对每个关键 agent 环节，跑**持续的行为与质量回归监测**（不只看能力榜），把"模型/供应商变更"列为**人审 gate 的触发器**。

2. **分层路由 + 单位经济学是必修课，不是可选项。** 微软自己在做 routine→便宜 MAI、复杂→前沿 OpenAI。这就是我们该抄的 per-task 模型分级路由：量大可缓存的低难任务走廉价/自研/开源模型，最难的多步 agentic 任务留前沿兜底。**别把"token 会永远变便宜"当产品假设**（呼应 7/16 TSMC 深研：上游满产满价，降本只能靠架构侧）。定价/合同要能扛推理成本上浮。

3. **你依赖的平台会变成你的竞争者，且会自我垂直整合。** 微软既是 OpenAI 最大金主，又开始正面卖它对家。**若你的护城河是"我接了当前最强的某家模型"，那不是护城河。** 壁垒必须回到 workflow / 验证 / 治理 / 数据面 / 领域专长——这些平台方换个模型也搬不走的东西（呼接"harness 才是护城河"主线）。

4. **要么成为治理层，要么把"可切换/合规/可审计"做进产品讲清楚。** 竞争维度已是"谁掌握切换成本"。对我们：把**多模型热切换、多辖区合规、可回滚、可审计、模型可见性**做成一等能力和对客户的显式卖点，而不是隐藏的实现细节——这既对冲了"被平台锁定/静默替换"，也正好是企业买家现在会追问的（呼应 WAIC 两阵营 + 中国拟人化新规带来的多辖区约束）。

5. **"good enough"的双刃：便宜模型在 agent 命门会放大成事故。** 工具调用、指令遵循、长程可靠性，是量化/廉价模型最先掉链子的地方（呼应 7/14 Bonsai 端侧量化伤 agent 命门）。**别只比单价，测每任务端到端质量 + 无人工跑完率（per-step 可靠性）。** 微软在 summarize/draft 上用 MAI 也许没事，但一旦推进到多步 agentic Copilot 任务，这个赌注就危险得多——我们自己降本时同理。

---

## 接下来盯什么（信号）

- **MAI 家族的真实 agentic 评测**（工具调用 / SWE-bench / Terminal-Bench）能否被独立复现、对标 OpenAI/Anthropic——决定"good enough"的边界画在哪。
- **微软是否把 MAI 从 summarize/draft 推进到更复杂、多步的 agentic Copilot 任务**——这是"够用经济学"会不会翻车的分水岭。
- **企业客户的反应**：是接受"底层被换"，还是开始要求模型可见性 / 选择权 / SLA。
- **OpenAI / Anthropic 的反制**：Anthropic 在 M365 的位置会否被进一步挤出；两家 IPO 叙事是否因"最大分发渠道反水"受损。
- **"分手"是否升级**：Azure 独家条款、算力承诺、S-1 里的关联交易披露是否出现新变化。
- **是否外溢成行业打法**：谷歌 Gemini Enterprise、Salesforce、AWS 是否跟进"平台方吞并模型层 + 分层路由 + 正面反供应商销售"。
