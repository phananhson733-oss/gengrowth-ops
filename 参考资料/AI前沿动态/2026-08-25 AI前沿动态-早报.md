# 深度研究 · 每秒 3,400 个 token——$200 亿买来的 Groq 量产，Nvidia 把 agent 的时钟拨快 4 倍

**一句话定性**：Nvidia 宣布用 $200 亿 license+hire 吞下的 Groq LPU 架构正式量产（Groq 3 LPX），在 10 万 token 上下文下跑出 3,400 tok/s 的输出速度——推理速度第一次被最大的芯片厂当成独立产品线来卖，而它瞄准的买家就是「跑几百上千步循环的 agent」。

**来源**：NVIDIA Newsroom 官方新闻稿（2026-08-24）
🔗 https://nvidianews.nvidia.com/news/nvidia-groq-3-lpx-now-in-full-production-with-world-class-speed-for-agentic-ai

## 为什么值得深读 / 背景

去年 12 月 24 日，Nvidia 用约 **$200 亿**完成了它史上最大一笔交易：**非独占授权 Groq 的 LPU 技术 + 雇走创始人 Jonathan Ross（Google TPU 初创团队成员）、总裁 Sunny Madra 及核心员工**——Groq 法律实体存续，但关键资产实质易主。这是「license+hire」模板的第一单（后来被复制到 Enfabrica $9 亿、Poolside $60 亿）。当时的疑问是：Nvidia 买一个「GPU 替代路线」到底是为了用，还是为了让它消失。

8 个月后答案落地：**Groq 3 LPX 全面量产**，作为 Vera Rubin NVL72 平台的扩展进入 Nvidia 正式产品线。这不是又一张更快的 GPU，而是 Nvidia 第一次把「**专用推理 ASIC**」纳入自家货架——承认 GPU 不是推理的终局。

时机耐人寻味：这条产品线落地的同一周里，Cerebras 刚发布对标的 CS-4（8/18）、Anthropic 押注同为 SRAM 路线的 Fractile（$65 亿估值洽谈中）并挖来 Google TPU 创始人 Amir Salek 筹建自研芯片（8/21）。**推理速度/产能正在取代训练算力，成为 2026 下半年最激烈的军备竞赛**——别忘了 8/18 那条刷屏的抱怨：Raoul Pal 说 Claude「utterly unusable」，根源就是推理产能。

## 核心事实

**性能（Artificial Analysis 8/21 测量，官方引用）**
- Gemma 4 31B、**100,000 token 上下文**下：**3,400 output tokens/s**
- 同条件下 **Cerebras 为 882 tok/s**——约 **4 倍**领先（官方口径「4x faster than the nearest alternative platform」）
- Nvidia 称相比上代 GB300 NVL72，在 140K 上下文 agentic 负载下 **每兆瓦 token 吞吐量提升 30 倍**（官方口径，未公布绝对功耗）

**硬件形态**
- 每机架最多 **256 颗 LP30 加速器**；2U 液冷托盘 × 16 颗 LPU；托盘内 32 路芯片间**直连光互连**；对外 400Gb/s 以太网，可选 BlueField-4 DPU 或 ConnectX-9 网卡
- LPU 架构核心：**片上 SRAM 取代 DRAM**，带宽约 **150 TB/s**，但**每芯片仅 ~500 MB 内存**（约为顶配 Rubin GPU 显存的 1/576）
- 关键设计：**异构分工**——Vera Rubin GPU 负责 prefill（上下文摄取），LPX 负责 decode（逐 token 生成）。快的不是整条链路，是延迟最敏感的那一段

**商业化**
- 状态：**full production**（全面量产），机架年内上线
- 首发客户：AI 云 **Nebius**（经其 Token Factory 推理服务）；Groq 公司自身的推理云也将早期采用
- 接入方式：官方称经现有 API 接口即可，无需迁移代码到新框架
- Jensen Huang 在新闻稿中的定调：「**推理是 AI 的增长引擎**」（Inference is the growth engine of AI）

## 机制拆解：为什么 agent 对 decode 速度如此敏感

普通聊天场景里，60 tok/s 和 3,400 tok/s 的差别只是「爽不爽」；但 agent 工作流是**串行循环**：思考 → 调工具 → 读结果 → 再思考，每一步的 decode 延迟会在几百上千步里**线性累积**。一个 50 万 token 输出量的长程编码任务，在 60 tok/s 下光生成就要 2.3 小时，在 3,400 tok/s 下不到 3 分钟——这就是官方那句「agentic coding tasks in minutes rather than hours」的算术。

SRAM 路线（Groq/Cerebras/Fractile 同源逻辑）之所以快，是因为 decode 阶段的瓶颈是**内存带宽**而非算力：每生成一个 token 都要完整读一遍模型权重。把权重放进 150 TB/s 的片上 SRAM，而不是几 TB/s 的 HBM，decode 速度就有了数量级差异。代价是 500 MB/芯片的容量——模型必须切碎摊在几十上百颗芯片上，这正是所有争议的起点。

## 正反观点

**支持方**
- 基准由第三方 Artificial Analysis 测量，不是纯厂商自评；4 倍优势的对照对象（Cerebras）本身就是速度王者
- 异构 prefill/decode 分工是务实工程：不宣称 LPU 万能，只切延迟最敏感的那段，且并入现有 Vera Rubin 平台与 API 生态——这是 Groq 独立时期做不到的规模化通道
- 「每兆瓦 token 吞吐 30 倍」若在生产负载中兑现哪怕一半，在电力成为数据中心最硬约束的当下（参考 8/19 共和党备忘录里的数据中心民怨）就是决定性优势

**质疑方（The Register, Tobias Mann 8/24 拆解最系统）**
- **基准是精心挑选的 best case**：Gemma 4 31B 小而稠密，恰好塞进单机架；跑 DeepSeek V3 级的大 MoE 需要 **1,342+ 颗加速器**横跨多机架走以太网，优势可能大幅缩水。同一模型 Cerebras 只需 1-2 颗晶圆级芯片，Nvidia 要 64+ 颗 LPU——芯片数量差两个数量级，成本结构完全不同
- **测量口径不对等**：Nvidia 用的是 pre-release 专用端点，对比的却是竞品的**生产环境**实时端点（StorageReview 指出）
- Cerebras CS-4 已发布、规格翻倍，还拉上了 AMD 与 AWS；Mann 的原话是「Nvidia 的 Gemma 4 31B 对比**可能不会好看太久**」（may not age well）
- 未公布定价与 $/token 经济性——速度是 marketing 数字，单位成本才是采购决策

## 深度解读：对行业 + 对我们

**对行业：推理分层时代开始，「速度」第一次成为独立 SKU。**
1. Nvidia 用一笔交易同时做了两件事：消灭了唯一有声量的「GPU 替代」叙事（Groq 独立时的全部卖点），又把该路线收编为自家平台的一个档位。对 Cerebras、Fractile 和各家自研芯片（Anthropic/Google/Meta）来说，竞争对手从「一家创业公司」变成了「Nvidia 的整个生态」——这也解释了为何 Anthropic 同周既投 Fractile 又挖 Salek：**不能把推理速度这个变量留在别人手里**。
2. 结合上一篇深研（8/24：Fable 5 采用率停在 11%，「无脑用旗舰」终结）：硬件正在为「**中小模型 × 极速推理**」这条路线投票。500 MB SRAM 约束意味着 LPX 天然偏爱 30B 级稠密模型——最快的芯片跑不了最大的模型，这会进一步把负载从旗舰模型往「够用就好」的中档模型上推。软件端（模型采用率）和硬件端（专用推理硅）第一次形成同向合力。
3. 推理市场将从「一种算力」分化为 **prefill 池、decode 池、batch 池**的异构组合，定价随之分层。Stripe 买 OpenRouter、Ramp 做 Router 抢的路由层，恰好是这个分层世界的收费站。

**对做多 agent 系统的我们，三个可执行判断：**
1. **把「token 速度」当成一等设计参数，而不是给定常量。** 我们现在按「模型慢」设计的所有折衷——砍验证步、压缩循环深度、避免多轮 self-critique——在 50 倍速度差面前都该重新算账。可行动作：架构上把「深循环、多验证、real-time 多 agent 协作」设计成随推理速度可伸缩的模式，速度红利来了直接吃到。
2. **关注「interactive 档位」的出现，而非等官宣降价。** Nebius Token Factory 的 LPX 定价、以及 OpenAI/Anthropic 是否推出「fast inference」档位，是未来一季 agent 单位经济性最大的变量。若 interactive decode 档价格落在合理区间，「agent 跑得慢所以要异步排队」的产品假设会失效——竞品会先做出「秒回的 agent」。
3. **中小模型 + 极速硬件的组合值得立刻实验。** 30B 级开源模型（Qwen3.8-27B、Gemma 4 31B）在 LPX/Cerebras 级速度下的「有效智能/秒」，在很多 agent 子任务（工具调用、格式转换、检索汇总）上可能已超过慢 50 倍的旗舰模型。Agent 编排里的「小模型干快活、大模型做关键决策」分工，硬件正在把它从省钱技巧变成性能策略。

## 接下来盯什么

- **Cerebras CS-4 上线后的同条件复测**：Artificial Analysis 上 4 倍差距是否保持
- **大 MoE 模型上 LPX 的真实数据**：若始终只晒 30B 级稠密模型，说明 SRAM 容量瓶颈无解
- **Nebius Token Factory 的 LPX $/M token 定价**：决定 agent 经济性的关键数字
- **OpenAI/Anthropic 是否跟进「interactive/fast」推理档位**（采购 LPX、用 Cerebras，还是自研）
- **Groq 存续实体的走向** 与 license+hire 模板的第四单
- **反垄断信号**：Nvidia 收编最有名的 GPU 替代路线，是否进入 FTC/欧盟视野
