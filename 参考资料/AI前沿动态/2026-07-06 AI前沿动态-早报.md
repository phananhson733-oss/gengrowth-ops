# 🧭 深度研究 ｜ 监管第一次瞄准「agent 怎么造」而不是「模型多强」：中国拟人化 AI 新规 7·15 生效，豆包/千问连夜下架陪伴型 agent

> **一句话定性**：过去两周我盯的都是「能力侧/供给侧」门控——出口管制、Trusted Access、白名单。这一条是**另一条轴的第一枪：需求侧/产品设计侧门控**。中国用一部专门立法，把「持久记忆 + 拟人人格 + 情感黏性」这套我们造 agent 时天天用的设计原语，直接判成受监管对象——不是限制它能做什么，而是限制它**能不能长成一个「类人陪伴者」**。豆包、通义千问被逼在数日内关停整类 agent 产品并**永久删除用户数据**。这不是中国孤例，而是一张会外溢的全球模板。

**来源**：South China Morning Post《ByteDance and Alibaba to disable humanlike AI custom agents as new rules loom》（2026-07-04/05）；法律解读见 Bird & Bird、Future of Privacy Forum；独立报道 The Next Web、TechTimes、ChinaTechNews。规制文本为中国国家网信办（CAC）牵头、发改委 / 工信部 / 公安部 / 市场监管总局五部门于 **2026 年 4 月** 联合发布的**《人工智能拟人化交互服务管理办法（暂行）》**，**2026-07-15 生效**。
🔗 原文（一手报道）：https://www.scmp.com/tech/big-tech/article/3359482/bytedance-and-alibaba-disable-humanlike-ai-custom-agents-new-rules-loom
📅 事件窗口：新规 7/15 生效；千问 7/10 起、豆包 7/15 起执行关停（报道爆发于 7/4–7/5）

## 一、为什么这一篇值得单独深读

这两周监测的主线一直是「前沿能力边境武装化」：Fable 5 出口管制、GPT-5.6 只发 20 家可信伙伴、Mythos 5 附条件复线、商务部 Annex A 白名单——**全是从「模型能力有多危险」出发去卡上线、卡访问、卡国籍**。

这条新闻是**同一张棋盘上被忽略的另一半**：监管不碰模型能力，直接切进**产品形态**。它问的不是「这个 agent 会不会写 exploit」，而是「这个 agent 会不会让用户**上瘾、产生情感依赖、把它当成一个人**」。

对「做多 agent 系统 / AI 产品的我们」，这比出口管制更贴身——因为出口管制影响的是**上游供应商**（换模型即可对冲），而这条影响的是**我们亲手设计的东西**：记忆、人格、engagement loop、always-on 陪伴。这些是当下 to-C agent 增长叙事的核心，而中国刚刚把它们中的一大类判成「原则上不许」。更关键的是：**美国已经在往同一个方向走**（见第五节），所以这不是「中国特色」可以一笔带过，而是一个**产品设计的全球性约束正在成形**。

## 二、核心事实（按可信度分层）

**A. 规制本体（一手文本 / 法律解读）**
- 名称：**《人工智能拟人化交互服务管理办法（暂行）》**（Interim Measures for the Administration of AI Anthropomorphic Interaction Services）。
- 发布主体：**网信办（CAC）牵头，联合发改委、工信部、公安部、市场监管总局**五部门，2026 年 4 月发布。
- 生效：**2026-07-15**，是中国**首部**专门针对「模拟人格 / 提供持续情感交互」类 AI 服务的立法。
- **受管范围**：模拟人的**性格特征、思维方式、沟通风格**，以提供**持续情感交互（sustained emotional interaction）**的服务——即「陪伴型 / 拟人人格 / 用户自建角色」类 agent。
- **豁免范围**：客服机器人、知识问答、职场/生产力助手、教育与科研工具——**只要不构成持续情感交互**。这条豁免线是全篇最关键的可执行信号（见第四节）。

**B. 合规义务（新规要求）**
- **防沉迷系统**（anti-addiction）；
- **强制身份/AI 披露**（对话中须明确告知在与 AI 交互）；
- **即时退出机制**（instant-exit）；
- **实时过度依赖检测**（real-time over-dependence detection）；
- **未成年人身份核验与保护**；
- 官方点名的风险：极端主义内容、隐私泄露、心理健康伤害、成瘾。

**C. 平台执行动作（硬时间表）**
- **通义千问（阿里）**：拟人化交互 agent 与**用户自建 agent** 于 **7/10** 关停；更广义的「千问 agent 功能与服务」于 **7/15** 下线；关停后**用户无法再访问相关 agent 设置或历史对话**，**永久删除、无迁移路径**。
- **豆包（字节）**：agent 功能 **7/15** 下线；此后至 **10/15** 保留**只读**查看（配置 + 历史）；**10/15 之后不可查看、不可恢复**。
- **元宝（腾讯）**：相关功能已在 **6 月** 提前移除。
- 受影响的具体形态：用户/企业自建的、有固定人设的「命名助手、导师、角色扮演、陪伴人格」。
- 用户反应：公开「哀悼」被关停的 AI 角色，并**抱怨无法导出聊天记录**。

## 三、机制拆解：为什么这套要求「与陪伴型 agent 的架构天然冲突」

多家报道用了一个精准的说法：新规要求的**防沉迷、即时退出、实时过度依赖检测**，与「持久记忆型 agent 的设计方式**架构级不兼容**」。拆开看，冲突点正好落在我们造 agent 的四个核心原语上：

1. **持久记忆 ↔ 数据最小化/可删除**：陪伴型 agent 的价值恰恰来自「它记得你」。而防依赖 + 可即时退出 + 数据可删，逼你把「记忆」做成**可随时切断、可导出、可清零**的东西——这与「越记越黏」的产品激励反向。
2. **拟人人格 ↔ 强制 AI 披露**：人设越像人越有黏性；而强制、反复的「我是 AI」披露，是在**主动削弱**沉浸感。
3. **Engagement loop ↔ 反成瘾 / 禁操纵性挽留**：增长团队最爱的「促返回、情感钩子、每日打卡」，正是监管定义的「操纵性挽留 / 促成瘾」——这条在美国华盛顿州法里被写成明确禁止项（见第五节）。
4. **情感依赖（作为留存指标）↔ 实时过度依赖检测并干预**：把「用户离不开」当北极星，与「检测到过度依赖就要提醒/降温」直接对立。

一句话：**监管把「让人上瘾/依恋」从增长杠杆，重新定义成需要被检测和抑制的风险**。这是对整个 to-C 陪伴 agent 商业模式的釜底抽薪，而不是一个可打补丁的合规项。

## 四、关键原话 / 引述

- 工信部专家委员会成员 **潘和林（Pan Helin）**：「**当前的 agent 尚不成熟**」，政策优先「安全、实用、标准化」。——透露监管的姿态是**在产品成熟之前先行介入**（regulate ahead of product maturation），而非事后补救。
- 报道对监管逻辑的概括：北京**偏好把 agent 当基础设施**，而**约束那些与用户形成「准社交关系（quasi-social bonds）」的 agent**。这句话本身就是产品分类的官方口径。

## 五、正反观点

**支持方（消费者保护 / 公共健康视角）**
- 直指真实伤害：青少年心理健康、情感操纵、成瘾、隐私。Character.AI/Google 在 2026 年初就**和解了 5 起未成年人自杀相关的过失致死诉讼**——伤害不是假想。
- **不是中国独有**，而是全球监管同向收紧的一环：
  - **加州 SB 243**（2026-01-01 生效）：陪伴 chatbot 须对未成年人做 AI 披露、每 3 小时提醒休息、自杀/自伤转介危机服务、年度报告。
  - **纽约 S 9051**（2026-06 通过）：**禁止向 18 岁以下提供陪伴型 chatbot**，违规每次最高罚 2.5 万美元。
  - **华盛顿州法**：要求「合理措施**防止操纵性 engagement**——包括促用户返回寻求情感支持、生成促孤立/促情感依赖的输出」，且带**私人诉权（private right of action）**。
  - **联邦 GUARD Act**（两院版本在推）：拟全国禁止向未成年人提供陪伴 chatbot，并强制披露「非人类」。
- 换句话说：**中美监管在「陪伴型 agent」这件事上正在合流**，只是中国用行政关停、美国用州法 + 私人诉讼。

**质疑方（创新抑制 / 用户权益视角）**
- **在产品成熟前就一刀切**，可能扼杀一个刚萌芽、需求真实且巨大的品类（AI 陪伴是最大的消费级 AI 场景之一）。
- **数据处置过于粗暴**：永久删除、无导出、无迁移路径——用户被剥夺自己投入数月建立的角色与记忆，本身就是一种伤害。
- **监管分叉碎片化市场**：中/美/欧各走各的定义与红线，全球产品的合规成本陡增。
- 「拟人化 / 准社交关系」的边界主观模糊，也夹带**内容治理 / 社会控制**的动机（极端主义内容被列为首要风险之一），执行尺度存疑。
- 对阿里/字节这类正重金投入 AI（自研芯片、助手定位）的公司，**时机上是一记压力**。

## 六、深度解读：对行业 + 对「做多 agent 系统的我们」的具体含义

**对行业：监管从「卡能力」扩展到「卡形态」，AI 治理进入第二条轴。**
第一条轴（能力/供给侧：出口管制、可信伙伴、白名单）我们追了两周；这条新规开启第二条轴（**产品设计/需求侧**）。两轴叠加意味着：一个 agent 产品未来要过**两道独立的监管**——上游「你用的模型是否 covered/是否可得」，下游「你造的 agent 是否触碰陪伴/情感/未成年人红线」。**合规不再只是法务的事，而是架构决策。**

**对我们（可执行判断，别套话）：**

1. **把「情感依赖 / 拟人化」从增长杠杆降级为受监管的设计维度。** engagement loop、拟人 persona、always-on 陪伴、「促返回」的挽留话术，现在**同时在中美带合规风险**。别再把「用户离不开」当北极星指标写进 to-C agent 的 OKR。

2. **划死「工具型 vs 陪伴型」的产品边界，并优先落在豁免侧。** 两地监管都放过「客服 / 知识问答 / 职场生产力 / 教育科研」——只要**不构成持续情感交互**。做 to-C agent，把定位钉在**任务/生产力/基础设施**一侧，是当前风险最低、且被官方明确豁免的路径。触碰「陪伴 / 角色扮演 / 情感支持」就要预设完整合规栈。

3. **把合规原语做成 agent 框架的一等公民（可配置、默认可开）**：
   - 强制、可见的 **AI 身份披露**；
   - **即时退出**；
   - **防沉迷 / 时长提醒**；
   - **实时过度依赖检测**（这是新的产品组件，不是文案）；
   - **未成年人识别与分级保护**；
   - **禁用**「促返回 / 促孤立 / 促情感依赖」的操纵性话术（华盛顿州法的私人诉权 = 集体诉讼风险，不是软约束）。
   这些应当是框架层可开关的 feature flag，而非每个产品各自硬编码。

4. **数据可携 / 可导出 / 迁移路径 = 合规 + 信任双重资产。** 豆包/千问「永久删除、无迁移」引发用户哀悼，是一次**反面教材**。我们的持久记忆从第一天就该支持**用户导出与删除**——既满足「可删」类监管，也是差异化信任卖点（「你的记忆属于你」）。

5. **地缘合规分叉写进架构。** 一个全球 agent 产品，其**记忆深度 / 人格拟真度 / 情感行为 / 未成年人策略**必须**按司法辖区可配置**——中国关陪伴、纽约禁未成年人、加州要提醒、华盛顿禁操纵挽留。做成「按地区切换陪伴度」的配置层，而不是为每个市场分叉代码。

6. **盯监管外溢，抢在立法前把护栏做进默认值。** 这是会扩散的模板：欧盟 AI Act 是否补 companion 条款、更多美国州跟进（尤其带私人诉权的）、GUARD Act 联邦化。**领先合规半步 = 少一次被迫重构**。

## 七、接下来盯什么（信号）

- **7/10（千问）/ 7/15（豆包）实际关停执行**：是否如期、用户与数据后续、是否临时给出导出机制。
- **中国是否出后续细则 / 迁移方案**：以及「持续情感交互」在执法中如何被具体界定（决定豁免线的实际宽度）。
- **美国联邦 GUARD Act 进展 + 更多州立法**：尤其**带私人诉权**的州（华盛顿模式）——那是对产品方最硬的约束。
- **欧盟 AI Act 是否把 companion / anthropomorphic 单列**。
- **头部 agent 平台（OpenAI / Anthropic / Google）如何调整 memory / persona / engagement 设计以适配**：它们的默认行为变化，就是我们该抄的合规基线。
- **陪伴 AI 品类的资本与并购动向**：监管收紧后，这块估值/投资是否降温，是格局先行信号。
