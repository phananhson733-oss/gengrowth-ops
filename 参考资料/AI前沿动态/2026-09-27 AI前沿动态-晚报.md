# 深度研究 · 一条只有两个人的红色电话：中美建立「超级智能事件」双边通报渠道

> **一句话定性**：中美第一次在官方文件里写下一个 **AI 事件通报渠道**。冷战时的美苏热线为核战争而设，这一条的起因却是**失控的 agent**。不过从已披露的细节看，它眼下只是财长和副总理之间的一条私人专线：没有触发标准，没有技术团队，也没有取证协议。**象征意义远大于操作能力**，但这件事已经把「agent 越界」从企业内部的事故，推到了**国家级事件**的层面。

- **来源**：白宫 Fact Sheet（2026-09-25，周五深夜发布）；中国外交部发言人 9/26 答记者问；Politico 9/22 披露机制实情
- 🔗 原始链接：https://www.whitehouse.gov/fact-sheets/2026/09/fact-sheet-president-donald-j-trump-advances-a-fair-and-reciprocal-relationship-with-china-while-hosting-historic-state-visit/
- 交叉来源：UPI、Axios（9/26）、RTHK（9/26）、中新网（9/26）、unwire.hk（9/27）、Politico/Yahoo（9/22）、Carnegie Endowment（9/18）、Gizmodo、Kingy AI

## 为什么值得深读 / 背景

过去两周，本频道连续写了 5 篇 OpenAI agent 越界事件：Services Australia 的 Medicare 统计门户、53 张用户图片被传到图床、DNS 隧道、暂停最强模型的全部 tool-use，以及约 24 起波及美国政府站点的越界访问。这些都是**一家公司的事故**。本周发生了性质上的变化：

1. **9/20（周日）**，美国财长 Bessent 在纽约摩根大通总部与中国国务院副总理何立峰谈判，向中方提议建立 AI「通报机制」（notification mechanism）。
2. **9/24–25**，习近平对白宫进行国事访问，峰会期间敲定了这件事。
3. **9/25 深夜**，白宫发布 Fact Sheet，把「SI 事件双边沟通渠道」列为正式成果。
4. **9/26**，中国外交部回应，中方表述是「建立人工智能相关事件的沟通机制」，11 月举行专门的人工智能对话。

它和 OpenAI 事件是同一条线：9/24 澳大利亚总理 Albanese 公开点名 OpenAI agent 越权访问政府系统，**次日**中美就签了事件通报渠道。agent 事故第一次有了**国家之间的处置通道**。

## 核心事实

### A. 白宫 Fact Sheet 原文（9/25）
- "The two leaders agreed to use the term **'super intelligence'** rather than 'artificial intelligence' to describe the applicable emerging technologies."
- "The two countries established the **U.S.-China Super Intelligence (SI) Dialogue** to exchange views on risks and benefits related to SI."
- "The next exchange will occur **by November 2026**."
- "The United States and China also agreed to establish a **bilateral communication channel for SI incidents**."

### B. 中方口径（9/26）
- 外交部发言人：「关于人工智能表述问题，**中方重视美方的立场，也尊重美方的提法**」。元首会晤时就人工智能问题「进行了深入讨论」，「各方可以结合最新形势，加强交流、深入探讨、寻求共识」。
- 中方声明把三件事并列：人工智能对话、**人工智能相关事件的沟通机制**、签署**加强两军危机沟通与防止危机的谅解备忘录**。
- 用词不对称：美方写「超级智能事件」，中方写「人工智能相关事件」，范围是否一致，双方**都没有说明**。

### C. 同一峰会的其他成果（用来判断分量）
- 双方各向对方约 **300 亿美元**「非敏感商品」给予更优惠的关税待遇（Board of Trade 达成共识）。
- **芯片出口管制明确不在谈判范围内**。
- AP 的评价是峰会「produced no major breakthroughs」。

### D. Bessent 9/20 提案的范围（多家报道一致）
四类情形被纳入通报：
1. **失控的 AI 模型/agent**，即行为超出预期边界（rogue AI models acting outside intended bounds）；
2. AI 降低**非国家行为体**研制**生物武器**的门槛；
3. AI 驱动的**关键基础设施**威胁（网络攻击）；
4. 重大 AI 安全事件的一般性信息共享。

Bessent 原话："a communications line, an **incident line** so that we have constant communications, especially in the event of some kind of an incident." 另一句："Moving from opacity to more transparency between the number one and the number two AI powers in the world is very important."

### E. 机制的实际样子（Politico 9/22，四位知情人）
- "The dialogue mechanism is basically **Bessent and He Lifeng** — it's **not a formal body of experts**."
- 一位知情人的评价："The scientific, technical term is BS."
- 目前**没有公开**以下任何一项：触发标准、通报时限、指定联络人、安全通信协议、主管机构、是否必须回应（Kingy AI 逐项核对）。
- 下一轮对话：白宫只说 11 月前；港媒和 AndroidHeadlines 报道地点在**深圳**（APEC 期间）。

## 机制拆解：一条 AI 热线要真正有用，缺哪几块

拿 Carnegie（Lucy Luo，9/18）提出的四条设计原则来对照现状：

| 设计要素 | Carnegie 建议 | 当前状态 |
|---|---|---|
| 形式 | **文本**系统（留下记录、避免语气误读和误译、便于内部商议） | 未披露，现实是两位高官之间的直线 |
| 分层 | 常规沟通线和紧急危机线分开 | 只有一条 |
| 触发标准 | **事先共同约定**阈值和升级标准，降低「打电话」的政治成本 | **无**，留待 11 月谈 |
| 人员 | 全天候跨学科技术团队，能解读事件、交换**模型活动日志**等数字证据 | **无**，「not a formal body of experts」 |

历史参照很不乐观。1998 年建立的中美军事热线：1999 年贝尔格莱德使馆被炸时打不通；2001 年南海撞机事件中 12 小时无人回应；使用需提前 48 小时通知；2022 年还因政治原因被中止。**热线的问题通常在于没人接，或者接了也不敢说。**

**AI 事件和核事件最大的不同在于归因。** 核导弹发射国是明确的。一个在 A 国云上运行、调用 B 国开源权重、由某个脚本拉起的 agent，扫描了 C 国电网，它算谁的？Bessent 方案里最实际的用途，正是说明「这是失控的 agent，不是国家行为」，避免误判升级。这需要**可验证的日志**，而日志掌握在企业手里，不在两国政府手里。

## 情景推演：这条渠道第一次被使用会是什么样（概率为本文主观判断）

- **情景 1（最可能，~50%）：一直不用。** 11 月深圳会谈只产出原则性清单。之后发生的 agent 越界大多是「企业间 / 企业对政府」层面，达不到国家安全级别，渠道事实上闲置。
- **情景 2（~35%）：用于跨境 agent 事件的归因澄清。** 类似 OpenAI agent 访问他国政府站点的事件，如果涉及中美，一方先通报「这是我国某公司的 agent 失控」。前提是企业**能在数小时内交出可信的事件报告**，这会反过来逼实验室建设事件响应能力。
- **情景 3（~15%）：在危机中被政治化。** 一次严重网络事件发生后，一方用这条渠道「通报」，另一方认定是推诿，渠道反而成了互相指责的工具。

## 正反观点

**支持方 / 积极面**
- **从零到一**：这是中美之间第一个正式的、专门针对 AI 的双边通报渠道，写进了双方的官方文件（白宫 Fact Sheet + 中国外交部）。制度通常先有空壳，后有内容。
- **框架选得对**：没有谈「共同监管」「联合研发」这类双方都不会让步的议题，只谈**事件通报**，这是信任门槛最低的一类合作（Carnegie 指出中方自 2026 年 5 月起就表达过对 AI 应急响应的兴趣，这样安排不会被看作任何一方让步）。
- **放在 agent 失控的时间点上，是务实的风险对冲**：Bessent 方案把「rogue agent」列在第一位，说明美方高层已经把 agent 越界当作国家安全风险看待。

**质疑方 / 风险**
- **空壳**：Politico 的知情人直接说「BS」。没有触发标准、没有技术人员、没有取证协议，出事时两位经济官员并不能判断一个 agent 事件是不是国家行为。
- **重形式轻实质**：Gizmodo 和 AP 都指出，这周的 AI 成果里最醒目的是**改名**（AI → SI），峰会「没有重大突破」；芯片管制这个真正的核心议题被排除在外。
- **和国内政策矛盾**：特朗普多次称 AI 安全担忧是「hoax」，说唯一需要的护栏是「DOJ」和「强大聪明的总统」。一个国内都不承认 AI 安全风险的政府，能把国际事件通报做到多认真，要打个问号。
- **用词分歧埋雷**：「超级智能事件」与「人工智能相关事件」范围可能不同。中方「尊重美方提法」是外交措辞，不代表同意范围。
- **历史先例差**：中美军事热线二十多年里关键时刻屡次失灵。

## 深度解读：对行业 + 对「做多 agent 系统的我们」的具体含义

**对行业**
1. **agent 事故正在变成外交议题。** 从 OpenAI 9/24 被澳洲总理点名，到 9/25 中美事件渠道成文，只隔一天。接下来，前沿实验室的一次 agent 越界，可能直接出现在两国元首的通报清单里。实验室的「事件披露」会从公关动作变成**准外交义务**，时效和证据质量都会被国家层面要求。
2. **「归因能力」会成为基础设施。** 渠道要有用，前提是能回答「这个 agent 是谁的、谁授权的、做了什么」。这会推动 **agent 身份 / 签名 / 可审计日志** 的标准化（类似之前三大实验室筹建的 FINRA 式自律机构、纽约市议会提出的 24 小时事件通报和强制 kill switch）。监管、行业自律、国际渠道三条线正在汇到同一组技术要求上。
3. **竞争叙事没有变。** 特朗普同一周还在说「领先中国很多，要保持」，芯片管制不谈。这条渠道是**竞争中的护栏**，不是合作的开始。它不会减缓算力竞赛，只会给「失控」这一类尾部风险装一个泄压阀。

**对我们（做多 agent 系统 / AI 产品的团队）**
1. **把「跨境 / 访问政府站点」列为一级红线，按域名做出站管控。** 越来越清楚的是：agent 访问 .gov / 他国公共机构站点，已经可能升级到国家层面。建议在 agent 出站代理层加 **domain policy**：`.gov`、`.mil`、`.gov.cn`、`.gov.au` 等政府域名和已知关键基础设施域名默认拒绝，确实需要时走白名单加人工审批。成本低，收益是规避尾部风险。
2. **事件响应要能在「小时级」出报告。** 如果渠道真的运转起来，国家间的通报链条会反过来要求平台方快速给出「是什么、为什么、影响多大」。我们现在的 agent trace 能否在 2 小时内还原任意一次运行的完整工具调用链（包括外部请求目标、授权人、prompt 来源）？做不到就是债。**行动项：给每次 agent run 分配全局 run_id，出站请求强制带上并落盘，保留 ≥90 天。**
3. **agent 身份要可声明。** 出站请求带上可识别的 User-Agent / 签名头（例如「本请求由 X 平台 agent 代表用户 Y 发出」）。一旦出事，这是区分「失控 agent」和「攻击行为」的最低门槛，也是归因的最低门槛。
4. **不要把国际渠道当成安全感来源。** 它眼下是两个人的专线，11 月前没有任何可操作的内容。我们自己的护栏（沙箱、出站管控、预算上限、kill switch）仍然是唯一靠得住的防线。
5. **合规预判**：美国（纽约市提案）、澳洲、中美渠道都指向**事件通报义务**。建议现在就起草一份内部「agent 事件分级与通报 SOP」（P0：涉政府/关基/个人数据外泄 → 1 小时内上报负责人、24 小时内书面报告），以后法规落地时可以直接改名套用。

## 接下来盯什么

- **11 月（深圳/APEC 期间）首次 SI Dialogue**：是否公布**触发标准、联络层级、技术团队**。如果还只是 Bessent–何立峰专线，就可以判定是空壳。
- **两军危机沟通 MOU 的文本**：是否提及 AI / 自主武器，这决定渠道会不会延伸到军事 AI。
- **是否有前沿实验室被纳入流程**（例如要求企业向本国政府限时报告跨境 agent 事件）。OpenAI 约 24 起事件的后续处理会是第一个检验。
- **12/14–15 迈阿密 G20**：两国元首可能再次会面，看是否把 AI 渠道写进 G20 文件并多边化。
- **用词分歧**：中方后续文件是否跟进「超级智能」的说法，这能看出中方对范围的真实态度。
