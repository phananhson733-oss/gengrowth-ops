# 深度研究 · 最强模型卖不动——Fable 5 停在 11%，「无脑用旗舰」的时代结束了

**一句话定性**：FT 援引 Ramp 对约 7 万家美国企业真实支出的分析：Anthropic 六月发布的旗舰 Fable 5 两个月后仅占 Anthropic 支出的约 11%、token 量的 6%，被上市一个月的自家便宜模型 Opus 5 反超——这是「企业默认买最强模型」这一行业惯性第一次被硬数据证伪，Ramp 直言「我们找到了企业愿为 AI 付费的价格上限」。

- **来源**：Financial Times（George Hammond）🔗 https://www.ft.com/content/5ee49718-c258-4f01-aa32-7e5b76ae5245 （2026-08-23/24；FT 有付费墙，数据经 Ramp 一手指数与多家独立转述交叉核实）
- **一手数据**：Ramp《August 2026 AI Index: Cracks in the AI thesis》🔗 https://ramp.com/data/ai-index-august-2026
- **热度**：Techmeme 8/24 头版第一条；Hacker News 601 分 / 534 评论

## 为什么值得深读 / 背景

过去三年，AI 行业有一条不言自明的商业假设：**能力最强的模型自动赢得付费**。每代旗舰发布→企业迁移→收入上台阶，这是 OpenAI 和 Anthropic 估值故事的地基。Fable 5 是 Anthropic 今年 6 月发布的最强通用模型（与受管制的 Mythos 5 同底、带额外安全措施），定价约 $10/百万输入 token——约为 GPT-5.6 Sol 的两倍、自家 Opus 5 的两倍。

现在第一份大样本企业支出数据说：**这条假设失效了**。而且时点极其敏感——Anthropic 的 S-1 最快本周公开递交（目标估值约 $2 万亿、拟募 $1000 亿+），「旗舰定价权」正是 IPO 叙事的核心之一。这也解释了为什么这条新闻能在 HN 上冲到 601 分、534 条评论，全行业都在讨论。

## 核心事实

**Fable 5 的采用数据（Ramp，2026 年 7 月，约 7 万家企业的卡+token 支出）**
- 仅占 Anthropic **token 购买量的 6%**、**支出金额的 11.4%**（尽管它是最贵的型号）
- Opus 5（7 月 24 日发布，$5/$25 每百万 token）**上市一个月即在企业支出上反超** Fable 5
- 7 月 Fable 5 的模型归因支出仅为 OpenAI 旗舰 GPT-5.6 Sol 的 **75%**
- 对照：GPT-5.6 Sol 占 OpenAI token 的 25%、支出的 23%——同为旗舰，渗透率约为 Fable 5 的 2~4 倍
- Vercel AI Gateway 同期口径：Fable 占网关支出 13.2%，且 90% 的 Fable 用户是新用户（增量尝鲜，非存量迁移）

**但 Anthropic 整体盘子仍在扩大（同一份 Ramp 指数，常被标题忽略）**
- Anthropic 覆盖 **43.5%** 的美国企业（月增 1.1 个百分点，市场第一）；OpenAI 39.7%（月增 0.23）
- xAI 4%（月增 0.94，一年来最快）；Google 高个位数；DeepSeek 接近零
- 开源/中国模型 serving 平台：占 AI 付费企业的 **6.1%**（1 月为 4.5%）——且是「叠加使用」而非「替换厂商」
- 支出强度分化极端：Top 1% 企业每员工每月 **$7,400**，Top 10% 约 $650，**中位数企业只有约 $12**

**财务与竞争背景**
- Anthropic：7 月底 ARR **$650 亿**（5 月 $470 亿），Q2 收入 $115 亿（约 14 倍同比），调整后经营利润转正；6/1 秘密递交 S-1，最快 8 月底公开
- OpenAI 8/21 刚把 GPT-5.6 Sol 降价至 $4/$20（−20%/−33%，为期三个月），明言应对 Anthropic 与中国模型
- dbreunig 测算:GLM 5.2 价格约为 Fable 的 **1/9**、Opus 5 的 **1/5**，常规编码任务「够用」
- SemiAnalysis 8/22《Are Open Models Catching Up?》：开源追平闭源代际的周期逐代减半，GLM 5.3 / Kimi K3 已能承接把 Anthropic 推到 $650 亿 ARR 的相当部分编码/agentic 工作负载

## 机制拆解：旗舰为什么卖不动

1. **价格-能力曲线弯了**。定价翻倍，但企业感知的工作负载增益不成比例——benchmark 领先转化不成生产环境的边际价值。Ramp 的结论是经济学式的：需求曲线在 $10/M 处出现了拐点。
2. **「够用」阈值已被越过**。企业大头工作负载（编码、客服、文档、数据处理）在 Opus 5 / GPT-5.6 / GLM 级别已达标。旗舰的增量能力（超长程自主任务）对应的是少数场景。
3. **Agent 化改变了 token 经济学**。Agent 工作流让 token 消耗量爆炸式增长（GitHub 月提交量 4 个月翻倍的那条曲线），模型从按次咨询的「顾问」变成持续燃烧的「燃料」——单价敏感度随用量指数级上升。这恰恰是 Fable 5 最受伤的地方：它的目标场景（长程自主 agent）正是 token 消耗最大的场景。
4. **合规与信任摩擦是隐性税**。Fable 5 带额外安全措施、文本水印（8 月中引发大规模用户争议）、更严的访问控制与数据留存政策，且有 6 月被出口管制下线、7/1 才复线的前科。对企业采购来说，这些都计入「单一依赖风险」。dbreunig 明确把这一条列为企业转向多模型策略的加速器。
5. **最强对手是自家便宜模型**。Opus 5 的反超说明这更多是**体系内自蚕食**而非客户流失——Anthropic 整体份额还在涨。但自蚕食同样杀伤旗舰的毛利叙事。

## 正反观点

**看空方（FT/Ramp 叙事）**：旗舰溢价卖不动 = 前沿实验室的核心商业假设破产。训练成本按代数十亿美金地涨，而变现天花板已经出现；叠加 OpenAI 降价、开源逼近，前沿模型正在滑向大宗商品化。在 IPO 定价前夜，这是对 $2 万亿估值最直接的一击。HN 社区的第一手证据（护栏误伤、效果不稳、Claude Code 被抓到 A/B 测试「降低思考力度」）指向同一件事：厂商在成本压力下悄悄降质，进一步侵蚀旗舰溢价的信任基础。

**看多方 / 细读数据方**：①这是**自蚕食不是流失**——Opus 5 的每一美元仍是 Anthropic 的收入，公司总份额还在扩大（43.5% 且月增第一）、ARR 三个月涨 $180 亿、经调整经营利润转正；②旗舰的战略价值从来不只是直接收入：它是能力上限的证明、品牌锚点、以及 Opus/下一代蒸馏的源头；③Ramp 样本偏科技公司、按卡支出统计，大企业直采协议（往往正是旗舰的主力买家）不在样本里；④Vercel 数据显示 90% Fable 用户是新增用户——它在开辟新场景（长程自主 agent），这个场景本身还太早期，两个月下结论为时过早。

## 深度解读：对行业 + 对我们

**对行业：定价权换了主人，「模型分层」成为默认结构。**
这份数据宣告行业从「单一最强模型通吃」进入「组合定价」时代：旗舰做尖刀场景，中档模型吃大盘，开源吃底层。三个直接推论：
1. **前沿实验室的商业模型要重写**。当 90% 工作负载停在中档价位，旗舰研发成本必须靠尖刀场景（科研、安全、长程 agent）+ 蒸馏反哺中档来回收——Anthropic 把 Mythos 5 只按「产物」发放给安全厂商、把蛋白设计做成访问计划，都是同一逻辑：**最强能力开始按结果卖，而不是按 token 卖**。
2. **价格战会继续向下传导**。OpenAI 的三个月限时降价、GLM 的 1/9 价格锚，会把中档价位持续往下压。模型 API 的毛利故事整体承压，厂商会更依赖 harness/工作台/企业协议等上层变现。
3. **对 Anthropic IPO 是叙事考验而非基本面崩塌**。S-1 公开后，最值得看的是收入按模型层的拆分——如果 Opus 层贡献了绝大部分且增速健康，「组合胜于单品」反而是更稳的故事。

**对我们（做多 agent 系统的团队）——四条可执行判断：**
1. **模型路由从优化项升级为一等公民架构**。市场已经用钱投票验证了 dbreunig 的「免费午餐结束」论：不做路由 = 直接烧 2~9 倍成本。落地形态很明确——planner/critic/关键决策用旗舰或次旗舰，大批量 worker 用中档或开源（Opus 5 / GLM 级），机械性步骤用最便宜档。我们的 agent harness 里，模型选择应该出现在每个 agent 的配置层，而不是全局一个默认值。
2. **「旗舰做顾问、便宜模型做执行」是当前最优工作流**。dbreunig 的实践（用 Fable 审问设计、用 GLM 写常规实现）与 Claude Managed Agents 的 advisor 模式（工作 agent 会话中途向不弱于自身的模型要第二意见）指向同一个 pattern：旗舰以低频、高杠杆的方式介入。这比「全程用旗舰」便宜一个数量级，比「全程用便宜模型」质量高得多。
3. **现在是锁短约、不锁长约的谈判窗口**。OpenAI 限时降价、Anthropic 旗舰滞销、开源逼近——买方议价能力处于两年来最强点。任何年度级模型采购承诺都应该重新谈。
4. **单一厂商依赖要按「已发生过」来管理**。Fable 5 今年已经真实地被出口管制下线过一次；水印、数据留存政策还在变。多模型冗余（至少一个开源 fallback）不是架构洁癖，是业务连续性。
