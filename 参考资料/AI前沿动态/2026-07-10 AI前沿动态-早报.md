# OpenAI ChatGPT Work「超级 App」发布：市场领导者正面接战「agent 工作台」

**一句话定性：** OpenAI 把 ChatGPT 从"聊天框"重构为"交付成品的执行平台"——用 ChatGPT 与 Codex **合体**而成的 ChatGPT Work，正面回击两天前刚上移动/网页的 Anthropic Claude Cowork。两大前沿实验室在 **48 小时内**做出几乎同形态的「通用办公 agent」，标志着「谁占住工作真正发生的界面」正式取代「谁模型最强」，成为前沿竞争的主战场。

**来源：** OpenAI 官方公告《ChatGPT is now a partner for your most ambitious work》 · 🔗 原始链接 https://openai.com/index/chatgpt-for-your-most-ambitious-work/ · Bloomberg / Reuters / 9to5Mac / TestingCatalog 交叉核实 · **日期：2026-07-09**（GPT-5.6 全球 GA 同日）

---

## 为什么值得深读 / 背景

我们在 **7/8 早报**深挖了 Anthropic 把通用 agent **Claude Cowork** 推到手机/网页，并首次公开「91.3% 的用量与软件开发无关」的数据，判断"战场从'谁模型/chatbot 最强'移向'谁占住工作真正发生的界面'"。**48 小时后，市场领导者 OpenAI 用几乎同形态的产品接战。** 这不是巧合，而是两家在同一周独立收敛到同一个结论。

这一条比"又一个 agent 功能"重要，原因有三：

1. **出手的是在位领导者**：OpenAI 手握约 8 亿周活消费用户 + 200 万家企业客户，Codex 已达 **500 万周活**且大多为付费用户。领导者亲自下场，把叙事从"Anthropic 的差异化打法"升级为"整个前沿行业的产品共识"。
2. **能力融合是真变化**：ChatGPT Work 把编码 agent（Codex）与通用聊天**合成一个 agent**，让"读代码/改代码"的自主执行能力**外溢到 docs/slides/sheets/网页/跨 app 操作**这类白领胶水活——编码红利变通用生产力。
3. **它是"门控范式"故事的另一面**：ChatGPT Work 绑定 **GPT-5.6**，而 GPT-5.6 正是昨天（7/9）刚跑通"国家安全门控 → 全球 GA"的那款模型。前沿能力刚解禁，立刻被包进企业工作台变现——能力—门控—分发—变现的闭环在同一周走完。

## 核心事实（分层）

**产品形态（硬事实，多源一致）**
- **ChatGPT Work = ChatGPT + Codex 合体**：旧的独立 Codex app 并入统一桌面应用，被更名为 **"ChatGPT Classic"**；Chat / Work / Codex 三种模式共享 1,400+ 插件、同一桌面 App，**所有档位（含 Free）**都拿到统一桌面端。
- **交付"成品"而非答案**：直接产出**电子表格、幻灯片、文档、可交互网页 App**（Sites 公测）——不是给建议，是给可用的交付物。
- **长跑数小时**：把复杂项目拆成小步、**独立跑数小时**完成；桌面端 **Computer Use** 可在后台跨 app/工具/浏览器"点击、打字、搬文件"。
- **Scheduled Tasks（定时/事件触发）**：可把 Microsoft Teams / Slack 的新消息**自动**转成更新后的 docs/slides 并推给团队；支持一次性/按计划/事件触发/持续运行。
- **Atlas 浏览器停运**：agentic 浏览能力被吸收进 ChatGPT 桌面浏览器 + Chrome 侧栏。

**模型与定价**
- 由 **GPT-5.6（Sol / Terra / Luna）**驱动，昨日同步全球 GA。API 价：Sol $5/$30、Terra $2.5/$15、Luna $1/$6（每百万 token 输入/输出）。
- **用量计费（usage-metered，沿用 Codex 结构），无公开的按任务 rate card**；企业/Edu 管理员拿到支出管控：工作台默认额度、组级上限、个人覆盖、申请额度流程。

**人在环 + 治理**
- **Plan Mode**（动工前逐步审批）、**可配置 check-in**、**动作审批**（所有动作以用户签核为闸）。
- **Auto-Review**：更强的模型在执行前审查重要的"连接工具"动作；官方红队结论——**"auto-review 拦下了 100% 的受保护数据提取尝试"**；Compliance API 提供对话与动作的规模化审计。

**采用基线（OpenAI 自报）**
- Codex **500 万+周活**、桌面上线后 **6x 增长**、**100 万+**用户已把 Codex 用于**非开发**用途。
- 铺开节奏：Pro/Enterprise/Edu 于 7/9 上 web/mobile，Plus/Business 数日内跟上；桌面 macOS 全档 7/9，Windows 滚动。

**早期客户成效（官方案例，直接量化）**

|---|---|---|---|
| Zapier | 线索三审 QA/QC | 35–45 分钟/线索 | **每月七位数管道**交接销售 |
| Virgin Atlantic | 竞品对标 | 每轮数周 | 每轮数小时 |
| NVIDIA | GTC 大会筹备 | 占 GTM 经理约 40% 时间 | 每周跑两次 |

| OpenAI 财务 | 月末结账 | 数天 | 数小时 |

## 机制 / 竞争拆解：为什么两家在同一周撞了同一个形态

**共同的产品公式**：`长跑数小时 × 跨 app 操作（Computer Use/连接器）× 交付成品 × 定时/事件触发 × 人在环审批 × 企业审计`。Cowork 与 ChatGPT Work 逐条对得上。这不是抄袭，而是"通用办公 agent"这个物种被两家同时收敛出来——说明**这套契约已经是前沿共识，不再是谁的独门叙事**。

**战略分层（OpenAI 的算盘，据 FourWeekMBA 拆解）**：一名资深员工的说法是 **"Chat is dead"（聊天已死）**。OpenAI 在把 ChatGPT 从"信息界面"改成"执行平台"，因为用户为"生成信息"付得少、为"替我干完活"付得多。其栈是：**ChatGPT（获客/分发）→ Agents（执行）→ 企业工作流（营收）→ AI 操作系统（长期平台赌注）**，目标是让 ChatGPT 成为"AI 时代的浏览器"。配套动作是**收缩消费侧**：关掉结账（checkout）、上线不到一年就停掉 Sora，把资源压向可变现的企业自动化。企业已占 OpenAI 约 **40% 营收，年底预期 50%**。

**与 Anthropic 的战略趋同**：历史上 OpenAI 走消费优先、Anthropic 走企业优先；如今两家打同一套牌——企业客户、编码产品、agentic 工作流、IPO 级经济学。**竞争从"模型性能"移到"业务执行层"**，两家都认定：会复利的是执行层，不是聊天。这把战火同时烧向 Microsoft（Office/Teams + Work IQ）与 Google（Workspace + Gemini Enterprise Agent Platform，Gemini 3.5 Pro 预定 7/17 GA）。

## 正反观点

**支持方（在位者优势 + 真实采用）**
- 领导者规模是护城河：2M 企业 + 5M Codex 周活 + 已有分发面（桌面/手机/Chrome 侧栏/Slack/Teams），让 agent **嵌进工作真正发生的容器**而非做外挂——这正是 Cowork 的分发短板。
- 早期案例是**量化**的（Zapier 七位数管道、财务月末结账"数天→数小时"），不止 demo；100 万 Codex 用户已在跑非开发用途，说明"编码 agent 外溢通用工作"有真实需求底座。

**质疑方（可靠性 + "有什么真新" + 经济学）**
- **可靠性仍是真瓶颈**：Understanding AI 直言 agent"还远没到能真正托付的可靠度""一个经常做错事的 agent 往往比没有还糟"。IBM 指出这类系统放大了监督、可靠性、安全三重问号。
- **"有多少是真新的"**：the-decoder 指出——Scheduled Tasks、插件、Computer Use **在 ChatGPT/Codex 里早已存在**，公告里很难分清哪些是全新能力、哪些是重新打包。企业要的是**更高准确率 + 更紧控制**，而演示更偏个人用户场景。
- **经济学不可预测**：用量计费**没有公开按任务 rate card**——延续 GitHub Copilot"单次 agentic 会话烧 $30–40""隔夜 runaway agent $437 账单"的隐忧，成本对企业不透明。
- **红队"100%"是营销数不是生产保证**：受控红队 ≠ 真实对抗环境，不能当作可托付关键工作流的凭据。

## 深度解读：对行业 + 对「做多 agent 系统的我们」的具体含义

**对行业**：这一周确认了一个结构性转向——**前沿竞争的第一战场从"模型榜单"下移到"占住工作发生的界面 + 交付成品"**。两巨头 48h 趋同、Vercel 数据（编码 agent 触发的部署半年内从 <3% 升到 >50%、月 token 2 万亿→20 万亿）、Cowork 的 91.3% 非编码用量，三条独立证据指向同一件事：**价值重心正从"聊天/编码"外溢到"整个办公桌上的胶水活"**。模型能力正在被商品化，护城河搬到 workflow / harness / 分发（呼应 7/2 Claude Science"护城河搬到工作流"）。

**对我们（落到可执行判断）**：

1. **分发战场已确定 = 嵌进容器，别做外挂。** 两家都把 agent 塞进桌面/手机/浏览器侧栏/Slack/Teams。我们没有平台级分发，**只能嵌进客户已经在用的界面 + 低摩擦自下而上**，并选平台方够不着的垂直细分。有界面就把 agent 嵌进"工作真正发生的容器"。
2. **选题往非编码胶水活走。** ChatGPT+Codex 融合 + 100 万 Codex 非开发用户 + Cowork 91.3% 非编码，共同说明 agent 价值重心≠编码。选题优先"业务流程运营 / 内容 / 数据整理"这类人人要做、非主业的胶水活。
3. **把"后台长跑 + 人在环"做成一等架构，别把 demo 当自主。** 直接抄 ChatGPT Work 的契约：**Plan Mode 式预批 + 危险原语 allowlist + 可回滚 + 循环熔断 + 高危动作强制人审**。判断自主度用**"无人工跑完率"KPI**，不用 hype video；给"需人审动作"建预算 + 批量异步审批队列，压通知疲劳。
4. **"执行前审查连接工具动作"值得抄，但别信 100%。** 把 Auto-Review 那层（危险/外发动作在执行前过一道模型审查）做成一等安全原语；但红队 ≠ 生产，**独立验证器、异源监督者、审计日志仍要自扛**（呼应 6/22 DeepMind"监督者悖论"未解）。
5. **cost-per-task 升为一等 KPI + 现在就上支出护栏。** usage-metered 无公开 rate card = runaway bill 风险。上工作台默认额度、组级上限、单任务熔断；名义 $/Mtok ≠ 每任务成本，评测口径加"平均输出 token/任务"。
6. **模型可换、agent 层中立。** ChatGPT Work 锁 GPT-5.6、Cowork 跑 Opus 4.8——**别与单一 provider 不可逆绑定**。保留多模型热切换 + 独立 API key + 备胎（承接 Vercel"把模型从 agent 里拆出来"、Lindy→DeepSeek 降 90% 效率主线）。
7. **别把巨头趋同当"我们输了"。** 可靠性仍是真瓶颈（Understanding AI / the-decoder）。高价值 / 低容错路径留人审 + 顶级模型；巨头做宽平台，我们做深垂直 + 把治理/可复现/审计做成可卖的信任资产。
