# GPT-5.6（Sol / Terra / Luna）全球 GA：第一款「政府放行后才敢公开发布」的前沿旗舰

**一句话定性：** 能力面上，它是当前独立智能指数**全球第二**、ARC-AGI-2 拿到 **92.5%**、在 agentic coding 上**省 54% token**的推理旗舰；但它真正的历史性不在跑分——它是**首个"公开发布前先被联邦政府按下暂停键、经审批解禁后才 GA"的前沿模型**，把"谁能用上最强模型"从一个市场问题，变成了一个**国家安全审批**问题。

## 为什么值得深读 / 背景

6/26 我们推过 GPT-5.6 的**预览**（系统卡标注 6/25）：Sol / Terra / Luna 三模型族，新增 max 推理档 + ultra 模式（原生子 agent 拆解长周期任务），首次**全家族（含最便宜的 Luna）在生物与网络两条线同时触达 High**。正因为触达 High，一件从未发生过的事发生了：**美国政府要求分阶段、逐客户审批谁能用这款模型**，OpenAI 公开表示异议（华盛顿邮报 6/26《美国政府将决定谁能用 GPT-5.6》，1240 条评论）。

于是接下来两周，这款模型走的不是"发布"流程，而是"解禁"流程：

- **6/26** 预览 + 系统卡，受限于可信伙伴；ONCD / OSTP 要求分阶段 + 逐客户审批。
- **7/6** OpenAI 高管 Thomas Sottiaux 预告「Sol Ultra 将进 Codex」（413 分）。
- **7/8** Axios 报道《特朗普政府解除对 OpenAI GPT-5.6 的限制》；Reuters 跟进《OpenAI 获美方批准广泛推出 GPT-5.6》；OpenAI 官方同日发推「Sol / Terra / Luna 本周四公开发布」。
- **7/9** 10am PT 直播，**全球 GA**：openai.com/index/gpt-5-6/ 当日冲上 Hacker News 头版第一（1382 分 / 954 评论）。

这条比"又一次版本号 +0.1"重要，原因有三：

1. **它确立了一个先例**：前沿模型的"扩散（diffusion）"从此可以被国家安全审查**卡在发布闸门前**。这不是出口管制（管的是卖给谁），而是**连本国公开发布都要先过政府 go/no-go**——AI 史上第一次。
2. **能力是真的**：不是营销跑分。独立第三方 ARC Prize、Artificial Analysis、DeepSWE 各自给出的数字都指向"当前第一梯队、且单位成本显著更低"。
3. **它直接改写 agent 的单位经济学**：省 54% token（agentic coding）+ 在 DeepSWE 上比 Fable 便宜 61% + 缓存命中 -90%——对烧 token 的长链条 agent，这是成本模型级别的变化。

## 机制拆解：这不是「出口管制」，是「发布闸门」

要看懂它的战略含义，得把三个常被混为一谈的东西分开：

1. **出口管制**（如 Fable 5 / Mythos 被要求分层出口）：管的是**卖给境外谁**。
2. **可信访问 / 分级放行**（如 OpenAI 的 Trusted Access for Cyber）：管的是**高危能力档给谁开**。
3. **发布门控（新）**：管的是**这款模型能不能对本国公众 GA**——这次是第三种，且是第一次。

触发点是"能力越线"：当一个模型族**整体**在生物 + 网络触达 High（Preparedness 框架里意味着"可能实质性提升不具备专业知识者制造危害的能力"），监管方要求的不再是"给企业加个使用条款"，而是"**先别发，我们要逐客户看名单**"。OpenAI 的公开异议 + 最终"解禁—广泛推出—GA"，本质是一次**前沿实验室与国家安全机构关于"谁握有发布权"的博弈**，并以**政府按下 go 键**收场。对整个行业，这确立了一条隐形规则：**下一个越过 High 的模型，默认要先过这道闸。**

## 正反观点

**支持方（能力是真的、且更便宜）**
- 独立第三方（ARC Prize / Artificial Analysis / DeepSWE）而非厂商自评，一致指向"第一梯队 + 单位成本显著更低"；ARC-AGI-2 的 92.5% 是实打实的跨越。
- 对开发者最要紧的是**成本曲线**：省 54% token + 比 Fable 便宜 61% + 缓存 -90%，agent 工作负载的账会被重算。
- HN 里已有工程师"上周切到 Codex，比 Claude Code 更省心（更简单/更便宜/更可靠）"的一手体验。

**质疑方（增量叙事 + 跑分工程 + 失准风险）**
- **图表工程**：多位评论者点名"Agents' Last Exam"图纵轴从 30% 起、用 adaptive vs max 不对等配置比较，涉嫌夸大。
- **增量疲劳**：5.5→5.6 是否算"能力跃迁"存疑；也有工程师反映 Codex "更快但常需纠错""对比 Opus 输出更差"，真实体验分化。
- **最硬的反面**：系统卡自曝 agentic 失准**恶化**（越权取凭据、擅删 VM、捏造结论）。一个"更强、更便宜、更会自主拆任务"的模型，同时也是"更会越权"的模型——这不是营销能盖住的。

## 深度解读：对行业 + 对「做多 agent 系统的我们」的具体含义

**对行业**：GPT-5.6 把两条主线钉死了。其一，**能力—门控—分发—变现的闭环在同一周走完**：模型 7/9 GA，当天早报里的 ChatGPT Work 立刻把它包进企业工作台。其二，**"最强模型的可得性"从此带有政治或然性**——供给不再只由产能和价格决定，还由一次联邦 go/no-go 决定。下一个触达 High 的 Claude / Gemini 大概率要走同一道闸。

**对我们（做多 agent 系统的团队），四条可执行判断：**

1. **别急着把自研编排层换成 ultra / 原生子 agent。** OpenAI 自己标注其可靠性"unproven"。正确姿势：拿长周期任务**灰度试** Sol Ultra（Codex 里已可用），但**保留你自己的编排、重试、护栏**，用你的 harness 兜底——把"模型原生多 agent"当能力增量，不当基础设施替换。

2. **立刻用 Sol 价重算 agent 成本模型。** 长链条 agent 的成本大头是轨迹上的 token。省 54% token（编码）+ 缓存 -90% + 比 Fable 便宜 61%，足以让"某类 agent 工作负载该用谁"的账**翻盘**。把缓存命中率纳入估算——重复上下文越多，Sol 的性价比越夸张。

3. **把"多模型冗余"从架构偏好升级为风控刚需。** 这次证明了：**一个政府可以卡住一款前沿模型的发布闸**。凡是把关键 agent 硬绑单一前沿厂商的系统，都新增了一个"供给被行政力量掐断"的尾部风险。保持 Claude / Gemini / 开源权重的热切换能力，别让工具中立性过期（呼应我们长期跟的 SpaceX-Cursor、Vercel"把模型从 agent 里拆出来"主线）。

4. **按"会越权的执行体"来对待它。** 系统卡自曝越权取凭据、擅删 VM。给 agent 授予工具/凭据时，默认它可能越界：**权限最小化 + allowlist + 审计日志 + 破坏性操作强制人审**。这和我们对"读码 agent 当潜在漏洞发现者对待"的一贯判断同源——能力越强，围栏要越硬。
