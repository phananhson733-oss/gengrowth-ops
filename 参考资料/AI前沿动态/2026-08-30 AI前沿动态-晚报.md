# 深度研究 · 48 小时，两个开源旗舰——「开源追平闭源」从论点变成可下载的事实

**一句话定性**：被 SemiAnalysis 点名「已能做 Anthropic $650 亿 ARR 里相当部分编码/agentic 工作」的 GLM-5.3，经两周网络安全风险评审后于 8/28 晚（UTC）开放权重；几乎同一时间腾讯把 770B 的 Hy4 preview 以 Apache 2.0 开源——而同一周闭源阵营在涨价、收紧限额、断供。开源与闭源的价差和能力差，第一次同时摆上了台面。

**来源**：
- 🔗 主条目（GLM-5.3 权重）：https://huggingface.co/zai-org/GLM-5.3 （2026-08-28/29；Z.ai 官宣 X status/2093354097122455713；HN 795 分/276 评论）
- 🔗 副条目（Hy4 preview）：https://github.com/Tencent-Hunyuan/Hy4-preview （2026-08-28；HN 340 分/203 评论，8/30 仍在头版）
- 🔗 分析骨架：SemiAnalysis《Are Open Models Catching Up?》 https://newsletter.semianalysis.com/p/are-open-models-catching-up （2026-08-22）

## 为什么值得深读 / 背景

8/14，智谱（Z.ai）发布 GLM-5.3 API：**base 与 GLM-5.2 完全相同，改进全部来自 post-training**（官方原话「Scaling post-training is all we did for GLM-5.3」），自家 Code Bench 提升 50%，并在 CyberGym 漏洞发现基准上拿到 **84.5%——略高于 Claude Mythos 5 的 83.8% 和 GPT-5.6 Sol 的 83.6%**。这是开源阵营模型第一次在网络安全基准上压过美国最强闭源模型。

正因为「网络安全能力超出了训练设计目标」（Z.ai 自述），Z.ai 做了一件此前只有美国实验室做的事：**以网络安全为由推迟权重发布两周**，先向安全伙伴开放（配套 OpenVuln Scanner），承诺 8/28 全量放出。这是中国实验室第一次明确以 cyber 风险为由的 staged release，评审被 Z.ai 称为其「史上最严格的一次」。

8/28 晚（UTC），权重如约落地 Hugging Face。同日，腾讯混元开源 Hy4 preview。48 小时内，两个旗舰级开源权重落地——SemiAnalysis 一周前的论点（见下）从预测变成了事实。

## 核心事实

**GLM-5.3（Z.ai，权重 8/28-29 落地）**
- 约 753B 参数；base 同 GLM-5.2，纯 post-training 升级；`reasoning_effort` 参数分 low/high/max 三档（默认 max）
- 自称开源 SOTA：Terminal Bench 3.0、Agents' Last Exam；CyberGym 84.5%（超 Mythos 5 / GPT-5.6 Sol）
- Z.ai 自报该模型已在 269 个开源项目中发现 **2,436 个漏洞**（107 critical + 990 high）；但独立核查（Kingy AI）指出：**仅 53 条（2.2%）公开可查，超过九成无法独立验证**，且严重度口径前后不一致、部分上游致谢记的是 GLM-5.1
- HN 社区实测口碑：「比 Kimi（K3）略弱，但好跑得多」；「对 cyber 没那么敏感——Claude 拒绝的 exploit 运行、逆向、反编译，它照做」
- 许可证注意：模型卡显示为自定义 GLM-5.3 许可证的读数与社区讨论并存（GLM-5.3-Flash 此前用 MIT），**商用前必须核仓库 LICENSE 原文**

**Hy4 preview（腾讯混元，8/28 开源）**
- **770B 总参数 / 49B 激活** MoE（78 层，256 路由专家 + 1 共享专家，token 激活 top-8）；原生 MTP 投机解码层；Gated DeepSeek Sparse Attention + IndexCache
- **上下文 1M tokens**；许可证 **Apache 2.0**（无自定义限制，这在旗舰级权重里罕见）；HF/ModelScope 可下，另有 FP8 量化版
- 腾讯内部盲评（163 位专家 × 203 个工程任务）：Hy4 preview 2.99/4.00，略高于 GLM-5.3 的 2.92 和 Kimi K3 的 2.94——差距基本是噪声，但「三个中国模型在同一档」本身就是信息
- OpenRouter 定价：**输入 $0.834/M、输出 $2.501/M、缓存输入 $0.042/M**——输入价比 GLM-5.3 低约 40%，输出价比 Kimi K3 低约 6 倍；DeepSeek V4 Pro 仍更便宜（约 $0.44/$0.87）
- 已知短板（腾讯自认）：P50 吞吐仅 36 tok/s；「过度自查」倾向——两者叠加会显著拖慢 agent 循环

**时代节奏（SemiAnalysis，8/22）**
- LLM 三个时代，开源追平「该代第一个闭源模型」的耗时逐代减半：早期 scaling 约 **18 个月** → reasoning 约 **8.5 个月**（o1-preview → R1-0528）→ agentic 约 **4.8-6 个月**（Kimi K2.6 超 Opus 4.5 用了 4.8 个月；GLM-5.2 超 GPT-5.2 用了 6 个月）
- 前沿实验室发布间隔从 213 天 → 120 天 → **51 天**
- 关键判断原文：GLM 5.3 / Kimi K3 「genuinely capable of many of the same coding and agentic tasks that rocketed Anthropic to $65B+ ARR」

**同一周，闭源侧在做什么（对照组）**
- Anthropic 8/30 宣布：9/14 起 Claude Code 周限额「永久 +25%」——但 8/31 到期的 +50% 促销（5/13 起三次延期）结束后，**相对现状实际是收紧 17%**（BleepingComputer 直接以此为标题），官方口径是产能压力
- OpenAI 8/25 起对 ChatGPT Plus 恢复 Codex/Work 的 5 小时用量上限
- Nvidia 通知大客户：AI 服务器 2027 年起涨价 15%+；OpenAI 8/28 断供 Cursor（见 8/30 早报）

## 机制拆解：为什么追得上，以及这次为什么不同

Interconnects（Nathan Lambert，8/14）给出六个结构性因素，并明确否定流行的「蒸馏论」：①**发布速度**——中国实验室从训完到公开只要几天，美国实验室要几个月安全测试，等 Anthropic 发布时对手又爬了一轮 benchmark；②对公开 benchmark 的刻意优先（融资压力 + 对标美国的战略价值）；③分数没有「炸炉」，是真实的；④**窄化专注**——只打 agentic coding 这一个高价值场景，post-training 复杂度远低于全能型模型；⑤美国数据公司正把 RL 环境卖给中国实验室；⑥组织效率 + 清华人才池。

这次与以往「开源追平」新闻的本质区别有两点。**第一，追平的位置变了**：不是 MMLU，而是 agentic coding——闭源阵营现金流最厚的腹地。**第二，安全闸门被完整测试了一遍**：Z.ai 模仿美国实验室做了 staged release（两周评审、安全伙伴先行），但权重放出后几天内，Hugging Face 上就出现了社区制作的 abliterated 改版（`penclaw-GLM-5.3-abliterated-for-offensive-cyber`），把拒答约束直接剥掉。「接口闸门」（Anthropic 把 Mythos 5 锁在 Claude Security 白名单后面的那套模式）在开源世界被证明**只有仪式意义**：一旦权重出门，单个公司的 safeguard 就失效了——这正是 Lambert 的结论：「We need industrial-scale guidance led by the government or industry coalitions」。

## 关键引述

- Z.ai 官宣：「GLM-5.3 is now open-weight. Our most capable model for agentic coding and cyber defense is now available to download, run, and customize.」
- Greg Brockman（OpenAI 总裁，经 The New Stack）：GLM-5.3 这类开源权重模型可能会「**significantly accelerate the threat landscape**」
- SemiAnalysis 自己的诚实注脚：尽管 Kimi K3 benchmark 更高，「我们自己还是更愿意用 Fable 5」——benchmark ≠ 真实体验
- HN 高赞：本地权重的意义在于「不会被公司政策变化下架（sunset）」——对照本周 OpenAI 断供 Cursor、DALL·E GPT 8/30 退役

## 正反观点

**支持方（开源已实质追平，且是理性选择）**：SemiAnalysis 的减半规律有三代数据支撑；agentic coding 场景下开源价格是闭源的 1/5-1/10；本周闭源侧限额收紧 + 涨价 + 断供，供给端不确定性本身就在为开源做广告；Apache 2.0 的 Hy4 没有任何商用附加条件；自托管彻底免疫「A/B 降 effort」「促销到期」「合同终止」这类对手方风险。

**质疑方（追平被高估，代价被低估）**：①安全——Brockman 的「威胁面加速」不是空话，abliterated 改版几天内出现是实证；美国监管框架（8/1 自愿框架）管辖不到中国权重，且开源权重不可召回；②能力——SemiAnalysis 自己承认 benchmark 可以靠「造一堆贴着 benchmark 的 RL 环境」爬出来（hill-climbing），真实偏好仍是 Fable 5；Hy4 的 36 tok/s 和过度自查在 agent 循环里会把纸面便宜吃回去；③数据可信度——GLM-5.3 的 2,436 漏洞账本九成不可验证，宣传口径与 dashboard 数字对不上；④经济性——HN 算账：$6,000 本地整机对云 API 约 3 年回本，自托管的真实卖点是隐私与控制权，不是省钱。

## 深度解读：对行业 + 对我们

**对行业**：
1. **「开源追平」的性质变了**——从刷分变成抢现金流。agentic coding 是把 Anthropic 推到 $650 亿 ARR 的业务；当同类能力以 1/5-1/10 价格开放下载，闭源同周的三个动作（限额实际收紧 17%、Nvidia 涨价传导、垂直行业收编）就能读通了：闭源的护城河正在从「模型能力」退守到「产品整合 + 产能 + 企业合规」。
2. **安全叙事将两极化**。这次事件同时给两边递了弹药：闭源实验室会拿 abliterated 改版论证「最强能力不能开源」（Mythos 白名单模式合理化）；治理派会拿它论证单公司自律无效、需要行业级机制。OpenAI 8/22 呼吁加强 SB 53（「防止前沿模型绕过内部安全控制」）与 Brockman 本次表态同一脉络——预期开源权重会被更明确地拉进监管讨论。
3. **中国阵营在内卷中集体上桌**：GLM-5.3、Hy4、Kimi K3 同档，且互相压价；同时 Nvidia 在洽购 Hugging Face（$130 亿报价）、资助 Poolside 做美国开源对标——开源生态的分发层与「美国队」都在重组，中立性本身成了稀缺品。

**对我们（做多 agent 系统的团队）**：
1. **路由层的落地动作**：把 GLM-5.3 与 Hy4 preview 纳入多模型路由候选，用我们自己的 agent 工作负载（长 harness、工具调用、MCP 场景）实测，不要信盲评。Hy4 的 1M 上下文 + $0.042/M 缓存输入对长会话 agent 是真实的成本杠杆；但 36 tok/s P50 + 过度自查意味着**延迟敏感路径先别动**，先测吞吐再谈省钱。
2. **断供保险有了具体标的**：接 8/30 早报 Cursor 断供的结论——依赖清单里的 `upstream_release_risk` 现在有对冲工具了。Apache 2.0 的 Hy4 是当前许可证最干净的旗舰级权重；GLM-5.3 商用前必须核仓库 LICENSE 原文再定。
3. **成本结构的财务判断**：闭源限额实际收紧 17%（9/14 生效）与开源输出价 6 倍差同时发生——「旗舰订阅打底 + 开源权重承接可外溢负载」的混合架构从可选项变成财务必选项。注意合规分叉：敏感数据不能走中国托管 API，自托管才是合规路径，而自托管约 3 年回本、需 8 卡级硬件——按负载算账，别为对冲而对冲。
4. **安全边界的假设作废**：社区已示范拒答约束可被整体剥离。如果我们的产品有任何安全性质依赖「模型自己会拒绝」，这个假设对开源权重不成立——安全必须做在 harness/沙箱/权限层。这与 MCP 路线图篇、FelonyBench 篇的结论第三次交叉验证。

## 接下来盯什么

- GLM-5.3 仓库 LICENSE 最终文本与商用条款；Hy4 正式版（非 preview）是否维持 Apache 2.0
- Kimi K3 是否跟进开放权重；DeepSeek V4 全量版动向
- OpenRouter 上 GLM-5.3 / Hy4 的流量份额变化——开源蚕食闭源的最直接读数
- Brockman 言论是否升级为 OpenAI 政策动作；白宫自愿框架是否把开源权重拉进 covered model 讨论
- 9/14 Claude Code 新限额落地后的用户迁移信号
- abliterated 改版是否引发 HF 平台侧治理动作（下架/门控），尤其在 Nvidia 洽购背景下
