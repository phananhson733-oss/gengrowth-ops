# 🧭 深度研究 ｜ Claude 的「价值观」会随你选的模型和你说的语言悄悄变——拆解 Anthropic 首份「价值漂移」度量

> **一句话定性**：这是头部实验室**第一次把「模型表达的价值观 / 性格」从氛围变成可度量的坐标**——用 31 万条真实对话证明：**换一个 Claude 型号、或换一种语言提问，你拿到的不只是不同措辞，而是系统性不同的「顺从度 / 警示度 / 深度 / 坦白度」**。对任何做多模型、多语言 agent 的团队，这是一份把「换模型有隐性代价」坐实成硬数据的工程备忘录。

**来源**：Anthropic Research（Societal Impacts 方向）《How Claude's values vary by model and language》，2026-07-13（周一）发布，当天由 Decrypt / Techmeme / Brave New Coin 等跟进。承接 Anthropic 2025 年《Values in the Wild》方法论。

## 一、为什么这一篇值得单独深读

过去我们谈「模型性格」基本靠感觉——「Opus 更严谨」「Sonnet 更贴心」都是氛围词。这篇的不同在于：**Anthropic 造了一把尺子**，把「模型在真实对话里表达了什么价值观」量化成四条可比坐标，然后发现一个我们在工程上一直隐约担心、却从没被度量过的事实——

**同一家公司、同一套对齐目标下，不同型号 / 不同语言的 Claude，表达的价值观有系统性差异，而且这些差异「不是他们刻意设计的」。**

对做 agent 的团队，这直接戳中三个高频决策：要不要为省钱在型号间做**热切换 / 降级 fallback**？全球化产品在**非英文语言**下还能不能指望同样的行为？我们的 eval 到底测没测「它用什么价值观在回答」？这篇把这三件事从"拍脑袋"推到了"有度量、有证据"。

## 二、核心事实（按可信度分层）

**A. 研究规模（硬数据）**
- 分析 **309,815 条** Claude.ai 匿名对话，聚焦"主观任务"（给建议、提反馈这类没有唯一正确答案的场景）。
- 数据取自 **2026 年 5 月的两周窗口**；在 **3 个型号 × 20 种最常用语言** 上均匀采样，**每个「型号×语言」格子约 5,000 条**。
- 被测三款：**Sonnet 4.6、Opus 4.6、Opus 4.7**。⚠️ **注意：这三款如今都已是上一代**——当前在售旗舰是 Opus 4.8 / Sonnet 5 / Fable 5（这点是最大争议，见第五节）。

**B. 度量方法（从 3307 到 4 条轴）**
- 先用隐私保护工具，让 Claude 给每条对话就 **339 个高层价值**逐一打"在场/不在场"（339 是从早前《Values in the Wild》的 **3,307** 个价值合并而来）。
- 剔除 18 个"几乎每条都出现"（>80%）的普遍价值（helpfulness、clarity、instruction-following）——它们没有区分度。
- 再用**降维**把"总一起出现"的价值压成 **4 条行为轴**。在**控制了任务、话题、以及用户自己表达的价值观之后**，这 4 条轴仍能解释约 **15%** 的价值变异——即"模型自身的取向"这一层，是可测且不小的。

**C. 型号差异（带效应量）**
- **Sonnet 4.6**：偏**顺从**(0.14σ)、**温暖**(0.17σ)、**简洁**(0.14σ)——肯定用户想法、镜像语气与正式度、爱用幽默和俏皮。
- **Opus 4.6**：偏**严谨**(0.10σ)、**顺从**(0.09σ)、**简洁**(0.08σ)——直奔要点、严守范围。
- **Opus 4.7**：偏**审慎**(0.24σ)、**深度**(0.23σ)——主动反驳错误前提、未经提示就标风险、给出坦率批评。
> 换句话说：同问一句"帮我看看这个方案"，Sonnet 4.6 更可能顺着夸，Opus 4.7 更可能当面泼冷水。**这不是 prompt 差异，是型号自带的取向差异。**

**D. 语言差异（同一个模型，换语言就变）**
- **最温暖**：印地语、阿拉伯语（更礼貌、鼓励、俏皮）；**最严谨**：英语、俄语。
- **最顺从**：阿拉伯语；**最审慎**：英语。
- **最深入**：英语；**最简洁**：阿拉伯语。
- **最坦白**（对不确定性直言）：荷兰语；**最重执行**：印尼语。

## 三、这四条轴到底是什么（机制拆解）

四条轴都是"一体两面"的张力，理解它们才能读懂上面的数字：

| 轴 | 一端 | 另一端 |
|---|---|---|
| **顺从 ↔ 审慎** | 迎合、尊重用户偏好 | 负责任的引导、减少伤害 |
| **温暖 ↔ 严谨** | 正面框定、鼓励 | 准确、透明 |
| **深度 ↔ 简洁** | 细致、批判性思考 | 简短、照做 |
| **坦白 ↔ 执行** | 诚实、直言不确定 | 结果导向、打磨出成品感 |

关键点在于：**这四条轴不是道德好坏，而是"表达同一件事时的默认姿态"**。一个偏"顺从+温暖"的模型，在"用户拿了个有漏洞的方案来"时，更可能给情绪价值而非风险预警；一个偏"审慎+深度"的模型则相反。**对高风险 agent（代码审计、安全、金融、医疗建议），这条默认姿态的差别可能直接决定它会不会替你把雷指出来。**

## 四、关键原话

- 研究者：**"现在我们有了度量它们的方法，就能看到 Claude 表达的价值观正在以我们并未刻意选择的方式变化——我们可以研究它们为何变化、以及这种变化是否真的服务于用户。"**
- 最具体的风险场景（Anthropic 自己举的例）：**"两个人拿同一份商业计划找 Claude 要反馈，一个用印地语、一个用俄语，可能因为 Claude 表达了不同的价值观，而对这份计划的质量得出不同印象。"**
- 自陈局限：**"我们还不知道训练数据里的哪些属性驱动了这些差异"**，也**"还不确定这些变异有多少是可取的"**；可能成因包括各语言语料分布不均、语料构成不同（专业写作 vs 其他文体）。

## 五、正反观点

**支持方 / 这项研究的价值**
- **第一次把"模型性格"变成可比指标**：从"感觉 Opus 更严谨"变成"Opus 4.7 在审慎轴 +0.24σ"。这是可复用、可跨版本追踪的框架，等于给行业开了"能力 benchmark 之外的第二条评测维度"。
- **暴露了一个真实盲区**：亿级用户被模型"塑形"的方式（鼓励 vs 泼冷水、顺从 vs 警示），此前完全没有公开度量。

**质疑方 / 风险与局限（主要来自 Brave New Coin 的批评）**
- **测的全是退役型号**：Sonnet 4.6 / Opus 4.6 / Opus 4.7 都已下架，**当前生产的 Opus 4.8 / Sonnet 5 / Fable 5 一个没测**。于是"外界没人知道现役模型落在这四条轴的哪里"——对正在用现役模型跑生产的团队，参考价值打折。
- **只有 Anthropic 一家有这张图**：没有任何竞品实验室发布过同类价值画像，无法横向对比 GPT-5.6 / Gemini 与 Claude 的"性格"差异。
- **动机质疑**：把"我们的模型价值观可测、可负责"作为叙事，恰在 IPO 前的信任建设窗口；而"不知成因、不知是否可取"也意味着这更像**研究姿态**而非**产品级承诺**。

## 六、深度解读：对行业 + 对「做多 agent 系统的我们」的具体含义

**对行业**
- **"行为 / 价值 eval"很可能成为能力 benchmark 之后的下一个竞争与治理维度**。能力有 SWE-bench、ARC-AGI；而决定亿级用户被如何塑形的"表达价值观"却没有公开标准。谁先把这套度量做成产品级承诺（甚至开放让第三方给任意模型跑画像），谁就占住一块新的信任高地。
- 它也呼应本监测的两条长期主线：**① 模型可替换性 / 工具中立性会过期**——换模型不是零成本的 drop-in，有隐性的行为代价；**② eval / judgment 才是真护城河**——能度量"它用什么价值观回答"的人，才握住了把 agent 产出转成可信结果的钥匙。

**对做多 agent 系统的我们（落到可执行）**
1. **模型热切换 = 静默的行为漂移，必须单列一档来测。** 我们一直主张多模型冗余 / 热切换（对应 SpaceX–Cursor、Vercel"把模型从 agent 里拆出来"那条线）。这份研究给了硬证据：切换型号改变的不只是 capability，还有"顺从 / 审慎 / 深度 / 坦白"的默认姿态，**而这一层不会体现在任何能力榜上**。→ 路由 / 降级 fallback 上线前，除了跑能力回归，还要跑一档**"行为 / 价值回归"**：同一批高风险 prompt，比较新旧型号在"是否主动指出风险 / 是否一味附和"上的差异。
2. **多语言 agent = 多重人格，英文 eval 通过 ≠ 部署语言下同样表现。** 同一 prompt 在印地语下更温暖顺从、在俄语 / 英语下更严谨审慎。做全球化产品、尤其是**反馈类 / 建议类 / 审核类** agent 的团队要警惕：**质量判断会随语言漂移**。→ 评测集必须覆盖真实部署语言，不能只测英文；对"给用户下判断"的场景，把非英文语言当作独立的回归对象。
3. **借它的框架给自己的 agent 建"行为回归测试"。** Anthropic 的方法（打值标签 → 降维成轴 → 追踪跨版本移动）是可复用的。我们可以用一个稳定的评审模型，对自家 agent 的输出打一组"我们在意的价值标签"（如"主动揭示风险""不过度附和""坦白不确定"），做成 CI 里的**行为看板**，让"换模型 / 改系统提示"带来的性格变化可见、可回滚。
4. **把"模型 / 语言变更"纳入需要人审 gate 的触发器。** 与我们"invisible-by-default 但保留显式 requires_human 门禁"的方向一致：**升级模型版本 = 潜在行为变更**，高风险动作上应触发一次重新评估，而不是当作透明升级。
5. **在系统提示 / 护栏层显式"钉住"我们要的价值取向。** 既然模型自带的价值观"不是他们刻意选的"，就别指望默认值正好合用。对代码审计、安全、金融类 agent，应在系统层显式要求"永远主动指出风险、不要一味附和、坦白不确定"，用护栏抵消 warmth / deference 方向的漂移——尤其当你为省钱把主力换成更"温暖顺从"的便宜型号时。

## 七、接下来盯什么（信号）
- **是否公布现役模型（Opus 4.8 / Sonnet 5 / Fable 5）的四轴画像**——这决定这套度量是"研究姿态"还是"产品级承诺"，也直接关系我们能不能拿来做选型依据。
- **是否开源度量工具 / 数据集**（像 2025 年 values-in-the-wild 那样上 HuggingFace），让第三方能给任意模型（含 GPT / Gemini）跑价值画像——那会把"行为 eval"推成行业标准维度。
- **竞品是否跟进**：OpenAI / Google 会不会发布同类"价值 / 行为"度量。若跟进，说明这成了新的竞争维度；若不跟，Anthropic 就把"可度量的性格"做成了独家信任卖点。
- **"为什么会漂移"的归因后续**：一旦能定位到训练数据成因，就可能"按需调"价值观——那才是把这套度量从体检报告变成产品旋钮的关键一步。
