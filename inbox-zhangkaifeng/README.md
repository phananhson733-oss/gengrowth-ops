## 文件管理规则

1. 新资料先进入 `00-inbox`，确认用途后再归类。
2. 日期型记录使用 `YYYY-MM-DD-主题-用途.md`。
3. 草稿和个人记录不视为已同步的正式公司文档。
4. 账号目录只保存必要的账号标识、负责人和资产说明，不保存密码、令牌、验证码或恢复信息。
5. 可重新生成的缓存、模型输出和媒体文件不提交到 Git；只保留必要的来源、参数和说明。
6. 已完成或不再使用的内容应保留可追溯记录，不直接覆盖或删除历史证据。
