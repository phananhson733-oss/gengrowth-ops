# GenGrowth 账号与视频工作台（张凯风）

这里是张凯风的个人工作区，主要用于账号管理和视频剪辑。工作区保留账号状态、素材来源、剪辑进度、审核版本、发布链接与复盘记录，但不保存账号密码、令牌、验证码或其他登录凭据。

## 目录索引

| 目录 | 用途 |
| --- | --- |
| `00-inbox` | 临时输入、会议记录、待分类链接和新收到的任务。 |
| `01-账号管理` | 账号台账、平台状态、负责人、权限申请和日常运营记录。 |
| `02-视频剪辑` | 剪辑任务、项目说明、版本记录、审核反馈和交付记录。 |
| `03-素材与参考` | 素材来源、授权说明、脚本、字幕、音乐和视觉参考。 |
| `04-发布记录` | 已排期或已发布内容的账号、平台、时间、真实链接和状态。 |
| `05-数据与复盘` | 视频表现、账号数据、阶段复盘和下一步结论。 |
| `06-requirements` | 需要同事评估、开发或协作推进的需求草稿。 |
| `output` | 本地工具生成的临时输出；默认不提交生成数据。 |
| `skills` | 仅存放张凯风工作区内的个人 Skill。 |
| `tools` | 视频与账号工作所用工具的说明、脚本和配置模板。 |
| `报销` | 报销凭证投递区。 |

## 默认工作流

### 账号管理

1. 在 `01-账号管理` 记录平台、账号标识、用途、负责人、当前状态和最近检查日期。
2. 账号权限变更只记录申请和结果，不记录密码、令牌、验证码、Cookie、恢复信息或设备/IP 明细。
3. 内容排期或发布后，在 `04-发布记录` 补充真实发布时间、发布链接和异常情况。
4. 定期在 `05-数据与复盘` 记录数据来源、观察窗口、结论和下一步动作。

### 视频剪辑

1. 新任务先在 `00-inbox` 记录账号、平台、目标、素材入口、交付规格、截止时间和审核人。
2. 开始剪辑后移入 `02-视频剪辑`，记录当前版本、修改意见和交付状态。
3. 素材版权、音乐来源、字幕依据和视觉参考放在 `03-素材与参考`；来源不明时明确标记待确认。
4. 大体积原始素材和视频成片使用约定的共享存储，不直接提交到 Git；仓库只保留链接、版本说明、必要配置和可追溯记录。
5. 审核通过后记录最终版本和交付位置；实际发布后再写入 `04-发布记录`，不得把“已导出”当作“已发布”。

## 文件管理规则

1. 日期型记录使用 `YYYY-MM-DD-账号或项目-用途.md`。
2. 视频版本使用连续版本号，例如 `v01`、`v02`；不得用“最终版”“最终版2”代替版本记录。
3. 草稿和个人记录不视为已同步的正式公司文档。
4. 账号状态、剪辑完成、审核通过和实际发布是不同状态，分别保留证据。
5. 已完成或不再使用的内容应保留可追溯记录，不直接覆盖或删除历史证据。
