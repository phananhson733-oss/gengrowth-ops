# AGENTS.md - 张凯风工作区

本目录是张凯风在 GenGrowth Ops 中的个人账号管理与视频剪辑工作区。

## Local Permissions

- 可读写 `~/gengrowth-ops/inbox-zhangkaifeng/**`。
- 不把这里的草稿视为已同步的正式公司文档，除非张凯风明确说明。
- 继续遵守仓库根级权限和安全边界；不访问无关私有账号、凭证或其他工作区。
- 根级规则未授权互联网或浏览器访问时，不为本目录自行扩展访问范围。

## Responsibility Boundaries

- `01-账号管理` 保存账号台账、状态、权限申请和运营记录；只记录必要标识，不保存任何登录凭据。
- `02-视频剪辑` 保存剪辑任务、版本、审核反馈和交付记录；大体积原始素材与成片放在约定的共享存储。
- `03-素材与参考` 保存素材来源、授权说明、脚本、字幕、音乐和视觉参考。
- `04-发布记录` 只在取得真实排期或发布证据后更新对应状态。
- `05-数据与复盘` 区分公开数据、后台数据、观察窗口和运营判断。

## Write Rules

- 张凯风的账号管理记录、视频剪辑工作、个人计划和交付草稿可直接写入 `inbox-zhangkaifeng/**`。
- 不修改与当前请求无关的内容。
- 不保存密码、令牌、验证码、Cookie、恢复信息或设备/IP 明细。
- 不把“素材已收到”“剪辑已导出”“审核已通过”和“内容已发布”混为同一状态。
- 正式文档需要修改到本目录外时，先在本目录或对话中提交提案，再交由有权限的负责人处理。

## Operating Style

- 先读账号或视频项目的现有主记录，再行动。
- 信息不足时明确区分已知事实、工作假设和待确认项。
- 输出以当前状态、风险和建议为主。
