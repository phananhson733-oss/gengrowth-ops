# 配图 Prompt

## 1. 封面图

```
微信公众号封面图，2.35:1比例，无任何文字。
延续GenGrowth成长笔记统一视觉风格（深石墨灰背景，高级手绘战略图风格，米白线条为主）。
构图：左侧一个僵硬的大块（占30%）→ 中央边界松动、解体成发光节点（占40%）→ 右侧一张成型的专业节点网络（占30%）。
左侧画面：手绘风格的一整块"大而全的组织"——密集堆叠、棱角僵硬的矩形群，像一座科层金字塔或一整面砖墙，线条厚重、内部拥挤没有缝隙，表达"固定科层、大而全的公司"。块体右缘开始出现细小裂缝。
中央焦点：那个大块向右解体——边缘的矩形脱落、变薄，化成一个个独立的圆形发光节点；多条米白细线从这些节点汇聚，向中心一个圆形漩涡收拢，漩涡内核是琥珀金/暖白发光效果，象征"一群独立专业个体围绕一个共同结果点亮协作"的瞬间，光晕清晰，在深色背景上形成强视觉焦点。
右侧输出：一张已经成型的网络——五六个大小相近、地位平等的独立圆形节点，用清晰的米白连线互相插接成网状（不是自上而下的树状层级），每个节点内嵌一个不同的手绘专业图标（一条上扬的增长曲线、一个放大镜、一个齿轮、一支画笔、一个终端光标），暗示各有各的专业；节点之间留有充足间距，连线干净利落。
配色：背景始终深石墨灰；不同节点边框和图标用低饱和青蓝、淡青绿、橙黄、米白各自区分；中心汇聚焦点用琥珀金/暖白。
整体无任何文字，不写任何字符。
整体传达：一个大而全的组织，边界变薄、松动，散成一张由独立专业节点围绕共同结果插接而成的网。
```

**用途**：文章封面
**尺寸**：2560×1088

主题：组织形态从"科层大块"到"专业节点网络"的转变。

左半：一座手绘的科层金字塔/实心大块，内部是密集的小格子和自上而下的层级连线，线条厚重拥挤，暗示"大而全、层层汇报"。
右半：五六个大小相近的独立圆形节点，用清晰连线互相插接成网状（去中心、无层级），每个节点内一个不同的专业图标（增长曲线、放大镜、齿轮、画笔），其中几个节点的连线汇聚到一个琥珀金/暖白的小发光点，象征"围绕一个共同结果组网"。
