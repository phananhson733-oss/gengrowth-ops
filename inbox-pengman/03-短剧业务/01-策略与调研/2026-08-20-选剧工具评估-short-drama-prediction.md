# 选剧工具评估：short-drama-prediction（数据选剧台）

> 评估对象：https://short-drama-prediction-milo.vercel.app/
> 评估时间：2026-08-20（工具数据日 2026-08-19，快照日 2026-08-19，最后同步 2026-08-20 17:42 北京时间）
> 方法：webfetch + 浏览器实际操作读取数据、核对内部口径一致性、抽样验算。

---

## 一、它是什么

一个 **ReelShort 短剧的数据选剧看板**（"短剧数据选剧台 V2.2"），核心是给每部剧算"介入分"排序，直接给推广动作（优先推 / 可推 / 观察 / 暂不推）。

```
介入分 = 收益效率 40% + 增量势能 25% + 剩余空间 20% + 商业密度 15%
收益代理效率 = 滚动 30 日平台销售额 ÷ 累计推广人数（宣称硬门槛 > US$80）
```

**覆盖**：30,506 条剧集记录，**仅 ReelShort 一家（source_id 4）**；多语言、多标签、14 天历史快照、每日更新。

**与 AitoEarn 的关系**：页面方法论文字与 docs.aitoearn.ai 的"数据选剧台"几乎逐字一致（介入分公式、US$80 门槛、S/A/B/C/D 分位、指标口径），**基本可判定为同源工具**（AitoEarn 系或某部署者；URL 中 "milo" 疑为个人/项目代号）。

---

## 二、做得如何（产品/技术层面）

**完成度高，是正经可用的产品：**

| 能力 | 说明 |
|---|---|
| 数据 | 每日快照、连续 14 天历史、"数据日+快照日"双日期清晰 |
| 筛选 | 评级 / 生命周期 / 语言 / 题材标签 / 动作 / 平台 |
| 排序 | 介入分 / 收益效率 / 增量 / 剩余空间 / 商业密度 / 销售额 / 推广人数 / 剧名 |
| 详情 | 单剧评分拆解（四模块各自权重与贡献）、趋势图（收益/效率/竞争）、历史快照表 |
| 操作 | 分页（15–200 条）、导出（当前页/全部筛选）、实时剧集资料拉取 |
| 透明 | 指标口径与"不能回答的问题"全部写明，明确"不能直接等同真实 ROI" |

**方法论透明度是优点**：它把自己算不出什么（缺佣金、缺归因订单、缺真实结算收入）直接写出来，不装。

## 三、可靠性问题（关键发现，都是实测）

### 3.1 🔴 "优先推"队列全部低于自己宣称的 US$80 硬门槛

实测"优先推"前 15 条收益代理效率：$19.27 / $12.93 / $18.69 / $18.55 / $13.54 / $15.21 / $12.12 / $11.95 / $7.21 / $17.27 / $14.44 / $18.69 / $5.94 / $9.29 / $14.08——**15/15 全部 < US$80**。

工具自己写"机器人准入以原始收益代理效率为准，要求严格大于 US$80"，但"优先推"队列明显没执行这条门槛。**要么门槛只对自动机器人生效（与手动看板无关），要么是逻辑 bug，UI 自相矛盾。**

### 3.2 🟠 "累计推广人数"疑似平台级估算，不是逐剧真实值

抽样可见：几乎所有新剧的推广人数都是 1,150 / 1,135 / 1,165 / 1,180，按 15–30 的固定步长增长、很多天为 0。**推广人数是"收益代理效率"和"剩余空间"的分母——分母是估算值，效率与空间就都不精确。**

### 3.3 🟠 数据源不可验证

"所有数据均来自平台公开快照"说不清具体来源。罗马尼亚语新剧"滚动 30 日收益 US$22,166"这个数无法对任何公开渠道核验。对决策类工具，**来源不可复核 = 只能当黑箱信号，不能当事实。**

### 3.4 🟠 结构性偏向小语种小市场

"优先推"前 15 条：罗马尼亚语 ×8、法语 ×2、日语 ×1、俄语 ×1、印尼语 ×2，**英文 0 条**。原因：小市场推广人数少 → 分母小 → 效率虚高、剩余空间虚大 → 介入分虚高。**对想投英语/主流市场的我们，这个队列的参考价值直接打折**，需要按自己的目标语言过滤再看。

### 3.5 🟡 数据缺口

大量条目"缺标签"，这些条目的"商业密度"贡献明显偏低（实测一例贡献仅 8.21/54.7）——缺标签会影响评分完整性。

## 四、参考价值结论

| 维度 | 评价 |
|---|---|
| 技术完成度 | ✅ 高（功能齐全、交互清晰、更新及时） |
| 方法论透明度 | ✅ 高（公式、口径、局限都写明） |
| 数据可靠性 | ⚠️ 中低（门槛矛盾 + 分母估算 + 来源不可验证 + 小语种偏置） |
| 作为"收益预测" | ❌ 不可用（它自己也声明不是 ROI 预测） |
| 作为"选剧雷达" | ✅ 可用（新剧上线节奏、生命周期阶段、增量趋势、题材起量信号有价值） |

**一句话**：**这是个完成度很高的"选剧雷达"，不是收益预测器。** 用它看"最近哪些新剧值得关注、处于什么生命周期、趋势在涨还是在跌"可以；信它的绝对收益数字（$X 滚动30日收益、US$XX 效率）不行。

**使用建议：**
1. **当 A/B 测试的输入之一，别当唯一依据**——最终判断用 dramafinds/ReelShort 后台自己的归因数据。
2. **重点看趋势/增量/生命周期**，别信绝对收益；优先推/评级只作关注排序。
3. **按目标市场语言过滤**（它默认排在前面的全是小语种小市场，别被带偏）。
4. 它只覆盖 ReelShort，**不含 DramaBox/ShortMax 等**；要跨平台对比另用 AitoEarn 的分成表/DataEye ADX 等。
5. 若它是 AitoEarn 系工具，注意 AitoEarn 结算可靠性本身待核实（见生态地图文档第七节）。
