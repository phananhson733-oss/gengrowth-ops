# My Black Python Wants My Eggs｜公开集剧情事件详解

本次阅读：本地第1—3集，约5分55秒。奇幻喜剧，靠第一人称旁白与画面推进。

## 人物和故事入口

Noah是爬行动物研究机构的饲养员，被安排照顾体型很大、看起来不好惹的黑蟒Avery。他以为黑蟒讨厌自己，试着用更友善的方式改善关系，却把对方的求偶反应不断看错。片尾出现与Avery关联的黑发男人，直接表达喜欢，并问他能否生育孩子。

这里的Noah与《Bound》主角同名，但属于不同故事。片名里的生育设想，尚未成为这三集已经发生的结果。

## 逐集事件与推进

### 第1集：饲养员想把工作做好，却觉得自己被针对

**1．一项看似普通的分工，建立不对等的相处。** 主管Harris把最凶的大黑蟒交给Noah，因为两者都是雄性，认为可以相处。Noah是来做饲养工作的；黑蟒的体型、行为和不可直接交流，让他无法判断对方想干什么。

**2．靠近被解释成威胁。** 黑蟒用尾巴碰他，吐信靠近他的脸，还追着他跑。Noah把这些动作理解成讨厌自己、想找自己麻烦。旁白却早早提示，这可能是在示好。观众因此能比主角先看懂一部分笑点。

**3．取名字也没改善关系。** Noah已经照顾它一个月，给它取名Avery，还想象过如果变成人会是怎样的帅哥。但命名那天仍被追着跑，令他觉得自己的好意得不到回应。这里的人形想象不是变身已经正式发生。

**4．他想去照顾别的蛇，也没有成功。** Avery不吃东西，Noah觉得不如去喂别的蛇；同事Ben却告诉他，其他蛇已被Avery吓得躲进角落。Noah没法轻松换一个工作对象，只能回来教训它不要闹。

**5．缠住人的动作出现另一种解释。** Avery绕住Noah，他一开始害怕自己会被吞掉，随后发现没有想象中那样勒紧，甚至像拥抱。他刚想到这种可能，又觉得自己单身太久、想多了。故事第一次让“它讨厌我”的解释出现松动，却没有让他真正接受另一种答案。

### 第2集：他主动示好，反而制造了更大的误会

**6．轻咬仍被当成针对。** Avery碰、轻咬他的脸，Noah觉得它继续找麻烦，决定换个方法：用爱感化。Ben对他的计划发笑，Noah则认真把工作困局当成可以用友善解决的问题。

**7．一个亲吻让黑蟒反应失常。** Noah亲了Avery的头，意在表达友好。Avery僵住、失去平衡，又躲到高处，画面和旁白把它的反应表现得像害羞。Noah却担心它厌恶自己，或出了健康问题。

**8．为保住工作，他找来兽医。** Noah害怕自己把负责的蛇弄坏了，催它下来，甚至用再亲一次来吓它。Avery作出反应后，检查终于进行。主角想修复相处，结果把事情推进到诊断，而非停留在又一次追逐。

**9．兽医给出求偶期的解释。** Dr. Carter检查后指出它正处于求偶阶段。Noah于是把“不愿吃饭、反应奇怪”理解成需要伴侣，产生了下一步解决办法。

### 第3集：他认真替它找伴侣，恰好把意思完全弄反

**10．两条雌蟒没有解决问题。** Noah向Harris报告，为Avery带来两条健康雌蟒。Avery却把它们赶到角落，又追着Noah跑。按Noah的理解，自己连对象都帮它找来了，它仍然刁难；按此前提示，问题恰恰在于它想找的对象是Noah。

**11．委屈使Noah第一次真正退出相处。** 他数落自己认真喂养、维持环境、整理住处的付出，问它为什么还不满意。解释越不通，他越觉得被辜负，最后眼眶发红，宣布不再理它，返回宿舍。

**12．人形出现，误会得到直接回答。** 夏夜空调坏了，Noah躺在床上，感到身边有凉意。黑发男人出现在他床边、靠近他，说自己没有讨厌他，而是非常喜欢他，并叫出Noah的名字，问他能否为自己生孩子。故事把Avery与人形的关联推到眼前，但没有展示完整连续的变身过程，也没有给出Noah的答复。三集在这个突变的问题上结束。

## 整条因果怎样接起来

被安排照顾黑蟒 → 把示好看成欺负 → 决定用亲吻表达友好 → 黑蟒害羞异常被看成生病 → 找兽医获知求偶期 → 带来雌蟒 → 黑蟒拒绝、再次追人 → Noah委屈离开 → 对方以人形直接表白，提出新的关系要求。

## 这一段已经讲到哪一步

“它是不是讨厌我”已有明确回答；“Noah是否接受它、人形身份意味着什么、两人如何相处”还没有结果。没有实际产卵、怀孕或建立正式关系的情节。整个公开段的乐趣主要来自主角认真解决一个被自己理解错的问题，越努力，越接近真正答案。
