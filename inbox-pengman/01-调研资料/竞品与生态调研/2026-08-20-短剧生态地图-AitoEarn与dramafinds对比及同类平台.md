# 短剧生态地图：AitoEarn 平台调研 + 与 dramafinds 的对比及同类平台

> 来源：AitoEarn 官方文档（docs.aitoearn.ai）与官网页面、dramafinds.com 各页面（/about /purchase /genre）、公开搜索摘要、此前 dramafinds 技术审计。
> 目的：说清 AitoEarn 是什么、能学什么，它和 dramafinds 的区别与关联，以及两个赛道各自的同类玩家，用于判断"该学谁、该和谁合作、该防谁"。

## 一、AitoEarn 是什么

**AiToEarn = 面向"一人公司（OPC）"和创作者的开源 AI 内容营销智能体平台**（GitHub 开源，文档标注 24,999 stars）。

一句话：**从内容创作→分发→互动→变现的全链路自动化平台**，核心模块：

| 模块 | 干什么 |
|---|---|
| Create | AI 生成视频/图文（内容创作） |
| Publish | 多平台一键分发（含定时发布） |
| Engage | 自动化互动运营（AI 互动） |
| Monetize | CPS/CPE/CPM 变现（淘金广场接任务） |

**覆盖平台**：国内（抖音、小红书、快手、B 站、视频号、微信公众号）+ 海外（TikTok、YouTube、Facebook、Instagram、Threads、Pinterest、LinkedIn、X）共 15+ 平台。

**核心产品 = 淘金广场（任务市场）**：广告主发推广任务（短剧、小说、平台推广、互动任务），创作者接任务发布内容赚分成/固定奖励。京ICP 备案（京ICP备19059131号-15），中方运营。

## 二、AitoEarn 短剧相关能力（对我们最有用的部分）

### 2.1 短剧任务中心 + 数据选剧台（最值得学）

它有一个**数据驱动的选剧看板**（数据选剧台 V2.2，数据日/快照日每日更新），给每部剧算"**介入分**"，用于选剧排序：

```
介入分 = 收益效率 40% + 增量势能 25% + 剩余空间 20% + 商业密度 15%
```

- 评级 S/A/B/C/D（S=前 5%，A=前 20%...）
- 分档动作：优先推（前 100）→ 可推 → 观察 → 暂不推
- 维度：生命周期（上线初期/增长窗口/成熟窗口/长尾）、语言、题材标签（爱情/霸总/复仇/狼人...）、滚动 30 日销售额、累计推广人数、竞争压力、剩余空间、风险标签
- 关键口径：**"收益代理效率 = 滚动 30 日销售额 ÷ 累计推广人数"，硬门槛 > US$80；声明"数据来自平台公开快照，不能直接等同真实 ROI，仅用于筛选测试资源"**——即它自己也承认这是选剧排序工具，不是 ROI 预测。

> 这正是我们此前调研里"如何选剧"缺的工具化答案：**别靠人工猜，用"销量÷推广人数"的效率 + 增量 + 竞争压力排序决定先推哪部。** 详见本文件第八节。

### 2.2 短剧 CPS 分成比例（公开明文，可作行业基准）

它的分成规则页公开了各短剧平台 CPS 比例（明确标注"仅用于理解口径，不构成结算承诺，以任务页为准"）：

| 平台 | CPS | 平台 | CPS |
|---|---|---|---|
| DramaBox | 60% | DreameShort | 70% |
| ShortMax | 60% | GoodShort | 65% |
| ReelShort | **45%** | StarShort / Sereal+ / Playlet / FlickReels | 58–60% |
| FlareFlow / StardustTV | 58% | TouchShort | 55% |
| HoneyReels / TopShort | 54–58% | MoboReels / KalosTV | 45% |
| Pancake | 48% | 小说类（GoodNovel 等） | 46–70% |

**意义**：这是目前我们见到的**最具体、可交叉验证的分成基准**（此前调研里教程站说的 45–65%、RS Boost 30% 都是二手说法）。它同时告诉我们：不同平台 CPS 差很多（45% vs 70%），选哪家推广对收入影响直接。**注意：这是 AitoEarn 渠道的结算口径，不代表各平台官方直签价格，仍需与平台/官方核实。**

### 2.3 运营方法论（与我们已调研结论互证）

它的 TikTok 账号运营指南非常实操，多与我们的调研结论一致，且更细：

- **口令推广 vs 链接推广**：粉丝 <1000 用"口令推广"（视频标题/评论区放推广口令，用户下载 App 后搜口令/剧名，充值触发收益），**不限制粉丝数**；粉丝 ≥1000 后建议"口令+主页链接"双覆盖。→ **这是"1000 粉以下怎么导流"的一个现成答案：做口令推广，不依赖 bio 链接。**
- **养号流程**：刷视频半天 → 间歇点赞（每 10 条 1–2 次）→ 自然评论 → 关注 3–5 个相关账号 → 发 ≤15 秒实拍测试视频 → 24 小时看播放：≤300=无效号弃用 / 300–1000=合格号 / ≥1000=天选号；48 小时内完善头像/bio/垂直标签；前 3 条日更。
- **账号包装**：昵称参考 ShortDramaSeries / ShortPlotTwist / ShortFlicksHub；头像用当地真人面孔；<1000 粉阶段 bio 引导涨粉，≥1000 粉阶段放链接+紧迫感文案。
- **剪辑要求**：时长建议 2–5 分钟（新号 3 分钟左右）；前 3–5 秒至少含 1 类高能元素（冲突爆发/感官刺激/身份逆转/情感共鸣）；避免全景慢镜头开头、避免线性叙事；**必须二创，禁直搬/简单去重**；封面统一。
- **最佳发布时间**：给了中国/美东/美西三时区对照表（美区晚间 8–9am / 5–6am 峰值等）。
- **审核红线**：禁 18+ 内容；视频被多次提示问题会限流封号。

### 2.4 账号报备机制（合规做法参考）

短剧任务要求先**报备账号**（提交昵称、账号 ID、主页链接，有的需审核），审核期不改资料，报备通过的账号不能中途替换。→ 一套"先报备再发布"的合规流程，可借鉴到我们对 dramafinds 的推广：**先拿到授权/报备，再发内容，避免"未经授权发布被举报"。**

### 2.5 智能剪辑 + 一键发布 + API（工具能力）

提供智能剪辑（提示词生成片段、选比例/时长/片段数）和 AI 发布（多账号定时发布、API 对接）。→ 若未来账号量上来，可用这类自动化降本；但**生成结果需人工质检**。

### 2.6 云工作区（多账号连接与定价）

**功能**：为每个账号提供一个独立的云端浏览器环境（独立 Cookie/设备指纹/IP），用于海外账号授权、养号和多账号隔离管理。文档明确"一个账号对应一个工作区"、"可以自由创建任意多个空间"。

**能连多个 TikTok 账号吗：能。** 机制：每个账号开一个云工作区 → 在工作区内登录 TikTok 并 OAuth 授权 → 在"我的频道"添加为频道 → 用 AI 发布批量/定时发布。

**能用自己买的 IP 吗：能。** 创建工作区时网络连接三选一：

| 方式 | 说明 |
|---|---|
| 默认网络 | 新加坡动态 IP，文档自己说不建议用于风控严格平台 |
| 系统代理 | 向 AitoEarn 购买地区代理，¥99/月 |
| 外部代理 | 填自己的 HTTP 代理（地址/端口/账号/密码），**仅支持 HTTP 协议** |

**定价（按量付费，充值积分制，最低 $10）**：

| 项目 | 价格 |
|---|---|
| 云空间（云工作区） | **$0.2/小时**（可选 15/30/60/120/240/360 分钟） |
| 系统代理 | ¥99/月 |
| 智能切片 | $0.1/分钟（按输入视频时长） |
| 视频超分 / 翻译 / 解说 | $0.36–1.43 / $1 / $2 每分钟 |
| 高光剪辑 / 字幕移除 | $0.15/分钟 |

**TikTok 发布 API 限制**：每账号每 24 小时最多 25 条；**不能通过 API 加热门音乐/音频库、贴纸、投票**（音乐需提前压进素材）；平台侧无分析/互动功能。

## 三、AitoEarn vs dramafinds：根本区别

| 维度 | AitoEarn | dramafinds.com |
|---|---|---|
| **角色定位** | 推广任务撮合平台 + AI 内容营销工具（连接创作者 ↔ 各短剧 App） | 短剧内容承载/观看网站（面向观众直接看剧） |
| **核心业务** | 接任务、剪片、发帖、按 CPS 分佣 | 托管/展示剧集，用户在线观看，订阅收费 |
| **变现模型** | CPS：用户**下载 App + 应用内付费/充值**后给创作者分佣（ReelShort 45% / DramaBox 60% 等） | **网站订阅**：周/月/年费，信用卡/PayPal，无虚拟币；自动续费、一般不退款 |
| **内容来源** | 不提供内容，聚合各短剧 App 的推广任务 | 自己托管剧集内容（首页图片素材来自 crazymaplestudios.com CDN = ReelShort 母公司 Crazy Maple Studio） |
| **面向对象** | 创作者/推广者（想赚钱的人） | 观众/用户（想看剧的人） |
| **运营主体** | 中方运营（京ICP 备案 京ICP备19059131号-15） | ShunGuang Technology Limited，香港（尖沙咀科学馆道 14 号） |
| **是否拥有账号** | 创作者自带账号（它提供云工作区做隔离） | 用户注册账号看剧/订阅 |
| **核心资产** | 任务市场、数据看板、自动化工具 | 剧集库、订阅支付链路、SEO 流量 |

**一句话**：AitoEarn 是**卖"如何把观众带过去"的能力**，dramafinds 是**承接观众并赚钱的地方**。一个在流量上游，一个在变现下游。

## 四、两者的关联（能不能连起来）

**理论上能连：** 如果 dramafinds 有 App 或支持订阅归因，它完全可以作为 AitoEarn 式任务的目标落地平台（创作者引流 → 用户注册/订阅 → 分成）。

**现实障碍：**
1. **结算模型不匹配**：AitoEarn 的 CPS 按"App 下载 + 应用内充值"触发；dramafinds 是**网站订阅制**，且明确"不提供虚拟货币/代币"——除非 dramafinds 自己建联盟系统或接入第三方联盟（如 Adscend/Armada 的 CPI/CPA），否则 AitoEarn 的现成结算链路套不上。
2. **不在任务清单里**：AitoEarn 的短剧任务和分成表覆盖的都是 App（ReelShort、DramaBox、ShortMax、TopShort 等），**没有 dramafinds**。
**我们（帮短剧推广）当前的两条并行合作线：**
1. **RS Boost（ReelShort 官方分销）= 社媒分发主路径**：邀请码制，官方授权素材 + 专属链接/口令 + 官方归因后台。**版权与归因由 RS Boost 官方承担**。要守 RS Boost 平台规则（只发授权集数、付费集素材必须二创、用官方链接/口令、遵报备与披露要求）。
2. **dramafinds = 并行独立合作（与社媒分发无关）**：dramafinds 已拿到 ReelShort 的版权合作链接，但这条合作目前和我们的社媒分发工作无关，是独立线。本文"AitoEarn vs dramafinds"的对比仍有效，但**不是"降级"——两者是不同层面的两条线**。

**对我们（帮 dramafinds 推广）的含义：** 我们做的正是"把观众带给 dramafinds"这层（视频端引流 → dramafinds 订阅/观看）。AitoEarn 的整套机制提醒我们：**要跑通，dramafinds 得先具备可归因的转化事件**（订阅成功、注册、有效观看时长），否则引流了也算不了你的业绩。

## 五、同类平台地图

### 5.1 类似 AitoEarn 的平台（推广/分销任务侧）

| 平台/类型 | 形态 | 说明 |
|---|---|---|
| **DramaCPS** | 短剧 CPS 聚合联盟 | 聚合多家短剧 App 的分佣任务，创作者接入后选剧推广 |
| **shortdramapartner.com** | ReelShort 联盟教程/服务 | 教程站 + 邀请码服务，此前调研已接触（数字按运营说法处理） |
| **ReelShort RS Boost**（官方） | 官方 CPS 分销 | 邀请码制，官方素材区，最高约 30% + 二级下线提成（待官方协议确认） |
| **ShortMax / TopShort / MoboReels / GoodShort / DreameShort / Playlet**（各官方） | 官方联盟/分销 | 各平台自建分销后台，部分走邀请制；AitoEarn 表上 CPS 45–70% |
| **Adscend Media / Armada App** | 第三方 CPA/CPI 网络 | 有 ReelShort/DramaBox 等按安装付费 offer（约 $0.2–0.5/install 量级） |
| **点众/番茄/红果 分销系统**（国内） | 国内短剧分销 | 抖音/快手生态内的短剧 CPS，与海外模型同源 |
| **DataEye ADX / 抖查查** | 选剧/投流数据工具 | 非分销平台，但提供选剧数据（与 AitoEarn 数据选剧台同类） |

**差异**：官方联盟（RS Boost 等）只推自家剧；聚合平台（DramaCPS/AitoEarn）可跨多家选剧，但结算走平台渠道、佣金被平台抽一层；第三方 CPA 网络按安装付费、无长线分成。

### 5.2 类似 dramafinds 的网站（内容承载/观看侧）

| **红果短剧**（字节系） | App | 看广告解锁免费集，字节系流量+广告变现 |

## 六、竞品关系判断

**结论：AitoEarn 不算直接竞品，是"生态内工具型玩家 + 潜在合作渠道 + 学习对象"。**

| 维度 | AitoEarn | 我们（帮 dramafinds 推广） |
|---|---|---|
| 角色 | 任务撮合平台 + 自动化工具（面向所有创作者） | 为单一客户（dramafinds）做专属推广 |
| 内容来源 | 聚合多平台短剧的 CPS 任务 | 单一客户授权的剧 |
| 变现 | 平台抽成/服务费 + 创作者分佣 | 与 dramafinds 的分成/服务费 |
| 账号 | 创作者自带账号（它不提供账号） | 我们已有 8 个账号 |
| 竞争关系 | 不直接抢我们的客户/账号 | 不冲突 |

**风险点**：如果未来我们想规模化做短剧矩阵、接多家平台的活，AitoEarn 这类平台既是可选渠道（有现成任务+数据看板+结算），也意味着**同赛道的个人/团队都在同一个盘子里抢单**——市场透明化会让单靠"接 CPS 任务"的利润变薄。

**关于云工作区的明确结论：我们不需要它。** 我们已有 10 台实体手机 + 10 个独立 IP——实体设备（真设备指纹 + 真 IP）是比云端虚拟环境更强的隔离方案，且云工作区对批量发布需要把 10 个账号 OAuth 授权给它（第三方看到全部账号 = 多一条关联线，有风险）。**账号隔离与发布层用自己的实体设备做，不授权给 AitoEarn；它真正有价值的只是数据看板、分成基准和任务市场这些情报/渠道层。**

## 七、关键待核实/风险

1. **结算可靠性**：京 ICP 备案可查，但"接任务→结算"是否有真实打款案例、结算周期多长，未核实（平台文档说"等待任务页面的最终统计与结算"）。**建议注册小号接 1 个最低门槛任务实测到账。**
2. **分成比例时效性**：页面明示比例会调整，且"不构成结算承诺"——以任务页为准。
3. **平台数据源**：数据选剧台的"滚动 30 日销售额"来自"平台公开快照"，口径不清（可能基于各短剧 App 的榜单/第三方数据），仅作排序用。
4. **合规边界**：它教的养号/口令/矩阵操作里，部分（买成品邮箱、口令引导、IP 切换）与 TikTok 官方"禁止用多账号绕过执法/虚假互动"存在灰色地带，**不能全盘照搬**；我们执行时仍以官方条款为准。
5. **AI 内容风险**：平台主打 AI 生成+自动化分发，但 TikTok 对 AI/无人脸内容执法趋严（详见切片引流工作流文档 6.1），用它的 AI 生成功能需谨慎。

## 八、对我们短剧工作的可学清单

| 可学项 | 怎么用 |
|---|---|

## 九、结论与动作建议

**生态位置：**
```
短剧版权方/制作方（ReelShort/COL Group 等）
   ↓ 授权/分销
短剧平台（App：ReelShort/DramaBox/ShortMax…；网站：dramafinds/Anyreel…）
   ↓ 推广渠道
分销联盟（RS Boost / DramaCPS / AitoEarn…）
   ↓ 推广动作
创作者/推广者（我们：8 个账号剪切片引流）
   ↓ 转化
用户下载/订阅/观看 → 分佣
```

**我们实际在"创作者/推广者"这一层，服务对象是"网站型平台（dramafinds）"这一层。**

**动作建议：**
1. **学 AitoEarn 的数据选剧 + 运营方法论**（本文第二节），但账号/发布层自己掌握，不授权第三方。
2. **当前走 RS Boost 路径（社媒分发主线，版权与归因已官方承担）**；dramafinds 是并行独立合作线（已有 ReelShort 版权合作链接，与社媒分发无关），若未来要把 dramafinds 纳入社媒分发，需另行确认归因/结算口径。
3. **盯同类网站玩法**：Anyreel（结构参考）、DramaWave（裂变解锁玩法参考）、红果（广告变现参考），用于反哺我们对 dramafinds 的推广设计。
4. **用 AitoEarn 分成表当谈判基准**，别被单一渠道的口头比例框住。
