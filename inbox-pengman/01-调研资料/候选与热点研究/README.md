# 候选与热点研究入口

这里只保存已经获准开展的候选内容研究和信息来源，包括：周一建立周计划、Pengman 明确要求重排、确认补充库存，或需要评估一个可能达到门槛的热点。

这里不是每天自动生成选题的入口，也不维护第二份内容进度。候选被人工选中后，在 [[inbox-pengman/02-生产/02-content-production/README|单条内容详情入口]]建立唯一记录，并由该记录保存实际阶段。

具体研究权限和来源要求以 [[inbox-pengman/AGENTS#候选与热点研究权限门|工作区规则]]为准。
