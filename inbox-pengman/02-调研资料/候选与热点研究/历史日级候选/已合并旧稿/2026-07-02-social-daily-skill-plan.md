# 2026-07-02 Social Daily Skill Plan

## 0. 怎么用 Lynne 给的 social-daily skill

这个 skill 更适合当成“社媒日更产线 SOP”，不是单条选题助手。

它的核心用法：

1. 先定今天的内容支柱。
2. 选 2 个母选题。
3. 每个母选题裂变成多平台内容。
4. 每条内容都要有对应落点和短链。
5. 发布后进内容追踪/复盘。

今天按 skill 的每周日历是：

- 周四：心理洞察
- 推荐支柱：心理洞察 / astrology + psychology
- 推荐形式：single AI host short video + X posts + 可拆 Pinterest / Reels / Shorts

当前限制：

- 关键词表 `生产候选 / 趋势词 / CTA Map` 暂未接入。
- 公司短链工具 `{{SHORTLINK_TOOL}}` 暂未配置。
- 因此今天先用已知 AstrologyWiki 页面作为 CTA 落点，正式发布前再替换成短链。
