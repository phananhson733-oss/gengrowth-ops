### 进入 Obsidian 的方式

单条内容只在 Brief 中记录：

1. 实际采用的账号/视频 URL；
2. 选题角度、Hook 类型、结构、CTA 和可借鉴机制；
3. 不应照抄的表达、人物、音频或素材；
4. `analysis_confidence` 与可验证表现数据；
5. 缺失项和证据限制。

不复制整张表，不在 Obsidian 维护第二套播放/互动数据。生成前重新读取在线表；高播放只能提高“值得测试”的优先级，不能直接升级为长期规则。

### 当前字段缺口

在线表已有账号、平台、主题、形式、Hook、结构、CTA、可复用/不可复用元素、适配建议、风险和数据置信度。当前缺少或不稳定的重点是：目标受众、评论区原文/高频问题、收藏数、完播率、平均观看时长、主页访问、链接点击、来源权限/版权状态。缺失时统一标记“待确认”。

## 竞品追踪模板

每周对选定的 10 个竞品账号（3 大号 + 4 中号 + 3 快速成长小号）记录以下字段：

| 字段 | 说明 |
|---|---|
| 账号名 | 竞品账号 |
| 发布时间 | 判断发布时间规律 |
| 视频标题 / caption | 看选题表达 |
| 开头 3 秒 hook | TikTok 最关键 |
| 视频形式 | 口播、图文、AI 主播、meme、街采、故事 |
| 播放量 | 基础表现 |
| 点赞 / 评论 / 收藏 / 分享 | 判断内容价值 |
| 互动率 | 不只看播放量 |
| 主题标签 | 判断流量池 |
| 评论区高频问题 | 反推下一条内容 |
| 可复刻点 | 选题 / 结构 / 表达 / 视觉 |
| 不建议复刻点 | 太娱乐、太低质、和品牌不符等 |

每周产出：① 最值得复刻的 5 个选题及理由 ② AstrologyWiki 改写版本 ③ 下周 7 条内容排期（含 hook、脚本结构、caption、CTA）。
