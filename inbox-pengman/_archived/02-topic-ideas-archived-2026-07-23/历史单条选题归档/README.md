## 使用规则

- 查旧脚本、旧选题、历史表达时看这里。
- 不在这里新建候选、维护排期或修改生命周期。
- 旧选题重新启用时，先按当前周计划检查去重、账号、Pool、成本、时效和容量；确认后在 `07-content-production` 建立或迁移主记录，并从主记录反链本归档。
