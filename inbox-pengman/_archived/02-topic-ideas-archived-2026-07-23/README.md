## 旧内容重新启用

若要重新使用这里的一条内容：

1. 先检查是否与最近 7–14 天发布或当前周计划重复。
2. 重新判断 `Evergreen / Predictable / Hot`、账号、形式、成本和事实有效性。
3. Pengman 明确确认后，才纳入未来两周产能。
4. 在 `07-content-production` 新建或迁移一份有独立 `content_id` 的主生产记录。
5. 缺失的 `pool / batch_id / expiry_date / source_evidence` 按现行 SOP 补齐。

不要直接在本归档目录继续维护脚本状态、排期或发布链接。
