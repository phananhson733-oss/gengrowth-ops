# Pengman 滚动周内容生产与 AI 协作操作卡

> **历史声明（2026-08-07）**：本文件已退役，不再作为当前操作入口。日常快捷操作见 `DAILY-COCKPIT.md`，首次接手或病假交接见 `04-production/00-evergreen-workflows/社媒内容生产接手指南.md`，正式规则见 `04-production/00-evergreen-workflows/weekly-rolling-content-production-sop.md`。

> 这是日常使用的简化卡片。正式规则见 [[inbox-pengman/04-production/00-evergreen-workflows/weekly-rolling-content-production-sop]]；当前事实以本周计划和单条主生产记录为准。

## 你只需负责五件事

1. 周一告诉 AI 本周可用时间、必须发布项和限制。
2. 确认本周发布清单与下周生产清单。
3. 对 Brief、脚本和视觉方案用自然语言反馈。
4. 明确确认最终稿并完成制作、排期和发布。
5. 把真实链接和后台数据交给 AI 复盘。

AI 负责读取周计划、检查库存和阻塞、做允许范围内的候选/热点研究、建立单条记录、记录反馈、更新阶段和整理复盘。AI 不擅自新增超出产能的任务，也不擅自把 Idea 提升到 `selected`。

## 周一：锁定本周

直接说：

```text
请按滚动周 SOP 建立本周计划。
本周可投入：X 小时
本周必须发布：无 / 具体内容
特别想做：无 / 具体方向
不做或避开：无 / 具体限制

请先区分 Publishing This Week 和 Producing for Next Week。
生成候选前必须保留并读取原有全部参考项，然后完成实时互联网调研：
1. 读取固定参考账号 CSV，并记录 checked_at 和采用的相关账号；
2. 尝试访问指定 Apps Script Library，若需要登录要明确说明未读取内部内容；
3. 查看至少 2 个与目标账号和选题直接相关的当前公开来源并附直接链接；
4. Hot 继续使用更严格的来源门槛。
固定 CSV 不可读时不要生成正式候选。

完成证据预检后，再给出账号配额、S/M/L 产能、候选、排期和 Batch。
先不要写完所有脚本。
```

确认时说：

```text
确认本周计划。以下内容进入 selected：【编号】。
其余保持 idea，不占产能。
```

## 周二至周五：只推进既定内容

每天开始说：

```text
读取本周计划，给我今天的执行卡。
我今天可投入：X 小时。
先处理即将过期、阻塞和库存不足；热点只做有限检查。
```

AI 应只返回今天要推进的既定内容、对应 Batch、发布动作、阻塞、库存和热点结论。没有合格热点时，不重新生成整套选题。

## 选择、写稿与确认

对已进入周计划的内容说：

```text
推进【content_id / 标题】。
先完成 Brief 和事实核验，再给我脚本工作稿。
```

反馈可以直接说：

```text
开头太慢，第一句直接点名 Scorpio。
中间解释保留。
结尾不要 CTA。
```

只有你明确说下面这句话后，AI 才能把脚本推进到 `scripted`：

```text
确认采用这个版本，进入制作。
```

## 快速通道与实验通道

- 快速通道：事实清楚、风险低、已有模板的 S/M 内容。Brief、脚本与简版制作卡可在一次确认周期内完成。
- 实验通道：新账号/形式、双模型、L 级内容、关键角度仍有争议或需要严格对照的内容。先冻结 Brief 和实验变量，再出候选。

使用 Claude 时说：

```text
推进【content_id】，走 Claude 通道。
```

Codex 负责生成冻结任务包、保留 Claude v1、记录你的原始反馈，并把最终确认版写回同一份主生产记录。Claude 对话不是长期事实来源。

## 制作、排期与发布

脚本确认后说：

```text
请按本周 Batch 生成最终制作卡。
```

实际方案有变化时直接说明，AI 更新当前记录，不重新走一遍选题。

发布后至少提供：

```text
已发布。
content_id：【ID】
平台/账号：【平台与账号】
链接：【真实链接】
发布时间：【时间或待补】
```

没有真实链接，AI 不得标记为 `published`。

## 热点临时插入

说：

```text
请按 10 分制评估这个热点：【链接/事件】。
只告诉我是否值得进入热点槽，以及会替换哪一条。
```

- 8–10：立即进入热点槽。
- 6–7：当天稍后或次日处理。
- 4–5：进入下周候选。
- 0–3：放弃。

AI 先用预留热点槽；没有槽位时，只能建议替换同账号最低优先级 Evergreen，并等待你确认。被替换内容只顺延一次。

## 每日结束

```text
结束今天的执行。请回写实际 content_stage、阻塞、库存和发布链接，
并列出明天只需继续推进的内容。
```

## 最短版

```text
周一：按滚动周 SOP 建本周计划，我有 X 小时。
平日：读本周计划，给我今天的执行卡，我有 X 小时。
写稿：推进【content_id】，先 Brief，再脚本。
确认：确认采用这个版本，进入制作。
发布：已发布，这是 content_id、链接和数据。
```
