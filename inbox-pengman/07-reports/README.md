# 报告与复盘入口

这里保存 AstrologyWiki 内容实际执行后的发布事实、周报、策略结论、`decision / next_test` 和专项复盘。

## 与调研资料的边界

- `02-调研资料/`：执行前或外部研究证据，回答“为什么可能这样做”。
- `07-reports/`：执行后的事实和结论，回答“实际发生了什么、下一步继续还是调整”。

## 当前入口

- 周报：根目录的 `2026-Www-weekly-report.md`。
- 专项复盘：`专项复盘/`。
- 历史发布记录：`历史发布记录/`，仅作数据底稿和追溯，不再维护第二套周级结论。

发布证据仍以真实链接、平台 ID 和实际发布时间为准；缺少这些字段时，明确写“主记录标记 published，发布证据待补”。
