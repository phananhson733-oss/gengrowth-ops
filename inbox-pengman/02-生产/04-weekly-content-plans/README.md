# 周度内容计划入口

这里保存滚动周执行计划，是“本周发布什么”和“本周为下周生产什么”的组合入口。

## 使用顺序

1. 先读 [[inbox-pengman/02-生产/00-evergreen-workflows/weekly-rolling-content-production-sop]]。
2. 每周一从 [[inbox-pengman/02-生产/00-evergreen-workflows/templates/weekly-content-plan-template]] 复制一份到本目录。
3. 文件命名：`YYYY-Www 周度内容计划.md`。
4. 日常执行优先读取当前周计划；单条真实阶段仍回写 `02-content-production` 的主生产记录。
5. 周五把发布结果、库存、阻塞和 `decision / next_test` 写回当周计划及对应周报。

## 边界

- 周计划维护产能、两个周次清单、账号配额、内容池、Batch 和热点槽。
- 单条主生产记录维护最终稿、素材、真实 `content_stage` 和发布回链。
- 周报维护周级公开数据及最终 `decision / next_test` 事实。
- Idea 不因出现在候选区自动成为 `selected`。
