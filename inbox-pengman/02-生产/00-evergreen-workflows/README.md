## 规则边界

- 一条规则只在上表对应主文档详细维护；其他文档只链接，不复制整段规则。
- 当前周目标只在 `04-weekly-content-plans/` 维护。
- 单条真实 `content_stage`、最终稿和发布证据只在 `02-content-production/` 主记录维护。
- 发布事实、周级 `decision / next_test` 和专项复盘统一在 `02-生产/03-data-review/` 维护。
- 工具文档不等于工具已部署；试验记录不等于当前稳定自动化。
