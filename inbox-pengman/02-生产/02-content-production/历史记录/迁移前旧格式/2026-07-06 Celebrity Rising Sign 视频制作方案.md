# 2026-07-06 Celebrity Rising Sign 视频制作方案

## 0. 本条视频目标

今日主选题：

**Why Celebrity Birth Charts Get This Wrong So Often**

建议做成 35-45 秒 TikTok / YouTube Shorts / Instagram Reels 可复用短视频。形式以 **AI host + AstrologyWiki 工具录屏/截图 + CapCut 图卡字幕** 为主；新闻截图只作为可选开头，不作为主体素材。

内容目的：

- 承接 `celebrity birth chart` / `rising sign` 相关搜索兴趣。
- 把用户从“查名人 Rising sign”引导到“自己的出生时间会影响 Rising sign 和 houses”。
- 建立 AstrologyWiki 的可信边界：不硬猜出生时间，不乱编 Rising sign，不把 celebrity chart 当确定事实。
- 导流到 AstrologyWiki Tools page，尤其是 Birth Chart Calculator / Rising Sign tool。

推荐成片：

| 项目 | 建议 |
|---|---|
| 视频长度 | 35-45 秒，优先 38 秒左右 |
| 画幅 | 9:16 |
| 平台 | YouTube Shorts / TikTok 首发，IG Reels 复用 |
| 视频形式 | AI host 口播 + 页面录屏/截图 + 概念图卡 |
| 制作复杂度 | 低到中，优先当天可完成 |
| CTA | `Check your own chart with real birth data on AstrologyWiki` |
| 落点 | `https://www.astrologywiki.com/en/tools` |

## 1. 推荐制作路线

首选路线：

```text
AI host 开场
→ celebrity chart / headline 风格截图可选
→ AstrologyWiki tools 页面录屏
→ CapCut 概念图卡解释 Sun / Rising / Houses
→ tools page CTA
```

为什么这样做：

- 本题不是新闻热点，不需要依赖真实新闻素材。
- 页面录屏可以直接展示 AstrologyWiki 工具，导流更自然。
- Rising sign 和 houses 是抽象概念，用图卡比 AI 乱画星盘更稳。
- AI host 只承担“解释者”角色，不需要全程数字人口播，降低脸和口型翻车风险。

不建议路线：

- 不用真实明星照片做主体，避免肖像和八卦感。
- 不展示某个名人的具体 Rising sign，除非 birth time 有可靠来源。
- 不让 AI 生成可读文字或具体星盘度数。
- 不做“震惊揭秘某明星真实上升星座”的包装。

## 2. 最终口播脚本

视频口播严格使用 7/6 每日内容包中的 `Final Voiceover Draft`，在明确要求前不改写、不压缩、不替换为其他版本。

```text
Why do celebrity birth charts get the Rising sign wrong so often?

Usually, it comes down to one missing detail: birth time.

A celebrity's Sun sign is easy to confirm from their birthday.
But the Rising sign depends on the exact time and place they were born.

If the birth time is missing, the Rising sign can only be guessed.

That matters because the Rising sign describes how you enter the world: your first impression, your instinctive style, and the starting point of the whole chart.

It also sets up the houses.

Houses show where different parts of life play out: relationships, career, family, creativity, money, identity.

So when the Rising sign is guessed, the houses can shift too. The chart may still be interesting, but the “where in life does this show up?” part becomes much less certain.

If you want to check your own chart with real birth data, use AstrologyWiki's free Birth Chart Calculator or Rising Sign tool.
```

## 4. 素材清单

| 编号 | 素材 | 获取方式 | 用途 |
|---|---|---|---|
| A1 | AI host opening shot | 复用 Mira host，或用 CapCut AI host / avatar | 开头和结尾解释者 |
| A2 | Celebrity chart / headline style screenshot | 可选：搜索结果、新闻标题、社媒截图；避免放大真实人脸 | 3 秒 hook 背景 |
| A3 | AstrologyWiki Tools page 录屏 | 浏览器打开 `https://www.astrologywiki.com/en/tools`，竖屏录屏或截图 | CTA 和可信落点 |
| A4 | Birth Chart Calculator / Rising Sign tool 局部截图 | 页面截图，CapCut 加高亮框 | 展示用户下一步 |
| A5 | Birthday vs clock/location 图卡 | CapCut 自制 | 解释 Sun vs Rising 数据需求 |
| A6 | Rising / Ascendant 起点图卡 | CapCut 自制，简单圆盘即可 | 解释 chart starting point |
| A7 | Houses life areas 图卡 | CapCut 自制 12 分区，不写具体假度数 | 解释 houses |
| A8 | CTA 结尾图卡 | CapCut 自制 + 页面截图 | 结尾停留 1.5-2 秒 |

素材规则：

- 所有可读文字都在 CapCut 加，不放在 AI 图里。
- 新闻截图/搜索截图如果使用，只露标题或搜索词，不要把真实明星人脸作为卖点。
- 星盘轮可以是抽象教学图，不要伪造真实出生盘、度数、相位。
- 页面录屏优先用 AstrologyWiki 自己页面，降低版权和素材查找成本。

## 5. AI Host 设定

可沿用 7/3 内容包里的固定 host **Mira**。

本条 host 气质：

- modern astrology explainer
- calm, credible, beginner-friendly
- 像知识型短视频主播，不像八卦解说，不像 fortune telling

如果需要新生成一张 host 镜头，可用：

```text
Mira, a modern AI astrology explainer host, speaking directly to camera with a calm credible educational tone, upper body portrait, simple navy and white outfit, subtle silver astrology necklace, soft studio lighting, minimal modern studio background with subtle astrology symbols, realistic natural skin texture, friendly but authoritative expression, vertical 9:16, centered composition, room above head for captions, no text, no logo, no watermark.
```

Negative prompt：

```text
no text, no fake letters, no watermark, no celebrity likeness, no exaggerated mystical costume, no crystal ball, no witch hat, no dramatic fantasy background, no extra fingers, no distorted face, no plastic skin, no beauty filter, no airbrushed skin, no fake zodiac chart, no readable symbols pretending to be data
```

如果 host 动作或口型不自然：

- 只保留 0:00-0:03 和 0:28-0:35 两段 host。
- 中间全部用录屏、截图、图卡和字幕遮掉。
- 不强求数字人全程出镜。

## 6. CapCut 制作步骤

1. 新建 9:16 项目。
2. 导入口播音频，先按音频波形切成 6-7 个段落。
3. 导入 AI host、AstrologyWiki 页面录屏/截图、图卡素材。
4. 每 4-6 秒换一次视觉，避免全程 talking-head。
5. 自动字幕后人工校对，重点检查：
   - AstrologyWiki
   - birth chart
   - Rising sign
   - birth time
   - birthplace
   - houses
6. 关键词单独做大字图层，不完全依赖自动字幕。
7. 用高亮框或手指点击动画强调 Tools page / Birth Chart Calculator / Rising Sign tool。
8. 背景音乐用 light electronic / clean explainer / soft pulse，音量 8%-12%。
9. 结尾 CTA 停留 1.5-2 秒。
10. 手机全屏预览一次，检查字幕不要挡住 host 脸、工具按钮和 CTA。

建议屏幕大字：

```text
Celebrity charts get this wrong often
Sun = birthday
Rising = exact time + place
Unknown birth time? Be careful.
Rising = chart starting point
Houses = life areas
Use real birth data
AstrologyWiki.com
```

## 7. 新闻截图 / 录屏 / AI Host 三种素材用法

### 新闻截图

本条只建议作为 hook 氛围，不建议作为主素材。

可用方式：

- 搜索结果截图：`celebrity birth chart rising sign`
- 新闻标题截图：只截标题区域，不强调明星照片。
- 社媒问题截图：如果有人问某明星 Rising sign，可作为“大家确实会查这个”的证据。

注意：

- 不要在视频里判断某个明星 Rising sign 对错。
- 不要用八卦标题做主要卖点。
- 截图出现真实人脸时，尽量裁掉或模糊。

### 页面录屏

本条最推荐。

录屏内容：

1. 打开 AstrologyWiki Tools page。
2. 慢慢滚动到 Birth Chart Calculator / Rising Sign tool。
3. 鼠标或手指停在工具入口上。
4. 结尾定格在工具页或 CTA 图卡。

CapCut 处理：

- 放大 110%-130%，保证手机上看得清。
- 加半透明高亮框。
- 页面文字不要太小，必要时只截局部。

### AI Host

本条适合做“可信解释者”，不做“新闻播报员”。

推荐出镜段落：

- 0:00-0:03 hook。
- 0:28-0:35 解释 guessed Rising 的不确定性。
- 0:35-0:42 CTA 可选出镜，或直接用页面录屏。
