# GSC 数据输入说明

这里用于接收 Pengman 明确提供的 AstrologyWiki GSC 导出 CSV，作为选题和落地页判断输入。

- 当前目录没有可用 CSV；不要把“缺数据”解释成 0。
- CSV 只保存原始导出，不手工改写成第二套指标表。
- 单条 Brief 只记录使用过的 query/page、日期范围和来源文件链接。
- 发布事实和社媒数据仍以 [[inbox-pengman/04-production/05-weekly-published-content-digests/README]] 为准。
- 若没有 GSC 输入，可使用已确认的产品页、文章页和当前业务优先级，但必须标记证据限制。
