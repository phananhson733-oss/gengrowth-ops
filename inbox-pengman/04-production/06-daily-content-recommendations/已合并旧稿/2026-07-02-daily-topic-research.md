## 3. 视频内容框架

推荐标题：

**Mercury Retrograde in Cancer: Why Old Feelings Come Back**

可用 hook：

```text
Old feelings coming back lately? Mercury retrograde in Cancer may be why.
```

结构：

1. **Hook**：old feelings / old messages / old memories coming back。
2. **Transit context**：Mercury retrograde in Cancer is active now；对外不必写具体日期。
3. **Simple meaning**：
   - Mercury = thoughts, words, messages, conversations。
   - Cancer = memory, family, home, emotional safety。
   - 合起来就是 emotional memory 和 unfinished conversations。
4. **Practical angle**：Before reacting, ask whether this is about today or an older emotional pattern。
5. **Soft CTA**：check AstrologyWiki's 2026 astrology calendar / birth chart guide for context。

### 给 3号 AI 视频制作人的 brief

请 3号完成：

1. 写一版 45-75 秒英文单人 AI host 解说脚本。
2. Host 语气：calm / clear / emotionally relatable / modern astrology explainer。
3. 拆出 5-7 个视觉段落。
4. 视觉方向：fixed talking-head avatar + large captions + clean astrology psychology visual cards。
5. 可用素材：
   - single AI host 画面
   - Mercury icon
   - Cancer glyph / crab symbol
   - old message / journal / family memory visual
   - AstrologyWiki calendar page screenshot
6. 先完成脚本和视觉段落，不直接生成素材，不写最终图像 prompt。

制作红线：

- 不做 “Mercury retrograde will ruin your life”。
- 不做复合预测或灾难化表达。
- 不使用“不是 X，而是 Y”式模板化反转句。
- 不过度上价值。
- 所有字幕、关键词、CTA 交给 CapCut。
