## curatedastrology 风格要素提炼（供脚本撰写参考）

### 语气规则
1. **第一人称分享**，不是第三人称教学。"I noticed…" / "Is it just me or…" / "I keep seeing people say…"
2. **邀请而非断言**。"Did you feel it?" / "I'm curious what showed up for you" / "What area of life is this hitting?"
3. **承认不确定性**。"I'm still learning this one" / "Not a professional but this is what I'm seeing" → 对应 astrologywiki 版本："The sky is doing [X] — here's one way to read it"
4. **日常行为翻译**。不说"太阳入狮子座代表创造力觉醒"，说"notice how you suddenly want to post more, dress louder, take up more space? That's Leo season."
5. **评论区是内容的一半**。每条必须有一个明确的"report in"式 CTA："comment your [X]" / "what showed up for you?"

### 视觉/形式规则（适配 ① 官方号）
- 保持现有品牌视觉（星空/行星/深色 + 大字幕）
- 但字幕语气从"权威断言"调整为"分享发现"
- 可以偶尔加一句口语化的 text-on-screen："ok but did anyone else feel this?"
- 片尾 CTA 不说"Use our tool"，说"I checked where this falls in my chart — you can too"

### 与 The Pattern 模式的区别
| | The Pattern（原定方向） | @curatedastrology 融入后 |
|---|---|---|
| 语气 | 品牌声音，简洁断言 | 个人声音，分享+邀请 |
| 权威感 | 高（我告诉你天象意味着什么） | 低（我也在学，一起看看） |
| 互动设计 | 被动（看完去用工具） | 主动（评论区报到 + 去查你的） |
| CTA | 直接推工具 | 先分享自己查的体验，再邀请 |
| 适合阶段 | 粉丝量大后的品牌建设 | **冷启动期更有效**——降低距离感，提高评论率 |

> **建议：① 号当前 3 粉冷启动阶段，优先用 curatedastrology 的低权威+高参与感调性。粉丝过 1K 后逐步向 The Pattern 品牌感过渡。**
