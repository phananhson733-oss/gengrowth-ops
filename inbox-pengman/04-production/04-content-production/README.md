# 历史单条内容生产记录

本目录保存迁移前的内容生产记录和旧格式证据，**不是当前单条内容生产入口**。

当前新建和推进中的主生产记录统一放在 [[inbox-pengman/04-production/07-content-production/README|07-content-production]]。当前周组合统一放在 [[inbox-pengman/04-production/03-weekly-content-plans/README|03-weekly-content-plans]]。

## 使用边界

- 只有追溯历史脚本、人工修改、工具消耗、发布证据或系列去重时，才读取这里的相关文件。
- 不从文件名日期、旧 `status`、目录位置或正文里的“已发布”字样推断当前阶段。
- 历史文件重新进入未来两周产能时，在 `07-content-production/` 建立或确认唯一主记录；不在两个目录同时维护状态。
- 不批量改写历史证据。真实链接、历史稿和当时的工具记录继续保留原样。
- `已合并旧稿/` 只保存更早的过程材料，默认不扫描。

现行生命周期、字段映射和迁移规则见 [[inbox-pengman/04-production/00-evergreen-workflows/weekly-rolling-content-production-sop#8-生命周期、完成定义和 WIP]]。
