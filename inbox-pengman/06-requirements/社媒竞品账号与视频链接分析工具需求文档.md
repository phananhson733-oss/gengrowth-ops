# 社媒竞品账号与视频链接分析工具需求文档

## v0.5 本次需要产品与开发更新的内容

> 这一节是本轮交接入口。产品和开发应先看这里；后面的章节用于补充完整背景、字段定义和验收细节。
>
> **✅ v0.5 功能已于 2026-07-25 前上线完成。** Photo/Carousel 支持和风格标签功能均已可用。

现有版本已经能处理普通视频和账号链接。本次不是重做整套工具，只新增两组能力：

1. **让飞书 Social 机器人能够识别并分析 TikTok Photo / Carousel 链接。**
2. **给 Google Sheet 中的账号和内容增加统一的主风格标签与四账号适配建议。**

### 更新一：支持 TikTok Photo / Carousel 链接

当前问题：飞书 Social 机器人无法读取类似下面的 Photo 链接：

`https://www.tiktok.com/@wealthyastrogirl/photo/7657694164477431048`

产品与开发需要完成：

| 优先级 | 需要更新的能力 | 预期结果 |
|---|---|---|
| P0 | 根据 TikTok URL 中的 `/photo/` 识别内容类型 | Photo 链接不再进入普通视频播放器或直接报“不支持” |
| P0 | 读取 Photo / Carousel 的公开图片 | 返回图片数量、图片顺序和可读取的原图或截图 |
| P0 | 提取首图与各页文字 | 对图片做 OCR，区分首图 hook、正文推进和最后一页 CTA |
| P0 | 读取 caption 和公开互动字段 | 能读取多少写多少；缺失字段标记 `待补数据/待确认` |
| P0 | 输出结构化内容分析 | 返回主题、hook、页面结构、CTA、可借鉴点、风险和风格标签 |
| P0 | 提供明确失败原因和补充入口 | 说明失败发生在页面访问、图片提取、OCR 还是指标读取，并允许用截图或人工补图继续分析 |

验收时必须包含上面的 `wealthyastrogirl` 链接，不能只用普通视频验证。

### 更新二：给账号和内容增加风格标签

当前问题：表格里虽然有 `main_formats` 或 `format_type`，但 Pengman 仍需逐行阅读，才能判断内容属于“科普图文、AI 口播、真人自拍、素人分享”等哪类形式，以及适合四个账号中的哪个账号参考。

本次需要在现有 Google Sheet 增加以下字段：

#### `account_analysis` 新增字段

| 字段 | 用途 |
|---|---|
| `primary_style_tag` | 一个主风格标签，例如 `科普图文`、`AI口播`、`真人自拍`、`素人分享` |
| `secondary_style_tags` | 可选辅助标签，最多 2 个；没有则留空 |
| `recommended_account` | 官方账号 / AI 占星师 / 热点占星 / 普通占星爱好者 / 暂不适配 |
| `account_fit_reason` | 用一句话说明适配理由，以及值得模仿的是选题、形式、语气还是视觉 |

#### `video_links` 新增字段

| 字段 | 用途 |
|---|---|
| `content_type_hint` | `video / photo / unknown`；可人工预填，也可由系统识别 |

#### `video_analysis` 新增字段

| 字段 | 用途 |
|---|---|
| `content_type` | `video / photo / carousel / unknown` |
| `photo_count` | Photo / Carousel 的图片数量；普通视频留空 |
| `slide_text` | Photo / Carousel 各页可见文字或 OCR 结果；普通视频留空 |
| `primary_style_tag` | 一个主风格标签，必须使用统一词表 |
| `secondary_style_tags` | 可选辅助标签，最多 2 个 |
| `recommended_account` | 官方账号 / AI 占星师 / 热点占星 / 普通占星爱好者 / 暂不适配 |
| `account_fit_reason` | 说明适合哪个账号及原因 |

### 标签使用规则

- 每个成功分析的账号和内容必须有 1 个 `primary_style_tag`；
- 主标签使用统一词表，避免同一种形式出现多个近义名称；
- 标签用于快速筛选，不替代原有完整分析；
- AI 给出的标签是建议，Pengman 可以人工修改；
- 后续重新分析时，不得覆盖 Pengman 已确认的人工标签；
- 现有 `account_analysis` 和 `video_analysis` 记录也需要补充标签，但不得覆盖已有备注。

第一版标签词表和具体判断标准见本文“默认表格结构 → 主风格标签规则”。

### 本轮不需要更新的内容

- 不需要重做现有 Google Sheet；直接增加字段即可；
- 暂不把 `video_links / video_analysis / video_url` 全部改名为 `content_*`，避免破坏旧自动化；
- 不自动寻找新竞品；
- 不自动生成最终选题或脚本；
- 不将 AI 标签直接当成最终账号策略；
- Google Sheet 是当前默认界面，但底层字段仍应兼容飞书多维表格、CSV 或其他记录界面。

### 本轮交付完成的判断标准

1. 示例 Photo 链接能够被识别为 Photo，而不是普通视频；
2. 至少 5 条 Photo / Carousel 测试链接中，有 3 条可以输出图片结构、首图 hook、CTA 和主风格标签；
3. 无法读取的 Photo 链接会返回具体失败环节和补充方式；
4. Google Sheet 上述字段已经建立；
5. 新分析结果会自动填写主风格标签和四账号适配建议；
6. 已有账号和内容记录完成标签回填，且不会覆盖人工内容。

## 0. 一句话结论

第一版不要做完整“竞品社媒增长系统”，先做一个**给链接就能分析账号或内容的半自动工具**。

最重要的三个能力：

1. **输入账号链接 → 输出账号概览、主风格标签和四账号适配建议。**
2. **输入 TikTok 视频或 Photo 帖子链接 → 输出内容结构、hook、表现形式和可借鉴点分析。**
3. **为账号和单条内容生成一个主风格标签，帮助 Pengman 快速判断适合哪个账号参考。**

自动寻找竞品账号、长期监控、自动生成选题、自动生成脚本都放到后续阶段。

### 系统做什么

- 读取账号链接和视频链接；
- 识别 TikTok 普通视频和 Photo / Carousel 帖子；
- 抓取公开可见字段；
- 输出结构化账号分析和内容分析；
- 输出主风格标签、可选辅助标签和四账号适配建议；
- 回写到默认记录界面。

### 系统不做什么

- 不自动寻找竞品账号；
- 不自动发布内容；
- 不依赖登录态；
- 不承诺拿到后台数据；
- 不把 AI 结论直接当最终运营策略。

### 第一版成功标准

- 10 条普通视频链接里至少 7 条能产出可用分析或明确失败原因；
- 5 个账号链接里至少 3 个能产出账号概览或明确失败原因；
- TikTok Photo 链接不能再直接按不支持的视频链接失败，必须识别内容类型并尝试读取；
- 输出结果是结构化记录，不是散文；
- 成功分析的账号和内容必须有一个主风格标签；
- 抓不到的字段统一标记 `待补数据/待确认`。

## 一、为什么要做

现在做社媒竞品调研时，主要问题不是“不会分析”，而是：

- 每次都要手动打开账号和视频；
- 手动记录粉丝、播放量、点赞、评论、时长很慢；
- AI 分析格式不统一；
- 视频分析容易只停留在“讲了什么”，没有拆 hook、第一帧、字幕、CTA；
- 飞书 Social 机器人目前无法读取 TikTok Photo / Carousel 链接；
- 账号和内容虽然已有形式分析，但缺少一个便于筛选和四账号路由的统一标签；
- 调研结果不方便沉淀到结构化表格或记录系统里，后续难比较。

所以第一版工具的目标是：**把人工看账号 / 看视频 / 整理表格的重复劳动降下来**。

## 二、第一版范围

### 第一版只做

| 功能 | 说明 |
|---|---|
| 内容链接分析 `P0` | 输入 TikTok 普通视频、TikTok Photo / Carousel 或 YouTube Shorts 链接，输出单条内容分析 |
| TikTok Photo 读取 `P0` | 识别 Photo 链接，读取可见图片、图片顺序、首图文字、caption 和公开指标；受阻时返回明确原因与人工补充入口 |
| 风格标签 `P0` | 为账号和单条内容输出一个主风格标签，并给出四账号适配建议 |
| 账号链接分析 `P1` | 输入 TikTok / YouTube Shorts 账号链接，输出账号概览 |
| 结构化结果回写 | 把账号和视频分析结果写入固定表格或记录系统 |
| AI 结构化总结 | 用固定字段输出分析，不要散文式总结 |
| 数据缺口标记 | 抓不到的字段标记 `待补数据/待确认` |

### 第一版不做

- 不自动寻找竞品账号；
- 不自动判断哪些账号是最终竞品；
- 不做 Instagram / X；
- 不自动发布内容；
- 不自动下载和长期保存所有视频；
- 不依赖登录态；
- 不做复杂数据库；
- 不做长期监控和定时周报。

## 三、使用流程

第一版不把“Google Sheet 手动填入”写死。链接输入方式可以是以下任一种：

- Google Sheet；
- 飞书多维表格；
- CSV；
- 简单表单；
- 机器人 / Agent 对话输入后再写入表格。

第一版默认使用 `Google Sheet` 作为输入输出界面，因为最容易先跑通、也最容易给同事排查问题。

如果同事更习惯 `飞书多维表格`，可以一比一替换，字段保持一致即可。

`CSV` 和 `机器人 / Agent 自动写入` 不作为第一版必须支持。

### 流程 A：账号链接分析

```text
运营提供账号链接
→ 工具读取账号链接
→ 抓取公开账号数据
→ 抓取最近公开视频列表
→ AI 总结账号定位、内容形式、常见主题
→ 回写账号分析表
```

适用场景：

- 发现一个可能值得学习的账号；
- 想快速判断这个账号值不值得继续研究；
- 想看这个账号主要做什么内容、表现如何。

### 流程 B：单条内容链接分析

```text
运营提供视频或 Photo 帖子链接
→ 工具识别平台和内容类型
→ 抓取公开视频数据
→ 普通视频：提取 caption / 时长 / 播放 / 点赞 / 评论 / 分享
→ Photo 帖子：提取图片数量 / 图片顺序 / 首图文字 / 每页可见文字 / caption / 公开互动
→ 如可行，补充转写文本、OCR 或关键帧
→ AI 输出结构化内容分析、主风格标签和四账号适配建议
→ 回写内容分析表
```

适用场景：

- 看到一条竞品视频或 Photo 帖子表现好；
- 想拆解它为什么有效；
- 想判断是否适合改编给自己的产品账号。

### TikTok Photo 链接示例

需要支持类似链接：

`https://www.tiktok.com/@wealthyastrogirl/photo/7657694164477431048`

系统应根据 URL 中的 `/photo/` 识别为 Photo / Carousel，而不是继续送入仅支持视频播放的解析流程。

如果页面访问受限，系统至少要返回：

- 已识别内容类型为 Photo；
- 失败发生在页面访问、图片提取、OCR 还是指标读取；
- 是否可通过浏览器登录态、截图、手工图片或其他采集器补充；
- 不得用账号其他视频或 caption 猜测图片内容。

### 5. 主风格标签规则

主风格标签的目标是帮助 Pengman 快速判断“这是什么类型、适合哪个账号参考”，不是替代完整分析。

每个账号和每条内容必须输出 **1 个主标签**；确有必要时可再输出最多 **2 个辅助标签**。

第一版使用受控词表，允许按实际样本扩充，但不能让 AI 每次随意发明近义词：

| 标签 | 判断标准 |
|---|---|
| 科普图文 | 以多页图片、文字卡片或 slideshow 解释知识 |
| AI口播 | AI Avatar / AI Host 作为主要讲述者 |
| 真人口播 | 真人正面讲解，表达较完整 |
| 真人自拍 | 手机自拍感强，强调个人身份与即时表达 |
| 素人分享 | 弱品牌感、像普通用户自然发现或推荐 |
| 录屏教程 | 以产品、网站或 App 操作录屏为核心 |
| 产品演示 | 以产品功能、结果或使用前后对比为核心 |
| 热点解读 | 围绕明星、关系、事件或当下热点展开 |
| 情绪B-roll | 实拍氛围素材承载字幕或旁白 |
| AI意象 | AI 生成的人物、星座或情绪意象为主要视觉 |
| 星座卡片 | 固定星座卡、PPT 或简易文字卡轮播 |
| Meme | 使用梗、反应画面或高娱乐表达 |

标签选择原则：

- 主标签描述用户第一眼能识别的主要形式或风格；
- `format_type` 可以保留更细的客观形式，`primary_style_tag` 用于运营筛选；
- 同义标签需要归一，例如 `AI主播`、`AI host` 统一为 `AI口播`；
- 证据不足时写 `待确认`，不要为了填满字段强行归类；
- 标签不能单独决定模仿对象，必须结合 `recommended_account` 和 `account_fit_reason`。
- 标签是 AI 的结构化建议，Pengman 可以人工修正；后续重新分析时不得覆盖已经确认的人工标签。

四账号使用仓库当前口径：

1. AstrologyWiki 官方账号；
2. AI 占星师人设；
3. 热点占星测试；
4. 普通占星爱好者。

## 五、AI 分析要求

AI 不要只回答“视频讲了什么”，而要拆短视频结构。

### 单条内容至少分析

1. 视频主题；
2. 内容类型；视频记录时长，Photo 记录图片数量；
3. 内容表现形式和主风格标签；
4. 开头 hook；
5. 首屏文字或第一帧，如可见；
6. 前 3 秒是否有身份代入 / 好奇缺口 / 情绪刺激；
7. 视频结构；
8. CTA；
9. 可借鉴点；
10. 不适合复制点；
11. 如何改编给当前产品账号；
12. 最适合四账号中的哪个账号，以及原因；
13. 数据缺口。

### Photo / Carousel 额外分析

1. 首图是否单独构成 hook；
2. 图片数量和阅读顺序；
3. 每页文字、画面和信息推进；
4. 最后一页 CTA；
5. 是否属于科普图文、星座卡片、Meme、AI 意象或其他形式；
6. 哪些页面结构可以借鉴，哪些具体图片或文案不能复制。

### 账号至少分析

1. 账号定位；
2. 粉丝和视频规模；
3. 近期内容主题；
4. 主要内容形式；
5. 主风格标签；
6. 表现较好的内容类型；
7. 最适合四账号中的哪个账号参考；
8. 是否值得继续监控；
9. 值得借鉴的方向；
10. 不建议模仿的方向。

## 六、平台数据边界

### TikTok

TikTok 是重点平台，但公开数据不稳定。

第一版要求：

- 能抓多少抓多少；
- 账号页抓不到完整视频列表时，不算失败；
- 允许运营手动补视频直链；
- 单条视频链接优先于账号列表；
- 必须识别 `/photo/` 链接并走 Photo / Carousel 解析流程；
- Photo 帖子优先读取原图、图片顺序、首图文字和 caption；
- 无法直接读取图片时，允许通过飞书 Social 机器人可用的浏览器能力、截图或人工补图完成分析；
- 抓不到字段必须写 `待补数据/待确认`。

### YouTube / Youtube Shorts

YouTube / Youtube Shorts 相对更稳定，适合作为第一版重点。

第一版优先获取：

- 标题；
- 发布时间；
- 播放量；
- 视频链接；
- 频道信息。

likes、comments、retention 如果拿不到，不影响第一版验收。

## 七、技术实现建议

第一版可以用任一方案：

| 环节 | 可选方案 |
|---|---|
| 操作界面 | Google Sheet / 飞书多维表格 / CSV |
| 自动化编排 | n8n / Make / 本地脚本 |
| TikTok 数据 | 飞书 Social 机器人浏览能力 / Apify / 第三方公开采集器 / 页面解析 |
| YouTube 数据 | YouTube Data API / 公开页面解析 |
| AI 分析 | GPT / Claude / Gemini / 通义 / DeepSeek |
| 输出 | Google Sheet 回写 |

优先级：

1. 先做一个最简单的链接输入和结果回写界面；
2. 先做 `P0` 普通视频与 Photo 链接识别、内容分析；
3. 同步输出主风格标签和四账号适配建议；
4. 再做 `P1` 账号链接分析；
5. 最后再考虑自动找账号。

## 八、验收标准

第一版只用一个测试产品验收即可。

### 内容链接分析验收

输入 10 条 TikTok / YouTube 视频链接后：

- 至少 7 条能返回基础公开数据或明确失败原因；
- 每条成功记录能写入 `video_analysis`；
- 每条成功记录至少包含主题、hook、形式、CTA、可借鉴点、不适合复制点；
- 每条成功记录包含 `content_type`、一个 `primary_style_tag`、`recommended_account` 和适配理由；
- 缺失字段有 `待补数据/待确认` 标记。

### TikTok Photo 验收

输入至少 5 条有效 TikTok Photo / Carousel 链接后：

- 5 条都能被正确识别为 Photo / Carousel，而不是普通视频；
- 至少 3 条能返回图片数量、首图 hook、页面结构、CTA 和主风格标签；
- 其余失败记录必须说明失败发生在哪个环节，并给出可执行的补充方式；
- 不得根据 caption 或账号其他内容猜测未读取到的图片；
- 至少用用户提供的 `wealthyastrogirl` Photo 链接做一条验收样本。

### 账号链接分析验收

输入 5 个账号链接后：

- 至少 3 个账号能返回账号概览或明确失败原因；
- 成功记录能写入 `account_analysis`；
- 每个成功账号能输出账号定位、主要主题、主要形式、是否值得继续看；
- 每个成功账号能输出一个主风格标签、推荐参考账号和适配理由；
- 如果无法抓完整视频列表，也要说明原因。

### 表格验收

- 默认表格或记录界面可正常使用；
- `status` 可从 pending 更新为 done / failed；
- 抓取失败有原因；
- AI 输出格式稳定，不是散文。
- 标签使用统一词表，同类样本不会随机出现多个近义标签。
- 上线后对 `account_analysis` 和 `video_analysis` 已有记录补齐主风格标签与账号适配建议；不能覆盖已有人工备注和已确认标签。

## 十、当前结论

这份需求第一版应该收缩成一个“链接分析工具”。

最小可交付不是完整竞品增长系统，而是：

```text
给账号链接 → 出账号分析、主风格标签和四账号适配建议
给普通视频或 Photo 链接 → 出结构化内容分析和主风格标签
分析结果 → 回写默认记录界面
```

只要这一步跑通，后面再扩展自动找账号、批量监控和内容建议。
