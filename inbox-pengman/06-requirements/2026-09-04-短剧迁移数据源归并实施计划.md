# 短剧迁移数据源归并 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Google 历史采集与最新 SQLite 安全归并到正式四表 Base，归并重复剧目，并将合法但无法唯一匹配的发布记录作为可审计 warning 迁移而不猜测关系。

**Architecture:** 扩展现有 Google 只读适配器以输出规范 capture 行，由 `migration.mjs` 对 Google/SQLite account/post 做纯函数归并，并生成 digest-bound `shortdrama-migration/v2` manifest。现有 phased apply、Base 空集合门、canary/权限证据和写后读回保持不变；verify 改为核对两源并集、归并决策和 warning 空关系。

**Tech Stack:** Node.js 24+、`node:test`、`node:sqlite`、Google Sheets API read-only、Feishu Base v3、现有 `shortdrama_ctl.mjs` CLI。

## Global Constraints

- 需求 SSOT 是 `inbox-pengman/06-requirements/2026-08-30-短剧数据采集迁移与发行管理平台需求文档.md`，本次迁移变更以 `inbox-pengman/06-requirements/2026-09-04-短剧迁移数据源归并设计.md` 为准。
- 正式 Base 固定仅四表：`账号台账 / 选剧池 / 采集数据 / 发布记录`，不新增历史表。
- 不修改 Collector Schema、TikTok Daily Metrics、AstrologyWiki Social OS 或其他 Google 流程。
- Google 始终只读；不复制公式，不将凭证写入 manifest、日志、Git 或终端输出。
- `Post ID`、剧 ID、发布 ID 和非空发布 Post claim 必须唯一；`0` 与 `null` 不可互换。
- 不使用剧名模糊匹配或 Post 候选猜测；人工 URL/Post ID 冲突仍致命阻塞。
- 旧 `shortdrama-migration/v1` manifest 不可 apply；所有 v2 证据、warnings 和归并决策进入 canonical SHA-256。
- 本计划代码阶段只执行本地测试和正式 Base 只读 plan。Schema/data/presentation/sequences apply、Hermes 重启、launchd 安装和 Google 只读切换仍需各自动作时确认。

const SOURCE_POLICY = "shortdrama-source-reconciliation/v1";

function mergeMetric(sqliteValue, googleValue) {
  return sqliteValue === null ? googleValue : sqliteValue;

test("v2 manifest binds reconciliation and permits warnings but not blockers", async () => {
  const google = normalizedSource();
  google.releases[0] = { ...google.releases[0], 视频链接: null, "Post ID": null, 日期: "2026-08-25" };
  const manifest = await planMigration(migrationContext({ google, now: () => "2026-09-01T00:00:00Z" }));
  assert.equal(manifest.version, "shortdrama-migration/v2");
  assert.equal(manifest.counts.warnings, manifest.warnings.length);
  const tampered = structuredClone(manifest);
  tampered.warnings[0].reason = "forged";
  await assert.rejects(() => applyMigration({ repos: memoryRepos(), expectedSha256: manifest.sha256, ...schemaGate(manifest) }, tampered),
    (error) => error.code === "migration_digest_mismatch");
  const result = await applyMigration({ repos: memoryRepos(), expectedSha256: manifest.sha256, ...schemaGate(manifest) }, manifest);
  assert.equal(result.status, "applied");
});

test("verify proves the union and pending relations exactly", async () => {
  const google = normalizedSource();

  await applyMigration({ repos, expectedSha256: manifest.sha256, ...schemaGate(manifest) }, manifest);
  const report = await verifyMigration({ repos }, manifest);
