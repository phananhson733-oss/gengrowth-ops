> **完整说明**：详细的系统使用指南见 `00-inbox/系统使用说明.md`

## 📅 每天该做什么？

**每天都可以生产内容**，只是周一侧重选题、周五侧重复盘。节奏灵活，不用卡死。

| 时间 | 重点 | 说什么 |
|------|------|--------|
| **周一（优先）** | 选题 — 锁定本周计划 | "按滚动周 SOP 建本周计划，我有 X 小时" |
| **周一（选题完）** | 有余力就开始生产 | "读本周计划，给我今天的执行卡" |
| **周二-周四** | 生产（Brief → 脚本 → 制作） | "读本周计划，给我今天的执行卡" |
| **周五（优先）** | 复盘 — 整理本周数据 | "整理本周已发布内容的数据复盘" |
| **周五（复盘完）** | 有余力继续生产 | "读本周计划，给我今天的执行卡" |
| **随时** | 热点评估 | "评估这个热点：[链接]" |

## 🆘 常见问题快速解答

### Q: 今天不知道该做什么？

**A:** 直接问 AI：
```
读本周计划，给我今天的执行卡。
我今天有 X 小时。
```

---

### Q: 竞品有条视频爆了，要不要跟？

**A:** 3 步快速决策：
```
1. "调用 gengrowth-social，拆解 [链接] 的 Hook、结构、话题"
2. "评估这个热点，10 分制打分"
3. 如果 ≥8 分，"生成差异化选题"
```

---

### Q: 上周内容表现怎么样？

**A:** 周五复盘：
```
1. 从 Google Sheet 复制本周 8 条数据
2. "调用 social-media-analyzer，分析本周表现"
3. "写 decision/next_test，保存到 digest"
```

---

## 📊 一周节奏

```
周一              周二-周四              周五
选题(优先)        生产                  复盘(优先)
 ↓                                      ↓
选完就生产    Brief→脚本→制作     复盘完继续生产

每天都能生产，选题和复盘各有重点日
```

---

## 🎯 核心原则（记住这 3 条）

1. **周一锁定**：全周选题在周一确定，平时只执行不新增
2. **库存优先**：本周发布上周库存，本周生产下周内容
3. **数据驱动**：每周复盘写 `decision/next_test`，周一自动读取
