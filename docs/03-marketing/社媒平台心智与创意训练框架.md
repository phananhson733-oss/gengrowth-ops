# 社媒平台心智与创意训练框架

关联文档：

1. `docs/03-marketing/01-strategy/GenGrowth整体营销框架.md`
2. `docs/03-marketing/02-social-media/social-media-operations.md`

## 1. 核心结论

跨平台内容不是“同一份内容换长度、比例和标题”，而是：

> 同一个事实与观点，按照用户打开不同平台时的心理动机，重新选择入口、承诺、证据、叙事和行动。

统一公式：

> 平台版本 = 不变的内容内核 × 平台心智 × 用户当下情绪 × 原生叙事方式 × 平台内行为

所有平台版本必须保持事实一致，但允许表达方式完全不同。

### 1.1 不应改变的内容内核

1. 核心事实与数据。
2. 主要结论及其适用边界。
3. 品牌立场和产品真实能力。
4. 证据来源及可信度。
5. 最终业务目标，例如官网访问、Waitlist、咨询或产品使用。

### 1.2 必须按平台重做的部分

1. Hook：用户为什么愿意停下来。
2. Tension：用挑战、焦虑、好奇、身份、问题还是争议切入。
3. Promise：用户看完能得到什么。
4. Evidence：先展示结果、过程、案例、数据还是个人经验。
5. Narrative：内容按什么顺序展开。
6. Tone：口吻是直接、克制、专业、生活化还是社区化。
7. CTA：让用户评论、收藏、讨论、搜索、转发还是点击。

## 2. 国内平台核心内容心智

| 平台  | 一句话心智        | 用户打开平台时想要什么          | 原生内容入口          | 更匹配的内容                 | 主要平台行为         |
| --- | ------------ | -------------------- | --------------- | ---------------------- | -------------- |
| 抖音  | 玩的是即时刺激与年轻挑战 | 快速获得反差、情绪、爽点和参与感     | 先给结果、冲突或异常画面    | 挑战、反差、实验、POV、前后对比、趋势改编 | 停留、完播、评论、跟拍、转发 |
| 视频号 | 玩的是现实焦虑与熟人信任 | 判断某件事是否影响自己、家庭、事业或财富 | 风险、机会、代价、过来人判断  | 现实案例、趋势判断、经验提醒、可信人物讲述  | 转发给熟人、评论、私聊、关注 |
| 小红书 | 玩的是攻略与理想解法   | 找到可以照着做、值得收藏的具体答案    | 人群 + 场景 + 明确结果  | 清单、步骤、避坑、测评、模板、前后对比    | 收藏、搜索、私信、评论求资料 |
| 快手  | 玩的是猎奇猛料与真实见识 | 看真实的人、少见的事和未经修饰的过程   | 真实场景、人物、冲突或意外结果 | 纪实、幕后、反常识、真实操作、人物故事    | 完播、评论、直播互动、关注  |
| B 站 | 玩的是深度讲解与认知获得 | 真正看懂原理、过程和完整证据       | 问题、争议或“为什么”     | 教程、深度拆解、实验、测评、复盘、系列内容  | 长时观看、收藏、投币、追更  |
| 公众号 | 玩的是情感共鸣与长期关系 | 被理解、获得完整判断，并形成对作者的信任 | 场景、故事、冲突或共同感受   | 长文、人物故事、趋势判断、方法论、阶段复盘  | 读完、转发、关注、咨询    |

### 2.1 国内平台改写公式

| 平台 | 推荐结构 |
|---|---|
| 抖音 | 结果或冲突 → 发生了什么 → 关键过程 → 一句判断 → 评论或参与 |
| 视频号 | 现实风险或机会 → 对谁有影响 → 案例或身份背书 → 应对建议 → 转发给相关的人 |
| 小红书 | 明确人群与结果 → 3—7 个步骤 → 截图、清单或模板 → 避坑 → 收藏或私信 |
| 快手 | 真实人物或场景 → 异常过程 → 意外结果 → 直接结论 → 评论交流 |
| B 站 | 核心问题 → 背景与原理 → 完整案例或实验 → 局限 → 结论与下一期 |
| 公众号 | 具体场景或故事 → 情绪张力 → 核心洞察 → 方法框架 → 可执行行动 |

| 平台        | 推荐结构                                         |

| Facebook  | 熟悉的生活或社区问题 → 实用建议或故事 → 共同身份 → 分享、群组讨论或私信     |

## 4. 跨平台改写七步法

### 第一步：先做“内容原子卡”

任何改写开始前，先固定以下内容：

| 字段   | 要回答的问题                |
| ---- | --------------------- |
| 核心事实 | 确定发生了什么，哪些数据已经验证？     |
| 核心观点 | 我们真正想让用户相信什么？         |
| 目标人群 | 这件事首先与谁有关？            |
| 核心张力 | 用户面临的冲突、损失、欲望或好奇是什么？  |
| 证据资产 | 有哪些截图、数据、过程、人物、案例或演示？ |
| 业务目标 | 最终希望用户访问、订阅、咨询还是使用产品？ |
| 表达边界 | 哪些不能夸大，哪些仍只是假设？       |

没有完成内容原子卡，不进入多平台生成。

### 第二步：选择用户打开平台的那个瞬间

不要只写“目标用户是独立开发者”，要写清：

- 他在 TikTok 上想获得快速刺激，还是在 YouTube 上系统解决问题？
- 他在 X 上想参与观点讨论，还是在 Reddit 上寻找真实经验？
- 他在小红书上想收藏一份攻略，还是在视频号上判断一项现实风险？

### 第三步：重写 Hook，而不是翻译标题

同一观点必须从不同心理入口进入：

- 刺激入口：结果、反差、挑战。
- 焦虑入口：代价、风险、错过。
- 攻略入口：步骤、清单、避坑。
- 身份入口：我是谁、我想成为什么样的人。
- 观点入口：鲜明判断、争议、反常识。
- 问题入口：真实经历、求证、开放讨论。
- 搜索入口：明确问题与完整答案。
- 情感入口：场景、人物、共同经历。

### 第四步：按平台重新排列证据

- 短视频平台：先看到结果，再解释过程。
- 攻略平台：先看到可执行步骤，再补原理。
- 深度平台：先定义问题，再完整展示方法和边界。
- 观点平台：先给判断，再给证据和反方条件。
- 社区平台：先交代真实背景，再展示原始过程，最后邀请讨论。
- 视觉收藏平台：先给成品或模板，再把用户带到常青内容页。

### 第五步：改成平台原生叙事

不能只做这些表面变化：

- 长文缩成短文。
- 横版裁成竖版。
- 中文翻译成英文。
- 同一开头替换几个关键词。
- 所有平台使用同一个 CTA。

必须改变的是用户进入内容的理由和消费内容的顺序。

### 第六步：把 CTA 改成平台内自然行为

| 平台行为 | 适合的 CTA |
|---|---|
| 讨论型 | 你会怎么判断？把反例放在评论里。 |
| 收藏型 | 保存这份清单，下次发布前逐项检查。 |
| 搜索型 | 查看完整教程、案例或工具页。 |
| 参与型 | 用同一方法做一次挑战、模仿或对比。 |
| 关系型 | 转发给正在遇到这个问题的人。 |
| 商务型 | 如果你也在解决同类问题，可以进一步交流。 |

平台内 CTA 服务于内容分发，最终业务 CTA 再承接到官网、Waitlist、咨询或产品。

### 第七步：记录改写决策

每个版本必须留下四行记录：

1. 这次选中的平台心智是什么？
2. 为什么采用这个 Hook？
3. 为什么先展示这项证据？
4. 发布后用什么指标判断成立？

## 5. 同一选题的改写示例

示例母题：

> 一稿多发并不等于跨平台分发；同一观点必须按平台用户动机重新包装。

以下仅演示入口差异，不代表已发布或已验证的数据结果。

| 平台 | 示例入口 |
|---|---|
| 抖音 | “同一条内容发 6 个平台，为什么 6 个都没人看？问题不是内容，而是你把 6 群人当成了同一个人。” |
| 视频号 | “团队每天都在做内容，却没有一个平台真正积累信任，可能是从一稿多发开始就做错了。” |
| 小红书 | “同一选题改成 6 个平台版本：这张 Hook、证据、CTA 检查表直接收藏。” |
| 快手 | “我把同一条内容原样发到不同平台，最真实的结果是：每个平台都像广告。” |
| B 站 | “为什么一稿多发通常失效？从平台心智拆解内容分发的完整逻辑。” |
| 公众号 | “我们以为复用内容是在提高效率，后来发现，省掉的恰好是理解用户的那一步。” |
| TikTok | “同一条内容，换 6 个尺寸，依然不会变成 6 条原生内容。”配合快速前后对比。 |
| Instagram | “一套内容内核，如何在不同平台表达不同身份。”用轮播展示 6 种视觉与叙事入口。 |
| YouTube | “我如何把一个选题重写成 6 个平台版本：Hook、证据、结构和 CTA 完整拆解。” |
| X | “一稿多发不是分发，而是忽略场景。平台差异不在格式，在用户为什么打开它。” |
| Reddit | “我曾把同一篇内容机械同步到多个平台，结果都很差。下面是我的改写过程，欢迎指出反例。” |
| Pinterest | “跨平台内容改写检查清单：Hook、承诺、证据、结构、CTA。” |
| LinkedIn | “内容团队效率低，不一定是产能问题，可能是缺少平台级决策规则。” |
| Facebook | “你的团队是否也把同一条内容复制到所有平台？这个社区里哪些改写真正有效？” |

## 6. 训练与复盘闭环

### 6.1 最小训练单元

每次只选一个真实选题，先产出 3 个平台版本，不一次铺满所有平台。

1. 选择一个已有事实和证据的真实选题。
2. 完成内容原子卡。
3. 选择 3 个心智差异明显的平台。
4. 为每个平台写 Hook、结构、证据顺序和 CTA。
5. 逐版解释决策依据，不接受“平台都流行这样”作为唯一理由。
6. 小规模发布，比较平台内指标和最终业务回流。
7. 保留有效规则，删除无效模板。

### 6.2 首轮建议组合

为了验证“平台心智”而不是仅验证文案，优先选择差异明显的组合：

- 海外：`TikTok + Reddit + YouTube`。
- 国内：`抖音 + 小红书 + B 站`。
- GenGrowth 创始人内容：`X + LinkedIn + 公众号`。

### 6.3 当前阶段性分工

目前社媒协同和分工尚未形成正式规范，阶段性安排如下：

| 负责人 | 当前主要职责 |
|---|---|
| 高璇 | 负责 Reddit，以及各平台的 KOC 对接。 |
| 彭满 | 主要负责 TikTok、YouTube，以及视频生成工作流的搭建。 |

### 6.4 复盘指标

| 心智类型      | 优先看什么                  |
| --------- | ---------------------- |
| 即时刺激 / 参与 | 前段停留、完播、分享、参与行为        |
| 攻略 / 收藏   | 收藏、搜索进入、资料请求、外链点击      |
| 深度解决      | 点击率、观看或阅读时长、订阅、回访      |
| 观点 / 讨论   | 有质量的回复、收藏、转发、主页访问      |
| 真实经验 / 社区 | 长评论、追问、正反讨论、社区接受度、引荐访问 |
| 身份 / 向往   | 收藏、分享、主页访问、私信          |
| 情感 / 关系   | 读完、转发、关注、咨询            |
| 专业 / 商务   | 目标人群互动、主页访问、有效对话、线索    |

不能只比较总曝光，因为不同平台的成功行为并不相同。

## 7. 发布前质量闸门

每项计 1 分，低于 5 分不发布：

1. 是否明确写出了平台心智，而不是只写平台名称？
2. Hook 是否符合用户打开该平台时的动机？
3. 证据顺序是否按平台重新组织？
4. 叙事方式是否像平台原生内容，而不是搬运？
5. CTA 是否对应平台内自然行为？
6. 事实、数据、产品能力和表达边界是否与母题一致？
7. 是否定义了发布后要验证的指标？

### 7.1 常见错误

1. 把“平台心智”理解成固定刻板印象，忽略具体垂类和账号阶段。
2. 把视频号的焦虑入口做成恐吓，把 TikTok 的刺激做成无关噱头。
3. 为追求平台感而修改事实、夸大数据或承诺不存在的功能。
4. 一开始就做 10 多个平台版本，导致没有任何一个版本被真实验证。
5. 把所有 CTA 都写成“访问官网”，忽略平台内互动对后续分发的作用。
6. 只记录结果，不记录为什么选择这个 Hook、证据和结构。
