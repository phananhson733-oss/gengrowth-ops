# 海外短剧社媒分发平台合作地图（2026-09）

## 结论

截至 2026-09-02，能够通过公开官方页面确认“允许第三方拿平台剧集素材，在 TikTok、YouTube Shorts、Instagram、Facebook 等社媒推广并按效果分成”的头部或腰部平台，主要是 ReelShort 的 RS Boost 与 FlexTV Alliance；MoboReels 有公开 CPS 招募和机构合作意愿，但缺少可公开核验的完整 CPS 协议、企业/API 政策。DramaBox、GoodShort、NetShort、ShortMax、DramaWave 等虽然平台规模更大或增长更快，公开入口主要是版权发行、内容生产或商务联系，不能据此默认取得社媒剪辑分发权。

因此，早期执行应将“平台规模”和“合作开放度”分开判断：先用开放度高的平台跑出账号、题材、语种和付费数据，再用数据争取头部平台的企业授权、数据接口与预播权。

## 三类合作模式

### 1. 官方 CPS / 达人联盟

平台给剧集素材和专属链接，分销者在社媒发布切片，将用户导回 App 或 H5，按充值、订阅或约定事件分成。门槛低、上线快，适合验证账号和选题；通常不授予整剧托管、独立站播放、批量目录 API 或转授权能力。

代表：RS Boost、FlexTV KOL、MoboReels 个人/团长体系。

### 2. 机构/MCN 渠道合作

平台给机构渠道 ID、子账号、批量素材、对账能力和更高阶分成，可能允许自然流与付费流并行。通常要求账号矩阵、月度量级、反作弊能力和历史转化数据。API 是否开放、可返回哪些字段，取决于单独合同和技术评估。

代表：MoboReels 已公开表达对 MCN/专业发行团队的合作意愿；其他头部平台需要通过商务定向争取。

### 3. 内容授权 / 联合发行

这才是“网站 + SEO + 预播权”的对应模式。合同需明确剧目、地区、语种、期限、免费预播集数、在线播放/嵌入权、SEO 落地页权、素材改编权、目录/播放/归因 API、用户与支付归属、数据回传、下架和版权投诉责任。它与普通 CPS 是两份不同的权利包。

代表：DramaBox、GoodShort、NetShort 等公开的是内容/制作/版权商务入口；能否反向授权其平台剧目给第三方网站，必须逐案谈判。

## 当前建议组合

1. 同时跑 ReelShort RS Boost、MoboReels 团长/达人、FlexTV KOL 三条，不超过三家，统一记录每部剧、语种、账号、播放、点击、安装、首充和 30 日收入。
2. 以 60–90 天为一期，争取至少跑出 2–3 个可复制的“题材 × 语种 × 平台”组合。没有流量时，企业主体不是最重要的筹码，稳定的付费用户和反作弊数据才是。
3. 第二阶段向 MoboReels、NetShort、GoodShort、DramaBox 提交企业试点：先争取 10–20 部剧、1–2 个国家、8–12 周的预播与 SEO 落地页授权，避免一开始要求全库 API。
4. 网站先做索引层、榜单页、剧情介绍、演员/题材页和官方深链，不自行托管平台正片；拿到书面预播权和播放器/API 后再上线视频。

## 权利核验红线

- 有 CPS 链接，不代表有网站播放权。
- 有素材下载，不代表允许去水印、重配音、长片段拼接或投放广告。
- 有“团长”资格，不代表可以把版权和素材再授权给下游公司或站群。
- 第三方聚合平台声称合作，不等于获得平台官方授权；至少索取授权链、剧目清单、区域/语种/期限和结算主体证明。

## 附录：ReelShort 二级渠道与 AdSense 风险判断（2026-09-07）

### 1. 文件效力与解释前提

合作方提供的专项条款要求所有拟合作的二级第三方平台、机构或推广团队事先报备并经审核；未获审核者不得接触合作内容、推广数据、归因链接、推广素材或其他业务资源。专项条款还限定资源仅用于 ReelShort 项目推广和收益结算，禁止将其作为独立经营产品向第三方出售、转授权、出租、共享或开展其他商业合作。

该专项条款比公开 RS Boost 服务协议更严格。公开协议原则上允许在合法的自选网站、页面、App 或其他线上媒体传播广告素材和推广链接，但同时禁止将通过服务获得的信息或内容用于销售、商业开发，或向第三方提供使用。因此，自建 CPS 推广网站原则上属于可接受的推广媒介；是否允许同时接入 AdSense，不能由公开协议直接推出，需以专项协议的定义、文件效力顺序和平台书面确认决定。

### 2. 二级渠道识别口径

判断重点不是对方叫个人、KOC、机构还是“合作伙伴”，而是是否为合同主体之外的独立第三方，以及是否接触或控制 ReelShort 资源。

| 场景 | 建议口径 |
|---|---|
| 合同主体的员工使用公司自有账号、设备和后台，公司统一发素材、收数据、结算 | 原则上主张属于内部执行人员，不是二级渠道；仍应让平台书面确认 |
| 独立 KOC 使用自己的社媒账号，取得素材、归因链接或按结果结算 | 高概率属于二级渠道 |
| MCN、代理公司或推广团队取得素材/链接后组织旗下 KOC 发布 | 机构本身及其实际执行网络均在条款覆盖范围内；需谈批量名单机制 |
| 外包剪辑、翻译、数据或建站服务商能够接触平台素材、API 或推广数据 | 即使不直接发帖，也可能构成分包商或数据处理方，至少应按第三方服务商报备 |
| 普通用户自发转发公开页面或推广链接，没有合同、后台权限或结算关系 | 通常不应视为合作二级渠道 |

不能通过把 KOC 统一称为“内部团队”、只提供一个机构名称或不披露实际控制人来规避报备。条款明确要求实际控制人和数据处理方式，故完全匿名报备很难成立。

### 3. 可落地的报备机制

不建议要求删除事前审批，而应把逐人审批改成“准入标准预审 + 批量滚动报备 + 异议机制”：

1. 附件预先批准三类渠道：公司内部账号、签约个人创作者、审核通过的 MCN/机构。
2. 只报项目必需字段：渠道 ID、主体类型、实际控制人、国家/平台、账号 URL、素材/API/数据访问级别、启用与停用日期；不报非本项目客户名单、商务报价、分成和资源关系。
3. 每周或每月提交增量名单；约定平台在两个工作日内提出书面异议，逾期视为同意。若平台不接受默示同意，则要求提供 API/表格批量审批和明确 SLA。
4. 公司对二级渠道实行同等义务穿透：保密、版权、数据、广告披露、反作弊、停止合作后的删除；公司承担第一责任并保留日志。
5. 平台对报备资料承担保密和用途限制，只能用于合规审核、反作弊与争议处理；不得绕过合作方直接招揽、签约或以报备信息开展其他商业用途。争取 12–24 个月不绕行/不招揽期。
6. API、原始素材和汇总后台不直接开放给 KOC；使用子渠道 ID、最小权限、动态水印、到期撤权和操作日志降低平台顾虑。

建议补充条款：

> 经平台预先书面确认的渠道类型及准入标准列于附件。合作伙伴可按约定模板批量新增符合标准的二级渠道，平台应在收到完整资料后两个工作日内完成审核或提出书面异议；逾期未回复视为审核通过。合作伙伴无需披露与本项目无关的客户名单、报价、分成或其他商业资源。平台应将报备信息仅用于本项目合规、反作弊及争议处理，未经合作伙伴书面同意不得用于直接招揽、绕行合作或其他商业用途。

还应明确：合同主体的员工及完全由合同主体控制的自有账号是否排除在“二级渠道”之外；MCN 是否可以按机构加准入规则整体审批，还是必须穿透到每个账号和实际执行者。

### 4. CPS 网站接入 AdSense 的风险

风险结论为中高。网站本身若只承载获批素材、官方归因链接并用于拉新，符合公开协议允许的线上媒体方向；但在展示 API 素材的同一页面接入 AdSense，会形成 ReelShort CPS 与 Google 广告收入两种商业目的，可能被专项条款解释为把合作资源用于“其他商业合作”或经营性产品。AdSense 还会通过广告代码、Cookie、IP 地址等处理访客信息，应纳入二级渠道报备中的数据处理方式和第三方服务商清单。

同时，Google 不允许在仅复制或嵌入他人内容、缺少原创评论、策展或其他增值内容的页面投放广告，也不允许在侵权内容或以 framing 方式展示他人内容的页面投放广告。即使 ReelShort 同意 CPS 使用，纯 API 批量生成的剧目页仍可能因低价值/复制内容不符合 AdSense 政策。

| 页面方案 | 合同风险 | AdSense 风险 | 建议 |
|---|---|---|---|
| API 海报、简介、视频或预播为主体，同页放 AdSense | 高 | 高 | 未获书面豁免前不要上线广告 |
| 原创剧情解读、榜单、评论为主体，仅使用少量获批素材和官方 CPS 深链，同页放少量广告 | 中 | 中 | 仍先取得平台书面批准，并保证原创增值内容明显占主导 |
| ReelShort/API 推广页完全无广告；独立的原创编辑页投放 AdSense，页面不使用受限 API 素材 | 低 | 低至中 | 最稳妥的早期架构 |

### 5. 建议的技术与合同隔离

1. 将获批域名、子域名和页面路径写入合作附件。
2. `/reelshort/` 等 API 推广页面关闭 AdSense，只展示推广所需信息和官方归因链接；原创内容区再单独投放广告。
3. API 密钥和原始响应只留在服务端，不向 Google、KOC 或其他第三方传输；不将 ReelShort 用户级归因、订单或后台数据用于广告定向。
4. 页面必须有实质原创内容、版权/推广关系披露、隐私政策和 Cookie 说明；针对 EEA、英国、瑞士流量使用 Google 认证 CMP。
5. 若坚持同页投放广告，先取得专项书面豁免，未确认前不启用；若已经启用，先暂停受限页面广告，再向平台披露并申请追认。

建议补充的 AdSense 豁免条款：

> 平台同意合作伙伴在经备案的自有推广网站使用 Google AdSense 等程序化广告服务。前述使用在同时满足以下条件时，不视为本条所称独立经营产品、出售、转授权、出租、共享或其他第三方商业合作：广告不嵌入或覆盖 ReelShort 播放器及推广素材；合作伙伴不向广告服务商提供平台 API 原始数据、归因数据、后台信息或用户级业务数据；不对平台内容单独收费或许可；页面仍以 ReelShort 推广和官方归因链接为主要目的；广告服务商仅按其标准广告与隐私机制处理访问数据。获批域名及广告版位见附件。

如果平台不接受该豁免，执行底线是：所有含 ReelShort API 数据、推广素材或预播内容的页面不展示 AdSense；广告仅放在不使用受限资源的原创编辑页面。

### 6. 对平台的沟通方式
