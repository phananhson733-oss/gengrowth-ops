# X 发帖稿 · 暴跌不等于降权

## 单条版（274 字符）

```
A new site that drops 90% hasn't necessarily been demoted.

Compare the query set before and after — not the rankings.

Broad queries gone, exact-match long tail surviving → a new-site boost expiring.
Same queries sitting 40 spots lower → an actual demotion.

Different fixes.
```

## Thread 版（4 条）

**1/**
```
A site launches in April. By early June it's doing 12-15k impressions a day. On June 7 it drops 90%.

The instinct is to ask how to get it back.

That may be the wrong question.
```

**2/**
```
A two-month-old site doing 12-15k impressions a day was plausibly still inside the window where Google shows a new site more than it has earned, then re-evaluates.

If that's what ended, recovery isn't the target. The post-drop number may be the baseline it actually earned.
```

**3/**
```
You can tell the two apart, and it isn't by looking at position.

Export the query set from before the drop and from last week.

Compare the sets themselves, not the rankings.
```

**4/**
```
Broad queries you never really competed for are gone, exact-match long tail survived → the boost expired. Grow from there.

Same queries still present, forty positions lower → an actual demotion. Different problem, different fix.

Checking which one you have costs one export.
```
