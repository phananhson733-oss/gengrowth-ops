# 页面审计指标规范 v1

## 一、评分体系

### 1.1 两个数，不是一个

```
健康度  71 / 100        🔴 阻断项  1
```

| 概念 | 定义 | 显示规则 |
|---|---|---|
| **阻断项** | 会导致页面**无法被索引或无法参与排名**的问题 | 红色，任何 >0 时提到主位 |
| **健康度** | 加权通过率，0–100 | **阻断项 >0 时灰显**，但仍显示数值 |

**为什么两个数**：对标 Okara 时实测到一个自相矛盾——它给出 `On-Page Score 100`，同一面板下却列着 3 个 Warning。**单一总分会掩盖问题。**

### 1.2 三条硬规则

1. **阻断项 > 0 时，健康度灰显**，但**保留数值**（用户需要知道修完阻断项后大概处在什么水平）
2. **不显示 100 分** —— 最高显示 99。满分只在"所有项通过且无待接入引擎项"时出现
3. **每个扣分项必须可点开**，展示：实测值 · 阈值 · 影响 · 怎么改。**分数不可解释就是噪音**

### 1.3 分组权重

按「对能否拿到流量的影响」排，**不按检查项数量**：

| # | 组 | 权重 | 说明 |
|---|---|---:|---|
| 1 | 索引与可抓取 | **阻断制** | 不参与加权 |
| 9 | 搜索机会 | 25% | 决定这页值不值得投入 |
| 2 | TDK | 20% | 直接影响点击 |
| 4 | 内容 | 15% | |
| 6 | 链接 | 15% | 孤岛页 = 白写 |
| 3 | 标题结构 | 10% | |
| 8 | 性能 | 8% | |
| 7 | 结构化数据 | 4% | |
| 5 | 图片 | 3% | |

**组内得分 = Σ(通过项权重) ÷ Σ(全部项权重) × 100**
**健康度 = Σ(组得分 × 组权重)**，性能组未接入时按剩余权重归一化。

### 1.4 判定级别

| 级别 | 含义 | 扣分 |
|---|---|---|
| 🔴 **阻断** | 页面无法被索引/排名 | 不扣分，单独计数 |
| ⚠️ **警告** | 明确影响表现，应该修 | 该项计 0 分 |
| 💡 **提示** | 可优化，不紧急 | 该项计 50% |
| ✅ **通过** | — | 满分 |
| ○ **未接入** | 引擎未就绪 | 排除出加权 |

## 二、九组检查项明细

### 🔴 组 1 · 索引与可抓取（阻断制）

| # | 检查项 | 阈值 | 未达标级别 | 数据来源 | 引擎 |
|---|---|---|---|---|---|
| 1.1 | HTTP 状态码 | 200 | 🔴 阻断 | HTTP 响应 | ✅ P0-4 |
| 1.2 | robots.txt 是否放行 | 允许抓取 | 🔴 阻断 | robots.txt 解析 | ✅ P0-4 |
| 1.3 | `noindex` 标签 | 不存在 | 🔴 阻断 | meta robots / X-Robots-Tag | ✅ P0-4 |
| 1.4 | Canonical 目标 | 自指或指向 200 页面 | 指向 404 → 🔴 阻断<br>指向他页 → ⚠️ 警告 | HTML head | ✅ P0-4 |
| 1.5 | 是否在 sitemap 中 | 是 | ⚠️ 警告 | sitemap.xml | ✅ P0-4 |
| 1.6 | 跳转链长度 | ≤ 1 跳 | ≥2 跳 → ⚠️<br>终点非 200 → 🔴 阻断 | 跟随跳转 | ✅ P0-4 |
| 1.7 | hreflang 目标有效性 | 全部返回 200 | 指向 404 → 🔴 阻断 | HTML head + 逐个请求 | ✅ P0-4 |
| 1.8 | 软 404 检测 | 非 200+空壳 | 🔴 阻断 | 状态码 + 内容长度 | ⚠️ 需补 |

> **这一组决定"这页存不存在"，所以唯一能产生阻断项。**
> **我们自己站上出现过其中四种**：308→404（1.6）、hreflang 指向 404（1.7）、全站软 404（1.8）、canonical 到列表页（1.4）。

### 组 2 · TDK（权重 20%）

| # | 检查项 | 阈值 | 未达标级别 | 引擎 |
|---|---|---|---|---|
| 2.1 | Title 长度 | 30–60 字符 | ⚠️ 警告 | ✅ P0-4 |
| 2.2 | Title 全站唯一 | 唯一 | ⚠️ 警告 | ✅ P0-4 |
| 2.3 | **Title 含主词** | 包含 | ⚠️ **警告（组内双倍权重）** | ❌ **需补** |
| 2.4 | Meta description 长度 | 120–158 字符 | 💡 提示 | ✅ P0-4 |
| 2.5 | Meta description 全站唯一 | 唯一 | ⚠️ 警告 | ✅ P0-4 |
| 2.6 | Open Graph 三项 | og:title / og:description / og:image | 💡 提示 | ⚠️ 需补 |

> **2.3 给双倍权重**：我们自己吃过两次亏——P0-5 落地页主词全页出现 **0 次**；P0-3 的 Title 被换成自造产品名 `SEO Traffic Drop Diagnosis`，丢了主词。
> **实施依赖**：需要页面绑定"目标词"。这来自左栏的「目标关键词」文档。

### 组 3 · 标题结构（权重 10%）

| # | 检查项 | 阈值 | 未达标级别 | 引擎 |
|---|---|---|---|---|
| 3.1 | H1 数量 | 恰好 1 | ⚠️ 警告 | ✅ P0-4 |
| 3.2 | H1 含主词或近义 | 包含 | 💡 提示 | ❌ 需补 |
| 3.3 | H 层级无跳级 | H1→H2→H3 连续 | 💡 提示 | ⚠️ 需补 |
| 3.4 | H2 数量 | 5–8 | 💡 提示 | ✅ P0-4 |
| 3.5 | H3 数量 | 15–25 | 💡 提示 | ✅ P0-4 |
| 3.6 | **每个 H3 下平均字数** | ≥ 80 词 | <50 → ⚠️ 警告<br>50–79 → 💡 提示 | ❌ **需补（计算成本极低）** |

> **3.6 是我们独有的检查，两个对标都没有。** 依据：P0-4 落地页有 **27 个 H3 但全页仅 935 词**，平均每标题 35 词。**只数 H3 个数会给出"结构良好"的错误结论。**

### 组 4 · 内容（权重 15%）

| # | 检查项 | 阈值 | 未达标级别 | 引擎 |

| 4.5 | 与站内其他页相似度 | < 70% | ≥70% → ⚠️ 警告 | ⚠️ P0-4 有重复检测，需接入 |

> ⚠️ **4.5 有假阳性历史**：P0-4 在 astrologywiki 上报出的 105 个重复标题**全部是假阳性**（canonical、sitemap、内链、实际收录四者一致）。**接入前必须先排除已 canonical 收敛的情况。**

### 组 8 · 性能（权重 8%）❌ 引擎未接

| # | 检查项 | 阈值 | 数据来源 |
|---|---|---|---|
| 8.1 | **LCP** | <2.5s 良好 · 2.5–4.0s 待改进 · >4.0s 差 | CrUX / PageSpeed Insights API |
| 8.2 | **INP** | <200ms 良好 · 200–500ms 待改进 · >500ms 差 | 同上 |
| 8.3 | **CLS** | <0.1 良好 · 0.1–0.25 待改进 · >0.25 差 | 同上 |
| 8.4 | TTFB | < 800ms | HTTP 响应计时 |
| 8.5 | 页面总体积 | < 2MB | 资源统计 |
| 8.6 | 渲染阻塞资源数 | 0 | Lighthouse |

> 🔴 **口径必须在界面上分开标注：**
> **CWV（8.1–8.3）是 CrUX 真实用户数据、第 75 百分位、28 天滚动窗口；Lighthouse 是实验室模拟。两者会不一致。**

>
> **实施建议**：接 PageSpeed Insights API（免费），一次调用同时返回 CrUX 字段和 Lighthouse 字段，**分开渲染**。

### ⭐ 组 9 · 搜索机会（权重 25%）—— 两个对标都没有

| # | 检查项 | 判定 | 依据 | 引擎 |
|---|---|---|---|---|
| 9.1 | **目标词是否被 AI Overview 完整覆盖** | 是 → ⚠️ **警告：排上去也拿不到点击** | astrologywiki 实测：9 词中 6 个被覆盖，**1,330 曝光 → 1 次点击** | ❌ 需 SERP 抓取 |
| 9.2 | 前十有无近两年注册的域名 | 无 → 扣分 | 选词规则三问 | ❌ 需 SERP 抓取 |
| 9.3 | 前十有无十万月访以下的站 | 无 → 扣分 | 同上 | ❌ 需 SERP 抓取 |
| 9.4 | 有无 UGC 位（Reddit/Quora/Medium） | 无 → 扣分 | 同上 | ❌ 需 SERP 抓取 |
| 9.5 | 当前排名区间 | 1–6 最佳 · 7–10 低点击区 · 11+ 无效 | 2026 基准：7–10 带 CTR 仅 0.65–0.78% | ✅ GSC |

> **9.2–9.4 三问全否 = 赛道锁死**，该词不该作为该页主词。
> **跨行业验证**：`bmi calculator`（哈佛 1985/梅奥）· `qr code generator`（Canva 822M/Adobe 1986）· `ascendant calculator`（前七 381K–10M，零新进入者）——三个行业规律一致。
> **反例**：`humanize ai text` 第 2 名域名注册于 **2025-09**，压过 31.39M 月访的 QuillBot。**所以这不是"工具词一律锁死"，是竞争者密度问题。**
