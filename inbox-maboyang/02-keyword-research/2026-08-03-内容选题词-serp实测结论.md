## 一、⭐ 本轮发现的规律（⚠️ 已被 08-04 实测修正，见文末）

把 9 个词的成败排在一起，在**教学型查询**里规律很清楚：

> **主词如果是某个大厂 SEO 工具的「功能名」，教学型 SERP 就被锁死；如果是「概念 / 方法 / 争议」而不是功能，就有缝。**

| 词 | 是不是大厂工具的功能 | 结果 |
|---|---|---|
| content gap analysis | ✅ Ahrefs / Semrush 的 Content Gap 功能 | ❌ |
| how to fix keyword cannibalization | ✅ Semrush 的检测功能、Yoast 的核心卖点 | ❌ |
| internal linking best practices | ✅ 几乎所有 SEO 工具都有内链模块 | ❌ |
| long tail keyword research | ✅ 关键词工具的核心功能 | ❌ |
| site architecture seo | ✅ 技术 SEO 工具的功能 | ❌ |
| **pagerank sculpting** | ❌ **不是任何工具的功能**（是被 Google 否定过的历史手法） | ✅ |
| **zero search volume keywords** | ❌ **不是功能，是个策略争议** | ✅ |
| **how to find low hanging fruit keywords** | ⚠️ 半功能半概念 | ✅ |

**为什么在教学型查询里成立**：大厂对自己产品功能对应的词，会同时投入产品页 + 博客 + 帮助文档 + 视频，形成完整覆盖。**教学型 SERP 是他们内容营销的主场。** 而概念型、历史型、争议型的词对大厂没有商业价值，他们不会重点投入。

### ⚠️ 1.1 这条规律不完整 —— 08-04 实测的修正

**次日实测发现：被否决的词换一个查询形态，有一半能救回来。**

| 主题 | 教学型 | 工具型 | 结果 |
|---|---|---|---|
| keyword cannibalization | ❌ Semrush + Yoast 锁死 | ✅✅ **域名 2025-06 的站排第 2，Semrush 掉到第 6** | **救回** |
| content gap | ❌ Semrush + Backlinko + Ahrefs | ✅✅ 前七有 4 个中小站 | **救回** |
| internal link | ❌ 前八 DR76-99 | ❌ 前七 DR73-99 | 救不回 |
| seo audit | ❌ 品类 KD76-94 | ❌ 前九 DR73-92 | 救不回 |

**所以「是不是功能名」不是分界线，真正的分界线是：**

> **这个功能有多少家在免费提供。**
>
> - **标配免费工具**（站点审计、内链检查、速度测试、Title 检查）→ 几十家 DR70+ 拿它当获客入口 → ❌ 换形态也救不回
> - **专门功能**（关键词自噬检测、内容缺口对比，需要接 GSC 或做竞品对比）→ 单独做的人少 → ✅ 工具型查询有缝

**完整实测见 `02-keyword-research/2026-08-04-工具型与替代型serp实测.md`。**

### 1.2 这条规律的正确用法

**教学型选题时**，先问：这个词是不是 Ahrefs / Semrush / Moz 某个功能的名字？

- **不是** → 值得花 5 分钟验 SERP
- **是** → 教学型大概率打不动，但**别直接扔**，先判断它是标配功能还是专门功能：
  - 专门功能 → **改验工具型 / 替代型查询**，很可能能救回
  - 标配功能 → 直接换词

> 📌 这也解释了我们之前的两个教训：
> - `internal link audit` KD5 但前八全 DR 76–99 —— **它是标配免费工具**，所以工具型查询同样打不动（08-04 已验证）
> - `all in one seo` KD9 但被 DR75+ 霸屏 —— 它就是一个插件的名字

### 2.4 ⚠️ how to fix orphan pages（200 / KD16）—— 可写，但优先级中等

**SERP 构成**：Sitebulb、Botify、conductor.com、Semrush 等工具商为主，夹着 **Reddit r/TechSEO、Quora 两个 UGC 位**和 **thewayhow.com 一个小站**。

**有缝，但不宽。** 而且 SERP 顶部有 Videos 区（3 条 YouTube）、中部有 Discussions 区，**自然结果的可见位置被明显压缩**。

**一个正面因素**：相关搜索全是 `screaming frog / semrush / ahrefs orphan pages`——**用户意图是"想用工具解决"**。这对我们是好事，文章可以自然导向 P0-2。

**建议**：排在前三篇之后。

### 2.5 ❌ how to fix keyword cannibalization（600 / KD11）

**前二是 Semrush（DR92）和 Yoast（DR89）**，其余是 SmartSites、SplitMetrics、Databox 等有规模的工具商/代理。**只有 Reddit 一个 UGC 位。**

而且这个 SERP 被 **Videos 区 + Discussions 区 + "What people are saying" 区**三个板块挤压，自然结果的空间很小。

**KD11 是假象。** 这是本轮第五次遇到 KD 低但 SERP 被锁死的情况。

### 2.6 ❌ site architecture seo（600 / KD37）

前六：Semrush、Backlinko、Yotpo、Search Engine Land、Real Estate Webmasters、lumar.io——**全部是大站或工具商**。第 7 才是 Reddit，第 8、9 才出现小站。

**前六位被锁死，KD37 也偏高。**

### 2.7 ❌ content gap analysis（1,000 / KD35）

**Semrush（第1）+ Backlinko（第2）+ Ahrefs（第8）三大厂霸屏**，中间是 Heretto、Yotpo、manus.im、WG Content。只有 Reddit 一个 UGC 位。

**红海，KD35 名副其实。**

## 三、2.2 集群页主词重选 —— 两个候选也失败，建议改变策略

### 3.1 本轮候选的实测结果

| 候选 | SERP 实况 | 判定 |
|---|---|---|
| `internal linking best practices` | 前六 **全是 DR81–100**：Yoast(89)、Semrush(92)、Moz(91)、Google官方文档、Siteimprove(81)。第 7 才有一个小站 | ❌ **比原候选 `internal link analysis` 还难** |
| `long tail keyword research` | 前八里**五个是关键词工具商**（keyword.io、keywordtool.io、keywordspeopleuse.com 等），Semrush 第 1、Ahrefs 第 7 | ❌ 工具商霸屏 |

### 3.2 这不是候选选得不好，是集群页这个思路在当前阶段有结构性问题

**集群页（Pillar）的价值，在于用一个「更宽的词」把下面的文章聚合起来。**

但第一节那条规律说明：**越宽的词，越可能是大厂工具的功能名，越被锁死。**

我们已经连续否决了四个集群候选：

```
seo content strategy    → 被 Google / HubSpot / Semrush 通吃
internal link analysis  → 前七全是工具商
internal linking best practices → 前六全 DR81-100
long tail keyword research      → 工具商霸屏
```

**这不是运气问题，是 DR=0 阶段的结构性约束。**

### 3.3 建议：集群页暂缓，先用可打的单篇文章形成「事实集群」

**理由**：为一个我们拿不到排名的词建一个 Pillar 页，是在给一个空位置搭结构。投入产出比极低。

**替代方案**：

1. **先写三篇已验证可打的文章**（low hanging fruit / zero search volume / pagerank sculpting）
2. **三篇之间做内链**，形成事实上的主题聚合，但**不设 Pillar 页、不占 `/guides/` 的 slug**
3. **等 DR 上升后再回来建集群页**——那时现在打不动的宽词会陆续变得可打

**主纲领 5.4 的集群页结构规范不受影响**，可以先按结构开发前端，slug 留空。

> 这与 90 天计划「不同时铺六个话题簇，DR=0 阶段打透一个的收益远大于铺六个」是一致的。

### 3.4 如果一定要现在定集群主词

按第一节的规律，候选应该往**概念型而非功能型**找。可考虑的方向（**均需先查 Ahrefs 拿 Parent / KD / Volume，再验 SERP**）：

- 内链方向：`link equity`、`crawl budget optimization`
- 关键词方向：`keyword difficulty accuracy`、`search intent mismatch`

**注意这些只是方向，没有任何数据支撑，不要直接采用。**

## 六、方法论沉淀（累计）

**到目前为止，SERP 实测已推翻的词：**

| 轮次 | 验证词数 | 被推翻 | 推翻率 |
|---|---:|---:|---:|
| 工具页主词（7/31） | 8 | 4 | 50% |
| **内容选题词（8/03）** | **9** | **5** | **56%** |
| **累计** | **17** | **9** | **53%** |

**超过一半的词经不起 SERP 检验。** 这个比例稳定出现在两轮完全不同的选词中。

**结论：SERP 验证不是可选步骤，是必需步骤。** 写一篇文章的成本，远高于查一次 SERP 的 5 分钟。

**筛选顺序**（已并入 08-04 的修正，KD 和量级仍放最后）：

```
0. 意图对不对？              ← website architecture checker 是意图错配，不是竞争问题
1. 这个功能有多少家在免费提供？
     标配免费工具 → 直接换词
     专门功能    → 继续往下
2. 查询形态能不能换？
     教学型被锁 → 试工具型 / 替代型
3. Parent ＝ 自身
4. SERP 前十有低权重站
5. KD < 30
6. 量级
```

**并行判断**：

```
· 自然排名打不动的词，看一眼 AI Overview 里有没有小站
  有 → 该词可进 GEO prompt 组，走 AI 引用而非自然排名
```
