# 工具页内容辐射关键词分析 — 实验五候选

## 一、实验四复盘：为什么这批词被遗漏

### 根本原因：一个错误的筛选逻辑

初期关键词研究犯了一个逻辑错误：

**旧逻辑（错误）：** 大站出现在 SERP → KD 高 → 跳过

**正确逻辑：** 大站靠内容权威自然排进来，无主动外链建设 → KD 停在 0-4 → 反而是机会

这个区别只有跑 Ahrefs 才能发现。纯目测 SERP，看到 astrology.com / cafeastrology 排在第一页，会直觉性地认为竞争激烈，从而跳过。实验四的核心发现正是：**大站出现 ≠ 高竞争，KD 才是判断竞争强度的真实依据。**

### 第二个原因：研究框架的视角盲区

初期的研究框架（工具页词根挖掘）聚焦在工具页本身的命名和 URL slug 优化上，没有系统地问：

> **每个工具页，向外能辐射哪些"解读型"内容关键词？**

解读型内容词（如 `venus in gemini`、`aries rising meaning`）和工具在同一语义场内，天然适合做 crawl-bait 短文内链回工具，但在工具页 SEO 视角下容易被忽视——因为它们不是工具页本身的关键词，而是工具页的内容卫星。

## 二、可复制的机会：现有工具页内容辐射词

实验四验证的模式（[Planet] in [Sign] → birth-chart-calculator）可以套用在以下工具上：

---

### 机会一：Rising Sign Calculator → `[Sign] Rising` 解读词

**关键词形态：**
- `aries rising`
- `taurus rising appearance`
- `scorpio rising meaning`
- `[sign] rising personality / traits / physical appearance`

**词根规模：** 12 个星座 × 2-3 个变体 ≈ 30-40 条

**为什么值得做：**
- 和实验四完全同构：大站（cafeastrology、astro.com）自然排进来，但 KD 预计 0-5
- Rising sign 是占星入门高频话题，搜索意图极纯粹（用户想知道自己的上升星座意味着什么）
- 每篇文章 CTA 指向 rising-sign-calculator，转化路径最短
- 内容格式标准化，可以直接复制实验四的生产流程

**需要 Ahrefs 验证的词（抽样）：**

| 关键词                      | 预期 KD | 预期 Volume |
| ------------------------ | ----- | --------- |
| aries rising             | 0     | 3.4K      |
| scorpio rising           | 12    | 9.5K      |
| taurus rising appearance | 0     | 700       |
| libra rising             | N/A   | 0         |

**优先级：P0 — 结构最像实验四，验证成本最低**

---

### 机会二：Synastry Calculator → `[Planet] conjunct/trine/square [Planet] synastry` 解读词

**关键词形态：**
- `venus conjunct mars synastry`
- `moon square sun synastry`
- `saturn trine venus synastry`
- `[planet] [aspect] [planet] synastry meaning`

**词根规模：** 主要行星（7个）× 主要相位（5个：合/三分/六分/四分/对分）× 常见行星组合 ≈ 50-80 条

**为什么值得做：**
- 合盘解读是占星搜索中流量最大的品类之一
- 搜索意图非常纯粹（找某个相位含义），内容格式极度标准化
- 量级预计比 [Planet] in [Sign] 更大（合盘话题受众广）
- CTA 指向 synastry-calculator，承接路径清晰

**注意事项：**
- 词根数量多，需先抽样验证 KD 模式再批量展开
- 优先验证热门组合：venus conjunct mars / moon conjunct sun / venus trine mars

**优先级：P1 — 量级更大但词根数量多，需先抽样**

---

### 机会三：Solar Return Calculator → `solar return [Planet] in [Sign]` 解读词

**关键词形态：**
- `solar return moon in scorpio`
- `solar return venus in cancer`
- `solar return sun in virgo`
- `solar return [planet] in [sign] meaning`

**词根规模：** 主要行星（7个）× 12 个星座 ≈ 84 条

**为什么值得做：**
- 搜索意图明确：用户已知 solar return 概念，在找具体行星位置的含义
- 内容格式标准化，每篇指向 solar-return-calculator
- 每年有时效性需求激增（生日前后搜索高峰）

**注意事项：**
- 量级预计偏小（solar return 比 natal chart 小众）
- 优先验证量较大的行星位置：sun、moon、venus

**优先级：P2 — 量级偏小，排在前两个之后**

### 3.2 P1 Synastry — KD 全 0 但 Volume 不达标 ⚠️

| 关键词 | KD | Volume（US） | 结论 |
|---|---|---|---|
| venus conjunct mars synastry | 0 | 450 | ⚠️（差 50 未达 500）|
| venus trine mars synastry | 0 | 300 | ❌ |
| venus opposite mars synastry | 0 | 250 | ❌ |
| moon conjunct sun synastry | 0 | 150 | ❌ |
| saturn conjunct venus synastry | 0 | 150 | ❌ |
| moon square sun synastry | 0 | 90 | ❌ |

**结论：** 当前抽样词的 Volume 全部低于门槛。KD=0 有吸引力，但量级不支撑批量生产。

**待判断：** 是否需要补查更热门的合盘词组合（如 `sun conjunct moon synastry`、`venus conjunct venus synastry`、`mars conjunct mars synastry`）？这批词可能是低频组合，热门组合量级或更高。

**结论：Drop，不进入实验五生产计划。**
