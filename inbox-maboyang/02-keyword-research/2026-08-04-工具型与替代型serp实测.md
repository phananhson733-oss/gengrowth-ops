## 一、最强的一组对照：同一个主题，教学型 ❌ → 工具型 ✅✅

`keyword cannibalization` 昨天以「教学型」形态被否决，今天以「工具型」形态通过。**同一个主题，两个 SERP 完全不同。**

| 1 | **Semrush**（DR92） | Sitechecker（572K 月访 / 2016） |
| 2 | **Yoast**（DR89） | **geoptie.com（34.7K 月访 / 域名 2025-06-17）** ⭐⭐⭐ |

| 4 | SmartSites | **SERPninja（34.5K / 2017）** ⭐ |
| 5 | SplitMetrics | Reddit |
| 6 | Databox | **Semrush**（掉到第 6） |
| 7 | — | Rows |

| **判定** | ❌ Semrush + Yoast 锁死前二 | ✅✅ **一个注册一年出头的域名排第 2** |

**`content gap analysis` → `content gap analysis tool` 是同样的对照**（昨天已实测）。

**这两组对照直接证明了这个假设。**

## 二、⚠️ 但换 SERP 类型救不回所有词

| 主题 | 教学型 / 概念型 | 工具型 | 救回了吗 |
|---|---|---|---|
| keyword cannibalization | ❌ | ✅✅ | **✅ 救回** |
| content gap | ❌ | ✅✅ | **✅ 救回** |
| internal link | ❌（前八 DR76-99） | ❌（前七 DR73-99） | ❌ 救不回 |
| seo audit | ❌（品类 KD76-94） | ❌（前九 DR73-92） | ❌ 救不回 |
| site architecture | ❌ | ❌ 意图错配 | ❌ 救不回 |

### 2.1 分界线不是「教学 vs 工具」，是「标配功能 vs 专门功能」

看救不回的那三个的共同点：

**`internal link checker` 和 `free seo audit tool` 是「标配免费工具」** —— 几乎每一家 SEO 工具站都把免费内链检查、免费站点审计当作获客入口。所以有**几十家 DR 70–90 的工具站在抢同一个词**。

**`keyword cannibalization checker` 和 `content gap analysis tool` 是「专门功能」** —— 需要接 GSC 数据或做竞品对比，门槛稍高，单独做的人少。

**所以修正后的规律是：**

> **看这个功能有多少家在免费提供。**
>
> - **标配免费工具**（站点审计、内链检查、速度测试、Title 检查）→ 几十家 DR70+ 在抢 → ❌
> - **专门功能工具**（关键词自噬检测、内容缺口对比、GSC 数据分析）→ 做的人少 → ✅ 有缝

### 2.2 `free seo audit tool` 的否决，反过来确认了一个既有判断

前九全是 DR 73–92 的成熟工具站，**无论概念词还是工具词，SEO 审计品类都被锁死**。

**这确认了我们之前定的「P0-4 不承担获客」是对的**，不用再为它找词。

### 2.3 `website architecture checker` 是意图错配，不是竞争问题

前四名里两个是**技术栈识别**工具（BuiltWith、Wappalyzer），两三个是**设计阶段画站点图**的工具（PowerMapper、Octopus.do、FlowMapp）。

**这个词的主流意图是「看这网站用什么技术做的」或「设计新站时画结构图」，不是 SEO 审计。** 跟 P0-2 不匹配。

**这类失败要单独归类**——不是打不过，是根本不该打。

## 三、⭐ 意外发现：AI Overview 的准入门槛低于自然排名

这是本轮**战略价值最高**的观察。

在 `internal link checker` 这个自然结果被 **DR 73–99 完全锁死**的 SERP 里，AI Overview 引用了这些站：

```
Sitechecker、NextGrowthLabs、webaloha.co、zerply.ai、DNS Robot、RecoveryTools
```

**其中 webaloha.co、zerply.ai、NextGrowthLabs 这些小站，一个都没进自然结果前七——但进了 AI Overview。**

### 3.1 这直接印证了我们记录过的那个观察

> "AI 引用率高的基本也是高意图工具词，直接引用内容词的情况比较少。"

这个观察此前一直是**未经验证的一手感受**，推广方案里也据此把 GEO 降为"探索轨"。

**现在有了第一个实证：同一个 SERP 上，自然排名门槛是 DR73+，AI Overview 的门槛明显更低。**

### 3.2 战略含义

**「自然排名打不动」和「AI 引用拿不到」是两件事。**

对 `internal link checker`、`free seo audit tool` 这类被 DR 锁死的词——

- ❌ 追自然排名：确认无望
- ✅ **争 AI Overview 引用：可能有位置**

**这给推广方案里 GEO 那条线提供了一个具体的、可测的切入点**：不是泛泛地"提高 AI 可见度"，而是**挑那些自然排名打不动、但 AI Overview 里有小站的词，专门做 AI 可提取的内容**。

> ⚠️ **但这仍然是一个观察，不是方法论。** 我们还是不知道"做什么能让 AI 引用我们"。建议：**把这批词加进 GEO 基线的 30 个 prompt 里**，两周复测时就能看出有没有变化。

## 四、替代型词：可能是集群页的答案

`semrush alternatives`（3,600/KD12）和 `ahrefs alternative`（600/KD10）都可打。

### 4.1 SERP 形态

两者高度一致：**竞品工具商 + UGC 位 + 中小内容站**，没有绝对垄断。

`ahrefs alternative`：**Reddit 排第 1**（140+ 评论），behindrankings.com、cotera.co、OneLittleWeb 三个中小站在前九。

`semrush alternatives`：Reddit + Quora 两个 UGC 位，OneLittleWeb 第 3，**一篇 Medium 文章排第 5**——Medium 文章能进前五，说明这个 SERP 对非权威域名开放。

### 4.2 为什么大厂在这类词上不占优（结构性原因）

1. 大厂的产品页只能推自己，**做不了横评**
2. 大厂**不会写"替代我们的产品"**
3. 这类 SERP 天然容纳中小内容站

**注意 `semrush alternatives` 前四里 SE Ranking 和 SpyFu 都是竞品工具商——他们正是靠这个位置抢 Semrush 的用户。这个打法是被验证过的。**

### 4.3 建议：用替代型词做集群页

我们已经连续否决了**四个**集群候选（seo content strategy / internal link analysis / internal linking best practices / long tail keyword research），原因是"越宽的词越被大厂锁死"。

**`semrush alternatives` 可能是解**：

| 集群页要求 | `semrush alternatives` 是否满足 |
|---|---|
| 量级够大 | ✅ 3,600（比我们六个工具主词可打部分加起来还大） |
| SERP 可进 | ✅ Reddit 第 1、Medium 第 5、中小站多个 |
| 能自然聚合下游内容 | ✅ **天然可以链向我们每一个工具页** |
| 与工具页主词不自噬 | ✅ 完全不重叠 |

**形态**：一篇诚实的横评 Pillar 页，下面挂各个工具页和文章。

## 五、⚠️ 两个必须守住的前提

### 5.1 我们得真有那个功能

写「Best Content Gap Analysis Tools」把自己列进去，前提是我们真做这件事。

**好消息**：P0-5 关键词机会地图明确支持"输入用户网站 URL + 竞品网站 URL，发现关键词机会和内容缺口"——**这就是 content gap 分析**。所以 `content gap analysis tool` 与我们的功能是匹配的。

**`keyword cannibalization checker` 我们目前没有**，属于已记录但未开发的工具。要用这个词，得先做这个功能。

### 5.2 横评的利益冲突风险

如果我们写「最好的内链工具」并把自己排第一，这是明显的自利内容。

**而且我们刚做完的产品评审结论是：三个工具都停在观测、没有走到判断。** 在这个状态下写"我们比 Semrush 好"，**拿到 Reddit 会被撕**。

**能用的版本是诚实横评**：把自己列进去，如实写局限，甚至指出竞品在哪些方面更好。

这与已经定下的"在 r/SEO 用失败案例帖而非工具介绍帖"是同一个路子——**坦诚比吹嘘有用**。

## 六、累计的筛选规则（已按本轮更新）

```
0. 意图对不对？           ← 新增。website architecture checker 是意图错配，不是竞争问题
1. 这个功能有多少家在免费提供？  ← 本轮修正（原为"是不是大厂功能名"）
     标配免费工具 → 直接换
     专门功能   → 继续查
2. 查询形态能不能换？        ← 新增
     教学型被锁 → 试工具型 / 替代型
3. Parent ＝ 自身
4. SERP 前十有低权重站
5. KD < 30
6. 量级
```

**另外新增一条并行判断**：

```
· 自然排名打不动的词，看一眼 AI Overview 里有没有小站
  有 → 该词可进 GEO prompt 组，走 AI 引用而非自然排名
```
