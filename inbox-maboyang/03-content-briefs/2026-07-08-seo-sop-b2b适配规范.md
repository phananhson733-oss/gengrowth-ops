# SEO SOP B2B 适配规范

> 本文件以 unifab.ai B2C 打法为基准，系统说明 B2B 工业品场景下哪些规则直接复用、哪些需要改造、哪些是 B2B 独有。适用于 brdeco 类多语言、多站点、B2B 工业品客户。

---

## 一、核心差异：决策结构决定流量路径

| 维度 | B2C（unifab 基准）| B2B（brdeco 适配）|
|---|---|---|
| 决策者 | 个人，1 人决定 | 采购经理 + 工程师 + 财务，3–5 人决策链 |
| 决策周期 | 分钟到天 | 周到月 |
| 驱动力 | 功能 + 情感 | 合规 + 技术参数 + 价格 |
| 转化终点 | 直接购买 / 注册 | 询盘 → 报价 → 合同 |
| 关键词量级 | 万级，追搜索量 | 百级，追精准度 |
| 内容风险 | 低（无法被专业人士证伪）| 高（工程师会核验参数和认证）|

---

## 二、直接复用的规则（无需改动）

以下 B2C 补丁规则在 B2B 场景下逻辑相同，直接执行：

| 规则 | 来源补丁 |
|---|---|
| 产品页 URL 挂根目录，.htm 或简洁路径 | 补丁一 |
| 首页 H2 不放具体产品关键词，防止自噬 | 补丁一 |
| H1 = 核心词 + 规格极限 + 差异化点 | 补丁二 |
| Blog H2 按读者认知进度排列 | 补丁二 |
| 竞品对比文章，统一 T1，含功能差异矩阵 | 补丁四 |
| 每篇 blog ≥2 条产品页内链，功能描述锚文本 | 补丁三 |
| 产品页底部反向推荐相关 blog 4 条 | 补丁三 |
| FAQ schema，8–10 个问题，≤300 字符 | 补丁二 |
| GEO 三动作（robots.txt / 直接答案句 / Organization schema）| 补丁七 |

## 三、需要改造的规则

### 3.1 CTA 设计：从"立即下载"到"进入询盘漏斗"

B2B 用户不在网站上直接购买，所有 CTA 的目标是获取联系方式或触发询盘。

**三级 CTA 对应三种访客意图：**

```
研究阶段 → [ Download Spec Sheet ]
            触发：PDF 规格表，设置 email / 姓名 / 公司门控
            目标：获取潜在客户信息，判断资格

比较阶段 → [ Request a Quote ]
            触发：报价表单（含项目描述字段）
            目标：进入销售报价流程

决策阶段 → [ Contact Our Engineer ]
            触发：WhatsApp 直连 / 联系表单
            目标：直接进入工程顾问对话
```

**禁止在 B2B 产品页使用的 CTA：**
- "Buy Now"（B2B 工业品无法在线直接购买）
- 显示具体价格（B2B 定价按项目定制，显示价格会造成误导）

---

### 3.2 嵌入教程模块：从"How to Use"到"How to Specify"

B2C 教程模块是操作软件的步骤，B2B 模块是**产品选型和规格确认的步骤**。

**B2B 版模块结构：**

```
[H3] How to Specify [产品名] for [应用场景]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: 确定合规要求
        → 防火等级（EN 13501-1 / 本地标准）
        → 适用认证（SIRIM / SASO / FM Approvals）

Step 2: 根据性能目标选择规格
        → 所需 U 值 / λ 值范围
        → 推荐厚度区间（如 100mm / 150mm / 200mm）

Step 3: 确认本地交付条件
        → 属地子公司覆盖（马来西亚 / 沙特 / 印尼）
        → 安装服务可用性

Step 4: 获取项目定制方案
[ Contact Our Engineer → ]    [ Download Technical Guide → ]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**brdeco 适配示例（数据中心场景）：**

```
[H3] How to Specify Rockwool Panels for Your Data Center Project

Step 1: 确认防火等级要求
        数据中心机房墙面标准配置：A1 不燃等级（EN 13501-1）
        100mm 厚岩棉夹芯板可达该标准

Step 2: 确认隔热性能目标
        数据中心围护 U 值推荐：≤0.35 W/m²K
        对应 BRDECO 岩棉板厚度选型：100–150mm

Step 3: 确认本地认证要求
        马来西亚：SIRIM 认证 + BOMBA 消防规范
        沙特：SASO 建材标准

Step 4: 获取项目定制报价
[ Contact Our Engineer ]    [ Download Spec Sheet ]
```

**注意：** Step 内的技术参数必须来自客户提供的产品规格文件，不能由 AI 生成。详见胜任评估报告第五节。

---

### 3.3 Lead Capture 弹窗：从"邮件订阅"到"技术资料门控"

B2B 用户愿意提供更多信息换取真正有价值的技术文档，且填写公司和职位让销售团队可以直接做资格判断。

**B2B 版弹窗设计：**

```
[弹窗标题] Download Our Technical Product Guide
[副标题]   Complete specifications, fire ratings & installation
           guidelines for sandwich panels

[表单字段]
姓名
公司名称
职位（工程师 / 采购 / 项目经理 / 其他）
邮箱
WhatsApp（可选）
项目国家

[CTA] Send Me the Guide →

[小字] We'll also send occasional project insights.
       Unsubscribe anytime.
```

**触发时机：**
- 用户滚动至 blog 文章 80% 位置
- 用户在产品页停留超过 90 秒
- 不在首页触发

**与 B2C 的关键差异：**
- B2C 钩子 = 内容（每周运势）
- B2B 钩子 = 工具（技术规格文件），门控获取更高质量 leads

---

### 3.4 信任信号：从"媒体评分"到"认证 + 项目"

B2B 工程师不看媒体评测，看认证证书和真实项目数据。

**三层信任信号布局：**

```
页面顶部：合规信任
  [SIRIM 认证 logo]  [FM Approvals]  [CE 标志]  [EN 13501 A1]

页面中部：能力信任
  PDG Johor 数据中心 18,000㎡ 案例（含照片 + 规格 + 交付周期）
  参数对比表（自家产品 vs 行业标准 vs 竞品）

页面底部：专业信任
  工程师署名内容（"Tim Huang, CEO · 数据中心项目案例"）
  项目地图（80+ 国家交付记录）
```

---

### 3.5 关键词策略：低量高价，不追搜索量

**B2B 关键词判断标准：**

| 标准 | B2C | B2B |
|---|---|---|
| 最低月搜索量门槛 | 500+（T2）/ 1000+（T1）| 无门槛，50 条精准搜索 > 5000 条泛搜索 |
| 核心判断维度 | 搜索量 + KD | 搜索意图是否为采购 / 技术选型 |
| 最高价值关键词类型 | 竞品词 / 信息词 | 规格词 + 合规词 + 场景词 + 地区词 |

**brdeco 高价值关键词示例（量低但每条询盘价值 $10,000+）：**
- "rockwool panel data center malaysia"（月搜约 50）
- "SIRIM certified sandwich panel supplier"（月搜约 30）
- "cold room insulation panel -18°C specification"（月搜约 40）
- "A1 fire rated panel for server room"（月搜约 60）

## 四、B2B 独有内容类型

以下内容类型在 B2C unifab 打法中不存在，是 B2B 专属：

### 4.1 技术规格页

**定位：** 采购阶段的核心决策参考页，覆盖规格词和认证词。

```
URL: /rockwool-sandwich-panel-specifications
H1: Rockwool Sandwich Panel Specifications — A1 Fire-Rated, 50–200mm

核心内容区块：
- 产品参数表（λ值 / U值 / 防火等级 / 厚度范围 / 面板规格）
- 认证证书展示（SIRIM / SASO / FM / CE）
- 适用温度范围和应用场景
- 与同类材料（EPS / PU / PIR）的参数对比表

CTA: [ Download Full Spec Sheet ]  [ Request a Quote ]
```

**注意：** 所有参数必须来自客户提供的产品规格文件。

---

### 4.2 应用场景页

**定位：** 覆盖场景词，引入垂直行业流量，建立"场景专家"定位。

```
URL: /cold-room-insulation-solutions
H1: Cold Room Insulation Solutions — From -40°C Freeze to +10°C Chill

覆盖的场景子页面：
/data-center-panel-solutions       ← 数据中心
/cold-room-panel-solutions         ← 冷库 / 冷链
/cleanroom-panel-solutions         ← 洁净室
/pharmaceutical-storage-insulation ← 医药仓储
```

每个场景页需包含：该场景的温度要求 + 防火等级要求 + 推荐产品规格 + 相关项目案例。

---

### 4.3 地区合规页

**定位：** 覆盖"[地区] + 认证 / 合规 / 供应商"类关键词，本地化流量精准。

```
URL: /malaysia-sirim-certified-panel
H1: SIRIM Certified Sandwich Panels for Malaysia Projects

内容：
- SIRIM 认证要求说明（来自官方标准，需客户核实）
- BRDECO 马来西亚认证证书展示
- 马来西亚 BOMBA 消防规范适配说明
- 马来西亚本地子公司联系方式
- 本地交付案例（Johor / KL 区域项目）

CTA: [ Contact Malaysia Office ]  [ Download SIRIM Certificate ]
```

覆盖地区：马来西亚（SIRIM）/ 沙特（SASO）/ 日本（JIS）/ 印尼 / 全球（CE / FM）。

---

### 4.4 项目案例页

**定位：** B2B 最重要的信任建立内容，是采购决策者的核心参考。

```
URL: /projects/pdg-johor-data-center
H1: PDG Johor Data Center — 18,000㎡ Rockwool Panel Delivery

案例页必须包含：
- 项目规模（面积 / 用量）
- 客户类型（不一定要具名，可写"全球 TOP10 数据中心运营商"）
- 应用产品和规格（具体型号 + 厚度 + 防火等级）
- 项目挑战和解决方案（技术叙事）
- 交付周期和安装方式
- 项目现场照片（高质量，含施工和完工对比）

CTA: [ View Similar Projects ]  [ Discuss Your Project ]
```

---

### 4.5 选型对比页

**定位：** 在买家材料对比决策阶段拦截流量，覆盖"X vs Y"对比词。

```
URL: /rockwool-vs-pu-vs-eps-sandwich-panel
H1: Rockwool vs PU vs EPS vs PIR Sandwich Panel: Which Is Right for Your Project?

对比维度（必须用真实参数数据）：
- 导热系数（λ值）
- 防火等级
- 适用温度范围
- 承载能力
- 适合场景（数据中心 / 冷库 / 洁净室 / 工业厂房）
- 价格区间（相对高低，不需要绝对数值）
- 各国认证覆盖

结论：
"Choose Rockwool if: 防火等级 A1 是必须条件，数据中心 / 高防火场景"
"Choose PU/PIR if: 最高隔热效率优先，冷库 / 冷链场景"
"Choose EPS if: 预算优先，一般工业厂房场景"
```

## 五、B2B 内容类型优先级矩阵

| 内容类型 | 优先级 | 定级 | 原因 |
|---|---|---|---|
| 选型对比页（EPS vs PIR vs Rockwool）| P0 | T1 | 覆盖决策阶段高意图词，直接产生询盘 |
| 竞品对比文章（Kingspan vs BRDECO）| P0 | T1 | 拦截竞品调研流量，转化率高 |
| 应用场景页（数据中心 / 冷库）| P0 | T1 | 覆盖场景词，建立垂直权威 |
| 技术规格页 | P1 | T1 | 采购阶段必查页面，需 SME 审核 |
| 地区合规页 | P1 | T1 | 覆盖本地化精准词 |
| 项目案例页 | P1 | T1 | 建立能力信任，需真实客户数据 |
| 技术教程 blog（如何计算 U 值）| P2 | T2 | 流量辅助，建立工程师信任 |
| 行业概念 blog（什么是夹芯板）| P3 | T3 | 上层流量，转化率最低 |

## 六、内容生产前置条件（B2B 必须）

B2B 技术内容不能由 AI 独立生成，必须获取以下客户资料后才能生产：

| 资料类型 | 用途 | 无法替代的原因 |
|---|---|---|
| 产品技术规格表 | 填入参数数据 | AI 编造的 λ值 / U值会被工程师识破 |
| 现有认证证书（含有效期）| 合规内容来源 | 认证标准持续更新，AI 训练数据可能过时 |
| 真实项目案例数据 | 案例页内容 | 数字和规模无法核验，专业买家会追问 |
| 各市场本地规范要求 | 地区合规页内容 | 各国标准不同，需权威来源 |

**如果客户无法提供上述资料，只能生产 P3 级别的上层概念内容，不能生产 P0/P1 级别的技术内容。**

## 七、B2B 完整转化链路

```
用户搜索技术词 / 合规词 / 场景词
        ↓
进入 blog / 规格页 / 场景页（冷流量）
        ↓
遭遇嵌入选型模块（How to Specify）
        ↓
高意图用户 ──→ [ Contact Our Engineer ] → 进入销售对话
        ↓
中意图用户 ──→ [ Download Spec Sheet ] → 填写姓名/公司/职位/邮箱
                                          → 进入 email 培育序列
        ↓
低意图用户继续阅读至末尾
        ↓
触发 Lead Capture 弹窗（技术手册 PDF 门控）
        ↓
获取 leads → 销售团队跟进判断资格
        ↓
资格确认 → 项目报价 → 合同签订
```

## 八、与 B2C 补丁的对照总表

| 模块 | B2C（unifab 补丁）| B2B（本规范）|
|---|---|---|
| 主 CTA | Free Download | Download Spec Sheet |
| 次 CTA | Buy Now | Request a Quote / Contact Engineer |
| 教程模块 H3 | How to Use（操作步骤）| How to Specify（选型步骤）|
| 教程模块 CTA | 下载按钮（Windows/macOS 分支）| 联系工程师 + 下载规格表 |
| Lead 弹窗钩子 | 内容（每周运势邮件）| 工具（技术手册 PDF）|
| 弹窗表单字段 | 仅 email | 姓名 + 公司 + 职位 + 邮箱 + WhatsApp |
| 信任信号顶部 | 媒体评测（Trustpilot / Guru99）| 认证证书（SIRIM / FM / CE）|
| 信任信号中部 | 功能对比 / 演示 | 项目案例 + 参数对比表 |
| 信任信号底部 | 用户星级评价 | 项目照片 + 工程师署名 |
| 关键词量级门槛 | 月搜 500+ | 无门槛，精准度优先 |
| 独有内容类型 | 竞品评测、操作教程 | 规格页、案例页、地区合规页、场景页、选型对比页 |
| 内容生产模式 | AI 生成框架 + 人工润色 | AI 生成框架 + 客户数据注入 + SME 技术审核 |
| 转化终点 | 直接购买 / 注册 | 询盘 → 销售对话 → 项目报价 → 合同 |
