## 三、核心洞察：为什么世界杯内容 2–3 天出排名

世界杯预测文 CTR 9.1%，排名进前 15，**不是因为我们 DR 高，是因为那个查询发文前几乎不存在。**

Google 有 QDF 机制（Query Deserves Freshness）：对新生查询，不依赖权威积累，谁先写谁排。

| | 趋势词 | 竞争词 |
|--|--------|--------|
| 竞争页面 | 近 0 | 数万 |
| 出排名时间 | 2–3 天 | 6–18 个月 |
| 流量寿命 | 3–7 天 | 永久积累 |
| 依赖 DR | **不依赖** | 高度依赖 |

**这就是 3 个月路径的核心逻辑：我们不跟强手正面竞争，只打还没有人写的词。**

## 四、3 个月路径：趋势内容系统

每天识别 3–5 个热点词（搜索量刚起来、竞争近零），当日发文，社媒同步放大。

**UV 累积模型：**

```
每篇趋势文：发布后 3 天内约带来 200 UV
每天发 5 篇 → 当天新产出 1,000 UV
稳定运转 20 天 → 同时约 15 篇在峰值期 → 3,000 UV/天
持续 + 社媒放大 → 5,000 UV/天可期
```

**核心竞争力：速度。** 热点出现到文章上线必须当天完成，慢了竞争对手就进来了。

**已验证的热点类型：**
- 赛事占星预测（世界杯决赛预测文已跑通）
- 运动员/明星星盘（Bellingham、Yamal、Bueckers）
- 重大事件星盘解读（颁奖、选举、发布会）
