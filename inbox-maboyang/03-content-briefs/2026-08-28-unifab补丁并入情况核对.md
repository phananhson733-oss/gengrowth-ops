# unifab 补丁并入情况核对

新 SOP 的 `改造来源` 列了四份文档（v2.3 流程 / 变量预处理器 / System Prompt v4.5.2 / blog优化更新规范），**没有列这份补丁**。核对结果：20 条里实际并入 3 条。

## 一、已并入（3 条）

| 补丁 | 内容 | 落在哪 |
|---|---|---|
| 二（部分） | FAQ 8–10 条、答案 ≤300 字符 | SOP 七节 |
| 二（部分） | Direct Answer Block 结论先行 | 状态机 State 3 第 2 项 |
| 三（部分） | 内链锚文本必须描述性、不堆文末 | SOP 五节 + 状态机 State 2 |

补丁三只并入了一半：**数量与位置规则变形了**。

```
补丁三原文   每篇 ≥3 条，正文前 20%（首屏内）必须有第一条 + 中段 + 结尾
新 SOP      精修线 3–5 条 / 量产线 1–2 条，「分布在正文中，不要全堆在文末」
```

「前 20% 必须有第一条」这条最关键的位置约束没进去；量产线 1–2 条低于补丁下限。

## 二、该并未并（8 条）

这些是站型无关的通用规则，dramashortstv 同样适用：

| 补丁 | 内容 | 为什么该补 |
|---|---|---|
| **九** | 锚文本三维分布：精确 20–30% / 部分匹配 40–50% / 自然描述 20–30%；整站精确锚文本 ≤ 总页数 10% | 现在只规定「描述性」，没有比例。长期单一锚文本会触发过度优化 |
| **十一** | 单页总出链 ≤ 15 条（含组件卡片 + 相关文章） | 现在只有下限没有上限 |
| **十四** | 跨集群出链 ≤ 20%，须强语义关联 | 六类内容之间（演员页 ↔ App 档案页 ↔ 对比测评）正是跨集群场景，无约束会稀释主题信号 |
| **十** | nofollow 内链传语义不传 PageRank；组件链接不能替代正文静态链接 | 站上大量推荐卡是组件链接，这条直接影响内链审计怎么算 |
| **十七** | 数据化反差标题公式（第 5 种） | 新 SOP 各模板都写「标题三选一」，但没有公式库 |
| **一·动作二** | **Person schema 四字段**（knowsAbout / alumniOf / sameAs / worksFor），文章 author 指向 Person 而非 Organization | 🔴 **最该补的一条**。演员图鉴是主力内容类型，而 8-28 刚发布的那篇 blog schema 里 `author` 就是 `{"@type":"Organization"}` |
| **十五** | Core Web Vitals：LCP <2.5s / CLS <0.1 / FCP <1.8s / INP <200ms；LCP+CLS 不达标不得上线 | 新 SOP 完全没有技术验收项 |
| **十六** | 移动端触点 ≥48px、正文 ≥16px、行高 ≥1.5 | 同上 |

补充：**字数目标**新 SOP 一处都没有（补丁二给了 T1 4,000–6,000 / T2 2,000–3,000）。dramashortstv 用六类模板代替 T1/T2，需要按类型重定，不能照抄。

## 三、不适用（9 条）· 不建议并入

补丁是给 astrologywiki 写的——**那是工具站**（星盘计算器），dramashortstv 是内容/片库站，没有工具页。以下与工具站强绑定：

| 补丁 | 为什么不适用 |
|---|---|
| 三（工具页部分） | 没有工具页。等价物是剧集页 / App 档案页，需重新定义链接目标 |
| **五** | 嵌入产品教程模块（Step 1/2/3 + 免费试用按钮）——前提是有工具可演示 |
| 六 | Blog 末尾收 email 弹窗——dramashortstv 转化目标是导向 App / 剧集，不是邮件序列。**若确定要做邮件，这条要重新评估** |
| 七 · 八 | 工具页 H2 策略 / 工具落地页转化架构 / 版本日志 / Hero 信任横幅 / Upsell —— 整节工具页专属 |
| 一·动作三 | HowTo schema——没有操作流程可标 |
| 一·动作五 | Ask AI 按钮——品牌查询预填，短剧站没有对应的品牌问答场景 |
| 十二 · 十三 · 十八 · 十九 · 二十 | 内链审计/孤岛修复/锚文本集中注入/审计工具组合——**方法本身适用**，但依赖 Req 5 扫描等 astrologywiki 基础设施，且属于运维 SOP 不属于写作 SOP。建议单独立一份内链审计 SOP，不塞进写作流程 |

## 四、一条需要重写而非并入

**补丁四（竞品对比文章）** 给了 9 段完整结构：快速结论 / 竞品介绍 / 真实测试数据 / 定价对比 / 优缺点表格 / 功能差异矩阵 / 教程模块 / 二选一结论句 / FAQ。

新 SOP 4.3「对比测评」只有三句：

> 结构同 4.2，额外加一节「四问核查」，以及「与竞品同款内容的差异化说明」

缺了补丁四里最有价值的三项：**定价对比 / 功能差异矩阵（含「竞品有但我方没有」的诚实列举）/ 明确的二选一结论句**。对比测评是六类内容之一，这节太薄。

去掉工具站专属的「教程模块」一段，其余 8 段可直接用。
