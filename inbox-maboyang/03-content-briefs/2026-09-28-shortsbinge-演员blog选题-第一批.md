# ShortsBinge 演员 blog 选题 · 第一批

## 结论

**可以现在就写，不用等演员详情页上线。** 前提是 blog 和将来的演员页分工清楚：

| | 瞄准的词 | 内容形态 |
|---|---|---|
| **blog（现在写）** | "某某 movies / movies and tv shows" 这类片单词 | 编辑型导读：从哪部开始看、按题材分组、角色类型怎么变 |
| **演员页（下周排期）** | 演员名本身、"某某 reelshort" | 全量片单，自动生成 |

演员页上线后，blog 链到演员页，演员页也链回 blog，两边不抢同一个词。

## 写作规则

1. **只写能核实的信息**：演员表以本站剧集页和 IMDb 为准。不编角色名，不编剧情。
2. **不碰私人信息和成人向词**：Semrush 里有 "某某 age / wife / husband" 以及成人向的搜索词，**一律不写、不作标题、不作 FAQ**。这些不是我们的内容方向，也有隐私风险。
3. **每篇的落点要对读者有用**：告诉读者从哪部开始看、按什么题材分类、哪几部完结了、能免费看几集。不写成演员八卦。
4. **"演员 A vs 演员 B"不做**：这次没有找到有搜索量的例子。

## 数据局限

- **片库扫描不完整**：695 部英文剧只扫到了 497 部，其中只有 140 部页面上写了演员。**每位演员的在库剧目可能有遗漏**。动笔前请用站内搜索按演员名再查一遍。
- 扫到的剧 99% 是 ReelShort 出品（493/497），只有 4 部是 DramaBox，所以第一批演员都是 ReelShort 系的。
- 搜索量和 KD 来自 Semrush 美国库；Google 搜索结果每个词只在 2026-09-28 看过一次。
