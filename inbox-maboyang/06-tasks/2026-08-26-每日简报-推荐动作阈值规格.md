# Today's recommended actions · 阈值规格

## 一、两类任务

| 类型 | 每日条数 |
|---|---|
| **触发式**（数据事件，五类） | 0–3 条。**没有就不给，不要凑数** |
| **常规**（固定节奏，带状态） | 1–2 条 |

---

## 二、触发式任务 · 五类

**五类分开实现、分开展示。动作不同，混成一条会让用户做错事。**

| 类 | 信号 | 阈值 | 动作 |
|---|---|---|---|
| **C** | 曝光骤降 | 曝光较上期降 ≥80% 或归零，且原月曝光 ≥100 | 查页面是否还在、能否打开、canonical 指向哪 |
| **A** | 排名下降 | 预估月点击损失 ≥ 20 次 | 优化该 query 对应的页面 |
| **D** | 同类相食 | 同一 query 下 ≥2 个 page 有曝光，且都未进前十 | 留排名最好的，其余改意图或下架 |
| **B** | CTR 异常 | 实际 CTR < 基准CTR[位次] × 0.5，且月曝光 ≥200 | 去看该 SERP 现在长什么样 |
| **E** 🟢 | 新词进前十 | 位次首次 ≤6 | 加码：补内链、加深度、接工具页 |

**排序即上表顺序。** C 最紧急（可能是技术故障）；E 为正向，每日最多 1 条且不占 A–D 的 3 条配额。

### A 类的损失公式

```
预估月点击损失 = 该 query 月曝光 × (CTR[原位次] − CTR[现位次]) / 100
```

CTR 取值见附表，位 11+ 记 0。

对照：

| 变化 | 月曝光 | 预估损失 | 是否触发 |
|---|---:|---:|---|
| 1 → 2 | 10,000 | 约 2,110 次 | ✅ |
| 10 → 11 | 50 | 不到 1 次 | ❌ |

**不要用「掉出第一页」当判据**——第 10 名只有 1.6% 的点击，1→2 掉的是 21.1 个百分点。

## 三、常规任务 · 八类

**每条带进度或时距，不要只显示待办。** 排序即下表顺序（按改动成本 ÷ 预期收益）。

| 任务 | 阈值 / 节奏 | 状态显示示例 | 数据来源 |
|---|---|---|---|
| **高曝光零点击** | 30 天曝光 ≥200 且点击 = 0 | 3 个页面 30 天曝光 >200、点击 0 | GSC page × query |
| **上移机会** | 位次 4–10 且有真实曝光 | 8 个词排在 4–10 位 | GSC query |
| **新页内链** | 发布后 7 天入链数 = 0 | 2 个新页无入链 | 站内爬取 |
| **新页收录** | 发布后 14 天未收录 | 5 个页面 14 天未收录 | GSC / `site:` |
| **写前查重** | 待写词与已有页前十重合 >50% | 3 个待写词与已有页冲突 | SERP 抓取 |
| **内容产出** | 每日 | 本周已发 3 / 7 篇 | sitemap / CMS |
| **外链** | 每周 | 本月新增 2 个 dofollow RD | 外链工具 |
| **竞品调研** | 距上次 ≥14 天 | 上次调研 12 天前 | 手动打卡 |

**上移机会取 4–10 位，不取 11–20 位**：`11→10` 最多 +1.6 个百分点，`2→1` 是 +21.1。价值集中在头部三名。

## 四、通用口径

| # | 规则 |
|---|---|
| 1 | 数据粒度 **query × page**，不是 page。**页面均位是曝光加权的**，长尾词进来会拉低均值，不代表排名掉了 |
| 2 | 时间窗用**连续两个 7 天**（D-14~D-8 vs D-7~D-1），两窗都下降才触发。不要日对日——GSC 最后一天有约 34% 回填 |
| 3 | 所有判据用**绝对值**，不用占比 |
| 4 | CTR 曲线做成**可配置常量**，不要写死——基准每年都在变 |
| 5 | 每条动作要给出计算依据（原位次 → 现位次、曝光、预估损失） |

## 五、验收

| 样本 | 期望 |
|---|---|
| 均位下降但所有 query 排名未变 | 不触发 |
| 50 次曝光、10→11 | 不触发 |
| 10,000 次曝光、1→2 | 触发 A |
| 单日下降、次日回升 | 不触发 |
| 排第 5、实际 CTR 1.8%、月曝光 500 | 触发 **B**，不得归为 A |
| 原月曝光 300 → 本期 0 | 触发 **C**，排在 A 之前 |
| 原月曝光 30 → 本期 0 | 不触发（基数太小） |
| 同一 query 下 3 个 page 都有曝光、都未进前十 | 触发 **D**，动作是「留一个」不是「优化」 |
| 某 query 首次进入第 5 位 | 触发 **E**，不占 A–D 配额 |
