# 短剧新站 · 域名候选清单

**前提：词根定为 `drama shorts`，不是 `short drama`。**
美国月搜 3.6K vs 2.4K，且 `drama shorts` 的美英澳加占其全球量 75%，而 `short drama` 的量 93.6% 在印度/印尼/菲律宾。目标既然是欧美，用错词根等于放弃 75% 的需求。

| 域名                    | 现状                                                         | 出价上限建议                   |
| --------------------- | ---------------------------------------------------------- | ------------------------ |
| **`dramashorts.com`** | GoDaddy 公开挂牌，**只能出价、无标价**                                  | 🔴 **$2,000 封顶**。超过就放弃   |
| `dramashorts.tv`      | 2024-05 注册于 GoDaddy，**当前跳 parklogic 停放页**（域名投资人持有，非在运营的竞品） | 🟡 **$800 封顶**，优先级低于上面一条 |

**`dramashorts.tv` 为什么只值 $800：** 它没公开挂牌，得主动联系；`.tv` 续费约 $26–40/年（是 .com 的十倍）；而 `dramashortstv.com` 免费可注册、字符串几乎等价。**它是"更好看一点"，不是"更有用"。**

> 💡 如果真拿下 `dramashorts.tv`，顺手把 `dramashortstv.com` 也注上做跳转，堵住 .com 输入流失。

**为什么设 $2,000 上限：** 它没有内容历史（干净），但有 147 个引荐域名、无一 AS>30，锚文本里是「dofollow backlinks online cheap」这类卖链广告。
**这不是一票否决**——传个 disavow 文件就能处理，Google 现在对垃圾链接以忽略为主。**但它是压价理由，我们不该按干净域名的价买。**

⚠️ **无标价 = 周期不可控。这条必须和下面的注册并行推进，不能等。**

## 三、明确排除（不要买、不要注册）

| 域名 | 原因 |
|---|---|
| `dramashorts.co` / `.net` / `.me` | 🔴 **`.com` 正在公开挂牌**。做起来等于替别人的资产涨价，且任何人都能买走 `.com` 蹭我们品牌，用户默认敲 `.com` 流量直接漏走 |
| `dramashorts.stream` | `.stream` 与盗版站强关联，**而这个业务本身有版权敏感度**（同名 YouTube 频道挂着合规声明） |
| `dramashortsapp.com` | 我们没有 App |
| `dramashortz.com` | `z` 替 `s` 是垃圾站典型拼法 |
| `dramaticshorts.com` | 语义偏了，欧美听成电影节剧情短片，不是竖屏微短剧 |
| `dramastream.com`（2008）等老域名 | 历史不可控 + Google 2024-03「过期域名滥用」政策风险 |

## 四、⚠️ 这个决定的权重比看起来低

按 8/15 那份评估：**新站的搜索流量不会来自那 27,515 个剧集页**——内容与旧站完全相同，我们是副本，Google 只索引其中一个。域名选得再好也不改变这一点。

真正的胜负手仍是两条：**视频端能否起量**（同名 YouTube 频道 7 个月 1.09 万订阅，网站月访只有 600–1,000）、**品类词 blog 能否进前十**。

**建议这一步不要花超过一天。**

---

## 五、需要 Lynne 拍板的一件事

**选欧美 = 主动放弃这个品类约 80% 的全球搜索量**（全球 37.5K 的大头在南亚东南亚），换欧美更强的变现能力。

这个取舍大概率是对的，**但得是有意识的决定，不能是默认。**
