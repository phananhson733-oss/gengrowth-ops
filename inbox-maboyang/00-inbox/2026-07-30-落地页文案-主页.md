### 主页的SEO职责：不是不做，是做的事不一样

初稿这里写的是"主页不为排名服务，密度低反而更好"——**这个说法是错的，纠正如下**。

**"写得轻"这个结论对，但理由是转化不是SEO**：主页是被扫的不是被读的，访客几秒内决定去留，长文案直接降低转化。**视觉密度**要低。这跟工具页的做法一致，只是工具页靠折叠区块实现（内容留在DOM里给Google，不占首屏），主页靠本来就写得少。

**但"不为排名服务"是错的**。主页对SEO的作用跟工具页不同，不等于没有：

| 职责 | 说明 |
|---|---|
| **全站权重的入口和分发中枢** | 外链绝大多数落在首页。DR=0的站最先积累权重的就是首页，再通过内链分给五个工具页。首页薄，分发出去的也薄 |
| **域名级话题定义** | Google靠首页判断整个站是做什么的。首页含糊，工具页想排名会更吃力——而工具页排名正是我们最在乎的事 |
| **它确实有一个能打的主词** | `seo tools for small business` 350/KD6/**Parent＝自身**，实测可打。放在区块5的H2，不进H1 |
| **AI答案引擎的实体锚点** | GEO策略里，Organization schema + 一句可引用的实体定义句，决定了AI回答里"GenGrowth是什么"。缺了它我们就是一个没有实体的名字 |

**所以正确的表述是**：主页不追头部关键词、不堆篇幅，但它承担域名级的话题信号和实体定义，这两件事做砸了会拖累全部五个工具页。

**为什么H1不放主词**：`seo tools for small business` 是个品类词，放进H1会让主页读起来像"又一个SEO工具站"——而这正是执行计划3.0节判定为结构性红海、必须区隔的定位。H1要承担的是"这不是工具箱，是一套连起来的工作流"这个差异化，主词降到区块5的H2，那里讲工具矩阵，语境天然吻合。

## [区块1] Hero

```
[H1] Stop guessing what to fix next.

[副标题]
GenGrowth turns your search data into a step-by-step plan — one connected project,
five free tools, and an answer to "what now" at every stage.

[主CTA] Start free
[副CTA] Explore the tools
[信任行] No credit card needed · Built on diagnostic work we did on our own sites first

[实体定义句 · 紧跟信任行下方，小字]
GenGrowth is a free SEO toolset for small teams that connects diagnosis to action:
audit a site, find what's costing you traffic, and work the fixes through one
project instead of a checklist.
```

> 文案说明：H1直接对上"缺乏系统知识、不知道下一步做什么"这个核心痛点。副标题里"an answer to 'what now' at every stage"是刻意的——竞品给的是数据和清单，我们给的是下一步，这是全站叙事的支点。

> **实体定义句是为AI答案引擎写的，不是为人写的**。H1和副标题对人有效，但AI引擎从"Stop guessing what to fix next"里提取不出"这是什么"。当有人问ChatGPT或Perplexity"GenGrowth是什么"时，它们需要一句结构完整、可直接引用的定义——主语是品牌名、谓语说清品类、后面接差异化。这句和Organization schema一起构成实体锚点。视觉上可以做小、做淡，但**必须是页面上的真实文本，不能只放进schema**——AI引擎主要读正文。

## Schema（3种）

| Schema | 用途 | 关键字段 |
|---|---|---|
| **Organization** | 品牌实体声明，GEO基础 | name / url / logo / sameAs |
| **WebSite** | 站点级声明，支持站内搜索框富摘要 | name / url / potentialAction: SearchAction |
| **BreadcrumbList** | 导航层级 | Home |

> 主页不上FAQPage和SoftwareApplication——前者主页没有FAQ区块，后者应挂在各工具页。**Organization schema是GEO策略的基础设施**：AI答案引擎靠它确认"GenGrowth是什么"，缺了它我们在AI回答里就是一个没有实体的名字。

## 与工具页的分工核对

| | 主页 | 工具页 |
|---|---|---|
| SEO职责 | **域名级话题定义 + 实体锚点 + 权重分发**，外加一个可打主词(350/KD6) | 各自主词，页面本身是SEO战场 |
| 篇幅 | ~820词 | 1,000-1,500词 |
| 密度控制手段 | 本来就写得少 | 折叠深度区块（内容留DOM给Google，不占首屏） |
| 方法论/限制区块 | 无 | 有（默认折叠） |
| 深度 | 讲清楚是什么，快速分流 | 讲透一件事 |
| 转化终点 | 注册 / 分流到工具 | 注册 / 继续下一步 |

**两者共享同一条原则**：视觉密度要低，但不是靠删内容达成——工具页靠折叠，主页靠本来就该短。**"写得少"和"不需要SEO"是两件事，不要混。**
