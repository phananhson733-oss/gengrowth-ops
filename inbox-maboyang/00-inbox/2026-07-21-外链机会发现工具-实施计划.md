# 外链机会发现工具 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 交付一个本地运行的 HTML 工具：以关键词或竞品域名发现广义外链机会，排除黄赌毒等高风险页面，将原始列表保存到本地 CSV，并按状态同步到 Google Sheet。

**Architecture:** 浏览器仅负责输入、展示任务结果和触发同步；本地 Node.js 服务持有 API 密钥，调用 SerpApi 获取关键词 SERP、调用 Ahrefs 获取竞品反链及 DR。所有结果先经过 URL 归一、去重、内容安全硬过滤和机会类型判断，写入本地 CSV；可选的 Apps Script Web App 将合格、排除和任务记录同步至同一个 Google 工作簿。

**Tech Stack:** Node.js 18+ 内置 HTTP/Fetch/Test、原生 HTML/CSS/JavaScript、CSV 文件、Google Apps Script。

---

## Scope and non-goals

- 包含：关键词发现、竞品反链发现、Ahrefs DR、可配置黄赌毒词库、机会类型判断、本地 CSV、Google Sheet 同步。
- 不包含：自动评论、autoComment 回写、自动邮件、Web 表单填写、Playwright、定期重验证、数据库、AI 语义分类。
- 一行代表一个来源页面；同一页面多次发现时合并来源，不重复创建机会。
- `qualified` 表示自动规则通过，不能承诺一定能成功获得链接；人工可在 Google Sheet 中再标为 `approved`。
