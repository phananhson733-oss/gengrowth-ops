## 二、迁移的当前状态（供参考，不需要动作）

**配置六项在 8/10 已全部验证正确，8/13 复测仍然正确**：308 直达无跳转链、robots 未禁抓、主 sitemap 无旧 URL、站内无旧链接、canonical 自指、hreflang 无残留。

**旧 URL 仍在索引里，是迁移的正常中间态**，原因是抓取路径曾被清空（sitemap 和内链都不指向旧 URL），Googlebot 只能靠自己的历史排期轮回来。**B1 正是为了解决这个**。

> **口径提醒**：近 3 个月窗口下 `/en/` 曝光占比 86.1%，与此前记录的 68.9%（一周窗口）**分母不同，不构成"恶化"**。要看趋势必须取相同窗口重新导。

### ❌ 四件千万不要做的（B1 上线后依然适用）

1. 🔴 **不要在 robots.txt 里 `Disallow: /en/`** —— 一旦禁抓，Googlebot 永远看不到 308，旧 URL 会**永久卡在索引里**，比现在更糟
2. **不要把旧 URL 加进主 sitemap** —— 那是永久声明它有效。临时那份是独立的，这个已经做对了
3. **不要给旧 URL 加 noindex** —— 与跳转是矛盾指令，且阻断权重传递
4. **不要因为"新旧 URL 同时有曝光"就去改 canonical** —— 迁移中的正常现象

## 三、🔴 B7 · 工具结果页反馈入口（本周最高优先级）

### 为什么现在是最高优先级

站上三个工具（`/tools/low-competition-keywords`、`/tools/seo-quick-wins`、`/tools/traffic-drop-diagnosis`）**跑完结果后没有任何反馈入口**。

**自然进来的用户用完就走，我们不知道结果对他有没有用，也拿不到任何联系方式。** 推广渠道就算通了也接不住。

### 规格（可直接照做）

**位置**：三个工具的**结果页底部**，结果渲染完成后出现。不要放在运行前。

**结构**：

1. **一句提问 + 二选一按钮**（必答，一点就提交）
   - 提问：`Do you know what to do next?`
   - 选项 A：`Yes, it's clear`
   - 选项 B：`Not really`

2. **选填文本框**（点完二选一后展开，不强制）
   - placeholder：`What would have made this more useful?`

3. **选填邮箱**（同上）
   - placeholder：`Email (optional) — if you want a reply`
   - **不做任何强制，不挡结果，不弹窗**

**GA4 事件**：`feedback_submitted`

| 参数 | 取值 |
|---|---|
| `tool_name` | `low-competition-keywords` / `seo-quick-wins` / `traffic-drop-diagnosis` |
| `answer` | `clear` / `unclear` |
| `has_text` | `true` / `false` |
| `has_email` | `true` / `false` |

**存储**：三个工具写进**同一张表**，字段包含上述四项 + 文本 + 邮箱 + 时间戳，**要能导出 CSV**。

> **设计意图**：二选一那一步的答案本身就是核心指标——**「不太确定」的比例，直接就是产品是否解决了"不知道下一步做什么"这个痛点的度量。** 文本和邮箱是加分项，拿不到也不影响这个指标成立。
