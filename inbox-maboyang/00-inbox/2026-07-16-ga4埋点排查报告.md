## 二、Consent Mode 工作机制

**初次访问流程（无痕窗口）：**

```
页面加载
→ Z0() 运行：gtag("consent","default",{analytics_storage:"denied", wait_for_update:500})
→ 用户交互（任意操作）→ 懒加载 GA4 脚本（K0()）
→ 用户点击 Accept All → Dc({analytics:true}) → O0("granted") → localStorage 写入 "granted"

若 GA4 脚本在 Accept All 之后才初始化：
→ Z0() 再次读取 localStorage → Nc() 返回 "granted"
→ gtag("consent","default",{analytics_storage:"granted"})  ✅ 直接以 granted 状态启动
```

**结论：** 因为 GA4 是懒加载，用户 Accept All 往往早于 GA4 初始化，实际上 consent 状态是正确的。

## 三、事件架构

AstrologyWiki 有两套 CTA 事件，**事件名不同，不可混淆：**

### 3.1 `tool_click` — 文章页 CTA

| 属性 | 值 |
|---|---|
| 触发位置 | Blog 文章页、Wiki 页内嵌 CTA |
| 组件 | `my`（BirthChartCTA） |
| 变体 | nav / sticky / lead / bottom |
| module 映射 | nav→module_a, sticky→module_b, lead→module_c, bottom→article_bottom |
| 参数 | `cta_module`, `cta_variant`, `page_location`, `page_path`, `tool_target` |
| 代码路径 | `onClick:y → we("tool_click", {...})` |

### 3.2 `chart_funnel` — 工具页结果 CTA

| 属性 | 值 |
|---|---|
| 触发位置 | 工具页计算出结果后显示的 "See your full birth chart →" |
| 组件 | `ToolFunnelCTA`（从 `ToolFunnelCTA-DBP8aSTY.js` 加载） |
| 参数 | `tool`, `sign`, `step`（默认 `full_chart_cta_click`）, `placement`（`tool_result`） |
| 代码路径 | `onClick:u → tv({...}) → we("chart_funnel", sg({...}))` |
| 触发条件 | **仅在用户已输入生日并点击 Calculate 后**，结果区域才渲染此 CTA |

### 3.3 `cta_clicked` — 旧事件（仍在触发）

GA4 后台（7/13–7/16）显示 `cta_clicked` 有 9 次触发，来源组件待彪哥确认。新实现的 `tool_click` 目前 0 次（流量太低，非 bug）。
