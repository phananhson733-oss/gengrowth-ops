# SEO数据工具分层使用规范

> 核心结论：Semrush、GSC/GA4、Ahrefs三个工具测量的是不同层面的事实，不互相替代，不互相验证，各司其职。

---

## 一、为什么不同工具的数据不同

在使用多个工具时，同一个网站的"流量"或"关键词数"在不同平台经常相差数倍。这不是哪个工具出错了，而是它们从根本上测量的东西就不同。

### 1.1 测量对象不同

这是最常被忽略的差异来源。

| 工具 | 测量的是什么 | 方法 |
|---|---|---|
| Ahrefs / Semrush | 有机搜索流量的**估算值** | 关键词排名 × 搜索量 × CTR模型推算 |
| GSC | 有机搜索流量的**真实值** | Google直接记录的点击数 |
| GA4 | 网站实际被访问的**真实次数** | 用户行为埋点采集 |
| SimilarWeb | 全渠道总访问的**近似值** | ISP数据 + 浏览器插件面板 |

Ahrefs和Semrush的流量数字是模型推算，不是实测。所以它们可以与GSC/GA4的真实数字同时存在、方向不同，并不矛盾。

### 1.2 爬虫覆盖范围不同

Ahrefs和Semrush各自维护独立爬虫，抓取覆盖的网页不同：

- Ahrefs对英语和拉丁字母网站覆盖更全，更新频率更高
- Semrush对部分非英语链接（阿语、马来语等地区性链接）收录更多

这导致同一个网站的引荐域名数量在两个工具里可能相差数倍。

### 1.3 关键词数据库来源不同

- Semrush的搜索量数据部分来自Google Ads历史出价数据
- Ahrefs使用点击流数据（真实用户点击行为）校准搜索量，会扣除"有人搜但没人点"的部分

结果：同一个词的月搜索量在两个工具里可能差2-3倍，这是数据来源口径不同造成的，不代表哪个错了。

### 1.4 权威分数的计算公式不同

| 指标 | 计算逻辑 | 影响因素 |
|---|---|---|
| Ahrefs DR | 纯外链指标：dofollow引荐域名的数量和质量 | 只看链接 |
| Semrush Authority Score | 综合指标：外链 + 有机流量信号 + 垃圾链接惩罚 | 链接 + 流量 + 质量 |

两者是完全不同的东西，不能互相换算。一个站可以DR高但Authority Score低（外链多但流量差），也可以反过来。

## 二、三层数据架构

基于以上差异，正确的做法不是选一个工具替代其他，而是按功能分层使用。

```
┌─────────────────────────────────────────────┐
│  第一层：市场竞争层（Semrush）                │
│  · AI搜索曝光                               │
│  · Authority Score趋势                      │
│  · 竞品关键词对比                            │
│  用途：客户月报，回答"我们在市场上处于什么位置"│
└─────────────────────────────────────────────┘
           ↓
┌─────────────────────────────────────────────┐
│  第二层：真实表现层（GSC + GA4）              │
│  · GSC：Google实给的曝光数和点击数            │
│  · GA4：用户进站后的行为 + 转化事件           │
│  用途：效果验证，回答"我们实际带来了什么"      │
└─────────────────────────────────────────────┘
           ↓
┌─────────────────────────────────────────────┐
│  第三层：执行工具层（Ahrefs）                 │
│  · 关键词研究和KD判断                        │
│  · 竞品内容缺口分析                          │
│  · 外链质量筛选（DR + 均分DR）               │
│  用途：内部执行，回答"我们具体做什么"          │
└─────────────────────────────────────────────┘
```

### 各工具职责一览

| 场景 | 工具 | 原因 |
|---|---|---|
| 客户月报：AI曝光 / Authority Score | Semrush | 客户指定指标，且只有Semrush有AI可见度 |
| 客户月报：关键词增长 / 流量趋势 | Semrush + GSC双口径 | Semrush看竞争位置，GSC看真实点击 |
| 效果验证：SEO实际带来了多少流量 | GSC | 唯一来自Google的真实数据，不可替代 |
| 效果验证：流量有没有转化为询盘 | GA4 | 追踪WhatsApp点击、表单提交等转化事件 |
| 关键词研究 / 选题 | Ahrefs | KD计算逻辑更直接，CTR校准更贴近GSC |
| 外链建设质控 | Ahrefs | DR是行业标准，均分DR筛选逻辑建在DR上 |
| 竞品内容分析 | Ahrefs优先 | Content Explorer在内容层分析更强 |

## 三、为什么GSC是效果验证的核心

Ahrefs和Semrush的流量数字都是估算值，有一个根本风险：**Semrush的模型可以在实际流量不变时数字浮动，也可以在实际流量增长时显示下降**。

如果我们用Semrush估算流量向客户汇报，存在两种对我们都不利的情况：
- Semrush涨了但GSC没涨 → 客户会质疑我们的数字
- GSC涨了但Semrush没涨 → 我们做了真实成果却无法证明

GSC是Google直接给出的点击数，没有任何估算误差。当我们需要向客户证明SEO工作带来了真实流量增长时，GSC是唯一无法被质疑的来源。

### 3.1 只用Semrush单源考核的系统性风险

Semrush数字的波动来自两个来源，均与实际SEO表现无关：

**风险一：数据库更新波动**

Semrush定期更新关键词爬取范围。某次更新可能让一个站的词量从855跳到600或1,100，与我们是否做了工作无关。以BRDECO为例，Semrush显示brdecogroup.com有855个关键词，Ahrefs显示227个——差距达4倍，说明两个数据库的收录口径本就不同。一旦Semrush某次更新调整了这个站的覆盖，指标可能大幅波动，让三个月的工作看起来白做了。

**风险二：低流量站点的估算误差**

Semrush对月流量低于5,000次的站点，估算模型的误差范围本身就很大，信噪比低。BRDECO目前所有站点均处于这个区间，数字本身就不稳定。

**结论：验收若只认Semrush单源，我们暴露在其数据库更新的系统性波动下。**

### 3.2 双源考核原则

| 考核场景 | 主源 | 辅助源 | 说明 |
|---|---|---|---|
| 有机流量是否增长 | **GSC** | Semrush | GSC是Google直接数据，不可被质疑 |
| AI曝光是否增长 | **Semrush** | 无替代 | GSC没有AI可见度指标 |
| 竞争位置是否改善 | **Semrush** | Ahrefs | 需看竞品对比，只有第三方工具能看 |
| 询盘是否增长 | **GA4 + WhatsApp** | GSC | 最终业务结果，不依赖任何SEO估算工具 |

**当Semrush与GSC出现矛盾时，GSC数据优先。** Semrush的单次波动不作为考核依据，需连续观察3个月趋势方向，排除数据库更新噪音后再得出结论。

建议向客户这样表述：

> "我们在Semrush维度之外，同时用GSC数据作为实际点击的基准验证。Semrush指标反映市场竞争力和AI曝光，GSC反映Google真实给我们带来了多少访客。当两组数据出现矛盾时，以GSC为准；Semrush的单次波动不作为阶段性考核依据，需看连续三个月的趋势方向。"

## 四、GA4：连接流量与询盘的关键节点

对B2B工业品客户（如BRDECO），转化不在网站上完成——用户点击WhatsApp按钮即离开网站。这使得GA4成为整个数据链条中不可缺少的一环。

**完整的B2B转化验证链：**

```
Semrush
  → 市场竞争力和AI曝光是否在增长
      ↓
GSC
  → Google实际给我们带来多少搜索曝光和点击
      ↓
GA4
  → 点进来的人有多少产生了WhatsApp点击 / 表单提交
      ↓
WhatsApp Business / 询盘表单
  → 实际收到多少条询盘
      ↓
客户CRM（客户内部管理）
  → 询盘中有多少转化成订单
```

没有GA4，我们能证明流量涨了，但无法证明询盘涨了。GA4是把搜索流量和业务结果连接起来的节点。

**GA4需要配置的事件（B2B场景）：**
- WhatsApp按钮点击（`click_to_whatsapp`）
- 询盘表单提交（`form_submit`）
- 产品页停留时长（`engagement_time`）
- 规格表PDF下载（`file_download`）

## 五、关于Ahrefs vs Semrush关键词数据的准确说明

"Ahrefs关键词数据更准"是一个过于简化的结论，准确的表述是：

**Ahrefs在以下方面更可靠：**
- 搜索量估算：使用点击流数据校准，扣除了无点击搜索，更贴近GSC实际点击量
- KD计算：基于前10名页面的外链数量，逻辑直接，可操作性强
- 英语市场的链接数据库：覆盖更全，更新更频繁

**Semrush不弱的地方：**
- 关键词数据库广度在某些市场不输Ahrefs
- 非英语市场（阿语、马来语）的关键词收录可能更多
- AI可见度是Semrush独有指标

**实际结论：** Ahrefs在英语市场的关键词研究和外链执行上更可靠；Semrush在多语言市场的关键词发现和竞争情报上各有优势。我们现有SOP建立在Ahrefs指标体系上（KD阈值、DR筛选标准），如果客户只有Semrush账号，需要重新校准这些阈值。

## 六、BRDECO项目前置条件

在正式开始SEO执行之前，以下数据基建必须到位，否则后续无法完成效果验证：

| 前置条件 | 负责方 | 说明 |
|---|---|---|
| 所有站点完成GSC所有权验证 | BRDECO配合 | 五个站点各自验证 |
| GA4安装并正确触发 | BRDECO技术团队 | 覆盖所有五个站点 |
| WhatsApp点击配置为GA4事件 | BRDECO技术团队 | B2B最关键的转化事件 |
| 询盘表单提交配置为GA4转化目标 | BRDECO技术团队 | 另一个转化路径 |
| GSC与GA4完成关联 | BRDECO配合 | 在GA4后台操作 |
| Semrush当前数据截图存档（基线）| GenGrowth | 建立0号基线，后续月报的比较基准 |

**如果GA4目前未安装或配置不完整，第一个月的工作优先级是数据基建，而非内容生产。** 没有基线数据，后续所有月报都缺少"转化"这一层的验证。
