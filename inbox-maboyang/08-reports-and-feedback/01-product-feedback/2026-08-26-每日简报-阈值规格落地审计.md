## 三、常规任务专项

规格列了八类。**实际只落地 1 类，且口径与规格不符。**

### 逐项对照

| # | 规格常规任务 | 阈值 | 状态 |
|---|---|---|---|
| 1 | 高曝光零点击 | 30 天曝光 ≥200 且点击 = 0 | ❌ |
| 2 | 上移机会 | **位次 4–10** 且有真实曝光 | ⚠️ 口径不符，见下 |

### 三个问题

| 序 | 问题 |
|---|---|
| 🔴 A | **口径不符**：规格取 **4–10 位**，工具取「接近 1–10 区间」，把 **14.5 位**也算了进来。规格取 4–10 是因为价值集中在头部——`11→10` 最多 +1.6 个百分点，`2→1` 是 +21.1。14.5 位的词不该进常规清单 |
| 🔴 B | **无状态 / 进度**：规格明写「每条带进度或时距，不要只显示待办」（如「本周已发 3 / 7 篇」「上次调研 12 天前」）。两张卡都是纯待办，无任何状态 |
| 🟠 C | **文案完全相同**：两张卡逐字一致，没有针对具体词的信息。第二张卡的排名比第一张低 3.7 位，却给同一句话 |

### 需要你决策

第 3–8 类（新页内链 / 新页收录 / 写前查重 / 内容产出 / 外链 / 竞品调研）**不是 GSC 数据**，需站内爬取、CMS、外链工具。

- 若纳入本工具 → 需接这些数据源
- 若不纳入 → **从规格中移出**，不要挂在这个工具下

第 1、2 类是纯 GSC 数据，**本工具内即可实现，应优先补上。**

## 四、待改进

| 序 | 问题 | 处理 |
|---|---|---|
| 🔴 1 | **A 类缺失**：无 query 级排名下降判据 | 落地规格第二节公式 `预估月点击损失 = 该query月曝光 × (CTR[原位次] − CTR[现位次]) / 100`，阈值 ≥20 次；CTR 曲线做成可配置常量 |
| 🔴 2 | **D 类缺失**：同类相食未实现 | 同一 query 下 ≥2 个 page 有曝光且都未进前十 → 留一个，其余改意图或下架 |
| 🔴 3 | **「高曝光零点击」常规任务缺失** | 本次实测漏了一个明显信号：`manual seo service` 曝光 138 · 点击 0 · 排名 9.6，只在「进入 1–10 区间」下被提及。这条判据（曝光≥阈值且点击=0）**不依赖品牌词拆分**，可独立于 CTR 路径运行 |
| 🟠 4 | **E 类口径与规格不符** | 规格 ≤6，实现 ≤10。本次三条查询词记录中两条是 10.8 / 14.5，标为「接近 1–10 区间」——边界值信息量低。建议收紧到 ≤6，或对 8–10 区间降级为观察不出动作 |
| 🔴 5 | **常规任务八类只落地 1 类，且口径不符** | 见第三节专项 |
| 🟠 6 | **站点级与页面级动作并列，无先后** | 本次同时出现「诊断全站点击下降」（点击 24→14）与两条「页面曝光几乎消失」，均指向 Traffic Drop Diagnosis。规格定的是 C 排在 A 前（可能为技术故障）；现在用户不知道先看哪个 |
| 🟡 7 | **文案缺字** | 「常规 · 查询词 2 项 · 页面 **不可得** 项」——数字位缺失，读起来像 bug |
| 🟡 8 | **GSC 曝光 bug 未来会踩到** | 当前 3 个月窗口起点约 2026-05-26，晚于修复日 2026-04-27，暂时安全。**若增加同比或更长窗口，需加提示**：曝光自 2025-05-13 起被高报，CTR 与均位受连带影响 |
