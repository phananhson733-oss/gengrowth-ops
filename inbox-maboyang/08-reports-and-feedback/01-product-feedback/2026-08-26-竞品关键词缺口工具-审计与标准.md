# 竞品关键词缺口工具 · 审计与标准

## 一、难度判据

**取消 KD 硬阈值 60。不做 DR→KD 对照表。**

### 主判据 · RD 对比

```
N = 进前十所需引荐域数   ← Ahrefs 逐词给出（KD 分数下方直接显示）
R = 用户站引荐域数       ← 取 DR 时一并获取

R ≥ N        →  可做
R ≥ N × 0.5  →  边缘，标注
R < N × 0.5  →  延期
```

### 副判据 · 前十结构三问

```
前十有注册不满 18 个月的域名   →  是 / 否
前十有月访低于阈值的站         →  是 / 否
前十有 UGC 位（Reddit 等）    →  是 / 否
─────────────────────────
全「否」  →  不进缺口列表
≥1「是」  →  可做
```

月访阈值（提案，需回测）：

| 用户站强度 | 前十最弱站月访 |
|---|---|
| 新站 / 极弱 | < 5,000 |
| 中等 | < 50,000 |
| 较强 | < 100,000 |

### 两者如何合并

| 主判据 | 副判据 | 最终 |
|---|---|---|
| 可做 | 任意 | **可做** |
| 边缘 | ≥1「是」 | **可做** |
| 边缘 | 全「否」 | **延期** |
| 延期 | ≥1「是」 | **边缘**，标注「外链不足但盘面有缺口」 |
| 延期 | 全「否」 | **不进缺口列表** |

### 需补的字段

| 字段 | 说明 |
|---|---|
| 前十最弱站月访 | 三问第二问 |
| 前十最年轻域名注册年份 | 三问第一问 |
| 用户站引荐域数 R | 主判据 |
| 逐词所需引荐域数 N | 主判据，Ahrefs 提供 |
| **页面类型折扣** | 普通内页 45% · 专营着陆页 65% · 首页 100% |
| **域名迁移标记** | 年轻域名 + 高 DR + 搜索流量占比低 → 标为「DR 由旧域 301 传递」，不计入「前十有新域名」 |
| 竞对页面流量 ÷ 该词月搜索量 | 区分竞对是靠这个词吃饭还是顺带 |

KD 保留展示，标为参考值，不作判据。

## 二、GSC 排名可信度

| 28 天曝光 | 处理 |
|---|---|
| ≥ 30 | 正常显示位置 |
| 10–29 | 显示并标「样本少」 |
| < 10 | **不显示位置**，改显示「已有曝光，排名待确认」 |
| 1–2 | 视同未排名，位置字段留空 |

附加条件：**出现天数 ≥ 3 天**，否则降一档处理。

### 同比功能需加提示

Google 官方：GSC 曝光自 **2025-05-13** 起因记录错误被高报，点击不受影响。CTR 与平均排名均由曝光推导，受波及。

**跨 2026-04-27 的同比不可用。**
