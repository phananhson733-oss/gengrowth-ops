## 五、⚠️ 查基线时发现的四个问题（两个是硬伤）

### 5.1 🔴 硬伤 · www 版本没有 301，正在与主域重复竞争

```
https://www.gengrowth.ai/   →  HTTP 200（不重定向）
https://gengrowth.ai/       →  HTTP 200
```

**两个版本都返回 200，各自被索引、各自在排名。**

GSC 数据证实：

| 版本 | 点击 | 曝光 | 排名 |
|---|---:|---:|---:|
| `https://gengrowth.ai/` | 9 | 135 | 12.33 |
| `https://www.gengrowth.ai/` | 3 | 129 | 13.50 |

**同一个首页被拆成两条，点击和权重都在分流。** 全站有 16 个 www 页面在独立产生曝光。

www 版本的 canonical 确实指向了非 www（`<link rel="canonical" href="https://gengrowth.ai"/>`），但 **canonical 只是建议，301 才是指令**。Google 目前显然没有完全采纳。

**修法**：在 DNS / Vercel / Cloudflare 层配置 `www.gengrowth.ai → gengrowth.ai` 的 301。**成本极低，应立即做。**

### 5.2 🔴 硬伤 · glossary 整个板块变成软 404

```
/en/glossary/brand-visibility-score  →  308  →  /glossary/brand-visibility-score  →  最终落到 /blog
/glossary/brand-visibility-score     →  最终落到 /blog
/glossary                            →  最终落到 /blog
```

**17 个 glossary 页面、437 次曝光，全部落到一个内容不相关的博客列表页。**

这是**软 404**：返回 200 但内容与 URL 承诺无关。Google 识别后会去索引这批页面，437 次曝光会消失。

其中 `brand-visibility-score` 单页就有 **237 次曝光**（排名 50.03）。

**要决定的**：
- 如果 glossary 板块要保留 → 恢复页面，加进 sitemap
- 如果不保留 → **改成 410**（或 404），别用重定向到不相关页面

**现在这个状态是最差的一种**——既拿不到流量，又给 Google 发送"这个站有软 404"的质量信号。

### 5.3 🟡 79 页 Google 不给索引

68 页「已发现 - 尚未编入索引」+ 11 页「已抓取 - 尚未编入索引」。

这是 DR=0 的直接表现，也说明**抓取预算紧张**。改版时应该：

- 清掉不需要索引的 URL，把预算让给要排名的页面
- 别再往 sitemap 里塞低价值页面

### 5.4 🟡 有排名的内容，全部是旧定位内容 —— 与 90 天计划 1.2 冲突

曝光前十的页面：

```
best-cheap-seo-tools            857
google-july-2026-update         798   ← 唯一真正带量的
best-white-label-seo-tool       717
why-use-a-backlink-monitor-tool 632
free-seo-company                446
all-in-one-seo                  349
saas-seo-platform               329
9-best-marketing-attribution-tools  329
glossary/brand-visibility-score 323
free-seo-consultation           284
```

**除了 `google-july-2026-update`，其余全是与六个工具无关的旧定位内容**（white label、backlink monitor、attribution、seo company）。

**这与 90 天计划 1.2「清理旧定位内容」直接冲突：这批内容是我们目前唯一的索引和曝光资产。**

**我的判断：仍然应该清理，理由是这些曝光没有价值。**

| 为什么可以清 | 数据 |
|---|---|
| 不带流量 | 非品牌词 CTR **0.14%**，5,811 曝光换 8 次点击 |
| 排名太靠后 | 主力词在第 2–9 页，短期不可能进前十 |
| 稀释站点主题 | DR=0 阶段话题聚焦是少数几个能完全控制的变量 |
| 占用抓取预算 | 79 页已发现/已抓取但未索引，预算已经不够用 |

**但两个例外必须保留**：

1. **`google-july-2026-update`** —— 全站 56% 的点击来自这一篇，排名 7.19
2. **`best-cheap-seo-tools`** —— 857 曝光是全站最高，而 `cheap seo tools` 是唯一带来点击的非品牌词。**这个词与 P0-5「关键词机会地图」的定位有关联**，可以改造而不是删除

> 💡 **另一个观察**：`google-july-2026-update` 是全站唯一跑通的内容类型——**Google 算法更新解读**。它排到 7.19 并带来 56% 的点击，说明这类时效话题在 DR=0 阶段是能打的。**代价是会过期**，需要持续产出才能维持。这条值得单独评估要不要做成常规栏目。

## 六、❌ 缺失：外链数据

90 天计划 1.1 要求记录「RD 数、DR、哪些页面被链」。

**「下载」文件夹里的 `Links for https___gengrowth.ai_.csv` 不是反链报告**，它是首页的**出链清单**（25 条，其中 23 条内链、2 条外链指向 x.com 和 linkedin.com）。

**需要补**：Ahrefs 或 GSC「链接 → 外部链接」报告，记录：

- 引荐域名数（RD）
- 域名评级（DR）
- 哪些页面获得了外链
- 锚文本分布

> 📌 **顺带发现**：首页出链里有 `https://x.com/gengrowth` 和 `https://linkedin.com/company/gengrowth`。
>
> **这与推广方案里「GenGrowth 社媒从零开始」的前提不符** —— 至少 X 和 LinkedIn 的账号是存在的。需要确认这两个号的实际运营状态，推广方案的社媒现状那一节要跟着改。
